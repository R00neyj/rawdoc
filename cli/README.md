# rawdoc CLI

[rawdoc](https://rawdoc.app/) 문서를 터미널·스크립트·AI 도구에서 읽고 고치는 명령줄 도구입니다.

## 설치 없이 쓰기

```
npx -y rawdoc ls
```

`-y` 는 처음 실행할 때 나오는 설치 확인을 건너뜁니다. AI 도구(Claude Code 등)에서 비대화형으로 부를 때는 이 형태를 씁니다.

## 전역 설치

```
npm i -g rawdoc
rawdoc ls
```

## 로그인

```
rawdoc login
```

브라우저가 열리고 rawdoc 계정으로 승인하면 토큰이 이 컴퓨터에 저장됩니다(`%APPDATA%\md-editor\credentials.json` 또는 `~/.config/md-editor/credentials.json`).

원격 셸(SSH·컨테이너)처럼 브라우저가 이 기계의 `127.0.0.1` 에 닿지 않는 환경에서는 웹의 계정 메뉴 → API 토큰에서 만든 토큰을 표준 입력으로 넘깁니다:

```
rawdoc login --with-token < token.txt
```

## 환경 변수

| 이름 | 뜻 |
| --- | --- |
| `RAWDOC_TOKEN` | 저장된 토큰 대신 쓸 API 토큰. CI·AI 도구용이며 저장하지 않습니다 |
| `RAWDOC_SERVER` | 기본 서버(`https://rawdoc.app`) 대신 쓸 주소. `http://localhost:8790` 처럼 로컬 서버만 `http` 를 허용합니다 |

## 명령

| 명령 | 하는 일 |
| --- | --- |
| `login` | 브라우저로 로그인해 토큰을 저장합니다 |
| `logout` | 이 컴퓨터에 저장한 토큰을 지웁니다(서버 토큰은 남습니다) |
| `whoami` | 로그인한 계정을 보여 줍니다 |
| `ls [--folder <id>]` | 내 문서 목록 |
| `get <id> [-o <파일>]` | 문서 원문을 출력하거나 파일로 받습니다 |
| `new [<파일>\|-] [--title <제목>] [--folder <id>]` | 새 문서를 만듭니다 |
| `put <id> [<파일>\|-] [--title <제목>] (--base-version <n>\|--force)` | 문서를 고칩니다 |
| `folders` | 폴더 목록 |
| `mkdir <이름> [--parent <id>]` | 폴더를 만듭니다 |
| `upload <이미지파일>` | 이미지를 올리고 붙일 마크다운을 출력합니다 |
| `link <id>` | 읽기 전용 링크를 만듭니다 |

모든 명령은 `--server <주소>`, `--json`, `-h/--help` 를 받습니다.

## 종료 코드

| 종료 | 뜻 |
| --- | --- |
| 0 | 성공 |
| 1 | 연결·시간 제한·서버·파일 오류 |
| 2 | 인자 사용법 오류 |
| 3 | 로그인 필요·토큰 무효 |
| 4 | 권한 없음·찾을 수 없음·운영자가 계정 쓰기를 막음 |
| 5 | 문서가 그 사이 바뀜(충돌). 브라우저에서 그 문서를 치는 중일 때도 |
| 6 | 실시간 연결 없이 편집 중인 브라우저가 문서를 잠금 |
| 7 | 용량 초과(문서 하나·이미지 저장 공간·계정의 문서 저장 공간·문서 수) |
| 8 | 요청 한도 초과(잠시 뒤 또는 다음 날 다시) |
| 130 | Ctrl+C |

## 한도에 걸리면

서버는 계정마다 쓰기 횟수와 문서 저장 공간에 한도를 둡니다. 걸리면 명령이 다시 시도하지 않고 바로 끝납니다.

- 종료 코드 8 은 잠시 뒤(분당 한도) 또는 다음 날 오전 9시(한국 시간, 하루 한도)에 풀립니다. 기다릴 시간은 표준 오류 문구에 나오고, `--json` 이면 오류 줄의 `retryAfter`(초)에 있습니다.
- 종료 코드 7 에서 `--json` 오류 줄의 `error` 가 `doc_quota_exceeded` 이면 문서 하나가 큰 것이 아니라 계정 전체가 찬 것입니다. 문서를 지우거나 줄이면 다시 올릴 수 있습니다.

## 원문 보존

`put`·`new` 에 올린 파일은 앱의 가져오기와 같은 해독을 거칩니다 — 섞인 줄바꿈은 CRLF 로 통일되고 BOM 은 제거됩니다(그때 표준 오류에 안내가 뜹니다). `get` 은 문서 원문을 한 글자도 바꾸지 않고 그대로 표준 출력에 씁니다.

**Windows PowerShell 5.1** 에서 `>` 로 표준 출력을 파일에 받으면 UTF-16 으로 바뀌고 한글이 깨집니다. `get -o 파일.md` 를 쓰세요.

## 토큰 폐기

`logout` 은 이 컴퓨터에 저장한 토큰만 지웁니다. 서버에 남은 토큰을 폐기하려면 웹의 계정 메뉴 → API 토큰에서 폐기하세요.
