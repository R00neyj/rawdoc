# 터미널에서 문서 읽고 쓰기

브라우저를 열지 않고 문서를 다루고 싶을 때가 있습니다. 로컬에서 쓴 `.md` 파일을 올리거나, 매일 도는 스크립트가 결과를 문서에 남기거나, AI 코딩 도구가 문서를 읽어 가게 할 때입니다. 명령줄 도구 `rawdoc`이 그 일을 합니다.

Node 22 이상이 필요합니다.

## 로그인

설치하지 않고 바로 씁니다.

```
npx -y rawdoc login
```

브라우저가 열리고 승인 화면이 뜹니다. 승인하면 토큰이 이 컴퓨터에 저장되고, 터미널에 로그인한 계정이 찍힙니다. 브라우저가 열리지 않으면 터미널에 찍힌 주소를 **통째로** 복사해 브라우저에 붙여 넣습니다. 주소가 잘리면 `잘못된 로그인 주소`가 뜹니다.

자주 쓴다면 전역으로 설치해 두고 `rawdoc`만 칩니다.

```
npm i -g rawdoc
rawdoc whoami
```

SSH나 컨테이너처럼 브라우저가 그 기계에 닿지 않는 곳에서는, 웹의 계정 메뉴 → API 토큰에서 토큰을 만들어 표준 입력으로 넘깁니다.

```
rawdoc login --with-token < token.txt
```

## 자주 쓰는 명령

| 명령 | 하는 일 |
| --- | --- |
| `rawdoc ls` | 내 문서 목록 |
| `rawdoc get <id> -o 노트.md` | 문서 원문을 파일로 받기 |
| `rawdoc new 노트.md --title 회의록` | 파일로 새 문서 만들기 |
| `rawdoc put <id> 노트.md --base-version <n>` | 문서 고치기 |
| `rawdoc folders` · `rawdoc mkdir <이름>` | 폴더 보기·만들기 |
| `rawdoc upload 그림.png` | 이미지를 올리고 붙일 마크다운 받기 |
| `rawdoc link <id>` | 읽기 전용 링크 만들기 |

모든 명령은 `--json`을 받습니다. 스크립트에서 결과를 다룰 때 씁니다.

## 원문은 그대로

`get`은 문서에 든 글자를 한 글자도 바꾸지 않고 내보냅니다. 앱의 `.md 내보내기`와 같은 원칙입니다.

올릴 때(`new`·`put`)는 앱의 가져오기와 같은 정리를 거칩니다. 섞인 줄바꿈은 하나로 맞추고, 파일 앞의 BOM은 떼어 냅니다. 그때는 표준 오류에 안내가 뜹니다.

Windows PowerShell 5.1에서 `>`로 출력을 파일에 받으면 한글이 깨집니다. `get -o 파일.md`를 쓰세요.

## 덮어쓰기를 막는 장치

`put`에는 `--base-version`으로 **내가 읽은 판 번호**를 함께 넘깁니다. 그 사이 다른 곳에서 문서가 바뀌었으면 덮어쓰지 않고 종료 코드 5로 멈춥니다. 확인하고 덮어쓰려면 `--force`를 씁니다.

브라우저에서 누군가 그 문서를 치는 중이면 종료 코드 5로 멈출 수 있습니다. 다시 받아 고치거나, 치기가 멈춘 뒤 다시 시도합니다. 드물게 실시간 연결이 안 된 브라우저가 문서를 잡고 있으면 종료 코드 6으로 멈춥니다.

## 스크립트·AI 도구에서 쓰기

토큰을 파일에 저장하지 않고 환경 변수로 넘길 수 있습니다.

```
RAWDOC_TOKEN=... npx -y rawdoc ls --json
```

`-y`는 처음 실행할 때 나오는 설치 확인을 건너뜁니다. 대화형 입력을 받을 수 없는 AI 도구에서 부를 때 이 형태를 씁니다.

## 한도

계정마다 쓰기는 1분에 120번·하루 5,000번, 문서는 모두 합쳐 100MB·10,000개까지입니다. 쓰기 한도에 걸리면 종료 코드 8로 멈추고 기다릴 시간을 알려 줍니다. 하루 한도는 한국 시간 오전 9시에 풀립니다. 저장 공간이 차면 종료 코드 7로 멈춥니다. 문서를 지우거나 줄이면 다시 올릴 수 있습니다.

## 로그아웃

`rawdoc logout`은 이 컴퓨터에 저장한 토큰만 지웁니다. 서버에 남은 토큰까지 없애려면 웹의 계정 메뉴 → API 토큰에서 폐기합니다.
