# 옵시디언 볼트와 오가기

이 앱의 문서와 폴더는 옵시디언(Obsidian) 볼트로 내보낼 수 있고, 옵시디언 볼트를 이 앱으로 가져올 수도 있습니다. 한 번 옮기고 끝내도 되고, 옵시디언에서 고친 볼트를 다시 가져와 이 앱의 문서를 새 내용으로 바꿔도 됩니다. 두 쪽을 잇는 단서는 **폴더 경로와 파일 이름** 하나입니다.

콜아웃·`==하이라이트==`·`%%주석%%`·체크박스·문서 맨 위 속성은 오갈 때 손대지 않습니다. 바뀌는 것은 이미지, 일부 위키링크, 파일 이름 셋입니다. 문서 하나를 `.md`로 받거나 다른 도구로 옮기는 이야기는 [한 번 쓴 글을 다른 도구로 옮기기](/guides/markdown-portability)에 있습니다.

## 볼트로 내보내기

설정 `데이터` 탭의 `옵시디언 볼트로 내보내기`는 문서 전부를, 사이드바 폴더 `⋯` 메뉴의 같은 항목은 그 폴더와 하위 폴더를 zip 하나로 받습니다. 로그인해서 쓰면 내 문서만 들어가고 공유받은 문서는 빠지며, 인터넷에 연결되어 있을 때만 내보낼 수 있습니다.

- zip 안에는 사이드바 폴더 구조대로 `.md` 파일이 들어 있고, 이미지는 맨 위 `attachments` 폴더 한 곳에 모입니다
- 문서 제목이 곧 파일 이름입니다. 본문에 제목 줄을 더하지 않습니다
- 옵시디언 링크에서 뜻이 있는 `#` `^` `[` `]`와 파일 이름에 쓸 수 없는 `/` `:` `?` 같은 글자는 `_`로 바뀝니다. `왜?`라는 문서는 `왜_.md`가 됩니다
- 한 폴더에 같은 제목이 둘이면 나중에 만든 문서 이름 뒤에 ` (2)`가 붙습니다
- 전체 내보내기 zip에 있는 목록 파일 `manifest.json`은 넣지 않고, 문서가 하나도 없는 폴더는 만들지 않습니다

## 옵시디언에서 열기

받은 zip을 풀고, 옵시디언에서 그 폴더를 볼트로 엽니다.

- 이미지 자리에는 `![[0123456789abcdef.png|320]]`처럼 옵시디언의 이미지 넣기 문법이 한 줄로 들어갑니다. `|` 뒤 숫자는 이 앱에서 정한 폭입니다. 가운데·오른쪽 정렬과 이미지 설명은 옵시디언에 같은 문법이 없어 빠집니다
- 볼트 안에서 한 문서로 정해지지 않거나 이름이 바뀐 문서를 가리키는 위키링크만 고칩니다. 같은 이름 문서가 볼트에 둘 이상이면 `[[교안/회의록|회의록]]`처럼 폴더 이름을 붙이고, 이름이 바뀐 파일로 가는 링크는 `[[왜_|왜?]]`처럼 바뀐 이름을 가리킵니다. 원래 글자는 `|` 뒤 별칭으로 남깁니다. 표 안 링크에는 별칭을 붙이지 않습니다
- 고친 링크가 있으면 내보낸 뒤 알림 끝에 그 수가 붙습니다
- 볼트 밖 문서를 가리키는 링크(폴더 하나만 내보냈을 때 그 폴더 밖 문서)와 원래 끊긴 링크는 고치지 않습니다

## 볼트를 가져오기

가져오는 길은 셋이고, 모두 같은 `가져오기` 창으로 이어집니다.

- 설정 `데이터` 탭 `폴더 가져오기…`에서 볼트 폴더를 고릅니다
- 탐색기나 Finder에서 볼트 폴더를 앱 창에 끌어 놓습니다. 폴더는 한 번에 하나만 받습니다
- 볼트를 압축한 zip은 같은 탭의 `가져오기…`로 고릅니다. zip 안에 `manifest.json`이 있으면 이 앱의 전체 내보내기로 보고, 없으면 볼트로 봅니다

창에는 새로 만들 문서, 갱신할 문서, 건너뛸 문서, 들일 이미지의 수가 먼저 나옵니다. `넣을 폴더`에서 볼트를 들일 자리를 바꾸면 수가 곧바로 다시 계산됩니다. 처음 값은 볼트 이름과 같은 최상위 폴더가 하나 있으면 그 폴더이고, 없으면 `새 폴더 "{볼트 이름}"`입니다. 볼트 이름은 고른 폴더나 zip의 이름에서 정합니다. 볼트의 폴더 구조는 고른 자리 아래에 깊이 그대로 만들어집니다.

- `.md`·`.markdown` 파일이 문서가 되고, 파일 이름에서 확장자를 뗀 것이 제목입니다. 문서 맨 위 속성의 `title`은 제목으로 쓰지 않습니다
- 이름이 `.`으로 시작하는 폴더와 파일(`.obsidian`·`.trash` 등)은 보지 않습니다
- 문서도 이미지도 아닌 파일(PDF·캔버스 등)은 들이지 않고 창에 개수만 알려 줍니다. 어느 문서도 쓰지 않는 이미지 파일도 들이지 않습니다

## 옵시디언에서 고친 뒤 다시 가져오기

같은 볼트를 다시 가져오면 `넣을 폴더` 아래에서 폴더 경로와 파일 이름이 같은 문서를 찾아 맞춥니다. 볼트에는 이 앱의 문서 번호가 없어서 경로가 유일한 단서입니다. 대소문자는 가리지 않고, 이 앱 문서의 이름은 내보낼 때와 같은 규칙(`왜?` → `왜_`)으로 바꿔서 비교합니다.

| 볼트 쪽 | 이 앱에서 |
| --- | --- |
| 내용이 같은 파일 | 건너뜁니다. 아무것도 바꾸지 않습니다 |
| 내용이 바뀐 파일 | 바뀌기 전 내용을 같은 폴더에 `{제목} (가져오기 전)` 문서로 남기고 새 내용으로 갱신합니다. 문서 주소와 읽기 전용 링크는 그대로입니다 |
| 새로 만든 파일 | 같은 경로에 새 문서를 만듭니다 |
| 이름을 바꾸거나 다른 폴더로 옮긴 파일 | 새 자리에 새 문서가 생기고, 옛 문서는 그대로 남습니다 |
| 지운 파일 | 이 앱의 문서를 지우지 않습니다 |
| 대소문자만 바꾼 이름 | 제목을 볼트 쪽 이름으로 바꾸고 갱신으로 셉니다 |

볼트에 없어 손대지 않은 문서가 있으면 창에 `볼트에 없어 그대로 둔 문서 {N}개`가 뜹니다. `(가져오기 전)` 사본도 볼트에는 없으니 다음 가져오기 때 여기에 들어갑니다. 필요 없어진 사본은 직접 지웁니다.

이 앱에서 내보낸 볼트를 되돌릴 때는 `넣을 폴더`를 확인합니다. 처음 값이 원래 넣어 두었던 폴더가 아니면 목록에서 그 폴더를 고릅니다. 전체를 내보낸 볼트는 처음 값이 `새 폴더 "2026-09-27"`처럼 날짜 이름일 수 있는데, 그때는 `최상위`로 바꿔야 원래 문서와 맞춰집니다. 그대로 두면 모든 문서가 새 폴더 안에 새로 생깁니다.

## 이미지는 이렇게 바뀝니다

가져올 때는 **한 줄을 혼자 차지한** 이미지만 이 앱의 이미지로 바꿉니다. `![[그림.png]]` 같은 옵시디언 문법이든 마크다운 이미지 문법이든 같습니다. `|` 뒤 숫자는 폭이 되고, 글자는 이미지 설명이 됩니다. 문장 가운데나 목록 안에 있거나 한 줄에 여럿 있는 이미지는 원문 그대로 두고 창에 개수를 알려 줍니다. 인터넷 주소로 건 이미지는 바꾸지 않습니다.

- PNG·JPEG·GIF·WebP만 이미지로 들입니다. SVG 같은 다른 형식과 한 장에 5MB를 넘는 그림은 원문 그대로 둡니다
- 들인 그림은 영문과 숫자로 된 새 이름을 받습니다. 로그인해서 쓰면 PNG·JPEG는 WebP로 바꿨을 때 더 작으면 WebP로 저장합니다. 그래서 다시 내보낸 볼트에는 옵시디언에서 붙였던 원래 파일 이름이 남지 않습니다
- 이 앱에서 내보냈던 그림은 같은 이름으로 돌아와 이미 있으면 다시 올리지 않고, 정렬과 이미지 설명도 원래 값을 되찾습니다

## 위키링크는 이렇게 맞춥니다

가져올 때는 내보낼 때 붙였던 경로와 바뀐 이름을 걷어 원래 모양으로 되돌립니다. 이 앱에서 다른 문서로 가거나 끊길 링크만 고치고, 이 앱에서도 같은 문서로 가는 링크는 그대로 둡니다. 그래서 이 앱에서 내보낸 볼트를 손대지 않고 되가져오면 문서는 건너뜀으로 셉니다. 다만 따로 별칭을 달아 둔 링크에 경로가 붙었던 문서는 처음 한 번 갱신으로 셉니다.

- 옵시디언에서 쓴 `[[폴더/문서]]` 경로 링크와 `[[문서#제목]]` 제목 링크는 이 앱에서도 그대로 이어집니다. 쓰는 법은 [위키링크로 문서 잇기](/guides/wiki-links)에 있습니다
- 별칭이 이 앱에서 가리킬 이름과 같으면 별칭을 걷어 냅니다. `[[교안/회의록|회의록]]`이 이 앱에서 `[[회의록]]`만으로 같은 문서를 가리키면 `[[회의록]]`이 됩니다
- 블록을 가리키는 `[[문서#^abc123]]`은 그 문서만 엽니다

## 옮겨지지 않는 것

| 무엇 | 어떻게 되나 |
| --- | --- |
| 이미지가 아닌 `![[…]]`(문서·PDF 등) | 원문 그대로 두고 창에 개수를 알려 줍니다 |
| `#태그`, 각주, `aliases` 속성 | 원문 그대로 둡니다. `aliases`에 적은 다른 이름으로는 위키링크가 이어지지 않습니다 |
| 캔버스처럼 `.md`가 아닌 파일 | 들이지 않습니다 |
| 댓글 | 내보내는 파일에 들어가지 않습니다 |
| 공유받은 문서 | 내보내지 않고, 다시 가져올 때 맞춰 보지도 않습니다 |
| 금고 문서 | 열려 있으면 암호화되지 않은 파일로 나가고, 잠겨 있으면 빠집니다. 잠긴 금고 문서와는 맞춰 보지 않으니 금고 문서가 든 폴더로 다시 가져올 때는 금고를 먼저 엽니다. 자세한 것은 [금고로 문서 암호화하기](/guides/encryption)에 있습니다 |
| 로그인해서 쓸 때 1MB를 넘는 문서 | 건너뛰고 창에 개수를 알려 줍니다 |

## 정리

- 내보내기는 설정 `데이터` 탭(전체)이나 폴더 `⋯` 메뉴(폴더 하나)의 `옵시디언 볼트로 내보내기`입니다
- 가져오기는 `폴더 가져오기…`, 폴더 끌어 놓기, zip `가져오기…` 셋이고, 들이기 전에 `넣을 폴더`를 확인합니다
- 다시 가져오면 폴더 경로와 파일 이름으로 맞추고, 바뀐 문서만 `(가져오기 전)` 사본을 남긴 뒤 갱신합니다
- 옵시디언에서 지우거나 옮긴 파일의 옛 문서는 이 앱에 남습니다
- 한 줄을 혼자 차지한 이미지만 이 앱의 이미지가 되고, 그 그림의 파일 이름은 바뀝니다
