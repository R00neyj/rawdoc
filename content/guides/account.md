# 계정과 로그인

이 앱은 가입하지 않고 바로 씁니다. 로그인은 같은 문서를 여러 기기에서 쓰거나, 다른 사람과 나누거나, 스크립트로 문서를 다루고 싶을 때 합니다. 계정은 Google 또는 GitHub 계정으로 만듭니다.

## 로그인해야 쓸 수 있는 것

| 할 일 | 로그인하지 않았을 때 |
| --- | --- |
| 다른 기기·다른 브라우저에서 같은 문서 열기 | 안 됩니다. 문서는 지금 브라우저에만 있습니다 |
| 읽기 전용 링크, `사람 초대…`, `공유 관리` | 안 됩니다. 내용을 주소에 담는 `링크 복사`는 됩니다 |
| 초대받은 문서 보기(`공유받음`) | 안 됩니다 |
| 여러 탭·여러 기기에서 한 문서를 동시에 고치기 | 같은 브라우저의 한 탭만 고칩니다 |
| 댓글에서 `@`로 사람 멘션, 상단바 `알림` | 안 됩니다. 댓글 달기는 됩니다 |
| API 토큰, 명령줄 도구 | 안 됩니다 |
| 금고 | 됩니다. 이 브라우저에만 있는 금고입니다 |
| 편집, 검색, 지도, 템플릿, 내보내기·가져오기 | 됩니다 |

문서가 어디에 저장되는지와 연결이 끊겼을 때의 차이는 [오프라인과 동기화](/guides/offline-sync)에 정리했습니다.

## 로그인하기

상단바 맨 오른쪽 `계정` 버튼을 누르고 `로그인`을 고릅니다. 그 전에 저장을 기다리던 입력을 먼저 저장합니다. 로그인 화면에서 `Google로 계속`이나 `GitHub로 계속`을 누르고, 그 서비스에서 확인을 마치면 누르기 전에 보던 화면으로 돌아옵니다.

- 계정은 이메일 주소로 구별합니다. 이메일이 같으면 Google로 들어오든 GitHub으로 들어오든 같은 계정이고, 이메일이 다르면 문서가 서로 보이지 않는 다른 계정입니다. 계정의 이메일은 바꿀 수 없습니다
- 이 앱이 받아 두는 것은 이메일 주소입니다. 그 서비스가 함께 보내는 이름과 프로필 사진은 저장하지 않습니다
- 이메일 인증을 마치지 않은 Google·GitHub 계정으로는 로그인하지 못하고, 로그인 화면에 그 까닭이 뜹니다
- 하루에 새로 만들 수 있는 계정 수에는 한도가 있습니다. 그날 한도가 차면 새 가입만 막히고, 이미 있는 계정의 로그인은 됩니다
- 로그인은 마지막으로 쓴 날부터 30일 동안 이어집니다. 그 뒤에는 다시 로그인해야 하고, 그때 상태바에 뜨는 표시는 [오프라인과 동기화](/guides/offline-sync)에 있습니다

## 처음 로그인할 때 옮겨지는 것

로그인하지 않고 쓰던 브라우저에서 처음 로그인하면, 그 브라우저의 문서와 폴더를 계정에 넣고 서버로 보냅니다. 문서에 달아 둔 댓글도 문서와 함께 갑니다. 다 넣으면 `로컬 문서 3개를 계정에 넣었습니다. 서버로 보내는 중입니다.`처럼 알려 줍니다. 넣다가 실패하면 `로컬 문서를 옮기지 못했습니다. 다시 시도하려면 새로고침하세요.`가 뜹니다.

금고 문서는 이때 함께 옮기지 않습니다. 로그인 전 금고 문서가 있으면 화면 위에 `옮기기`·`나중에` 버튼이 붙은 알림이 따로 뜨고, 그 금고의 암호를 넣어야 계정 금고로 들어갑니다. 자세한 흐름은 [금고로 문서 암호화하기](/guides/encryption)에 있습니다.

이 브라우저의 원래 문서는 옮긴 뒤에도 남아 있습니다. 로그아웃한 채 고친 문서를 계정에 넣는 방법은 [오프라인과 동기화](/guides/offline-sync)에 있습니다.

## 계정 메뉴

로그인한 뒤 `계정` 버튼을 누르면 맨 위에 로그인한 이메일이 보이고, 서버와 연결되어 있으면 그 아래에 지금까지 쓴 양이 두 줄로 나옵니다.

- `이미지 42MB / 300MB`: 이미지 저장 공간
- `문서 12MB / 100MB · 340개`: 문서 본문 크기의 합과 문서 수
- 어느 한도든 90%에 이르면 그 줄 글자가 경고 색으로 바뀝니다. 한도에 닿았을 때 일어나는 일은 [오프라인과 동기화](/guides/offline-sync)에 있습니다

그 아래 버튼은 `공유 관리`·`API 토큰`·`로그아웃` 셋입니다. 연결이 끊긴 동안에는 이메일 옆에 `오프라인`만 붙고 버튼이 나오지 않습니다.

## 로그아웃

`계정` 메뉴의 `로그아웃`을 누르면 남은 입력을 저장한 뒤 이 브라우저의 로그인을 끝내고, 로그인하지 않은 상태로 앱을 다시 엽니다. 그러면 로그인 없이 만들었던 문서가 보입니다.

- 끝나는 것은 이 브라우저의 로그인뿐입니다. 다른 기기는 로그인된 채로 남습니다
- 로그인해서 쓰던 문서의 사본은 로그아웃해도 이 브라우저에서 지워지지 않습니다. 여럿이 쓰는 컴퓨터였다면 브라우저 설정에서 이 사이트의 데이터를 지웁니다
- 서버에 연결되어 있어야 로그아웃할 수 있습니다. 실패하면 `로그아웃하지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요.`가 뜨고 로그인 상태가 그대로 남습니다

## API 토큰

API 토큰은 스크립트나 명령줄 도구가 브라우저 없이 내 계정으로 문서를 읽고 쓸 때 내미는 열쇠입니다. `계정` 메뉴의 `API 토큰`을 누르고 `이름` 칸에 용도를 적은 뒤 `토큰 만들기`를 누릅니다.

- 만든 토큰 값은 그 창을 닫으면 다시 볼 수 없습니다. `복사`를 눌러 바로 옮겨 둡니다
- 목록에는 이름, 토큰 앞부분, `만든 날`, 마지막으로 쓴 날이 보입니다. 한 번도 쓰지 않은 토큰은 `사용 안 함`입니다
- 토큰은 계정마다 10개까지 둘 수 있고, `폐기`하기 전까지 기한 없이 쓰입니다. 쓰지 않는 토큰은 `폐기`합니다
- 명령줄 도구의 로그인 명령을 브라우저에서 승인하면 이름이 `CLI · `로 시작하는 토큰이 목록에 하나 생깁니다

토큰을 쓰는 방법은 [터미널에서 문서 읽고 쓰기](/guides/cli)에 있습니다.

## 초대받은 문서 보기

다른 사람이 내 이메일로 초대했다면, 그 이메일과 같은 주소의 Google 또는 GitHub 계정으로 로그인합니다. 초대 메일은 오지 않고, 로그인하면 사이드바 `공유받음` 묶음에 문서가 나타납니다. 받은 권한으로 할 수 있는 일은 [문서를 공유하고 함께 편집하기](/guides/sharing)에 있습니다.

## 운영자가 보내는 계정 알림

운영자가 계정의 사용 방식에 주의를 주면 화면 위에 `운영자가 이 계정의 사용 방식에 주의를 보냈습니다.`로 시작하는 알림이 뜹니다. 쓰기가 막히면 알림이 `이 계정은 운영자가 쓰기를 막았습니다.`로 바뀝니다.

막힌 계정은 로그인해서 자기 문서를 읽고 내보낼 수 있지만, 서버에 새로 저장하지는 못합니다. 그 계정이 만든 읽기 전용 링크도 열리지 않습니다. 계정 삭제는 막힌 뒤에도 할 수 있습니다.

## 계정 삭제

사이드바 `설정`의 `계정` 탭에서 `계정 삭제…`를 누릅니다. 이 탭은 로그인했을 때만 보이고, 버튼은 서버에 연결되어 있을 때만 눌립니다.

1. 창이 열리면 지울 서버 문서·폴더·이미지 수와, 있으면 API 토큰 수가 먼저 보입니다. 다른 사람과 공유 중인 문서가 있으면 그 수도 따로 알려 줍니다
2. 로그인한 지 10분이 지났으면 `다시 로그인…`을 눌러 한 번 더 로그인합니다. 지우려는 계정으로 로그인하면 이 창이 다시 열립니다
3. `계속하려면 삭제를 입력하세요` 칸에 `삭제`를 쳐야 `계정 삭제` 버튼이 눌립니다
4. 지우고 나면 이 브라우저에 있던 그 계정의 사본도 지우고, 로그인하지 않은 상태로 앱을 열어 `계정을 삭제했습니다.`를 띄웁니다

| 지워지는 것 | 남는 것 |
| --- | --- |
| 계정과 서버의 문서·폴더·이미지, 계정 금고와 그 안의 문서 | 이 브라우저에서 로그인 없이 만든 문서와 로컬 금고 |
| 내가 만든 읽기 전용 링크와 초대, 내가 받은 초대 | 다른 사람 문서에 쓴 글과 댓글 |
| API 토큰, 내 문서에 달린 댓글 | 장애 복구용 자동 백업. 최대 30일 뒤 사라집니다 |
| 이 기기에서 아직 서버로 보내지 못한 변경 | 다른 기기의 사본. 그 기기는 다음 연결 때 로그아웃되고, 사본은 그 브라우저의 사이트 데이터를 지워야 사라집니다 |

지운 계정은 되살릴 수 없습니다. 남겨 둘 문서는 먼저 설정 `데이터` 탭 `전체 내보내기`로 받아 둡니다.

## 정리

- 로그인은 여러 기기, 공유와 초대, 동시 편집, 멘션, API 토큰에 필요합니다
- 이메일 주소 하나가 계정 하나이고, Google과 GitHub 어느 쪽으로 들어와도 같습니다
- 처음 로그인하면 이 브라우저의 문서·폴더·댓글이 계정으로 가고, 금고 문서는 따로 묻습니다
- 로그아웃은 이 브라우저의 로그인만 끝내며, 받아 둔 사본은 남습니다
- 계정 삭제는 설정 `계정` 탭에서 하고, 로그인 없이 만든 문서와 남의 문서에 쓴 글은 남습니다
