# 검색과 찾기·바꾸기

찾는 도구는 둘입니다. 모든 문서를 한꺼번에 훑는 **검색**(`Ctrl+Shift+F`)과, 열어 둔 문서 하나 안에서 찾고 바꾸는 **찾기·바꾸기**(`Ctrl+F`·`Ctrl+H`)입니다. 검색 결과로 문서를 열면 검색어가 그 문서의 찾기 칸으로 이어집니다.

## 검색 창 열고 닫기

- 사이드바 위쪽 돋보기 버튼 `검색`을 누르거나 `Ctrl+Shift+F`(맥은 `Cmd+Shift+F`)를 누릅니다. 사이드바를 접었을 때와 좁은 창에서도 같은 돋보기 버튼이 있습니다
- 창을 열 때 지금 문서에서 저장을 기다리던 편집을 먼저 저장한 뒤 찾습니다
- 치는 동안 결과가 바로 바뀝니다. 창이 열린 채 `Ctrl+Shift+F`를 한 번 더 누르면 쳐 둔 검색어 전체가 선택됩니다
- 다른 대화상자가 떠 있을 때는 `Ctrl+Shift+F`로 열리지 않습니다
- `Esc`나 창 바깥을 누르면 닫히고, 다시 열면 검색어 칸은 비어 있습니다

## 검색어 쓰는 법

| 입력 | 걸리는 문서 |
| --- | --- |
| `회고` | 제목이나 본문 어딘가에 `회고`가 든 문서. `회고록` 안의 `회고`도 걸립니다 |
| `주간 회고` | `주간`과 `회고`가 모두 든 문서. 하나는 제목에, 하나는 본문에 있어도 됩니다 |
| `"주간 회고"` | 띄어쓰기까지 이 모양 그대로 든 문서 |
| `tag:일기` | 맨 위 속성 `tag`의 값이 `일기`인 문서 |
| `tag:` | 속성 `tag`를 가진 문서 전부 |
| `tag:"주간 회고"` | 값에 띄어쓰기가 있는 속성 |
| `tag:일기 회고` | 속성 조건과 낱말을 둘 다 만족하는 문서 |
| `"tag:일기"` | 속성 조건이 아니라 `tag:일기`라는 글자 |

- 대소문자는 구분하지 않습니다. 속성 이름과 값도 같습니다
- 조건은 늘 "모두 만족" 으로 묶입니다. 둘 중 하나만 맞아도 되는 검색은 없습니다
- 속성 값은 전체가 같아야 걸립니다. 값이 목록(들여 쓴 `- 항목` 줄이나 `[일기, 회고]`)이면 항목 하나만 같아도 됩니다
- 쌍점 앞 이름에는 한글·영문·숫자·`_`·`-`만 씁니다. 다른 글자가 섞이면 조건이 되지 않고 통째로 낱말로 찾습니다. `https://`처럼 쌍점 뒤가 `//`로 시작해도 낱말로 찾습니다
- 문서 맨 위 속성 부분의 글자는 낱말로는 걸리지 않습니다. 속성은 `이름:값` 모양으로만 찾습니다

속성을 붙여 문서를 묶는 방법은 [제텔카스텐으로 메모 쌓기](/guides/zettelkasten)에 있습니다. 지도 설정의 `파일 검색`도 같은 문법을 씁니다([지도로 문서 사이 연결 보기](/guides/wiki-map)).

## 결과 목록 읽기

결과 한 줄에는 문서 제목, 그 문서가 든 폴더(`상위 / 하위` 모양), 마지막으로 고친 날짜가 있고, 밑에 본문 발췌가 붙습니다. 친 낱말은 제목과 발췌에서 모두 칠해집니다. 제목이 빈 문서는 `제목 없는 문서`로 보입니다.

- 낱말이 전부 제목에 든 문서가 위에 모이고, 나머지는 그 아래에 둡니다. 두 묶음 안에서는 최근에 고친 문서가 먼저입니다. 속성 조건만 쳤으면 고친 날짜 순서뿐입니다
- 발췌는 본문에서 가장 먼저 맞은 자리를 기준으로, 맞은 글자 앞 30자와 뒤 70자를 잘라 보여 줍니다. 줄바꿈과 이어진 공백은 한 칸으로 접고, 잘려 나간 쪽에는 `…`이 붙습니다
- 본문에 맞은 자리가 없으면(속성 조건만 쳤거나 낱말이 제목에만 있을 때) 본문 맨 앞을 보여 줍니다
- 목록에는 200개까지 나옵니다. 넘으면 맨 아래가 `결과 1,234개 — 앞 200개만 보입니다`처럼 바뀝니다. 낱말을 더 붙여 좁힙니다
- 속성 조건을 쓰면 입력 칸 밑에 `필터 tag=일기 · 검색어 "회고"`처럼 알아들은 내용이 보입니다. `tag:`만 쳤으면 `tag=(모두)`로 나옵니다
- `↑`·`↓`로 줄을 옮기고 `Enter`로 엽니다. 줄을 눌러도 열립니다. 마지막 줄에서 `↓`를 누르면 첫 줄로 갑니다

결과 자리에 목록 대신 뜨는 말은 이렇습니다.

| 문구 | 뜻 |
| --- | --- |
| `검색어를 입력하세요` | 칸이 비어 있습니다 |
| `찾는 문서가 없습니다` | 조건을 모두 만족하는 문서가 없습니다 |
| `'tag' 속성을 가진 문서가 없습니다` | 그 이름의 속성이 어느 문서에도 없습니다. 이름 철자를 먼저 확인합니다 |
| `문서를 읽지 못했습니다` | 문서 목록을 읽다가 실패했습니다. 창을 닫았다 다시 엽니다 |

문서가 많아 목록을 읽는 데 시간이 걸리면 잠시 `목록을 새로 읽는 중…`이 보입니다.

## 검색에서 빠지거나 덜 보이는 문서

| 문서 | 검색에서는 |
| --- | --- |
| 공유받은 문서 | 제목으로만 찾고 본문은 보지 않습니다. 결과 줄에 `공유받음`이 붙고, 낱말을 치면 `공유받은 문서 3개는 제목만 찾았습니다` 같은 줄이 뜹니다 |
| 속성이 없는 문서, 속성 모양을 읽지 못한 문서 | 속성 조건을 쓰면 빠지고 `속성이 없거나 읽지 못한 문서 5개는 필터에서 빠졌습니다` 같은 줄이 뜹니다. 공유받은 문서도 여기에 셉니다 |
| 잠긴 금고 문서 | 찾지 않습니다. 무엇이든 치면 `금고가 잠겨 있어 금고 문서 2개는 찾지 않았습니다` 같은 줄이 뜹니다 |

- 속성은 `이름: 값` 줄, 그 밑에 들여 쓴 `- 항목` 줄, `#`로 시작하는 주석 줄만 읽습니다. 속성 안에 속성을 넣은 것처럼 이보다 복잡한 줄이 하나라도 있으면 그 문서의 속성 전체를 읽지 못한 것으로 칩니다
- 이 탭에서 금고를 열어 두면 금고 문서도 다른 문서처럼 찾습니다. 금고를 잠그면 검색이 기억해 둔 금고 문서 내용도 지웁니다. 검색 창을 연 채로 금고를 열거나 잠그면 목록을 새로 만듭니다. 금고는 [금고로 문서 암호화하기](/guides/encryption)에 있습니다
- 로그인해서 쓰다가 연결이 끊기면 `오프라인 — 이 기기에 저장된 문서에서 찾습니다`가 뜹니다. 연결이 끊긴 동안의 일은 [오프라인과 동기화](/guides/offline-sync)에 있습니다

## 결과로 연 문서에서 이어 찾기

`편집`이나 `원문` 모드에서 결과를 열면 그 문서 위에 찾기 칸이 열리고, 검색어가 들어가 본문의 같은 글자가 모두 칠해집니다. 첫 자리는 선택된 채이고 커서는 본문에 있습니다. `F3`이나 `Ctrl+G`로 다음 자리로 넘어갑니다.

- 낱말을 여럿 쳤으면 본문에 든 것 가운데 먼저 친 하나만 넘깁니다
- 넘길 낱말이 없으면 찾기 칸을 열지 않습니다. 속성 조건만 쳤을 때, 낱말이 제목에만 있을 때, 공유받은 문서를 열 때가 그렇습니다
- `보기` 모드에서 열면 넘기지 않습니다
- 넘길 때 찾기 칸의 `대소문자 구분`·`정규식`·`단어 단위`는 꺼집니다. 검색 창과 같은 방식으로 찾게 하려는 것입니다
- 첫 자리가 선택된 채로 글자를 치면 그 자리가 바뀝니다. `Ctrl+Z`로 되돌립니다

## 한 문서 안에서 찾기·바꾸기

`편집`·`원문` 모드에서 `Ctrl+F`를 누르면 편집 영역 오른쪽 위에 찾기 칸이 뜹니다. 커서가 사이드바에 있어도 `Ctrl+F`는 브라우저의 페이지 찾기 대신 이 칸을 엽니다. 편집 영역에서 `Ctrl+H`를 누르면 같은 칸을 열고 커서를 바꾸기 칸에 둡니다.

- 글자를 골라 둔 채 열면 그 글자가 찾기 칸에 들어갑니다
- 찾기 칸에서 `Enter`는 다음 자리, `Shift+Enter`는 이전 자리입니다. `F3`·`Shift+F3`, `Ctrl+G`·`Ctrl+Shift+G`와 칸 옆 화살표 버튼(`다음 찾기`·`이전 찾기`)도 같습니다
- 점 세 개 버튼(`옵션 더 보기`)을 누르면 `대소문자 구분`·`정규식`·`단어 단위`·`일치 항목 모두 선택`이 나옵니다. 처음에는 모두 꺼져 있습니다
- 두 번째 줄의 `바꾸기` 버튼은 선택된 자리 하나를 바꾸고 다음 자리를 고릅니다. 고른 자리가 없으면 먼저 고르기만 합니다. 바꾸기 칸에서 `Enter`를 눌러도 같습니다
- `모두 바꾸기`는 문서 안 맞는 자리를 한 번에 모두 바꿉니다. 바꾼 것은 `Ctrl+Z`로 되돌립니다
- 원문 전체가 대상이라 맨 위 속성 부분의 글자도 걸립니다
- 읽기만 할 수 있는 문서에서는 두 번째 줄(바꾸기)이 없습니다
- `Esc`나 `닫기` 버튼으로 닫습니다. 다른 문서를 열어도 닫힙니다

## 정리

- 여러 문서는 `Ctrl+Shift+F`, 지금 문서 안은 `Ctrl+F`, 바꾸기는 `Ctrl+H`입니다
- 낱말은 모두 들어 있어야 걸리고, 붙은 구절은 큰따옴표, 속성은 `이름:값`입니다
- 결과는 낱말이 제목에 다 든 문서부터, 그다음 최근에 고친 순서이며 200개까지 보입니다
- 공유받은 문서는 제목만, 잠긴 금고 문서는 찾지 않습니다
- 결과로 연 문서에는 본문에 든 검색어 하나가 찾기 칸에 들어갑니다
