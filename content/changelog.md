# 체인지로그

새로 생긴 기능과 고친 문제를 최신순으로 적습니다. 사용자가 화면에서 확인할 수 있는 변화만 담습니다.

## 2026-09-22

- 지도가 3차원이 되었습니다. 문서가 공중에 떠 있는 점으로 보이고, 오른쪽 버튼으로 끌면 덩어리가 돌아갑니다. 왼쪽 버튼으로 끌면 옮겨지고 휠로 확대하며, `맞춤` 으로 전체가 보이는 자리로 되돌립니다.
- 손가락으로도 돌립니다. 한 손가락이 회전, 두 손가락이 확대와 이동입니다.
- 점에 마우스를 올리면 그 문서와 바로 이어진 문서만 밝게 남고 나머지는 뒤로 가라앉습니다. 이름표도 그때만 뜹니다.
- 점을 우클릭하면 `열기`·`새 탭에서 열기`·`여기로 이동` 메뉴가 열립니다. 길게 눌러도 같습니다.
- 아직 없는 문서를 가리키는 점에서는 `이 제목으로 새 문서` 로 그 자리에서 문서를 만듭니다.
- 지도 설정 패널이 생겼습니다. 머리 줄 `지도 설정` 으로 열어 점 크기·선 두께·이름표가 뜨는 거리를 맞추고, 덩어리가 얼마나 뭉치고 흩어질지를 네 가지 힘으로 조절합니다. 맞춘 값은 저장됩니다.
- 지도 화면 위쪽 가로 막대를 셋에서 하나로 줄였습니다.
- 지도 이름표 글자를 키웠습니다.
- 목록 항목 안에 코드 블록을 넣으면 그 뒤에 나오는 `[[제목]]` 연결이 지도에서 통째로 빠지던 문제를 고쳤습니다.
- 문서 목록에서 고정된 문서의 고정을 풀면 아무 일도 일어나지 않던 문제를 고쳤습니다.
- 사이드바에서 `Shift` 를 누른 채 고를 때 범위가 누른 자리가 아니라 목록 맨 위까지 번지던 문제를 고쳤습니다.
- 이미 맨 바깥에 있는 문서와 폴더에도 `최상위로 옮기기` 가 뜨던 것을 고쳤습니다.
- 지도에서 이름표가 깜빡이던 문제, 마우스가 점에서 벗어날 때 원이 튀던 문제, 문서 수에 따라 배율이 어긋나던 문제를 고쳤습니다.

## 2026-09-21

- 도움말·이용약관 같은 사이트 글에서 본문만 바탕색이 달라 상자처럼 떠 보이던 문제를 고쳤습니다.
- 이미 쓰던 브라우저에서 편집기 대신 소개 화면이 뜨며 앱으로 들어가지 못하던 문제를 고쳤습니다. 이 문제를 겪었다면 열어 둔 탭과 설치한 앱 창을 모두 닫았다가 다시 열어 주십시오.
- 수식을 씁니다. `$E=mc^2$` 처럼 감싸면 편집 화면과 보기 화면에서 바로 식으로 보이고, 내보낸 HTML 에서도 인터넷 없이 보입니다.
- 문서 사이 연결을 지도로 봅니다. 사이드바 `지도` 를 누르면 위키링크가 그림으로 펼쳐지고, 아직 없는 문서를 가리키는 링크는 눌러서 바로 만듭니다.
- 검색 결과로 문서를 열면 그 문서 안에서도 검색어가 바로 표시됩니다.
- 문서를 새 탭에서 엽니다. 가운데클릭하거나 우클릭 메뉴에서 고릅니다. 여러 탭을 열어 두면 한쪽에서 만든 문서가 다른 쪽에도 곧 나타납니다.
- 사용법 글 3편을 열었습니다 — 위키링크로 문서 잇기, 제텔카스텐, 다른 편집기로 옮기기. 사이드바 `사용법` 에서 갑니다.
- 도움말을 앱을 열지 않고도 봅니다.
- 개인정보 처리방침과 이용약관을 올렸습니다. 아직 초안입니다.
- 편집과 보기 모드를 오갈 때 보던 자리가 그대로 남습니다.
- 탭을 복제했을 때 복제된 쪽에서 친 글자가 서버의 문서를 조용히 덮어쓰던 문제를 고쳤습니다.
- 사이트 글이 화면 폭 끝까지 퍼지던 문제를 고쳤습니다.
- A4 크기로 인쇄하거나 PDF 로 저장합니다. `Ctrl+P` 도 같은 결과입니다.
- HTML 파일로 내보냅니다. 서식을 살린 채 다른 편집기로 붙여넣는 복사도 됩니다.
- 내보낸 zip 보관함을 그대로 다시 가져옵니다.
- 여러 문서를 한 번에 찾습니다. `Ctrl+Shift+F` 로 열고 제목·본문·속성으로 걸러 봅니다.
- 설정을 `화면`·`편집기`·`데이터` 세 갈래로 나눴습니다.
- 끝낸 체크박스 항목에 취소선이 그어집니다.
- 어두운 화면에서도 다이어그램이 배경에 묻히지 않습니다.
- 공유 링크로 열리는 읽기 전용 화면을 앱과 같은 모양으로 맞췄습니다.
- 형광펜 표시(`==표시==`)의 색을 노란색으로 바꿨습니다.
- 이 체인지로그 페이지를 열었습니다.
- 접은 사이드바에서 설명 풍선이 잘리던 문제, 검색창에 입력칸이 한 겹 더 보이던 문제, 공유 문서에서 코드 복사 버튼이 옆으로 밀리던 문제를 고쳤습니다.

## 2026-09-20

- 문서 안에서 찾고 바꿉니다. `Ctrl+H` 로 엽니다.
- 사이드바 위쪽 버튼 줄을 고정하고 `모두 접기` 를 더했습니다.
- 내보내기를 메뉴로 모으고, 기호를 뗀 `.txt` 평문을 더했습니다.
- 문서 전체나 폴더 하나를 zip 파일로 내보냅니다. 폴더 구조와 이미지가 그대로 들어갑니다.
- `==표시==` 로 형광펜 표시를 합니다.
- 처음 오면 소개 화면을 한 번 보여주고, 한 번 쓰기 시작하면 다음부터 바로 편집 화면이 열립니다.

## 2026-09-19

- 공유 링크에서 문서 사이 연결을 따라간 뒤 뒤로 가기를 누르면 첫 화면으로 빠지던 문제를 고쳤습니다.

## 2026-09-18

- 시작 화면에 최근 문서 다섯 개가 보입니다.
- 코드블록에 언어 이름과 복사 버튼이 생겼습니다.
- 폴더를 지울 때 안에 든 문서를 위로 옮길지 함께 지울지 고릅니다.
- 만든 공유 링크를 한 화면에서 보고 끊습니다.
- 도움말을 대화상자에서 전용 페이지로 옮기고 오른쪽에 목차를 뒀습니다.
- 사이드바에서 여러 항목을 골라 한 번에 옮기거나 지웁니다.
- 문서 사이 연결(`[[제목]]`)로 이어진 문서를 묶어서 공유합니다.
- mermaid 문법으로 그린 다이어그램이 보기 모드에서 그림으로 나옵니다.
- 중첩 목록에 깊이 안내선을 넣고 단계마다 들여쓰기 폭을 고정했습니다.
- 한글을 입력하는 중에 목록에서 줄바꿈이 어긋나던 문제, 지운 문서·폴더가 되살아나던 문제, 새로고침한 뒤 한동안 문서가 잠겨 있던 문제를 고쳤습니다.

## 2026-09-17

- 공유 링크를 메신저나 SNS 에 붙이면 제목·설명·미리보기 그림이 있는 카드로 보입니다.
- 서비스 로고와 이름을 정했습니다.
- 처음 오는 사람을 위한 소개 페이지를 열었습니다.

## 2026-09-16

- 시작 화면이 생겼습니다. 설정에서 마지막에 보던 문서로 열리게 바꿀 수 있습니다.
- 상단바에 서식 버튼 줄이 생겼습니다. 굵게·제목·목록·표·링크·이미지를 눌러 넣습니다.
- 오른쪽 클릭 메뉴로 잘라내기·복사·붙여넣기와 서식 넣기를 합니다.
- 마크다운 문법 도움말을 앱 안에서 봅니다.
- 문서 제목 줄에 폴더 경로가 함께 보입니다.
- 아래쪽 상태 줄에 저장 상태가 점으로 보입니다. 입력 중·저장됨·실패를 색으로 구분합니다.

## 2026-09-15

웹 앱을 처음 공개했습니다. 아래는 첫 공개에 들어간 기능입니다.

- 마크다운 기호가 사라지지 않는 편집. `##` 이나 `**` 를 입력해도 기호가 화면에 그대로 남고, 내보낸 `.md` 파일은 입력한 그대로입니다.
- `편집`·`보기`·`원문` 세 가지 모드.
- 사이드바에서 문서와 폴더를 만들고 옮기고 맨 위에 고정합니다.
- 표를 칸 단위로 편집합니다. 칸 사이 이동, 행·열 추가와 삭제, 끌어서 범위 선택까지 됩니다.
- 안내 상자(콜아웃), 문서 사이 연결(`[[제목]]`), 문서 속성(프론트매터), 오른쪽 목차.
- 이미지를 붙여넣거나 끌어다 놓습니다. 정렬·크기를 고르고, 큰 이미지는 자동으로 줄여 저장합니다.
- `.md` 파일 가져오기와 내보내기.
- 화이트·세피아·다크 테마, 서체와 글자 크기, 줄 번호, 들여쓰기 폭 설정.
- 브라우저에 앱으로 설치해 인터넷 없이 씁니다.
- 로그인하면 문서가 서버에 저장되고 다른 기기에서 이어서 씁니다. 일회용 코드나 Google 계정으로 로그인합니다.
- 읽기 전용 링크로 문서나 폴더를 공유합니다. 받은 사람은 로그인 없이 봅니다.
- 사람을 초대해 보기·편집 권한을 줍니다. 같은 문서를 둘이 열면 한 사람만 편집합니다.
- API 토큰을 발급해 다른 프로그램에서 문서를 올리고 내립니다.
