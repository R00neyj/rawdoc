> IA(Information Architecture, 정보 구조): 화면에 무엇이 어디 있고, 사용자가 어떤 순서로 이동하며, 각 상태에서 무엇이 보이는지를 정한 문서

## 1. 화면 목록

M1 은 페이지 이동이 없는 단일 화면 앱이다

| ID | 화면 / 레이어 | 언제 보이나 |
| --- | --- | --- |
| S-1 | 편집 화면 | 문서가 1개 이상 있을 때 기본 화면 |
| S-2 | 빈 상태 | 문서를 전부 삭제해 0개일 때 |
| S-3 | 부팅 중 | 페이지를 연 순간부터 저장소에서 문서 목록을 읽을 때까지 (HTML 첫 페인트부터, F-2015) |
| D-1 | 삭제 확인 대화상자 | 문서 삭제를 누를 때 |
| D-2 | 설정 대화상자 | 사이드바 `설정` 을 누를 때 (I8). 왼쪽 탭 `화면`·`편집기`·`데이터` + 오른쪽 패널 (F-290) |
| D-3 | 폴더로 이동 대화상자 | 문서 `⋯` 메뉴 `폴더로 이동…` (F-126) |
| D-4 | 사람 초대 대화상자 | 공유 메뉴·폴더 `⋯` 메뉴 `사람 초대…`, 서버 저장소 owner (F-212, 모양 F-225) |
| D-5 | API 토큰 대화상자 | 계정 메뉴 `API 토큰`, 로그인 상태 (F-222) |
| D-6 | 검색 대화상자 | 사이드바·상단바 `검색` 버튼 또는 `Ctrl+Shift+F` (F-287) |
| S-4 | 공유받은 문서 | 해시가 `#/s/{조각}` 인 링크로 들어왔을 때 (F-130, 3.19) |
| S-5 | 공개 보기 | 해시가 `#/p/{토큰}`·`#/p/f/{토큰}` 인 읽기 전용 링크로 들어왔을 때. 저장소를 열지 않는다 (F-210, F-211) |
| S-6 | 공유 관리 | 계정 메뉴 `공유 관리` → `#/shares`. 문서를 열지 않는다 (F-243) |
| S-7 | 도움말 | 사이드바 `도움말` → `#/help`. 문서를 열지 않는다 (F-244) |
| S-8 | 위키링크 지도 | 사이드바 `지도` 를 눌렀거나 해시가 `#/map`·`#/map/{id}` 일 때. 문서를 닫지 않고 그 위를 덮는다. 3D 그래프이고 오른쪽에 접이식 설정 패널을 둔다 (F-292 개정판, 3.29) |
| N-1 | 알림 띠 | 가져오기 결과, 저장 실패, 저장소 사용 불가, 새 버전, 복사·공유 결과 |

- 페이지 이동은 없지만 **현재 문서를 해시 URL `#/d/{id}` 로 나타낸다** (I1). 규칙은 3.10
- **S-5·S-6·S-7 은 M1 이후에 생긴 전용 화면이다.** 편집 영역 자리를 통째로 쓴다. 앱 안 화면 분할은 두지 않는다 (F-296)
- **공개 사이트 페이지는 앱 밖이다** — `/`(랜딩, F-271)·`/changelog`·`/help`·`/privacy`·`/terms`·`/guides`(사용법 목록)·`/guides/*`(글)·`404`. 서버가 내려 주는 정적 HTML 이고 저장소·React 를 쓰지 않는다 (F-270·F-272). 위 표의 S·D·N 은 **앱 안**의 화면·레이어이고, 앱이 여전히 단일 화면이라는 문장은 그대로다
- 브라우저 기본 대화상자(`alert`·`confirm`)는 쓰지 않는다. D-1 은 앱 안에서 그린다

### 배치 원칙

- **현재 문서에 대한 동작은 상단바, 문서 집합에 대한 동작은 사이드바**에 둔다
- 삭제·이동·고정은 예외로 목록 항목의 `⋯` 메뉴에 둔다. 현재 문서가 아닌 문서도 열지 않고 다룰 수 있게 하기 위해서다
- 앱 전체에 걸린 것(설정, 앱 설치)은 사이드바 맨 아래에 둔다. 단 자주 바꾸는 보기 모드는 상단바에 둔다

## 3. 사용자 흐름

### 3.1 최초 실행

1. S-3 부팅 중 표시
2. 저장소에 문서가 0개이고 **최초 실행 기록이 없으면** 안내 문서 1개 생성
3. 안내 문서를 열고 S-1 표시. 에디터에 포커스를 주지 않는다

안내 문서를 삭제한 뒤 새로고침해도 다시 생기지 않는다 — 최초 실행 기록으로 구분한다

### 3.2 재방문

1. S-3
2. 열 문서를 아래 순서로 정한다
   1. URL 해시의 문서 ID — 그 문서가 있으면 연다
   2. 해시가 없으면 마지막으로 연 문서 ID
   3. 둘 다 없거나 해당 문서가 지워졌으면 목록 첫 번째(최근 수정) 문서
3. 해시에 적힌 문서가 없었으면 N-1 에 `문서를 찾을 수 없습니다.` 표시
4. 문서가 0개면 S-2

### 3.3 새 문서

1. `새 문서` 클릭
2. 제목 `제목 없는 문서`, 내용 빈 문자열, 줄바꿈 형식 CRLF 로 생성하고 즉시 저장 (`specs/product.md` Q9)
3. 새 문서를 열고, **본문 맨 위 제목 입력에 포커스 + 제목 전체 선택** (F-217)
4. Enter 를 누르면 포커스가 에디터로 이동

### 3.4 문서 전환

1. 목록 항목 클릭
2. 현재 문서에 저장 대기 중인 입력이 있으면 **먼저 저장을 끝낸다**
3. 선택한 문서를 연다. 에디터에 포커스, 커서는 문서 맨 앞
4. 실행 취소 기록은 문서를 전환하면 사라진다 (M1)

### 3.5 제목 변경

1. 본문 맨 위 제목 입력에서 수정 (F-217)
2. 입력하는 동안 사이드바 항목 제목도 함께 바뀐다
3. 비운 채 포커스를 잃으면 `제목 없는 문서` 로 되돌린다

### 3.6 삭제

1. 목록 항목의 `×` 클릭
2. D-1 표시: `"{제목}" 을(를) 삭제할까요? 되돌릴 수 없습니다.` / `삭제` `취소`. 기본 포커스는 `취소`
3. `삭제` 시 저장소에서 제거
4. 지운 문서가 현재 문서였으면 목록 첫 번째 문서를 연다. 남은 문서가 없으면 S-2
5. Esc 는 `취소` 와 같다

### 3.7 가져오기

1. `가져오기` 클릭 → 파일 선택 창 (`.md` 만 선택 가능)
2. 새 문서 생성: 제목 = 파일명(확장자 제외), 내용 = 파일 원문
3. 새 문서를 열고 N-1 로 결과 표시: `"{파일명}" 을(를) 가져왔습니다.`
4. 파일의 줄바꿈 형식(CRLF 또는 LF)을 문서에 기억한다. 한 형식만 쓴 파일은 그대로 두고 알리지 않는다. CRLF·LF·`\r` 단독이 섞여 있었으면 CRLF 로 통일하고 같은 알림에 `줄바꿈 형식이 섞여 있어 CRLF 로 통일했습니다.` 를 덧붙인다 (`specs/product.md` Q9)
5. 실패(읽기 오류, UTF-8 아님) 시 문서를 만들지 않고 N-1 에 오류 표시
6. 파일 맨 앞에 UTF-8 BOM 이 있으면 떼어 내고 같은 알림에 `파일 맨 앞의 BOM 을 제거했습니다.` 를 덧붙인다 (`specs/features/F-114.md`)

### 3.8 내보내기

1. `.md 내보내기` 클릭
2. 현재 문서를 `{제목}.md` 로 다운로드. 저장 대기 중인 입력도 포함한다. 문서에 첨부 이미지가 있으면 `{제목}.md` + `attachments/` 를 담은 `{제목}.zip` (F-158)
3. 성공 알림은 띄우지 않는다 (브라우저 다운로드 표시로 충분)

### 3.9 보기 모드 전환

1. 상단바 토글 클릭
2. 편집 영역만 다시 그린다. 커서 위치·스크롤 위치·실행 취소 기록 유지
3. 선택한 모드는 저장해 두고 다음 실행에도 쓴다. 기본값 `편집`
4. `보기` 는 원문을 HTML 로 바꿔 읽기만 한다. 본문 맨 위 제목도 글자로만 보인다(F-217). 편집으로 돌아오면 커서·실행 취소 기록이 그대로다 (F-123)
5. 편집 ↔ 원문은 같은 편집기를 다시 구성할 뿐이라 스크롤 위치가 그대로다. 편집·원문 ↔ 보기는 떠나는 화면의 **화면 맨 위에 보이는 원문 줄**을 기억했다가, 들어가는 화면에서 그 줄이 다시 맨 위에 오도록 맞춘다 (F-295)
6. 문서를 바꾸면 기억한 값을 버리고 맨 위부터 본다. 보기 화면의 이미지·다이어그램이 전환 뒤에 그려져 높이가 늘어나는 것까지는 따라가지 않는다 (F-295)

### 3.10 URL 과 뒤로 가기

| 동작 | URL | 브라우저 기록 |
| --- | --- | --- |
| 문서 전환 (목록 클릭) | `#/d/{새 id}` | 추가 — 뒤로 가기로 이전 문서 |
| 새 문서, 가져오기 | `#/d/{새 id}` | 추가 |
| 최초 실행·재방문에서 문서 결정 (3.1·3.2) | `#/d/{id}` | 교체 |
| 삭제 후 다른 문서로 이동 | `#/d/{id}` | 교체 |
| 문서 0개 (S-2) | `#/` | 교체 |
| 뒤로·앞으로 가기, 주소창 직접 수정 | 해시가 바뀜 | 해시의 문서를 연다. 저장 대기 입력은 먼저 저장 (3.4 와 같음) |

- 바뀐 해시의 문서가 없으면(삭제된 문서로 뒤로 가기 등) 3.2 의 2-3번 규칙으로 대신 열고 N-1 을 표시한다. 기록은 교체
- 해시 형식이 `#/d/{id}` 가 아니면 없는 ID 로 취급한다
- 마지막으로 연 문서 ID 도 계속 기록한다. 해시 없이 들어온 경우에 쓴다
- 경로가 1종류뿐이므로 라우터 라이브러리를 추가하지 않는다
- **사이드바·홈 화면의 문서 항목은 `#/d/{id}` 링크다.** 가운데클릭·우클릭 메뉴 `새 탭에서 열기` 로 새 탭에 연다. 일반 클릭·Ctrl+클릭·Shift+클릭은 지금 동작 그대로다 (F-296)

### 3.11 좁은 창의 사이드바 (1024px 미만)

1. 사이드바를 숨긴다. 상단바 제품명 옆 토글이 `사이드바 열기` 가 된다 (2026-09-14 F-151)
2. 토글을 누르면 사이드바가 편집 영역 위에 겹쳐 열린다(펼친 모양, 레일 아님). 편집 영역 너비는 변하지 않는다. 같은 토글(`사이드바 닫기`)로 닫는다
3. 문서 선택, 새 문서, 가져오기, 대화상자(D-1·D-2) 표시 시 사이드바는 닫힌다
4. 사이드바 바깥 클릭 또는 Esc 로 닫힌다
5. 창을 1024px 이상으로 넓히면 사이드바가 원래 자리에 표시되고 토글은 접기·펴기로 돌아간다

### 3.28 여러 문서 검색 (F-287)

1. 사이드바·상단바 `검색` 버튼 또는 `Ctrl+Shift+F` 로 검색 대화상자(D-6)를 연다. 이미 열려 있으면 단축키가 검색어를 전체 선택한다
2. 열리는 순간 저장 안 된 편집을 먼저 흘려보내고(`saver.flush()`) 인덱스를 만든다. 공개 보기(S-5)에서는 열리지 않는다
3. 검색어를 입력하면 150ms 뒤 결과가 바뀐다. 결과는 제목·폴더 경로·수정 날짜·본문 발췌로 보여 준다
4. 필터를 쓰면 검색창 아래에 해석 줄(`필터 tag=일기 · 검색어 "회고"`)이 뜨고, 그 아래에 오프라인·속성을 못 읽은 문서·공유받은 문서 안내가 붙는다. 결과 아래 꼬리 줄에 결과 수가 보인다 (F-288)
5. `↑` `↓` 로 결과 선택을 옮긴다(순환). 포커스는 검색창에 남는다
6. `Enter` 또는 클릭으로 그 문서를 연다. 대화상자가 닫히고 포커스는 에디터로 간다. **본문에 검색어가 있으면 그 문서의 찾기 패널(F-261)이 그 검색어와 함께 열리고 첫 매치가 선택된다. 필터만 친 검색·제목만 맞은 문서·보기 모드에서는 열리지 않는다 (F-294)**
7. `Esc` 또는 바깥 클릭으로 닫는다. 닫으면 검색어를 비운다 — 최근 검색어를 저장하지 않는다

### 3.29 위키링크 지도 (F-292)

1. 사이드바 `지도` 버튼으로 연다. 해시가 `#/map`(전체) 또는 `#/map/{id}`(그 문서 중심)이 되고, 열고 있던 문서는 닫히지 않는다 — 지도는 그 위를 덮는다 (S-8)
2. 저장 안 된 편집을 먼저 흘려보낸 뒤 문서 목록에서 위키링크를 읽어 그래프를 만든다. 만드는 동안 `연결을 읽는 중…`, 배치를 계산하는 동안 `배치를 계산하는 중…`
3. 3D 그래프가 뜬다. **왼쪽 끌기로 이동, 오른쪽 끌기로 회전, 휠로 확대**, `맞춤` 으로 전체가 보이게 되돌린다. **카메라는 240 ms 에 걸쳐 부드럽게 움직인다(움직임 줄이기 설정이면 즉시)** (F-2012). 터치는 한 손가락이 회전, 두 손가락이 확대·이동이다. **노드 위에서 왼쪽으로 끌면 그 노드가 따라오고, 놓으면 힘이 다시 잡는다. 터치는 노드 위 한 손가락 끌기가 그것이다** (F-2009)
4. 노드에 마우스를 올리면 그 문서와 직접 이어진 문서까지 이름표가 뜬다. 평소에는 이름표가 없다 (F-2004)
5. 노드를 클릭하면 지도를 닫고 그 문서를 연다. **노드 위에서 우클릭(터치는 길게 누르기)하면 회전이 아니라 메뉴가 열린다** — 문서 노드에서는 항목이 `열기`·`새 탭에서 열기`·`여기로 이동`·`이어진 문서만 보기` 넷이다 (F-2003, F-2007). **문서 노드에서는 이어진 문서만 보기 로 그 문서를 중심으로 1단계 필터를 켠다 (F-2007).** 끊긴 링크 노드에서는 항목이 `이 제목으로 새 문서` 하나다 (F-2004)
6. 끊긴 링크 노드를 클릭하면 그 제목으로 새 문서를 현재 문서와 같은 폴더에 만들고 연다 (F-131 5장 규칙 그대로)
7. 머리 줄 `지도 설정` 으로 오른쪽 패널을 연다. **`필터`·`그룹`·`표시`·`장력` 네 묶음이고 `필터` 만 펼쳐진다** — 그리는 묶음 중 맨 위가 펼쳐진다 (F-2005, F-2007, F-2008). **목록 보기에서는 `필터`·`그룹` 둘만 보이고, 그룹 색은 행 앞 점으로 나타난다** (F-2007, F-2008). 걸러진 문서는 자리에 남은 채 흐려지고 클릭되지 않는다. `몇 다리까지`(1~3단계)는 그 `필터` 안에 있다. **`장력` 을 바꾸는 동안에는 카메라가 움직이지 않는다 — 덩어리만 오므라들고 벌어진다** (F-2012)
8. `목록` 보기로 전환하면 같은 내용을 제목·연결 수 목록으로 본다. WebGL 을 못 쓰는 브라우저에서는 자동으로 이쪽이 된다
9. 닫기 버튼이나 뒤로 가기로 나온다. `Esc` 는 설정 패널이 열려 있으면 패널만 닫고, 지도 자체는 닫지 않는다

머리 줄 `맞춤`·`목록`·`닫기`는 아이콘 버튼 + 툴팁이다. 문구는 안 바뀐다 (2026-09-22 F-2011)

### 3.27 사이드바 너비 조절 (F-159, 1024px 이상)

1. 사이드바 오른쪽 테두리에 마우스를 올리면 선이 진해지고 커서가 좌우 화살표
2. 끌면 너비가 따라온다 (200~480px, 편집 영역이 너무 좁아지지 않게 창 폭에 따라 더 줄어듦). 놓으면 저장
3. 더블클릭하면 기본 너비 300px (2026-09-21 사용자 요청으로 224px 에서 넓힘)
4. 레일·좁은 창에서는 없다

### 3.26 이미지 넣기 (F-156~F-158)

1. 편집·원문 모드에서 이미지를 붙여넣거나 편집 영역에 끌어다 놓으면 커서 줄(놓은 줄) 아래에 이미지 블록이 생긴다. 원문은 `<div align="center">` + `<img src="attachments/…" alt width>` 3줄
2. PNG·JPEG·GIF·WebP, 한 장 20MB 까지. 긴 변 2000px 넘으면 줄이고 WebP 로 저장(GIF 제외, F-220), 결과는 5MB 까지. 로그인 계정은 이미지 합계 300MB 까지(F-221). 넘거나 다른 형식이면 N-1 알림
3. 편집 모드에서는 둥근 모서리 이미지로 보인다. 마우스를 올리면 오른쪽 위 정렬 버튼(왼쪽·가운데·오른쪽), 오른쪽 가장자리·오른쪽 아래 모서리 손잡이로 크기 조절(오른쪽 정렬이면 왼쪽). 바뀌는 것은 원문의 `align`·`width` 값뿐
4. 방향키로 들어가거나 더블클릭하면 원문 3줄이 드러난다
5. 보기 모드도 같은 모양. 공유 링크에는 이미지가 담기지 않아 자리 표시로 보인다
6. 내보내기는 3.8

### 3.25 문서 바깥 클릭 (F-146)

1. 편집 영역에서 문서 칸(최대 800px) 좌우 바깥 여백을 누르면 커서를 옮기지 않고 에디터 포커스를 잃는다
2. 에디터 포커스가 없으면 편집 모드도 커서 줄 기호를 드러내지 않아 보기 모드에 가깝게 보인다. 커서·선택 표시 숨김, 줄 번호는 유지
3. 문서 칸 안을 누르거나 Tab 으로 돌아오면 다시 편집 표시

### 3.24 `.md` 파일 끌어놓아 열기 (F-145)

1. 탐색기에서 `.md` 파일을 앱 창 위로 끌어오면 창 전체에 `여기에 놓아 .md 파일 가져오기` 덮개
2. 놓으면 3.7 가져오기 2~5단계. 여러 개면 파일마다 새 문서, 마지막 파일을 연다
3. 편집 영역에 놓아도 본문에 글자를 넣지 않고 새 문서로 가져온다
4. 대화상자·공유 화면에서는 받지 않는다

### 3.23 오른쪽 목차 (F-144)

1. 문서에 `#`~`###` 제목이 있고 메인 열 오른쪽 여백이 충분하면(56px 이상) 오른쪽에 제목마다 짧은 선이 세로로 보인다 (노션 방식)
2. 마우스를 올리거나 Tab 으로 들어오면 제목 목록 카드로 펼쳐진다. 현재 읽는 위치 제목이 강조된다
3. 항목을 누르면 그 제목 위치로 스크롤한다. 커서는 옮기지 않는다
4. 편집·원문·보기 모드 공통. 빈 상태·공유 화면에는 없다
5. 오른쪽 여백이 56px 미만(휴대폰·좁은 창)이면 선 대신 오른쪽 위에 `목차` 버튼이 뜬다. 누르면 아래로 같은 목록 카드가 열리고, 항목을 누르거나 밖을 누르거나 Esc 로 닫힌다 (F-229)

### 3.22 사이드바 접기 (F-143, 1024px 이상)

1. 상단바 제품명 옆 접기 아이콘 → 폭 48px 아이콘 레일로 접힌다. 토글·검색 묶음은 제품명 바로 옆으로 붙는다 (2026-09-14 F-151)
2. 레일: 위에 검색·새 문서·새 폴더·가져오기·지도(F-292), 아래에 `도움말`·`사용법`·앱 설치(조건부)·설정. 아이콘만, 툴팁으로 이름. 고정됨·트리는 숨김
3. 레일의 `새 폴더` 는 사이드바를 펼친 뒤 이름 입력을 시작한다
4. 접힘 상태는 저장해 다음 실행에도 쓴다. 좁은 창(3.11)에서는 쓰지 않는다

### 3.12 앱 설치 (F-115)

1. 사이드바 아래쪽 `앱 설치` 클릭
2. 브라우저 설치 확인 창이 뜬다 (브라우저가 그리는 창이며 앱이 문구를 바꿀 수 없다)
3. 설치하면 버튼이 사라진다. 취소하면 버튼이 남는다

### 3.13 새 버전 적용 (F-117)

1. 새 버전이 준비되면 N-1: `새 버전이 있습니다.` + `새로고침` 버튼
2. 사용자가 `새로고침` 을 누르면 저장 대기 입력을 먼저 저장하고 새 버전으로 다시 연다. 현재 문서·보기 모드는 유지 (3.10 URL 규칙)
3. 누르지 않으면 알림을 유지한다. 다음 실행 때 새 버전이 적용된다

### 3.14 OS 에서 `.md` 파일로 열기 (F-119)

1. 설치된 앱에서, OS 파일 탐색기의 `.md` 파일 `연결 프로그램` 으로 이 앱(`{제품명}`) 선택
2. 앱 창이 열리고 3.7 가져오기의 2~5단계를 그대로 탄다
3. 여러 파일을 한 번에 열면 파일마다 새 문서를 만들고 마지막 파일을 연다
4. 원본 파일에 다시 저장하지 않는다. 앱 안의 문서는 파일과 연결되지 않은 사본이다

### 3.15 설정과 제목 서체 전환 (F-121)

1. 사이드바 맨 아래 `설정` 클릭 → D-2 설정 대화상자
2. 설정 항목은 왼쪽 탭 3개로 나눈다 (2026-09-21 F-290. 그전에는 한 줄로 이어 놓았다). 탭 이름은 글자만 쓰고 아이콘을 붙이지 않는다 (I13)

| 탭 | 항목 (위에서 아래 순서) |
| --- | --- |
| `화면` | `테마`(`시스템` / `화이트` / `세피아` / `다크`, 기본 `시스템`), `제목 서체`(`세리프` / `산세리프`), `본문 서체`(`세리프` / `산세리프`, 기본 `산세리프`. 버튼 순서는 제목 서체와 같게), `글자 크기`(`작게` / `보통` / `크게`, 기본 `보통`), `시작 화면`(`홈` / `마지막 문서`) |
| `편집기` | `탭바`(F-233), `들여쓰기`(`2칸` / `4칸`, 기본 `4칸`), `줄 번호`(`표시` / `숨김`, 기본 `표시`) |

2a. **그릴 항목이 없는 탭은 숨긴다.** 공개 보기(S-5)처럼 보일 탭이 1개뿐이면 탭 목록 자체를 그리지 않고 항목만 세로로 놓는다 — 그 화면의 모습이 F-290 전과 같다 (F-290 3.4)

(항목 이력: 2026-09-14 테마·본문 서체 F-141, 줄 번호 F-147, 글자 크기·들여쓰기 F-154. 탭바 F-233, 시작 화면 F-232, 전체 내보내기 F-281)
3. 누르는 즉시 반영한다. 저장 버튼은 없다. 대화상자 뒤 화면에서 바뀐 모습이 보인다
4. 세리프를 쓰던 자리만 바뀐다: 편집·보기 모드 `#`~`######` 제목(F-153), 빈 상태 문구, 상단바 제품명 (`specs/design.md` 2.1). 본문·UI·원문 모드는 원래 산세리프·고정폭이라 그대로다
5. 커서 위치·실행 취소 기록 유지. 제목 줄 높이가 달라지므로 스크롤 위치는 몇 px 달라질 수 있다
6. 선택은 저장해 두고 다음 실행에도 쓴다. 기본값 `세리프`
7. 열 때 포커스는 **활성 탭 버튼**에 둔다. 탭 목록을 그리지 않는 화면(2a)에서는 F-290 전처럼 첫 세그먼트의 선택된 버튼이다. `닫기` 버튼, Esc, 대화상자 바깥 클릭으로 닫는다. 닫으면 포커스를 `설정` 버튼으로 되돌린다
8. 선택한 탭은 기억하지 않는다. 열 때마다 `화면` 부터다 (F-290 Q2)

### 4.2 알림 띠 (N-1)

- 상단바 아래, 편집 영역 위에 1줄로 표시
- 정보성(가져오기 성공, 문서를 찾을 수 없음)은 몇 초 뒤 자동으로 사라진다. 오류는 사용자가 닫기 버튼 `×` 를 누를 때까지 남는다
- Esc 로 닫지 않는다. 에디터 안의 Esc 동작(I3)과 겹치지 않게 하기 위해서다
- 다른 탭에서 지워진 문서의 알림은 오류(`error`)이고 `새 문서로 저장` 버튼을 함께 둔다 (F-296 7.3)
- 동시에 1개만. 새 알림이 이전 알림을 대체한다. 단 오류와 `새 버전` 알림은 정보성 알림에 대체되지 않는다

### 4.3 빈 상태 (S-2)

- 상단바: 제목 입력·보기 모드 토글·내보내기 비활성
- 사이드바: `새 문서`, `가져오기`, `설정` 활성. 목록 자리에 비어 있음 표시 없음
- 편집 영역 자리: `문서가 없습니다.` + `새 문서` 버튼 + `가져오기` 버튼
- 상태바 숨김

### 4.4 부팅 중 (S-3)

- 첫 페인트부터 `ready` 까지 스켈레톤(사이드바 목록 자리·편집 영역 자리의 흐린 막대)을 보인다. 공개 보기(S-5) 경로에서는 보이지 않는다
- 막대 모양은 ready 뒤 화면(문서/홈/그 밖)에 맞춘다. 다른 창이 저장소를 막고 있으면 스켈레톤을 걷고 F-136 문구를 보인다 (F-2015, 2026-09-23. 이전: 로딩 표시 없음)

### 4.5 검색 대화상자(D-6)의 상태 (F-288)

결과 자리에는 아래 다섯 가지 중 **하나만** 뜬다. 위에서부터 먼저 걸리는 것을 쓴다

| 상태 | 결과 자리 |
| --- | --- |
| 읽기 실패 | `문서를 읽지 못했습니다` |
| 빈 쿼리 | `검색어를 입력하세요` |
| 아직 못 읽음 (인덱스 없음) | 비워 둔다 — "없다" 가 아니라 "아직 모른다" |

- 검색 범위·해석을 말하는 안내(`오프라인 —`, `목록을 새로 읽는 중…`, `속성이 없거나 읽지 못한 문서 {N}개…`, `공유받은 문서 {N}개…`)는 위 다섯 가지와 **별개로** 검색창 바로 아래에 붙는다. 결과가 0개일 때도 보인다

- Tab 을 에디터가 들여쓰기로 가져가므로 Esc 다음 Tab 으로 빠져나간다 (I3). CM6 가 이 동작을 기본 제공하는지는 F-103 에서 확인하고, 없으면 직접 구현한다
- 포커스 순서: 사이드바(머리 줄 토글·검색부터) → 상단바 → 편집 영역 → 상태바(포커스 대상 없음). 좁은 창은 상단바 → 사이드바 → 편집 영역 (2026-09-14 F-159)
- 모든 버튼에 `:focus-visible` 표시 (`docs/prototype.html` 기준)
- 검색 결과로 연 문서에서는 찾기 패널이 검색어와 함께 열려 있어 `F3`·`Ctrl+G` 로 다음 매치, `Esc` 로 패널 닫기가 바로 된다 (F-261 키맵, F-294)
- 지도(S-8)에는 단축키가 없고 `Esc` 로도 닫히지 않는다. 닫기 버튼·노드 클릭·뒤로 가기로만 나온다. **설정 패널이 열려 있으면 `Esc` 가 패널만 닫는다** (F-292 개정판 6.3). 다만 **노드 메뉴나 앱 설정 대화상자가 위에 떠 있으면 지도 패널은 `Esc` 를 먹지 않는다** (F-2005 6.2). 캔버스 안 노드는 포커스 대상이 아니고 `목록` 보기가 그 대안이다 (같은 명세 6.10)
- 노드 우클릭 메뉴는 열린 뒤에는 방향키·`Esc` 로 다룰 수 있지만, 캔버스가 포커스를 받지 않아 **키보드만으로 여는 길은 없다.** `목록` 보기가 그 대안이다 (F-2003 8.1). 노드 끌기도 키보드로는 할 수 없다 (F-2009)
- 툴바가 없으므로 표·코드블록·체크박스 등은 마크다운을 직접 입력한다. M1 단축키는 위 표의 3개뿐이다. 우클릭 메뉴(F-170)로 서식·단락·삽입 명령에 접근할 수 있다
