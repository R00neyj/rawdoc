2. 예외 상황

상황제안
옛 제목과 같은 제목의 다른 문서가 있음해석기가 그 링크를 이 문서로 풀던 것만 고침. 다른 문서로 풀리던 링크는 안 건드림
새 제목이 이미 다른 문서 제목대화상자에 경고 한 줄 "같은 제목 문서가 있어 링크가 그쪽으로 갈 수 있습니다". 고치기는 막지 않음
오프라인대화상자 대신 알림 "오프라인이라 링크를 고치지 못했습니다" — 미뤘다 고치지 않음
제목을 지워 제목 없는 문서 로 돌아감묻지 않음(빈 제목 문서는 링크 대상이 아님)
칸반 카드 글자 안 링크칸반도 원문이라 같이 고쳐짐
CLI put 로 제목 바꿈이번엔 안 함. help 문구 "자동으로 고쳐지지 않아 끊깁니다" 유지

결정 (2026-10-24 사용자)

  1. 확인 방식 — 대화상자로 묻기
  2. 되돌리기 — 알림에 되돌리기, 고친 링크만 옛 제목으로(제목은 그대로)
  3. 금고 문서 — 늘 제외, 건너뛴 수만 대화상자에 표시
  4. 공유받은 문서·공유 폴더 — 편집 권한 있는 것만 같이 고침
  5. 함께 편집 중인 문서 — 제목을 바꾼 사람 화면에서만 묻고 고침
