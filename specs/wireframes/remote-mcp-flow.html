정한 것 (2026-10-16)

  1. 연결 관리 위치 — 설정 새 탭 연결된 앱
  2. 제한 안내 페이지 — 공개 페이지 rawdoc.app/limits, 로그인 시 내 사용량
  3. 지우기 도구 — 휴지통으로 보내기만. 서버 문서 휴지통이 아직 없어 선행 명세로 먼저 만든다
  4. 동의 화면 모양 — 기존 로그인 페이지(worker 렌더) 스타일 재사용
  5. 공식 등재 준비물 — 개인정보처리방침 MCP 항목 · 지원 연락처 · 시험 계정. 디렉터리 제출은 구현 뒤 사람이 함
