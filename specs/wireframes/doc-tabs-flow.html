5. 보이지 않는 탭 (구조)

활성 탭만 편집기·실시간 연결 유지
뒤 탭은 제목·스크롤·커서·되돌리기 기록만 보관
뒤 탭을 누르면 다시 연결지금 문서 전환과 같은 경로

정할 것 (기본값 제안)

  1. 보통 클릭 = 임시 탭 (VS Code 방식, 제안) — 아니면 클릭마다 새 탭(탭이 금방 쌓임) / 클릭은 지금처럼 바꾸기만(탭은 Ctrl+클릭으로만)
  2. 탭 개수 상한 — 두지 않음, 넘치면 탭 줄 가로 스크롤 (제안). 뒤 탭은 연결이 없어 비용이 작다
  3. 뒤 탭 되돌리기 기록 — 탭 전환 후에도 유지 (제안). 메모리에만, 새로고침하면 사라짐
  4. 보이는 곳 — 설치 앱 창(display-mode: standalone)이면서 넓은 화면일 때만 (확정). 브라우저 탭에서는 탭 줄 없음 — 탭 밑 탭이 겹쳐 보이고 Ctrl+W·Ctrl+Tab 이 브라우저와 부딪친다
  5. "새 탭에서 열기" — 설치 앱에서는 앱 안 새 탭, 브라우저에서는 지금처럼 브라우저 새 탭 (제안). 두 창 편집권 잠금(F-296)은 그대로
  6. 화면 분할 — 이번 범위 밖 (제안)
