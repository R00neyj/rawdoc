F-4018 심사 전용 비밀번호 로그인 — 사용자 흐름

OpenAI 심사 반려(로그인/OAuth 를 끝내지 못함) 대응. 심사자는 Google·GitHub 의 새 기기 확인 코드를 받을 수 없으므로, 정해 둔 심사용 이메일 1개만 비밀번호로 들어오게 한다. 새 가입은 없다

1. 입구 → 단계 → 분기

입구 A · ChatGPT 연결심사자가 ChatGPT 에서 앱 연결 → rawdoc /oauth2/authorize → 로그아웃 상태라 /login?oauth_query=…
→
로그인 화면Google·GitHub 버튼 아래 접힌 <details> 「이메일로 로그인 (시험 계정)」. 스크립트 없음 그대로
→
펼침 → 이메일·비밀번호 입력 → 로그인POST 로 서버가 확인. 허용 목록 이메일 + 비밀번호 일치면 세션 생성
→
복귀oauth_query 가 있으면 동의 화면(F-4010) → 허용 → ChatGPT. 없으면 앱(/?app=1 또는 return 해시)
입구 B · 웹 /login 직접같은 화면, 같은 폼. 복귀만 앱으로
오류: 틀린 이메일·비밀번호같은 화면 + 오류 줄 하나. 「이메일 또는 비밀번호가 맞지 않습니다.」 — 허용 목록에 없는 이메일인지 비밀번호가 틀렸는지 구분하지 않는다
오류: 너무 많이 시도같은 IP·같은 이메일 실패가 상한을 넘으면 잠시 막음 + 안내 줄
기능 꺼짐비밀(허용 이메일·비밀번호 해시)이 없으면 접힌 영역 자체를 그리지 않고, POST 도 404
