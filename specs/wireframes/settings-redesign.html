결정할 것

  1. 방향세 안 중 하나, 또는 조합(예: C의 행 문법 + A의 세로 목록, B의 검색을 A·C에 얹기).
  2. 단계 수보이는 단계가 9묶음 1단(A·B) / 5상위 → 9묶음 2단(C) 중 무엇인가. 상위 5개(모양·문서·도구·데이터·계정) 이름을 화면에 쓸지.
  3. 줄 번호“화면”(보이느냐)인가 “쓰기·읽기”(편집 동작)인가. 이 페이지는 화면에 둠.
  4. 기본 뷰·새 문서 템플릿“시작·새 문서”로 옮기는 데 동의하는지. 달력 문서 템플릿은 달력 옆(오른쪽 패널)에 그대로 둠 — 템플릿이 두 곳에 나뉘는 것을 받아들일지.
  5. 연결된 앱독립 묶음을 없애고 계정 › 연결 안에 GitHub와 나란히 두는 것.
  6. 칸반독립 묶음(지금 2항목)으로 둘지, 오른쪽 패널과 함께 “도구”로만 보일지. `칸반 설정…` 진입 시 강조 방식(A 페이지 열기 / B 스크롤+깜빡임 / C 도구 탭+스크롤).
  7. 로그아웃 상태계정 묶음을 통째로 숨길지, “로그인하면 알림·GitHub·연결된 앱을 쓸 수 있습니다” 자리 + 로그인 버튼을 둘지. 금고 미지원도 숨김/안내 중 택일.
  8. 사용자 CSS모양 아래 독립 묶음 유지 vs 화면 묶음 맨 아래 “사용자 CSS (5개 켜짐) ›” 한 줄 + 별도 화면.
  9. 소개·후원·닫기아래 고정 줄(C) / 왼쪽 목록 아래(A) / 스크롤 끝(B). 닫기 버튼을 ✕ 하나로 줄여도 되는지.
  10. 휴대폰 규칙B를 고르면 “≤600px: 목록 → 항목 페이지” 규칙을 “한 장 스크롤 + 칩” 으로 바꿔야 함. C는 “상단 탭 5개”로 바꿈. A만 규칙 그대로.
  11. 저장 방식모든 안은 바꾸는 즉시 저장(저장 버튼 없음)을 전제로 그림. 맞는지.
  12. 문구 미정위키링크 미리보기·기본 뷰의 실제 선택지, 댓글창 안내문, 할 일 표시 예시값은 현행 문구로 채워야 함(여기선 자리만).

  1. 왼쪽 목록에 9묶음을 상위 이름(작은 회색 글자) 아래 늘어놓아 “어디 있나”를 늘 보여 줌.

B안 · 검색 + 한 장 스크롤

탭 없이 전부 한 스크롤, 묶음 제목이 위에 붙어 따라오고 칩 줄·검색으로 건너뜀

묶음·간격·밀도를 이렇게 풀었다

  1. 탭을 없애고 9묶음을 한 스크롤에 차례로. 묶음 제목은 위에 달라붙고(sticky) 위쪽 칩 줄로 바로 건너뜀.
  2. 행은 왼쪽 190px 라벨 칸 | 오른쪽 컨트롤 칸 격자 — 세로 줄이 맞아 밀도를 높여도 읽힘. 묶음 사이는 굵은 선 + 48px.
  3. 검색하면 일치 행만 “상위 › 묶음” 경로와 함께 남고 그 자리에서 바로 바꿀 수 있음.

장점

  • 클릭 없이 전부 훑음, 짧은 묶음도 어색하지 않음
  • 검색이 “어느 탭이지?” 문제를 없앰
  • 묶음 개수가 늘어도 구조가 안 깨짐

단점

  • 길다(데스크톱 스크롤 약 4~5화면)
  • 계정 삭제 같은 위험 버튼이 일반 설정과 한 흐름에 섞임
  • 휴대폰 “목록 → 페이지” 규칙을 바꿔야 함
  • 검색 기능을 새로 만들어야 함

데스크톱 760 × 680 — 안쪽을 스크롤하거나 칩을 눌러 이동, 묶음 제목이 위에 붙음

템플릿에서 만들기
못 찾으면: “‘…’에 맞는 설정이 없습니다.” + 묶음 칩 그대로

B안은 위 데스크톱 대화상자 하나에 9묶음이 전부 들어 있음(안쪽 스크롤).

C안 · 상단 탭 5개 + 행 목록

위 탭은 상위 5개(모양·문서·도구·데이터·계정), 탭 안은 둥근 상자 행 목록(라벨 왼쪽·컨트롤 오른쪽 끝)

묶음·간격·밀도를 이렇게 풀었다

  1. 위 탭을 상위 5개로 줄이고, 탭 안은 묶음 제목 → 소묶음별 둥근 상자. 상자 하나가 곧 묶음 경계.
  2. 행 = 설정 1개: 라벨·설명 왼쪽, 컨트롤 오른쪽 끝 정렬, 행 사이 가는 선. 높이 일정해 밀도 높고 정돈됨.
  3. 라디오·체크 묶음·목록처럼 긴 컨트롤만 행 안에서 라벨 아래로 내려감. 아래 고정 줄에 소개·후원·닫기.

장점

  • 밀도 높고 정돈(시스템 설정 앱 문법)
  • 탭 5개라 폭이 남고 휴대폰 위에도 들어감
  • 한 탭 안 두 묶음이 왜 같이 있는지 상위 이름이 설명해 줌

단점

  • 9묶음 이름이 탭에 안 보여 2단계로 찾음
  • 사용자 CSS·연결된 앱 같은 긴 목록은 행 문법과 덜 맞음
  • 휴대폰 탭 글자가 작고 5개가 빠듯함
  • `칸반 설정…`은 도구 탭 + 스크롤 위치 맞추기가 필요
