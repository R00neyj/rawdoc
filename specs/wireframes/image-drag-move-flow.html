정할 것 (기본값 제안)

  1. PC 시작 조건 — 그냥 누르고 끌기(제안, 클릭과는 4px 이상 움직임으로 구분) / PC 도 꾹 누르기
  2. 놓을 수 있는 곳 — 블록 사이(줄 사이)만(제안) / 문장 중간 글자 사이도
  3. 휴대폰 꾹 누르기와 기존 길게 누르기(글자 선택·메뉴) — 이미지 위에서는 끌기가 우선(제안)
  4. 보기 모드 — 끌기 없음(제안, 편집 모드만)
