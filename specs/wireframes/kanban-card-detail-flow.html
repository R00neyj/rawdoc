칸반 카드 세부사항 — 보드에서 쓰기 · 불릿 표시

요청: "칸반 체크카드 아닐때 - 내용 /     - 내용 세부사항 이런식으로 작성이 안됨" · "세부사항 작성하려면 원문 편집으로 넘어가야함. 렌더는 불릿포인트 안되는거 빼고는 괜찮음" → 여러 줄 입력칸 선택
지금: F-2141 "하위 줄은 보드에서 고치지 않는다", F-2140 하위 줄은 "글자 그대로" 표시. 이 두 줄을 바꾸는 small change

1. 들어가기 — 지금과 같은 입구

카드 더블클릭 · 포커스 후 Enter / F2카드 우클릭 → 고치기
칸 아래 + 카드 추가
여러 줄 입력칸 (BoardInput, 한 줄 제한 해제)첫 줄 = 카드 글자, 둘째 줄부터 = 세부사항(들여쓰기 뗀 모양)

2. 입력칸 안 키

내용 - 내용 세부사항 - ▏

Shift+Enter줄바꿈. 지금 줄이 - 로 시작하면 다음 줄도 - 로 이어 줌(빈 항목에서 한 번 더 누르면 - 지움)

3. 저장 — 원문에 쓰는 모양

첫 줄이 비었나?
비었음

5. 정할 것

#질문추천다른 길
①새로 쓰는 세부 줄 들여쓰기카드에 이미 하위 줄이 있으면 그 들여쓰기 유지, 없으면 편집기 설정 들여쓰기(2·4칸)를 따름늘 4칸 고정
②입력칸 안 Tab세부 줄에서 Tab = 그 줄 한 단계 들여쓰기, Shift+Tab = 내어쓰기. 첫 줄(카드 글자)에서는 지금처럼 포커스 이동늘 포커스 이동(들여쓰기는 공백 직접 입력)
③세부의 - [ ] 줄 표시불릿 대신 누를 수 없는 체크 표시(☐/☑). 체크 켜고 끄기는 원문·입력칸에서다른 불릿과 똑같이 • 로
