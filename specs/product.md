# Rawdoc 전체 기능명세

작성일: 2026-09-13
상태: **초안 — 사람 승인 전.** 9장 결정됨 표 참고 (2026-09-13~14). 남은 미결은 Q5 인증, Q6 문서 크기 상한, Q14 제품명·메인 컬러

> 이 문서가 구현의 상위 원본이다. 여기 없는 기능은 만들지 않는다
> 작은 명세(`specs/features/F-xxx.md`)는 이 문서의 기능 ID 하나를 풀어 쓴 것이다

## 1. 제품 정의

소규모 개발팀용 원문 보존형 마크다운 협업 에디터

- **핵심 주장:** 입력한 마크다운 기호가 변환되지 않고 남는다. `.md` 로 내보내면 사용자가 친 원문과 바이트가 같다
- **편집 화면:** 옵시디언식 라이브 프리뷰 — 커서가 있는 줄(블록)은 원문, 나머지는 렌더링된 모습
- **차별화 축** (`docs/research.html` 5장):
  1. 한국어 — UI, 문서, 지원
  2. 데이터 위치 — 국내 리전 또는 자체 호스팅
  3. 댓글 앵커 정확도 — 줄 번호가 아니라 텍스트 내용에 붙는 앵커
- **직접 경쟁:** HackMD, HedgeDoc. 원문 보존 자체는 신규 컨셉이 아니다 (`docs/research.html` 1·2장)

## 3. 단계 구성

| 단계 | 목표 | 끝나면 되는 것 |
| --- | --- | --- |
| **M1** | 로컬 단일 사용자 에디터 | 브라우저 하나에서 여러 문서를 라이브 프리뷰로 쓰고, 새로고침해도 남고, `.md` 로 뽑거나 들여올 수 있다. 앱으로 설치해 오프라인에서도 같은 기능을 쓴다 |
| M2 | 백엔드와 계정 | 로그인하고, 문서가 서버에 저장되어 다른 기기에서 열린다 |
| M3 | 실시간 협업 | 같은 문서를 여러 명이 동시에 편집하고 서로의 접속·커서가 보인다 |
| M4 | 댓글 | 텍스트 내용에 붙는 댓글을 달고 해결·삭제할 수 있다 |
| M5 | 이미지 | 이미지를 올려 문서에 넣을 수 있다 |

- 단계는 순서대로 진행한다. 앞 단계가 끝나기 전에 다음 단계의 의존성을 설치하지 않는다
- **이번에 작은 명세로 쪼갤 대상은 M1 뿐이다.** M2 이후는 방향만 적고, 착수 시점에 이 문서를 먼저 고친다

### 4.4 PWA

2026-09-13 사용자 요구: "PWA 기능이 완벽해야 함". M1 은 서버를 쓰지 않으므로 **첫 방문 이후 네트워크 없이 모든 기능이 동작하는 것**을 기준으로 삼는다. 범위는 F-115~F-119 전부 (Q12)

| ID | 기능 | 내용 |
| --- | --- | --- |
| F-115 | 설치 | 웹 앱 매니페스트(이름, 짧은 이름, 아이콘 192·512px + maskable, `start_url`, `display: standalone`, 테마·배경색). 브라우저가 설치 가능하다고 알리면 앱 안에 `앱 설치` 버튼 표시 (`beforeinstallprompt`, Chromium 계열만 지원). Chrome 은 HTTPS, 매니페스트 필수 필드(`name` 또는 `short_name`, 192·512px 아이콘, `start_url`, `display`), 페이지 클릭 1회 이상·30초 이상 체류를 만족해야 이 신호를 보낸다 |
| F-116 | 오프라인 | 서비스 워커가 앱 전체(HTML·JS·CSS·폰트·아이콘)를 미리 캐시. 첫 방문 이후 네트워크 없이 실행·편집·저장·가져오기·내보내기 전부 동작. 외부 CDN 리소스 금지 |
| F-117 | 업데이트 | 새 버전이 준비되면 알림 띠로 알리고 사용자가 누를 때 적용. 적용 전 저장 대기 입력을 먼저 저장. **자동 강제 새로고침 금지** (편집 중 입력 손실 방지) |
| F-118 | 저장소 영속화 | `navigator.storage.persist()` 로 브라우저가 IndexedDB 를 임의로 지우지 않게 요청. 거절되면 내보내기로 백업하라고 1회 안내 |
| F-119 | 파일 열기 연동 | 설치된 앱을 OS 의 `.md` 파일 열기 대상으로 등록(`file_handlers` + `launchQueue`). 열린 파일은 F-114 가져오기 흐름을 탄다. **실험적 기능이며 데스크톱 Chrome·Edge 중심으로 지원** (MDN) |

- 오프라인 상태 표시는 두지 않는다. M1 은 네트워크를 쓰지 않아 온라인·오프라인 동작이 같다
- PWA 는 HTTPS 에서만 설치·서비스 워커가 동작한다(`localhost` 는 예외). 그래서 M1 도 배포한다 (F-120)

### 4.5 M1 에서 하지 않는 것

- 분할 보기(원문 | 미리보기 두 칸) — 라이브 프리뷰와 원문 모드 토글이 대체한다 (Q3)
- 여러 파일 한 번에 가져오기, 폴더 가져오기, 드래그 앤 드롭 가져오기
- 댓글, 접속자 표시 — 프로토타입에 있는 고정 UI 는 옮기지 않는다
- 이미지 업로드. 외부 URL 이미지 문법(`![]()`)은 원문으로만 둔다
- 수식(KaTeX), 다이어그램(Mermaid·PlantUML), 발표 모드, 각주
- 검색, 태그, 휴지통, 버전 히스토리 (폴더는 1차 수정으로 M1 에 넣음, F-126)
- 다크 모드
- 모바일 레이아웃, 그리고 모바일에서만 두는 문법 삽입 툴바(F-108: 제목, 굵게, 기울임, 취소선, 인라인코드, 목록, 체크박스, 인용, 링크, 표, 코드블록 텍스트 삽입) (Q15)

## 5. M1 데이터 모델

```
Document
  id         string   // 생성 시 발급, 변하지 않음
  title      string   // 비면 "제목 없는 문서"
  content    string   // 마크다운 원문 그대로 (줄은 lineEnding 으로 이음)
  lineEnding "crlf" | "lf"  // 새 문서는 "crlf". 가져온 파일은 원래 형식 (Q9)
  createdAt  number   // epoch ms
  updatedAt  number   // epoch ms
```

- 편집 중인 문서의 원본은 CM6 `EditorState` 다. IndexedDB 기록은 **`EditorState` → 저장소 단방향 스냅샷**이며, 편집 중에 저장소나 React 상태에서 에디터로 역방향 동기화하지 않는다
- 저장소에서 에디터로 읽는 것은 문서를 여는 시점 1회뿐이다
- 스키마 버전을 DB 에 기록한다. M2 이관 때 필요하다

## 7. M2 이후 방향

착수 전 이 장을 풀어 4장 형식으로 다시 쓴다

### M2 백엔드와 계정

- Cloudflare Workers(static assets)로 프론트·API 통합 배포. `wrangler deploy` 한 번에 나간다
- 메타 DB D1, 문서 원문 저장 위치는 착수 시 결정
- 인증 방식 미정 (9장 Q5). Worker 에서 OAuth + JWT 직접 구현 또는 인증만 외부 서비스
- 로컬(IndexedDB) 문서를 계정으로 옮기는 흐름
- **읽기 전용 공유 링크** (Q10) — 링크를 받은 사람은 문서를 렌더링된 상태로 보기만 한다. 편집 UI 없음. 로그인 없이 볼 수 있는지는 착수 시 결정
- 주의: Workers 는 `node_modules`·`.git` 을 자동 제외하지 않는다 → `.assetsignore` 필요 (`docs/research.html` 8장)

### M3 실시간 협업

- 문서당 Durable Object 1개, `y-partyserver`, 클라이언트 `y-codemirror.next`
- 접속자 목록·원격 커서
- **WebSocket Hibernation API 필수.** 안 쓰면 탭을 열어둔 시간 전체가 과금된다 (`docs/research.html` 7장)
- 5장의 "원본은 `EditorState` 하나" 불변조건은 M3 에서 Yjs 문서와의 관계로 다시 정의해야 한다

### M4 댓글

- 앵커는 줄 번호가 아니라 Yjs `RelativePosition` 기반. 위에 줄을 추가해도 댓글이 원래 텍스트를 가리킨다
- 선택 영역에 댓글 달기, 해결/다시 열기, 삭제, 거터 표시, 댓글에서 본문 위치로 이동 (`docs/prototype.html` 기능 기준)

### M5 이미지

- R2 업로드, 장당 크기 상한
- **핫링크 차단(서명 URL 또는 Referer 제한) 필수.** R2 는 이그레스가 무료라 무료 계정이 외부 이미지 CDN 으로 악용될 수 있다 (`docs/research.html` 5장)
