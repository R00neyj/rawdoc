# F-229 좁은 화면 목차 버튼

작성일: 2026-09-15
상태: 사용자 요청(2026-09-15 "모바일에서도 인덱스 보이도록"). 모바일 전용 배치는 여전히 범위 밖이고, 오른쪽 여백이 모자라 F-144 목차가 숨는 경우만 고친다(F-216·F-227 과 같은 예외)
근거: `specs/features/F-144.md` 2장("좁으면 숨긴다")을 이 명세가 바꾼다. `specs/ia.md` 3.23

## 2. 동작

### 2.1 언제
- F-144 목차가 보일 조건에서 **오른쪽 여백만 56px 미만**이면(창 폭·터치 여부와 무관) 선 목차 대신 목차 버튼을 보인다
- 제목이 없거나 빈 상태·해시 공유 화면(S-4)이면 버튼도 없다 (F-144 3.1 그대로)
- 여백이 56px 이상이면 지금의 선 목차 그대로. 창 크기가 바뀌면 즉시 바뀐다

### 2.2 버튼
- `.content-area` 오른쪽 위에 떠 있는 둥근 버튼: 오른쪽 16px, 위 12px (상단바·알림 띠 바로 아래, 2026-09-15 사용자 "인덱스는 우측 상단에 보이면 될거같아"). 크기 40×40, 터치 기기(`pointer: coarse`) 44×44. 스크롤해도 제자리
- 아이콘 Material Symbols `toc` 20px, 색 `--ink-2`. 바탕 `--panel`, 1px `--rule`, 원형, 그림자는 목록 카드와 같은 규칙(겹쳐 뜨는 것 — `specs/design.md` 경계 규칙)
- `<button type="button" aria-label="목차" aria-expanded aria-controls={카드 id}>`. 호버 `--rule-2` 바탕, 누름 표시는 `aria-expanded="true"` 일 때 F-153 선택 바탕
- 편집 영역 여백은 바꾸지 않는다. 버튼이 첫 줄 오른쪽 끝을 가리는 정도는 사람 확인 A9 에서 판단

### 2.3 목록 카드
- 버튼을 누르면 버튼 아래 8px 에 F-144 목록 카드가 열린다: 오른쪽 끝을 버튼과 맞추고 위에서 아래로 자란다. 폭 `min(280px, .content-area 폭 - 32px)`, 최대 높이 `min(60vh, .content-area 높이 - 80px)`, 넘치면 카드 안 스크롤
- 항목 모양·들여쓰기·현재 위치 강조·`aria-current` 는 F-144 2장·3.5 그대로
- 열릴 때 현재 위치 항목이 카드 안에 보이도록 카드만 스크롤한다(`block: 'nearest'`)
- 움직임: F-228 튀어나오는 움직임(`--ease-pop`, 기준점 오른쪽 위), 닫힘은 `--ease-out` 투명도만. 움직임 줄이기면 0ms

### 2.4 닫기
- 항목을 누르면 F-144 3.3 대로 스크롤만 하고 카드를 닫는다. 포커스는 버튼으로 돌아가지 않는다(편집 영역 포커스·커서 그대로)
- 버튼 다시 누름, 카드·버튼 밖을 누름(`pointerdown`), Esc 로 닫는다. Esc 로 닫으면 포커스는 버튼으로
- 호버로 열고 닫지 않는다(여백 부족 모드에서는 F-144 의 마우스 올림 펼침·150ms 접힘을 쓰지 않음)
- 사이드바가 겹쳐 열리거나(F-172) 대화상자가 열리면 닫는다

### 2.5 키보드
- Tab 으로 버튼에 온다. Enter·Space 로 열면 포커스를 현재 위치 항목으로 옮긴다. 항목 사이는 Tab. 카드 밖으로 Tab 이 나가면 닫는다
