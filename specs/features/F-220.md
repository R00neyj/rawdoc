## 2. 요구사항

### 2.1 축소 규칙
- 대상: PNG·JPEG·WebP. **GIF 는 건드리지 않는다**(움직임 보존)
- 긴 변이 **2000px** 넘으면 비율 유지로 긴 변 2000px 에 맞춘다(`fitWithin`, 정수 반올림, 짧은 변 최소 1). `imageSmoothingQuality = 'high'`
- 인코딩: `image/webp` 품질 0.85
- 줄이지 않은 이미지(긴 변 ≤ 2000)도 WebP 로 인코딩해 보고, **원본보다 작을 때만** 쓴다. 줄인 이미지는 크기와 무관하게 결과를 쓴다
- 결과가 쓰이면 `mime`·`ext`·`width`·`height` 를 결과 값으로 저장·원문 블록 `width` 계산에 쓴다
- 캔버스·인코딩 실패(브라우저 미지원 등)면 원본 그대로(아래 크기 제한은 적용)

### 2.2 크기 제한 순서 (attachImages)
1. 파일 크기 **20MB** 초과 → `이미지는 한 장에 20MB 까지 넣을 수 있습니다.`
2. 형식 검사·가로세로 10000px·넓이 4000만 픽셀 검사 (그대로)
3. 2.1 축소
4. 결과 크기 5MB 초과 → GIF 면 `GIF 는 한 장에 5MB 까지 넣을 수 있습니다.`, 그 외 `이미지는 줄인 뒤에도 5MB 를 넘어 넣지 못했습니다.`
- 로그인 여부(IndexedDB·서버 저장소)와 무관하게 같은 규칙

### 2.3 serverStore
- `putAttachment` 는 `ext === 'gif' || ext === 'webp'` 면 `toWebp` 를 건너뛴다(이중 인코딩 방지). 그 외 동작 그대로
