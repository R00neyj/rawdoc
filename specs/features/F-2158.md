# F-2158 최근 파일
상태: 승인(2026-10-21, 상시 지시 "열린 질문이 기본값이면 바로 구현" — 별도 검토 없음, Q1 기본값). F-2154 7장 마지막 자식 — 5장 `최근 파일` 행(원본) + 3장 권한(최근 파일 클릭). F-2155 5장 계약(`subscribeOpened`·`openLocalFile`)만 쓰고 `useLocalFile.ts`·`fileSystemAccess.ts` 는 안 고친다. 흐름 [`F-2154-flow.html`](../wireframes/F-2154-flow.html) 1장 `최근 파일` 갈래. `App.tsx 증가 허용` 없음(예상 +4)

## 근거 (2026-10-21 HEAD, 이름으로 찾는다)
- IndexedDB 는 `idb` `openDB`. 연결을 열고 닫는 짧은 함수 선례 `yjsStore.ts` `deleteYjsUserRows`. handle 저장 선례 `idbStore.ts` `linkFileHandle`(`fileHandles` 스토어), 같음 판정 `findDocByFileHandle` 의 `isSameEntry`(던지면 다름)
- 단위 테스트는 `fake-indexeddb/auto`. Node `structuredClone` 은 handle 을 모르니 `vi.stubGlobal('structuredClone', v => v)` 로 가짜 handle 을 넣는다(`idbStore.test.ts` "OS 파일 열기 재중복 방지")
- **실측(설치 Chrome, Playwright, `localhost`)**: `navigator.storage.getDirectory()`(OPFS)의 `FileSystemFileHandle` 은 IndexedDB 에 넣고 새로고침 뒤 꺼내도 `FileSystemFileHandle`, 새로 얻은 handle 과 `isSameEntry` 참, `getFile()` 원문 그대로, `queryPermission({ mode: 'readwrite' })` = `granted`. `removeEntry` 뒤 `getFile()` = `NotFoundError`. → e2e 는 가짜 picker 가 OPFS handle 을 돌려준다. 반면 F-2155 e2e 의 평범한 가짜 객체(함수 포함)는 IndexedDB 에 못 들어간다(`DataCloneError`)
- F-2155 3장 `openLocalFile` 은 ② `getFile()` → ③ 쓰기 권한 순서. 앱을 다시 연 뒤 저장한 handle 은 읽기 권한도 `prompt` 라 ②가 `NotAllowedError` → `'error'` + `열지 못했습니다` 가 난다 → 권한은 F-2158 이 먼저 받는다(3장)
- 홈 `EmptyState.tsx` `최근 문서` 절(`.empty-state-recent-*`, `formatDate`), `AppScreens.tsx` 가 props 를 넘김. 팔레트는 정적 `PALETTE_COMMANDS` 를 `CommandPalette.tsx` 가 `visibleCommands(PALETTE_COMMANDS, context)` 로 거르고, 고정·최근 기억은 `KNOWN_COMMAND_IDS` 로 거른다

## 2. 저장 (`md-files`)
```ts
export const RECENT_FILES_DB = 'md-files' // 버전 1, 스토어 'recent' keyPath 'id', 색인 없음
export type RecentFileRow = { id: string; handle: FileSystemFileHandle; name: string; openedAt: number } // architecture 2장 그대로
export type RecentFileItem = { id: string; name: string; openedAt: number }
export function planRecentAdd(rows: readonly RecentFileRow[], entry: Omit<RecentFileRow, 'id'>, sameId: string | null, newId: string): { put: RecentFileRow; remove: string[] }
export type RecentFilesStore = { list(): Promise<RecentFileRow[]>; add(handle: FileSystemFileHandle, name: string, now: number): Promise<RecentFileRow[]>; remove(id: string): Promise<RecentFileRow[]> }
export function createRecentFilesStore(dbName?: string): RecentFilesStore
```
- `planRecentAdd`: `sameId` 가 있으면 그 `id` 를 살려 handle·name·openedAt 을 새 값으로(맨 위로), 없으면 `newId`(`crypto.randomUUID()`). 넣은 뒤 `sortRecentFiles`(openedAt 내림차순, 같으면 id) 로 11번째부터 `remove`
- `add`: 행 전부 읽고 연결 닫음 → 트랜잭션 **밖에서** 각 행 `isSameEntry(handle)`(던지면 다름, IndexedDB 밖 await 는 트랜잭션을 끝내버린다) → `planRecentAdd` → 새 readwrite 트랜잭션 하나로 put·delete. 같은 탭 안 `add`·`remove` 는 Promise 사슬로 하나씩. 돌려주는 값은 정렬된 새 목록
- 매 호출 `openDB` → 일 → `close()`(10행이라 연결을 쥐지 않는다 — 버전 충돌·`blocking` 처리 불필요). 로그아웃·계정 전환·저장소 종류와 무관, 지우는 길은 `목록에서 빼기`·없어진 파일·10개 넘침뿐. 본문은 담지 않는다

## 3. 훅 (`useRecentFiles`)
```ts
export function useRecentFiles(o: { localFile: UseLocalFileResult; showNotice: (n: NoticeWithAction) => number }): { files: readonly RecentFileItem[]; open(id: string): Promise<void>; remove(id: string): Promise<void> }
```
- `localFileSupported()` 가 거짓이면 DB 를 열지 않고 `files` 는 늘 `[]`, 구독도 안 한다 → 절·명령이 없다(4·5장)
- 불러오기: 마운트 때 한 번 + 창 `focus` 때(다른 탭이 연 파일 반영). handle 은 훅 안 ref 에 두고 `files` 에는 `id`·`name`·`openedAt` 만
- **목록에 더하는 길은 `subscribeOpened` 하나** — `파일 열기…`·OS launch `edit`(F-2156)·최근 파일 모두 F-2155 ④에서 열림 구독자를 부른다. `'same'` 은 구독자를 안 불러 순서가 그대로다. `add` 실패(`DataCloneError`·IndexedDB 사용 불가)는 조용히 무시 — 열기는 이미 끝났다
- `open(id)` 순서 (클릭·팔레트 실행 = 사용자 동작 안, ref 의 handle 로 곧바로 — 앞에 IndexedDB 를 읽지 않는다):
  ① `await ensureWritePermission(handle, { gesture: true })` — 결과는 버린다. readwrite 허용은 읽기도 연다(Chrome 복원 창에 읽기만 허용 선택지는 없다) ② `const r = await localFile.openLocalFile(handle, { gesture: true })` — 이미 허용이면 F-2155 ③은 묻지 않는다 ③ `r === 'missing'` 이면 `remove(id)` + 알림(info) `"{파일명}" 을(를) 찾을 수 없어 목록에서 뺐습니다.` ④ 그 밖(`'opened'`·`'same'`·`'error'`·`'not-utf8'`)은 F-2155 가 알림·화면을 맡고 행은 그대로
  - 거절하면 ②의 `getFile()` 이 `NotAllowedError` → F-2155 `'error'`(`"{파일명}" 을(를) 열지 못했습니다.`), 행은 남는다 — 다음에 다시 물을 수 있게
- `remove(id)`: 행만 지운다(파일은 그대로), 확인 없음, 되돌리기 없음

## 5. 팔레트
- `PaletteContext.recentFiles?: { items: readonly RecentFileItem[]; open: (id: string) => void }` — `useCommandPalette` 가 `files.length > 0` 일 때만 넣고, `open` 은 `runAfterPaletteClose(() => void open(id))`
- `paletteCommands.ts` `recentFileCommands(ctx): PaletteActionCommand[]` — 행마다 `{ id: 'recentFile:' + item.id, kind: 'action', label: '최근 파일: ' + name, keywords: ['최근 파일', '파일', '컴퓨터', '로컬', 'recent', 'file', 'local'], when: () => true }`. `CommandPalette.tsx` 는 `visibleCommands([...PALETTE_COMMANDS, ...recentFileCommands(context)], context)` — 정적 명령 뒤라 빈 입력에선 `명령` 구역 끝, 입력이 있으면 파일명·`최근 파일` 로 찾힌다. 모든 화면(`doc`·`home`·`file` 등)에서 보인다
