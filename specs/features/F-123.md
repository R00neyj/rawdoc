# F-123 보기 모드

작성일: 2026-09-14
상태: 사용자 1차 수정사항(2026-09-14) 2번. C2 묶음 (F-124 와 병렬)
근거: 사용자 요청 "탭에 보기 뷰 새로 만들어야함, 편집 안되고 보기만 가능한 모드". 방식은 사용자 선택 "HTML 변환" (`specs/product.md` Q17). `specs/ia.md` 3.9·3.16, `specs/architecture.md` 1장

## 3. 요구사항

### 3.1 모드
- 상단바 세그먼트 `편집` / `원문` / `보기` 3버튼. `aria-pressed`
- `md.viewMode` 값에 `view` 추가 (`live` \| `raw` \| `view`). 다음 실행에도 쓴다
- S-2 빈 상태에서는 세그먼트 비활성 (기존과 같음)

### 3.2 변환 규칙 (`renderMarkdown(text) → string`)
- `new MarkdownIt({ html: false, linkify: true, typographer: false, breaks: false })`
  - `breaks: false`: 문단 안 줄바꿈 1개는 공백으로 이어 붙인다. GitHub 의 `.md` 파일 표시와 같다
- 기본으로 켜진 표(GFM table)·취소선을 쓴다
- **작업 목록**: 목록 항목의 첫 인라인 텍스트가 `[ ] ` 또는 `[x] `/`[X] ` 로 시작하면 그 3글자를 떼고 `<input type="checkbox" disabled>`(체크면 `checked`)를 앞에 넣는다. `<li>` 에 `class="task-list-item"`, 부모 목록에 `class="contains-task-list"` (github-markdown-css 가 이 클래스로 모양을 잡는다)
- **링크**: `<a>` 에 `target="_blank" rel="noopener noreferrer"`
- **이미지**: M5 이미지 기능 전까지 `<img>` 를 만들지 않는다. 외부 주소 요청을 만들지 않기 위해서다(오프라인 원칙, F-116). 대신 `<a href="{src}" target="_blank" rel="noopener noreferrer">이미지: {alt}</a>` 로 출력한다. `alt` 가 비면 `이미지`
  - 2026-09-14 변경: 로컬 첨부 이미지 블록(`attachments/…`)만 **F-158** 이 `<img>`(저장소 blob URL)로 그린다. 외부 주소 이미지는 이 규칙 그대로
- **코드블록**: `<pre><code class="language-{info 첫 단어}">`. 구문 강조 없음
- 원문 HTML 태그는 글자 그대로 보인다 (`html: false`). GitHub 는 일부 HTML 을 렌더하므로 이 점이 다르다
- 제목에 앵커(`id`)를 붙이지 않는다

### 3.3 화면
- 보기 모드면 편집 영역 자리에 `Viewer` 를 그리고 `Editor` 는 **언마운트하지 않고 숨긴다**. 편집 모드로 돌아왔을 때 커서·스크롤·실행 취소 기록이 남아야 한다 (ia.md 3.9)
- 변환 입력은 `editorRef.current.getText('lf')` 다. 저장소 값이나 React state 에 본문 사본을 두지 않는다 (CLAUDE.md 불변조건)
  - 변환 시점: 보기 모드로 전환할 때, 보기 모드에서 문서를 열 때(Editor 마운트 직후)
  - 보기 모드에서는 문서가 바뀌지 않으므로 그 사이 다시 변환하지 않는다
- 보기 모드에서 편집 불가: 에디터가 숨겨져 입력·단축키가 닿지 않는다. 상단바 제목 입력은 `readOnly`
- `Viewer` 는 세로 스크롤 영역, `tabIndex=0` 으로 키보드 스크롤 가능. 모드 전환 시 스크롤은 맨 위
- 보기 모드에서 `새 문서` 를 누르면 편집 모드로 바꾼 뒤 3.3 새 문서 흐름을 탄다 (제목 입력이 필요하므로). 문서 전환·가져오기·삭제는 보기 모드를 유지한다
- `.md 내보내기` 는 보기 모드에서도 동작한다
- 상태바: 보기 모드에서 `줄 N, 열 N` 을 숨기고 글자 수·단어 수·저장 상태는 표시

### 3.4 배치 (`viewer.css`)
- 편집 영역과 같은 가운데 정렬, 최대 너비 `--content-max`, 좌우 안쪽 여백 32px, 위아래 24px
- 바탕 `--panel`
