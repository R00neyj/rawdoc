# F-162 표 칸 안 줄바꿈 (Alt+Enter → `<br>`)

작성일: 2026-09-14

## 2. 요구사항

### 2.1 입력
- 칸 편집 중 **Alt+Enter** 를 누르면 하위 에디터 선택 자리에 `<br>` 5글자를 넣는다. 주 문서에는 기존 칸 편집 트랜잭션(`input.table`)으로 간다. Ctrl+Z 한 번에 되돌아간다
- 조합 중에는 가로채지 않는다 (F-161 3.2)
- Enter·Shift+Enter 등 다른 키 동작은 F-125 2.3·F-140 3.5 그대로
- 붙여넣기 줄바꿈 → 공백 1개 규칙(F-125 2.2)은 그대로

### 2.2 편집 모드 표시
- 편집 중인 칸(하위 에디터)은 원문 그대로 `<br>` 글자가 보인다
- 편집 중이 아닌 칸은 `<br>`, `<br/>`, `<br />`(대소문자 무시) 자리에서 줄을 바꿔 보인다. 칸 높이는 줄 수만큼 늘고 표 아래 줄 클릭 위치 규칙(F-124 3.4)을 지킨다
- 그 밖의 HTML 태그는 지금처럼 글자 그대로. `innerHTML` 을 쓰지 않는다 (F-140 3.2 보안) — `<br>` 조각은 `document.createElement('br')`
- 인라인코드(`` ` ``) 안의 `<br>` 은 글자 그대로

### 2.3 보기 모드·공유 화면
- 표 칸 안의 `<br>`, `<br/>`, `<br />` 만 줄바꿈 요소로 바꾼다. `html: false` 는 유지하고, 표 밖 문단의 `<br>` 과 다른 태그는 지금처럼 이스케이프된 글자
- 인라인코드 안은 바꾸지 않는다

### 2.4 원문
- 원문·`.md 내보내기`·마크다운 복사는 `<br>` 글자 그대로 (GitHub 미리보기에서 칸 안 줄바꿈으로 보인다)
