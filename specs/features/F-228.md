# F-228 툴팁·메뉴 튀어나오는 움직임

작성일: 2026-09-15
상태: 사용자 지시(2026-09-15 "툴팁 등 호버 모션 쫀득하게"). 색 전환은 F-173 결정("두 번 겹쳐 들어가는 느낌" → 튕기지 않음) 그대로 두고, 크기·위치 움직임만 더 탄력 있게
근거: F-149 2.2(툴팁 400ms 지연), F-172(메뉴·대화상자 나타남), F-173(`--ease-out`·`--ease-spring` 분리), `specs/design.md` 4장 전환 행

## 2. 요구사항

### 2.1 토큰
- `--ease-pop: cubic-bezier(0.34, 1.56, 0.64, 1)` — 끝에서 뚜렷하게 넘쳤다 돌아온다
- `--transition-pop: 240ms var(--ease-pop)`
- `--ease-spring`·`--transition-move`(F-173)는 겹침 사이드바 밀려 들어옴·알림 띠에 계속 쓴다(사이드바가 넘치면 왼쪽 끝이 벌어져 보인다)

### 2.2 툴팁 (`.icon-tooltip`, 표 `+` 툴팁)
- 나타날 때: `opacity` 0 → 1 (`--transition-fast`, 튕김 없음) + `scale` 0.9 → 1 과 버튼 쪽에서 4px 떨어진 자리 → 제자리 (`--transition-pop`). 아래 툴팁은 위로 4px 에서, `--side` 는 왼쪽 4px 에서 시작
- 가운데 정렬용 기존 `transform: translateX(-50%)` 와 겹치지 않게 움직임은 개별 속성 `scale`·`translate` 로 준다
- 원점(`transform-origin`)은 버튼 쪽 가장자리 가운데
- 나타남 지연 400ms·키보드 포커스 즉시(F-149) 그대로
- 사라질 때: 120ms `--ease-out`, 튕김 없음, 크기 그대로

### 2.3 메뉴·대화상자
- `⋯` 메뉴·공유 메뉴·계정 메뉴 목록: 열 때 위로 4px + `scale` 0.96 → 1, `--transition-pop`. 원점은 여는 버튼 쪽 위 모서리. 닫을 때 F-172 그대로(튕김 없음, 180ms)
- 대화상자: 열 때 `scale` 0.96 → 1, `--transition-pop`. 닫을 때 F-172 그대로
- 색·바탕·테두리·투명도는 계속 `--transition-fast`(F-173 A1 그대로)

### 2.4 움직임 줄이기
- `prefers-reduced-motion` 이면 `--transition-pop` 도 0ms (기존 토큰 규칙과 같음)
