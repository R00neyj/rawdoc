# F-148 콜아웃 종류 아이콘

작성일: 2026-09-14
상태: 사용자 요청(2026-09-14). **F-147 완료 후** 시작 (F-146 이 `lines.js` 를 고친다)
근거: 사용자 요청 "콜아웃 작동은 하는데 이모티콘 표시가 없음" + 종류별 예시 이모지 표(note ✏️, summary·abstract 🗒️, info ℹ️, todo ✅, tip 🔥, done·check ✔️, faq·help ❓, warning ⚠️, fail ❌, danger·error ⚡, example 🗄️ — "그냥 예시, svg 넣기 힘들어서"). F-128 은 아이콘을 정하지 않았다. 아이콘은 F-142 방식(Material Symbols)

## 1. 파일 소유

| 파일 | 변경 |
| --- | --- |
| `src/lib/calloutIcons.js`(+test) | 신규. 종류 → 아이콘 이름, 아이콘 svg 원문 (`?raw`). DOM 없음 |
| `src/editor/preview/lines.js`(+test) | 편집 모드 제목 줄 아이콘 위젯 (부분 Edit) |

- 새 의존성 없음 (`@material-symbols/svg-400` 설치됨). 의존 방향: `editor → lib`, `viewer → lib` (`specs/architecture.md` 1장)

## 2. 종류 → 아이콘 (Material Symbols Outlined 400)
종류 이름은 F-128 2.1 과 같은 규칙(대소문자 무시, 별칭 포함)으로 읽는다. 사용자 예시 이모지의 뜻을 따르고 Obsidian 기본 아이콘을 참고했다

| 종류 (별칭) | 아이콘 | 예시 |
| --- | --- | --- |
| `note` | `edit` | ✏️ |
| `abstract` (`summary`, `tldr`) | `summarize` | 🗒️ |
| `info` | `info` | ℹ️ |
| `todo` | `check_circle` | ✅ |
| `tip` (`hint`, `important`) | `local_fire_department` | 🔥 |
| `success` (`check`, `done`) | `check` | ✔️ |
| `question` (`help`, `faq`) | `help` | ❓ |
| `warning` (`caution`, `attention`) | `warning` | ⚠️ |
| `failure` (`fail`, `missing`) | `close` | ❌ |
| `danger` (`error`) | `bolt` | ⚡ |
| `bug` | `bug_report` | — |
| `example` | `format_list_bulleted` | 🗄️ |
| `quote` (`cite`) | `format_quote` | — |
| 그 밖의 이름 | `edit` (note 와 같음, F-128 규칙) | — |

- 색 묶음(F-128 2.1)은 바꾸지 않는다. 아이콘 색은 그 콜아웃의 `--callout-color`
- `calloutIcons.js`: `calloutIconName(type) → string`, `calloutIconSvg(type) → string`(svg 원문). 쓰는 13개 파일만 import 해 번들에 넣는다

## 3. 모양
- 제목 앞에 아이콘 18px, 아이콘과 제목(또는 `[!type]` 글자) 사이 8px, 세로 가운데. `fill: currentColor`, 색 `var(--callout-color)`
- 제목이 없는 콜아웃도 아이콘은 보인다

### 3.1 편집 모드
- 콜아웃 머리 줄에서 `[!type]` 바로 앞(`>` 와 공백 뒤)에 아이콘 위젯(`Decoration.widget`, `side: -1`). 문서 내용은 바꾸지 않는다
- **활성 줄(커서·선택이 닿은 줄)에서는 아이콘을 넣지 않는다** — 원문을 고칠 때 줄 앞 위젯이 입력·커서 이동을 방해하지 않게 (F-104 기호 드러냄 규칙과 같은 결). 활성 판정은 F-146 이후 규칙(포커스 없으면 활성 줄 없음)을 그대로 쓴다
- 위젯은 클릭해도 커서 이동만 하고 다른 동작 없음. `aria-hidden`
- 원문 모드는 콜아웃 모양이 없으므로 아이콘도 없음
- 한글 조합 중 재계산 보류·따라잡기 규칙 그대로

### 3.2 보기 모드
- `p.markdown-callout-title` 맨 앞에 `<span class="markdown-callout-icon" aria-hidden="true">{svg}</span>`. svg 는 앱에 들어 있는 파일 원문이라 사용자 입력이 아니다. 제목 글자 이스케이프 규칙(F-128 4.2)은 그대로
- 공유 화면(S-4)도 같은 렌더러라 같이 보인다

## 4. 수용 기준

브라우저 확인은 5173 외 포트, `--strictPort`. 끝나면 서버 종료. 다른 에이전트가 브라우저를 쓰는 중이면 "확인 못 함"
