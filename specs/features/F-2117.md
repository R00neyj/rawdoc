# F-2117 Ctrl+S 로 지금 문서 .md 내려받기

작성일: 2026-10-03
상태: 승인(2026-10-03, 갈림길이 없어 상시 지시로 승인 처리). 사용자 요청(2026-10-03) "ctrl + s 로 로컬 md로 내보내기". 선행 개요 없음 — 작은 명세 하나. 진짜 갈림길이 없어 8장 열린 질문은 모두 기본값대로 간다
구현 담당: `feature-implementer`

## 정해진 것 (사용자 결정, 바꾸지 않는다)

1. 동작은 지금 있는 `.md` 내보내기와 **완전히 같다** — `createExportActions` 의 `handleExportDoc` 를 그대로 부른다. 바이트·파일명·zip·알림을 새로 만들지 않는다(F-112 2.2, F-158 2.3, 원문 바이트 보존)
2. 브라우저 기본 "페이지 저장" 대화상자를 막고 대신 이 동작을 한다

## 근거 (직접 읽거나 돌려 본 것, 2026-10-03 HEAD `1285c21`)

- **`Mod-s` 를 쓰는 키맵이 없다.** `node_modules/@codemirror/*/dist/index.js`·`y-codemirror.next/dist/*` 의 `key: "…"` 수식키 바인딩 전수 목록에 `Mod-s`·`Ctrl-s`·`Cmd-s` 0건(맥 전용 emacs 키맵도 `Ctrl-a/b/d/e/f/h/k/n/o/p/t/v` 뿐). `src/` 의 키맵은 `Mod-b/i/k`(`commands.ts` `shortcutKeymap`), `Mod-h`(`createEditor.ts`), `Mod-z/y/Shift-z`(`yBinding.ts` `undoKeymap`)뿐. 문서·e2e 어디에도 `Ctrl+S` 0건
- **표 칸 하위 편집기에서도 창까지 올라온다.** `tableWidget.ts` `cellKeydown` 이 `consume`(preventDefault+stopPropagation)하는 키는 Tab·Enter·Esc·화살표·`Mod-z/y/b/i/k` 뿐 — `s` 는 `return false`. 칸 입력은 `updateListener` → `pushCellEdit` 로 **입력마다** 주 문서에 들어가므로 누르는 순간의 `getText` 에 칸 글자가 들어 있다
- 앱의 다른 keydown 처리 중 Ctrl+S 를 막는 곳 없음 — `stopPropagation` 쓰는 곳(`CommentComposer`·`MentionField`·`ShortcutPanel`·`ContextMenu` 등)은 모두 Esc·Enter·방향키 조건 안이다
- `exportDoc`(`exportDoc.ts`)에 연타 막기 없음 — 부를 때마다 `downloadBlob` 한 번. 상단바 `내보내기 › .md` 도 같아서 두 번 누르면 두 번 받는다
- `handleExportDoc` 는 `currentDoc`·`openDoc`·`openDoc.id === currentDocId` 만 본다. 팔레트 `doc.exportMd` 가 보이는 조건(`useCommandPalette` 의 `paletteOutputCtx`)은 거기에 `docScreenId !== null`(부팅 끝·문서 있음·공유 링크·공유 관리·도움말·지도 아님)과 `currentDoc.e2ee !== 'locked'` 를 더한 것이다
- `getText` 는 `view.state.doc` 을 읽는다(`createEditor.ts`) — 상단바 버튼·팔레트와 같은 값
- `useShortcutUsage` 는 창 keydown **캡처** 단계에서 카탈로그와 맞춰 기록만 한다 — 이 명세의 `preventDefault` 와 서로 영향 없음
- 카탈로그는 지금 **23개(맥 22)** — `tests/src/app/shortcutCatalog.test.ts` 가 23·22 를 단언한다. F-2052 3.2·`product.md` 의 "22개(맥 21)" 는 tweak(2026-09-28 `comment.toggleRail`) 뒤 고쳐지지 않은 값이다
- 도움말 `## 단축키` 본문 **479자**, 4.3 의 줄을 더하면 **510자**. `## 내보내기·가져오기` 는 200자 → **215자**(F-2039 U1 `appSections` 방식으로 스크립트로 셈, 600자·4문단 안)

## 2. 동작

### 2.1 키 판정 (계약)

```ts
// src/app/globalShortcuts.ts
export function isExportKey(e: KeyEventLike): boolean
```

- 참: `ctrlKey || metaKey`, `shiftKey`·`altKey` 없음, `e.key.toLowerCase() === 's'`. `isPaletteKey` 와 같은 모양 — `isComposing` 은 보지 않는다(2.3)
- `Ctrl+Shift+S`·`Ctrl+Alt+S`(윈도우 AltGr 포함)는 거짓 → 브라우저 몫으로 남는다

### 2.2 어디서 무엇을 하나

창 `keydown` **버블** 단계 리스너 하나(`Ctrl+P` effect 와 같은 단계). 위에서부터 먼저 걸리는 것

| 상황 | 동작 | 이유 |
| --- | --- | --- |
| 공개 보기 S-5(`publicRoute`) | effect 를 걸지 않음 → 브라우저 기본 | F-2022 6.1 첫 행과 같다. 공개 보기는 자기 `내보내기` 버튼이 따로 있다(`PublicView.tsx`) |
| 공유 링크 화면 S-4(`sharedDocRef`) | 가로채지 않음 → 브라우저 기본 | F-2022 6.1 둘째 행과 같다. 상단바 내보내기도 이 화면에서 꺼져 있다(`AppTopBar` `exportDisabled`) |
| 키 자동 반복(`e.repeat`) | `preventDefault`, 무시 | 길게 눌러 여러 파일이 받아지지 않게 (2.4) |
| 부팅 중(`bootPhaseRef.current !== 'ready'`) | `preventDefault`, 무시 | F-2022 6.1 과 같다 |
| 대화상자가 열려 있음(`dialog[open]`, 팔레트 포함) | `preventDefault`, 무시 | 대화상자 뒤 문서를 몰래 내려받지 않는다. 다른 전역 키(`Ctrl+Alt+M`·`Ctrl+M`·판)와 같은 판정 |
| `exportMdRef.current === null` — 홈·빈 상태 S-2, 공유 관리 S-6, 도움말 S-7, 지도 S-8, 잠긴 금고 문서, 문서 전환 중(`openDoc.id !== currentDocId`) | `preventDefault`, 무시. 알림 없음 | 팔레트에서 `.md 내보내기` 가 안 보이는 곳과 정확히 같다. 앱 안에서 `Ctrl+S` 가 어떤 때는 페이지 저장 창을 여는 편이 더 놀랍다(SPA 페이지 저장은 문서를 담지 못한다) |
| 그 밖 | `preventDefault`, `exportMdRef.current()` | 편집·원문·보기 모드, 보기 권한 문서 모두 — 상단바·팔레트와 같다 |

- 포커스 위치는 보지 않는다 — 본문·표 칸·찾기 패널·제목 칸·댓글 입력·사이드바 어디서 눌러도 위 표대로다. 제목 칸은 입력마다 `docs` 에 반영돼(`useTitleCommit` `commitTitle`) 파일명이 지금 글자를 따른다
- 포커스·선택·스크롤을 바꾸지 않는다

### 2.3 IME

- `view.composing` 중이어도 **그대로 내려받는다.** CM6 은 조합 중 글자를 `state.doc` 에 이미 넣고 있어 화면에 보이는 글자가 곧 파일 글자다. 조합을 끊거나 기다리지 않는다 — 읽기만 하고 문서를 바꾸지 않으므로 IME 불변식(원격 갱신 보류·`forceRecalc` 따라잡기)과 닿지 않는다
- 한글 입력 상태에서 `Ctrl+S` 의 `e.key` 가 `'s'` 인지는 확인하지 못했다. `'ㄴ'` 으로 오면 이 판정은 거짓이고 브라우저 페이지 저장이 뜬다 — `isPaletteKey`·`isFindKey` 와 같은 성질(H189·F-2022 H5)이라 판정을 맞추고 사람 확인 6장 1번으로 둔다. `e.code === 'KeyS'` 로 바꾸지 않는 이유: 다른 자판 배열에서 브라우저 자신의 `Ctrl+S` 판정과 어긋난다

### 2.4 연타

- `e.repeat` 만 거른다. **시간 창으로 막지 않는다** — 일부러 두 번 누르면 두 번 받는다. 상단바 버튼·팔레트와 같은 성질이고, 막는 장치가 `exportDoc` 에도 없다(근거). 막으려면 세 진입점 모두에 걸어야 해서 이 명세 밖이다

### 2.5 App 배선

- `exportMdRef = useRef<(() => void) | null>(null)` 를 선언하고 `useGlobalShortcuts` 에 넘긴다
- 이미 있는 "Ctrl+P·Ctrl+Shift+/ 가 매 커밋 최신 … 을 읽게 한다" effect 안에서 `exportMdRef.current = paletteContext.output?.exportMd ?? null` — 팔레트 표시 조건을 그대로 빌려 조건식을 두 벌 두지 않는다
- `// ----- 전역 단축키 6개 …` 주석의 수를 7 로
- 옵션 타입: `exportMdRef: RefObject<(() => void) | null>` (`UseGlobalShortcutsOptions` 끝에). effect deps 는 `[publicRoute, sharedDocRef, bootPhaseRef, exportMdRef]` — ref 를 deps 에 넣는 이유는 F-2062 근거의 ESLint 실측
- 리스너 자리: 여섯째(`Ctrl+Shift+/`) effect 뒤. 앞 여섯 effect 의 등록 순서는 그대로 둔다

## 6. 사람 확인 (구현 뒤 main 이 `specs/human-checks.md` 에)

1. 윈도우 크롬, 한글 입력 상태(조합 없이)와 한글 조합 중(`안녕` 의 `녕` 을 치는 중)에 `Ctrl+S` → 페이지 저장 창이 뜨지 않고 `.md` 가 한 번 받아진다. 조합 중이었으면 파일 끝에 그 글자가 들어 있다. 안 되면 H189 와 함께 판정을 다시 본다
