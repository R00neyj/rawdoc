- 새 의존성 없음

## 2. 데이터
- `Document.pinnedAt: number | null`. 필드가 없으면 null 로 본다. 일괄 재기록·DB 버전 올림 없음 (색인을 쓰지 않음)
- `store.setPinned(id, pinned: boolean) → Promise<Doc>` — true 면 `pinnedAt = Date.now()`, false 면 null. **`updatedAt` 은 바꾸지 않는다** (고정은 내용 수정이 아님). 없는 id 면 reject
- `store.list()` 결과에 `pinnedAt` 포함
- `folderTree.pinnedDocs(docs) → Doc[]` — `pinnedAt` 이 있는 문서를 **고정한 순서(오름차순)** 로. 먼저 고정한 것이 위에 있어 위치가 바뀌지 않게 한다

## 3. 사이드바

```
[＋ 새 문서] [＋ 새 폴더] [↥ 가져오기]
고정됨
  협업 규칙        ⋯
  API 초안         ⋯
문서
▾ 기획            ⋯
  ▌API 초안       ⋯
  협업 규칙        ⋯
```

- 고정한 문서가 1개 이상이면 트리 위에 `고정됨` 묶음. 0개면 묶음과 제목 모두 숨김
- 묶음 제목 `고정됨`, 트리 제목 `문서` (둘 다 기존 사이드바 섹션 제목 스타일). 묶음은 접지 않는다
- 고정한 문서는 원래 폴더 위치에도 그대로 보인다 (두 곳에 표시)
- 묶음 항목: 문서 제목만(들여쓰기 없음). 누르면 문서 열기. 현재 문서면 두 곳 모두 선택 표시(`aria-current="page"`)
- 묶음은 `role="list"` 의 `listitem` 버튼. 트리(`role="tree"`)와 따로 키보드 이동
- 묶음 안에서 끌어 순서 바꾸기·폴더로 끌어 놓기 없음 (M1)

## 4. 메뉴
- 문서 `⋯` 메뉴(트리·묶음 모두) 맨 위에 `상단 고정` / `고정 해제` (현재 상태에 따라 하나)
- 실행 후 알림 없음. 목록만 바뀐다
- 폴더는 고정할 수 없다
- 문서 삭제 시 묶음에서도 사라진다 (별도 처리 없음 — 목록에서 빠지므로)
