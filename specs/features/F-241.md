# F-241 홈 화면 최근 문서 5개

작성일: 2026-09-18
상태: 사용자 승인 대기 (2026-09-18 사용자 "메인화면 최근 내역 5개 보여줘야함. 새문서/ 가져오기 하단에 있으면 될듯")
근거: `specs/features/F-232.md`(시작 화면 홈, `EmptyState` 재사용), `specs/ia.md` 4.3(빈 상태 S-2)

## 1. 범위

### 문제
F-232 로 앱을 열면 홈 화면(`EmptyState`)이 먼저 뜬다. 지금 홈에는 문구 한 줄과 `새 문서`·`가져오기` 버튼뿐이라, 하던 문서로 돌아가려면 사이드바 트리에서 찾아야 한다. F-232 는 "홈에 최근 문서 카드" 를 **하지 않는다**로 두고 미뤘다 — 그 미룬 것을 여기서 한다.

### 한다
- 홈 화면 `새 문서`·`가져오기` 버튼 **아래**에 최근 문서 목록을 둔다
- 최근 = 내 문서를 `updatedAt` 내림차순으로 **최대 5개**. 이미 App 이 그 순서로 들고 있는 `docs` 를 그대로 쓴다
- 각 줄: 제목 + 마지막 수정 날짜. 누르면 그 문서를 연다(사이드바에서 고른 것과 같은 동작)
- 문서가 0개면 목록을 그리지 않는다(지금 화면 그대로). 1~4개면 있는 만큼만
- 제목이 길면 한 줄로 자른다(말줄임)

### 하지 않는다
- 공유받은 문서(F-212)·공개 링크 문서를 목록에 섞기 — 내 문서만
- 고정됨(pinned) 문서 우선 정렬, 즐겨찾기, 검색, 미리보기 글귀, 폴더 경로 표시
- 최근 **연** 문서 기록(별도 방문 기록 저장) — 이번엔 `updatedAt` 하나로만 정한다
- 항목 우클릭 메뉴·드래그
- `PublicView`·`SharedView` 화면 변경

## 3. 요구사항

### 3.1 데이터 (`App.tsx`)
- `docs` 는 이미 `sortByUpdatedAtDesc` 결과다(F-111·F-232) — 앞에서 5개를 그대로 넘긴다
- 공유받은 문서는 `docs` 에 `role !== 'owner'` 로 섞여 들어온다(F-212 `list()`) → **`role` 이 `owner` 인 것만** 거른 뒤 5개를 자른다
- 문서를 열 때 쓰는 콜백은 사이드바 항목이 쓰는 것과 같은 것을 넘긴다(해시 교체·`md.lastDocId` 저장·폴더 펼치기까지 같은 경로)

### 3.2 목록 (`EmptyState.tsx`)
- 버튼 줄(`.empty-state-actions`) **다음**에 `<ul class="empty-state-recent">`
- 목록 위에 작은 머리글 `최근 문서` (`--muted`, 12px)
- 항목은 `<li><button type="button" class="empty-state-recent-item">` — 제목 `<span class="empty-state-recent-title">`, 날짜 `<span class="empty-state-recent-date">`
- 날짜 형식은 `YYYY-MM-DD` (`ApiTokensDialog.tsx` 의 `formatDate` 와 같은 모양. 공용 유틸로 빼지 않고 이 파일 안에 같은 모양으로 둔다 — 쓰는 곳이 둘뿐이고 F-160 도구화 대상이 아니다)
- 제목이 빈 문서는 사이드바와 같은 대체 문구를 쓴다(사이드바가 쓰는 값과 같은 것을 App 에서 이미 만들고 있으면 그대로, 없으면 `제목 없음`)
- `recentDocs` 가 빈 배열이면 머리글도 목록도 그리지 않는다

### 3.3 모양 (`app.css`)
- `.empty-state button` 규칙이 모든 자손 버튼에 걸리므로(지금 `새 문서`·`가져오기` 용 테두리·padding), 목록 항목 버튼은 그 규칙을 받지 않게 **선택자를 좁힌다** — `.empty-state-actions button` 으로 바꾸고, 목록 항목은 자체 규칙을 쓴다
- 목록: 너비 100%, 최대 `--content-max` 안에서 가운데. 항목은 좌우 정렬(제목 왼쪽, 날짜 오른쪽), 한 줄, 제목 `text-overflow: ellipsis`
- 호버·포커스는 다른 목록 항목과 같은 방식(`--transition-colors`, 배경 `--rule-2`)
- 새 애니메이션 없음

### 3.4 접근성
- 목록은 `<ul>`/`<li>` + 버튼. 키보드 Tab 으로 `새 문서` → `가져오기` → 최근 항목 순
- 항목 버튼의 접근 이름은 제목 글자 그대로(날짜까지 읽혀도 된다 — 따로 `aria-label` 을 두지 않는다)
