## 3. 요구사항

### 3.1 매니페스트 (`VitePWA({ manifest })`)
- `name: brand.name`, `short_name: brand.shortName`, `description: '원문이 남는 마크다운 편집기'`, `lang: 'ko'`
- `id: '/'`, `start_url: '/'`, `scope: '/'`, `display: 'standalone'`
- `theme_color: brand.accent`, `background_color`: `src/styles/tokens.css` 의 `--paper` 값을 `vite.config.js` 가 파일에서 읽어 넣는다 (hex 중복 금지)
- `icons`: 192·512 (`purpose: 'any'`), maskable 512 (`purpose: 'maskable'`)
- `prefer_related_applications` 를 넣지 않는다
- `file_handlers` 는 F-119

### 3.2 아이콘 (`scripts/make-icons.py`)
- 제품명 글자를 넣지 않는다 (design.md 3.2). 도형: 마크다운 `#` 기호 모양 막대 4개
- 색: `tokens.css` 에서 `--ink`(바탕)·`--paper`(기호)를 정규식으로 읽는다. 스크립트에 hex 를 쓰지 않는다
- `icon-192/512`: 투명 바탕 위 반경 22% 둥근 사각형
- `icon-maskable-512`: 바탕을 전체에 칠하고 기호는 가운데 지름 80% 안전 영역 안에 둔다
- 실행: `python scripts/make-icons.py` (Pillow 설치돼 있음, 12.1.1). 결과 PNG 를 커밋 대상에 둔다

### 3.3 앱 설치 버튼 (ia.md 3.12)
- `useInstallPrompt()` → `{ canInstall, install }`
  - `beforeinstallprompt` 에서 `preventDefault()` 후 이벤트 보관, `canInstall = true`
  - `install()`: `prompt()` → `userChoice` 대기 → `accepted` 면 `canInstall = false`. `dismissed` 면 버튼 유지하되 같은 이벤트는 다시 못 쓰므로 보관 이벤트를 비우고 `canInstall = false` (다음 `beforeinstallprompt` 때 다시 표시)
  - `appinstalled` → `false`. `matchMedia('(display-mode: standalone)')` 가 참이면 처음부터 `false`
- 사이드바 `설정` 바로 위에 `앱 설치`. `canInstall` 일 때만 표시
