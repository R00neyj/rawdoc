## 4. 삭제된 문서 표시·금고 초기화
- ① **공개 보기 S-5**: `fetchPublicDoc`·`fetchPublicSetDoc`·`fetchPublicFolderDoc` 가 404 본문 `{"error":"deleted"}` 면 `PublicDocError('deleted')` → 칸에 `삭제된 문서입니다.`(폴더 칸의 `이 문서는 더 이상 공유되지 않습니다.` 보다 앞). 본문이 없거나 다르면 지금 `not_found`
- ② **없는 문서 해시**(`useHashRouting` 대체 분기·`bootFlow` `route.notFound`): 서버 저장소이고 `navigator.onLine` 이면 `probeGoneDoc(id)` — `GET /api/docs/:id` 가 404 `deleted` 면 `GET /api/trash` 에 id 가 있으면 `'trashed'`, 없으면 `'deleted'`, 그 밖 전부(네트워크 포함) `'not_found'`. 알림: `trashed` → `휴지통에 있는 문서입니다. 복원하면 열 수 있습니다.` + `휴지통 열기`(`location.hash = '#/trash'`) / `deleted` → `삭제된 문서입니다.` / `not_found` → 지금 문구. 대체 문서로 여는 동작은 그대로, 알림만 응답 뒤에
- ③ **금고 초기화 단계**(`runE2eeReset`, 서버 저장소만): `flushOutbox` 뒤 `list` 의 `e2ee` 문서 id 마다 `purgeTrashDoc` — 404 는 무시, 그 밖 실패는 던진다(지금 실패 길). 그래야 D-13 의 `지운 금고 문서는 되살릴 수 없습니다.` 가 참이고 초기화가 자기가 보낸 휴지통 문서에 막히지 않는다. **원래 휴지통에 있던** 금고 문서는 Q2 대로 막는다(3장 문구). F-3023 확인: `DELETE /api/trash/:id` 는 금고 문서도 지운다
