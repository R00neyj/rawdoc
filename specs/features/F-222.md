## 2. 요구사항

### 2.1 저장 (`0007_api_tokens.sql`)
```sql
CREATE TABLE api_tokens (
  id TEXT PRIMARY KEY,            -- uuid
  user_id TEXT NOT NULL REFERENCES users(id),
  name TEXT NOT NULL,             -- 1~40자
  token_hash TEXT NOT NULL UNIQUE, -- SHA-256 hex
  prefix TEXT NOT NULL,           -- 표시용 앞 11자 'rd_' + 8자
  created_at INTEGER NOT NULL,
  last_used_at INTEGER,
  revoked_at INTEGER
);
CREATE INDEX api_tokens_user ON api_tokens(user_id);
```
- 토큰 원문 = `rd_` + 32바이트 `crypto.getRandomValues` base64url(패딩 없음). 원문은 저장하지 않는다

### 2.2 관리 API (Access 로그인 경로)
- `GET /api/tokens` → 폐기 안 된 내 토큰 `[{ id, name, prefix, createdAt, lastUsedAt }]` 최근 만든 순
- `POST /api/tokens` `{ name }` → 이름 앞뒤 공백 제거 후 1~40자 아니면 400 `{error:'invalid', field:'name'}`. 폐기 안 된 토큰이 이미 10개면 409 `{error:'too_many', limit:10}`. 성공 201 `{ id, name, prefix, createdAt, lastUsedAt: null, token }` — **`token` 은 이 응답에만**
- `DELETE /api/tokens/:id` → 내 토큰이면 `revoked_at = now` 204, 아니면 404
- 토큰으로는 이 세 경로를 쓸 수 없다(Access 경로라 토큰 판정을 하지 않는다)

### 2.3 토큰 판정 (`auth.ts`)
- 요청 경로가 `/v1/` 로 시작하면 `getUser` 는 **`Authorization: Bearer rd_…` 만** 본다. Access JWT·`CF_Authorization` 쿠키·`DEV_AUTH_EMAIL` 은 무시한다 — 브라우저 쿠키로 `/v1` 쓰기가 되면 다른 사이트가 사용자 몰래 요청을 보낼 수 있다
- 토큰 SHA-256 hex 로 `revoked_at IS NULL` 행을 찾고 `users` 에서 `{id, email}`. 없으면 null(→ 기존 401 `unauthenticated`)
- `last_used_at` 은 기존 값이 10분 넘게 지났거나 null 일 때만 갱신, `ctx.waitUntil` 로 응답을 기다리게 하지 않는다
- `/v1/` 이 아닌 경로는 지금 동작 그대로(토큰 헤더를 무시)

### 2.4 화면 — 계정 메뉴 `API 토큰`
- 로그인 상태(`in`)일 때만 계정 메뉴 `로그아웃` 위에 `API 토큰` 항목(아이콘 `key`, material symbols). 누르면 대화상자
- 대화상자 제목 `API 토큰`, 설명 한 줄: `스크립트나 자동화 도구가 이 계정으로 문서를 올릴 때 씁니다. 토큰을 가진 사람은 내 문서를 읽고 고칠 수 있습니다.`
- 목록: 행마다 이름 · `rd_xxxxxxxx…` (고정폭) · `만든 날 2026-09-15` · `마지막 사용 2026-09-15` 또는 `사용 안 함` · `폐기` 버튼. 없으면 `아직 만든 토큰이 없습니다.`
- `폐기` → 행 안 확인 문구 `폐기하면 이 토큰을 쓰는 스크립트가 멈춥니다.` + `폐기`(위험 색)·`취소`
- 만들기: 이름 입력(자리 표시 `예: 교안 자동 업로드`, 최대 40자) + `토큰 만들기`. 성공하면 목록 위에 강조 상자: 읽기 전용 입력칸에 토큰 원문 + `복사` 버튼(누르면 `복사됨` 1.5초) + `이 토큰은 지금만 볼 수 있습니다. 안전한 곳에 보관하세요.` + 사용 예 코드블록
  ```
  curl -H "Authorization: Bearer {토큰}" https://rawdoc.app/v1/docs
  ```
  주소는 `location.origin` 으로 만든다. 대화상자를 닫으면 원문은 사라진다
- 오류 알림: 10개 초과 `토큰은 10개까지 만들 수 있습니다. 쓰지 않는 토큰을 폐기하세요.`, 그 외 `토큰을 만들지 못했습니다. 잠시 뒤 다시 시도하세요.`
- 대화상자 모양·포커스·Esc 는 기존 대화상자(설정·초대) 규칙 그대로
