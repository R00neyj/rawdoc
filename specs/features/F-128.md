## 2. 문법

```
> [!note] 제목
> 본문
```

- 인용(`Blockquote`)의 **첫 줄**이 `>` 뒤 공백 0개 이상 + `[!종류]` 로 시작하면 콜아웃이다. `>[!tip]` 처럼 공백이 없어도 된다
- 머리 줄 정규식: `^\[!([^\]\s]+)\]([+-]?)(?:[ \t]+(.*))?$` (`>` 와 그 뒤 공백을 뗀 나머지에 적용)
  - 1번: 종류. 대소문자 무시
  - 2번: 접기 기호. M1 은 인식만 하고 항상 펼친다 (Q25)
  - 3번: 제목. 없으면 기본 제목
- 두 번째 줄부터가 본문. 본문이 없어도 된다
- 안에 넣은 인용·콜아웃(`> > [!tip]`): 보기 모드는 안쪽도 콜아웃으로 변환. 편집 모드는 **가장 바깥 인용만** 콜아웃 모양이고 안쪽은 기존 인용 모양

### 2.1 종류와 색 묶음

| 종류 (별칭) | 색 묶음 |
| --- | --- |
| `note`, `info`, `todo` | note |
| `abstract` (`summary`, `tldr`), `tip` (`hint`, `important`) | tip |
| `success` (`check`, `done`) | success |
| `question` (`help`, `faq`) | question |
| `warning` (`caution`, `attention`) | warning |
| `failure` (`fail`, `missing`), `danger` (`error`), `bug` | danger |
| `example` | example |
| `quote` (`cite`) | quote |
| 그 밖의 모든 이름 | note (Obsidian 규칙: 지원하지 않는 종류는 `note`) |

- GitHub `[!IMPORTANT]` 은 tip, `[!CAUTION]` 은 warning 묶음이 된다. GitHub 화면 색(보라·빨강)과 다르다

### 2.2 `callout.js`
- `parseCalloutHeader(text) → { type, kind, fold, title, typeFrom, typeTo } | null`
  - `text`: `>` 와 뒤 공백을 뗀 첫 줄 글자. `type` 은 적힌 그대로, `kind` 는 2.1 묶음 이름, `fold` 는 `''|'+'|'-'`, `title` 은 앞뒤 공백 뺀 문자열 또는 `''`, `typeFrom`·`typeTo` 는 `text` 안에서 `[` 부터 `]`(접기 기호 포함) 끝까지의 위치
- `defaultCalloutTitle(type) → string` — 첫 글자만 대문자 (`note` → `Note`, `NOTE` → `NOTE`, `할일` → `할일`)

## 4. 모양 (`callout.css`)

공용 규칙: 색 묶음 클래스가 `--callout-color` 를 정한다 (`.md-callout--tip { --callout-color: var(--callout-tip) }` …)

| 항목 | 값 |
| --- | --- |
| 바탕 | `color-mix(in srgb, var(--callout-color) 8%, var(--panel))` |
| 왼쪽 선 | 4px `var(--callout-color)` |
| 모서리 | 오른쪽 위·아래 6px (편집 모드는 첫 줄·마지막 줄에만) |
| 제목 | 굵기 600, 색 `var(--callout-color)` |
| 안쪽 여백 | 보기 모드 8px 16px. 편집 모드 줄 왼쪽 16px, 첫 줄 위 8px, 마지막 줄 아래 8px (세로는 `padding`, F-124 3.2 이유) |
| 본문 글자색 | `var(--ink)` (인용의 흐린 글자색을 쓰지 않음) |

### 4.1 편집 모드
- 기호는 숨기지 않는다: `[!note]` 는 원문 글자 그대로 두고 `md-callout-type` mark 로 색 묶음 색·굵기 600·글자 크기 0.85em. `>` 는 기존 F-105 규칙(커서 없는 줄에서 숨김) 그대로
- 줄 클래스: 콜아웃의 모든 줄 `md-callout md-callout--{kind}`, 첫 줄 `md-callout-title`, 마지막 줄 `md-callout-last`. 이 줄들에는 `md-quote` 를 붙이지 않는다
- 제목 글자(3번 그룹)는 `md-callout-title` 줄 스타일로 굵기 600·색
- 콜아웃 머리의 `[!note]` 를 lezer 가 `Link` 로 읽어 F-104/F-129 가 `[` `]` 를 숨기는지 실측한다. 숨기면 `inline.js` 에서 콜아웃 머리의 그 범위를 숨김 대상에서 뺀다. F-129 링크 클릭 대상도 아니어야 한다(`URL` 이 없으므로 원래 대상이 아님)
- 원문 모드는 콜아웃 모양 없음 (프리뷰 확장이 없음)
- 편집 모드 `data-callout="{type 소문자}"` 는 줄 속성으로 넣는다 (나중 사용자 CSS 창구, Q21)

### 4.2 보기 모드
- 콜아웃 인용을 아래 HTML 로 바꾼다 (markdown-it core 규칙, 토큰 단위 변환. 정규식으로 HTML 문자열을 고치지 않는다)
  ```html
  <div class="markdown-callout md-callout--{kind}" data-callout="{type 소문자}">
    <p class="markdown-callout-title">{제목 인라인 렌더 또는 기본 제목}</p>
    …본문 블록…
  </div>
  ```
- 제목은 인라인 마크다운으로 렌더(굵게·링크 등). `html:false` 규칙 그대로라 원문 HTML 은 이스케이프
- 머리 줄의 `[!type]` 글자와 접기 기호는 출력하지 않는다
- 보기 모드 인용(F-124 `blockquote`) 스타일이 콜아웃에 섞이지 않게 `div` 로 바꾼다
