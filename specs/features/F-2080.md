작성일: 2026-09-28
상태: **승인(2026-09-28, 상시 지시 "결정할 갈림길이 없으면 바로 구현" 에 따른 것 — 별도 검토 아님). - 공개 보기 렌더(F-2059 3.5): 새 effect 는 `if (publicRoute) {` 보다 위이고, 읽는 `openPalette`·`toggleShortcuts` 는 그 위의 훅 반환이라 TDZ 가 없다

### 3.4 ③ `react-hooks/refs` 끄기 네 줄

모두 **진단이 난 줄 바로 위**다(여러 줄 식은 진단 시작 줄 기준 — 실측). 형식은 `useE2ee.ts` 선례 `// eslint-disable-next-line react-hooks/refs -- {이유}` 한 줄(`CLAUDE.md` Code comments).

| # | 바로 아래 줄 | 들여쓰기 | 이유 문구(기본값) |
| --- | --- | --- | --- |
| 1 | `  const [listRefresher] = useState(() =>` | 2칸 | `refresh·isStale 는 뒤 새로 읽기 때만 불려 렌더 중에 ref 를 읽지 않는다` |
| 2 | `    return createCachedListSource({`(`listSource` `useMemo` 안) | 4칸 | `hasLiveChanges 는 검색·지도가 목록을 읽을 때만 불린다` |
| 3 | `  } = createExportActions({` | 2칸 | `넘기는 ref 는 내보내기·인쇄 핸들러 안에서만 읽힌다` |
| 4 | JSX `autoFocus={focusTitleRef.current ? 'title' : focusEditorRef.current}` | 그 속성 줄과 같게(JSX 여는 태그 안 `//` 주석 — `<TopBar>` 의 `peers` 앞 주석과 같은 모양) | `포커스 요청 플래그는 마운트 때 한 번 읽고 passive effect 가 소비한다` |

- 2번은 `const listSource = useMemo(() => {` 위에 두면 **안 먹는다**(실측: "Unused eslint-disable directive" + 진단 그대로). 진단 시작 줄이 `return createCachedListSource({` 다
- 이유 문구는 구현자가 한 줄 안에서 고쳐도 된다. 줄 수와 자리는 바꾸지 않는다
- **끄기 예산(F-2076 Q4 "단계 4 전체 최대 8줄"):** F-2077~F-2079 0 + 이 조각 4 = **4**. 4번 줄은 F-2081 이 JSX 와 함께 `DocumentArea.tsx` 로 들고 가므로 F-2081 이 새로 쓸 수 있는 줄은 **4**다

## 5. 계약

이름이 다른 명세(F-2081·F-2082)와 맞물리는 것만 적는다.

```ts
// App 안, 지금 tabIdRef 선언 자리
const [tabId] = useState(newTabId)
const tabIdRef = useRef(tabId)

// App 안, useCommandPalette 호출 바로 아래
// Ctrl+P·Ctrl+Shift+/ 가 매 커밋 최신 openPalette·toggleShortcuts 를 읽게 한다 (F-2080)
useEffect(() => {
  openPaletteRef.current = openPalette
  toggleShortcutsRef.current = toggleShortcuts
})
```

- `useTabSync`·`useE2ee` 옵션 타입은 바꾸지 않는다(`tabId: string` 그대로)
- 새 effect 앞 주석 한 줄의 문구는 구현자가 바꿔도 된다
- 끄기 줄 형식: `// eslint-disable-next-line react-hooks/refs -- {이유}`. 규칙 이름을 여럿 적거나 `eslint-disable` 블록(`/* */` 짝)을 쓰지 않는다

## 11. 열린 질문 (모두 기본값 — 기본값대로면 사람이 정할 갈림길 없음)

### Q1. 범위 — **기본값: (가) App 을 분석되게 하고 드러나는 12개를 정리한다**

- 이유: 2.1 표. F-2076 3.3 이 준 일이 이것이고, 끄기 4줄로 예산 안에 든다. 분석되는 App 은 뒤 조각(F-2081·F-2082)이 렌더 중 ref 읽기·선언 전 접근을 새로 만들면 lint 가 바로 잡는다

### Q2. effect ③ 의 `saveCurrentAsNewDoc` — **기본값: ① 함수 둘(`requestE2eeOpen`·`saveCurrentAsNewDoc`)을 effect ③ 위로 올린다**
