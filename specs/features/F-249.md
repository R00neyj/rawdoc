# F-249 도움말 페이지에 오른쪽 목차

작성일: 2026-09-18
상태: 사용자 승인 (2026-09-18 배포 확인 중 "도움말에 목차 안뜸", 고칠지 되묻자 "ㅇㅇ")
근거: `specs/features/F-244.md` 3.2(도움말 전용 페이지), `F-144.md` 3.4(오른쪽 목차), `F-229.md` 2장(여백 부족 시 목차 버튼), `PublicView.tsx` 45~60행(`Outline` 용 가짜 핸들)

## 1. 범위

### 문제
F-244 가 도움말을 `#/help` 전용 페이지로 옮겼는데 **오른쪽 목차(`Outline`)를 붙이지 않았다.** 문법 12묶음이 `##` 제목으로 들어 있어 목차가 가장 쓸모 있는 문서인데 없다. F-244 명세에 목차 얘기가 없어 빠진 누락이다.

보기 모드(F-123)와 공개 링크(`PublicView`)는 둘 다 목차가 있다. 도움말만 없어 앱 안에서 어긋난다.

### 한다
- `#/help` 에 보기 모드·공개 링크와 **같은 `Outline`** 을 붙인다. 새 목차 컴포넌트를 만들지 않는다
- `Outline` 이 요구하는 핸들은 `PublicView.tsx` 의 `makeFakeHandle(content)` 와 같은 방식으로 만든다 — CM6 `EditorView` 없이 `EditorState` 하나로 제목·줄 위치만 흉내낸다
- 여백이 좁으면 `Outline` 이 알아서 목차 버튼 + 카드로 바뀐다(F-229) — 도움말에서도 그대로 동작한다
- 제목을 누르면 그 자리로 스크롤된다

### 하지 않는다
- `Outline`·`outlinePosition` 동작 변경 — 그대로 쓴다
- 도움말 본문 내용 변경(F-244 가 정한 12묶음 그대로)
- `PublicView.tsx` 의 `makeFakeHandle` 을 공용 모듈로 빼내는 리팩터링 — 같은 방식으로 쓰되, 옮겨 적을지 import 할지는 3.1 을 따른다
- 왼쪽 사이드바를 도움말에서 보이게 하기

`PublicView.tsx` 는 소유 밖이다. 그 안의 `makeFakeHandle` 을 **고치거나 옮기지 않는다** — 필요하면 `helpOutline.ts` 에 같은 내용을 새로 쓴다

## 3. 요구사항

### 3.1 핸들
- `helpOutline.ts` 가 도움말 원문(`HELP_DOC_CONTENT`)으로 `Outline` 이 쓰는 최소 핸들을 만든다: `getHeadings`·`onHeadingsChange`·`view`·`scrollToHeading`·`focus`
- `PublicView.tsx` 의 `makeFakeHandle` 과 같은 방식(`EditorState` + `extractHeadings`)이다. 도움말은 내용이 고정이라 모듈 스코프에서 한 번만 만들어도 된다 — `HelpPage` 를 훅 없는 순수 컴포넌트로 둔 F-244 3.3 의 성질을 유지한다

### 3.2 화면
- `HelpPage` 가 본문을 감싸는 요소에 `containerRef`·`viewerRef` 를 걸고 `Outline` 을 본문 오른쪽에 둔다 — 보기 모드와 같은 자리
- 목차가 머리줄(도움말 제목·`내 문서로 복사`·`닫기`)을 가리지 않는다
- 여백이 `MIN_MARGIN`(56px) 미만이면 F-229 대로 목차 버튼이 된다 — `Outline` 안에서 판정하므로 따로 분기하지 않는다
