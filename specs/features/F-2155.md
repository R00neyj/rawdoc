## 3. 열기·저장 (`useLocalFile`)
- `pickLocalFile`: `showOpenFilePicker(MD_PICKER_OPTIONS)`(`AbortError` 는 조용히) → `openLocalFile(handle, { gesture: true })`. `openLocalFile` 순서: ① 세션이 있고 `isSameEntry` 면 다시 읽지 않고 `'same'`(gesture 이고 쓰기 권한 없으면 권한만 다시) ② `getFile()` — `NotFoundError` 는 알림 없이 `'missing'`, 그 밖 실패는 `"{파일명}" 을(를) 열지 못했습니다.` + `'error'`, UTF-8 아님은 F-2154 3장 문구 + `'not-utf8'` — 셋 다 화면 그대로 ③ `canWrite = await ensureWritePermission(handle, { gesture })` ④ `await beforeLeaveDoc()` → `leave()` → `setCurrentDocId(null)` → 세션·`#/file` → 섞인 줄바꿈 알림 → 열림 구독자 호출 → `'opened'`
- `ensureWritePermission`: `queryPermission({ mode: 'readwrite' })` 가 `granted` 면 참, `gesture` 거짓이면 거짓, 아니면 `requestPermission` 결과가 `granted` 인지. 던지면 거짓
- dirty 는 `onChanges` 의 `local` 변경만 — 열기·`remount` 는 쓰지 않는다. 마지막 입력 뒤 `LOCAL_SAVE_DEBOUNCE_MS = 1000`
- 쓰기 직렬화(`runSave` 와 같은 규칙): 진행 중 Promise 하나, `while (dirty)` 마다 ① 쓰기 전 훅(5장)이 거짓이면 dirty 를 남기고 멈춤 ② 그 순간 `getText(lineEnding)` → `encodeMarkdown` → `createWritable()` → `write` → `close()` → `getFile().lastModified` 를 세션에. 쓰는 동안 입력이 오면 한 번 더 돈다. `canWrite` 거짓이면 쓰지 않는다
- 실패: `NotAllowedError`·`SecurityError` → `canWrite = false`. 그 밖 → `error` + 알림(error) `파일에 저장하지 못했습니다.`(`error` 로 들어갈 때 한 번), 다음 입력 1,000ms 뒤 다시
- 상태(`.statusbar-save` 글자·점): `saved` `파일에 저장됨`·saved / `dirty` `입력 중…`·dirty / `error` `저장 실패`·error / `permission` `저장 권한 필요`·error. 처음은 `canWrite ? saved : permission`
- Ctrl+S: App 이 세션이 있으면 `exportMdRef` 에 `canWrite ? saveNow() : grantWrite()` 를 넣는다(키 처리는 `useGlobalShortcuts` 그대로, 내보내기 안 뜸). 쓸 변경이 없으면 쓰지 않는다. `저장 허용` = `grantWrite`(동작 안 요청, 허용되면 곧바로 `saveNow`)

## 4. 떠나기·가져오기
- `beforeLeaveDoc` 에 `await localFileRef.current.flush()`(타이머 지우고 진행 중 쓰기까지 기다림)를 더한다. `leaveScreens` 가 `closeLocalFile()`(동기)을 부른다: 못 쓴 변경이 남았으면 그 본문을 잡아 `canWrite` 면 같은 줄에 마지막 쓰기(쓰기 전 훅도 거침), 못 쓰거나 실패·건너뜀이면 sticky 알림 `"{파일명}" 의 바뀐 내용을 파일에 쓰지 못했습니다.` + `.md 내보내기`(잡은 본문을 `encodeMarkdown` → `downloadBlob`, 이름 `{파일명}`). 그 뒤 세션 `null`. `beforeunload` 는 `hasUnwritten` 인 동안만 `preventDefault()`
- `importToDoc`: 편집기 본문으로 `File([encodeMarkdown(readText(), { hadBom })], name)` → `importLocalFileAsDoc(file, handle)` = `runImportFiles([file])` 뒤 idb 면 `linkFileHandle`(실패 무시). `runImportFiles` 가 flush·`leave()`(S-11 닫힘)·새 문서 열기를 한다. 가져오기가 성공하면 남은 변경은 새 문서에 있으니 `closeLocalFile` 은 쓰기·알림 없이 닫는다. 개요 5장은 "파일을" 읽지만, 쓴 뒤엔 디스크 = 본문이고 권한 없음·충돌·없음에선 본문이 맞으므로 늘 본문 — F-2157 은 이 함수를 그대로 부른다

## 5. 후속 명세 계약 (`useLocalFile.ts` 가 내보냄 — F-2156~F-2158 은 이 파일을 고치지 않는다)
```ts
export type LocalFileSession = { key: string; handle: FileSystemFileHandle; name: string; lineEnding: LineEnding; hadBom: boolean; lastModified: number; canWrite: boolean }
export type LocalSaveStatus = 'saved' | 'dirty' | 'error' | 'permission'; export type LocalOpenResult = 'opened' | 'same' | 'missing' | 'not-utf8' | 'error'
export type BeforeLocalWrite = (session: LocalFileSession) => Promise<boolean> // 거짓 = 이번 쓰기 건너뜀, dirty 유지
export type UseLocalFileResult = {
  session: LocalFileSession | null; status: LocalSaveStatus; hasUnwritten: boolean; editorKey: string | null; initialText: string
  openLocalFile(handle: FileSystemFileHandle, opts: { gesture: boolean }): Promise<LocalOpenResult>
  pickLocalFile(): Promise<void>; closeLocalFile(): void; flush(): Promise<boolean>
  saveNow(opts?: { skipGuard?: boolean }): Promise<boolean>; grantWrite(): Promise<void>; importToDoc(): Promise<void>
  readText(): string | null // 파일 줄바꿈으로
  remount(next: { text: string; lineEnding: LineEnding; hadBom: boolean; lastModified: number }): void // 새 editorKey, dirty·대기 버림
  setBeforeWrite(guard: BeforeLocalWrite | null): void; subscribeOpened(listener: (session: LocalFileSession) => void): () => void
}
```
- **F-2156**: `useImportFlow` 안에서 F-2155 가 넘긴 `localFileRef.current.openLocalFile(handle, { gesture: false })`. 여러 개 알림·설정은 F-2156 몫. `useLocalFile`·`LocalFileScreen` 은 안 고친다
- **F-2157**: 새 훅 파일 + `LocalFileScreen.tsx` 머리줄 바로 아래 띠(이 파일은 F-2157 만 고친다). `setBeforeWrite`·`remount`·`saveNow({ skipGuard: true })`·`importToDoc`·`hasUnwritten`·`session.lastModified`
- **F-2158**: 새 모듈·훅 + `subscribeOpened`·`openLocalFile(h, { gesture: true })`(`'missing'` 이면 자기 알림). `EmptyState`·`AppScreens`·팔레트 세 파일은 F-2158 만. App 은 F-2156·F-2158 이 서로 다른 줄만 더한다
