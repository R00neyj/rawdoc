## 2. 아이콘 공통
- 사용자 지정(2026-09-14): **Google Material Symbols**. Outlined, 굵기 400, 채움 0, 24px 기준
- SVG 파일 방식으로 쓴다: `@material-symbols/svg-400/outlined/{이름}.svg` 를 `?raw` 로 가져와 `icons.jsx` 가 인라인 SVG 로 넣는다. 쓰는 아이콘만 번들에 들어가야 한다
  - 가변 폰트 방식(`material-symbols` 패키지)·Google Fonts CDN 은 쓰지 않는다. 폰트 파일 전체를 받아야 하고 CDN 은 오프라인에서 안 된다 (`specs/design.md` 2.3 과 같은 이유)
- `aria-hidden="true"` `focusable="false"`. 이름은 버튼의 `aria-label` 이 준다
- 색은 CSS `fill: currentColor` 만. hex 금지
- 설치 버전에 3.1 이름의 파일이 없거나 `?raw` 인라인이 안 되면 대안을 만들지 말고 멈추고 보고한다

## 3. 요구사항

### 3.1 아이콘 목록
| 컴포넌트 | Material Symbols 이름 | 쓰는 곳 |
| --- | --- | --- |
| `IconEdit` | `edit` | 편집 |
| `IconRaw` | `code` | 원문 |
| `IconView` | `visibility` | 보기 |
| `IconShare` | `ios_share` | 공유 |
| `IconDownload` | `download` | 내보내기 |
| `IconChevron` | `chevron_right` | 폴더 토글 |

### 3.2 상단바 버튼
- 편집·원문·보기·공유·내보내기 버튼을 **아이콘만** 보이게 바꾼다. 글자 없음
  - 크기: 누르는 영역 32×32px, 아이콘 18px
  - 보기 모드 세그먼트는 지금 구조·`aria-pressed`·비활성 규칙 그대로. 선택된 버튼 표시는 지금 세그먼트 스타일을 따른다
  - 공유 메뉴 여는 방식·키보드 조작·메뉴 항목은 그대로
- 버튼 이름(`aria-label`)과 툴팁 문구

| 버튼 | 문구 |
| --- | --- |
| 편집 | `편집 — 서식을 보며 편집` |
| 원문 | `원문 — 마크다운 기호 그대로 편집` |
| 보기 | `보기 — 읽기 전용으로 보기` |
| 공유 | `공유 — 링크·마크다운 복사` |
| 내보내기 | `.md 파일로 내보내기` |

- 툴팁은 앱이 그린다. 모양은 F-125 2.4 표 툴팁과 같다: 배경 `--ink`, 글자 `--panel`, 12px, 모서리 6px, 안쪽 여백 4px 8px, `--font-sans`, 한 줄
  - 위치: 버튼 아래 6px, 가운데 정렬. 창 오른쪽 끝에 닿는 버튼(내보내기)은 버튼 오른쪽 끝에 맞춘다. 툴팁이 창 밖으로 나가거나 가로 스크롤을 만들지 않는다
  - 마우스를 올리고 400ms 뒤 표시, 키보드 포커스(`:focus-visible`)는 바로 표시. 공유 메뉴가 열려 있으면 공유 툴팁은 숨긴다
  - 문구는 `aria-label` 값을 그대로 쓴다 (화면 문구와 접근성 이름이 어긋나지 않게)
  - 비활성 버튼에도 마우스를 올리면 툴팁이 보인다
  - 툴팁이 편집 영역·사이드바 위로 겹쳐 보인다 (가려지지 않음)

### 3.3 제품 아이콘
- 상단바 제품명 바로 왼쪽에 20×20px 이미지. 간격 8px
- 경로는 `brand.config.js` 의 `icon` 에서 `src/brand.js` 로 읽는다. 코드에 경로를 직접 쓰지 않는다
- `alt=""` (옆에 제품명이 있어 장식). 클릭 동작 없음 (제품명과 같음)
- 좁은 창(`☰` 표시)에서도 보인다

### 3.4 폴더 토글
- `▸`·`▾` 글자를 `IconChevron` 으로 바꾼다. 아이콘 16px, 버튼 22×22px. 문서 행 앞 빈 칸(`tree-toggle-spacer`)도 같은 폭
- 펼치면 90° 회전. 전환 `--transition-fast` (움직임 줄이기 설정이면 0)
- 색 `--muted`, 호버 시 `--ink` + 바탕 `--rule-2`. `aria-label`·`aria-expanded` 는 그대로

### 3.5 폴더 가이드 선
- 펼친 폴더에 보이는 하위 항목이 있으면, 폴더 행 바로 아래부터 마지막 하위 행 아래 끝까지 세로 1px `--rule` 선
- 선의 가로 위치는 그 폴더 토글 아이콘의 가로 가운데
- 하위 폴더를 펼치면 그 폴더도 자기 선을 가진다
- 접힌 폴더, 하위 항목이 없는 폴더는 선 없음
- 선은 행 레이아웃을 밀지 않고(절대 위치 등), 마우스 입력을 막지 않는다(`pointer-events: none`). 현재 문서 행·호버 행 바탕에 가려지지 않는다
- 끌어놓기 강조, 이름 변경 입력, `⋯` 메뉴는 그대로 동작

### 3.6 공유 메뉴 가로 스크롤 (2026-09-14 추가)
- 근거: 사용자 확인 "공유 눌러서 드롭다운 메뉴 펼쳐지면 가로스크롤 생김"
- 원인: `.share-menu-list` 가 `left: 0`, `min-width: 200px` 이라 창 오른쪽 끝 근처의 공유 버튼 왼쪽 끝에서 오른쪽으로 펼쳐져 창 밖으로 나간다
- 수정: 메뉴 오른쪽 끝을 공유 버튼 오른쪽 끝에 맞춰 왼쪽으로 펼친다. 창 너비 1024px 이상에서 메뉴 전체가 창 안에 있고 가로 스크롤이 생기지 않는다
- 메뉴 항목·키보드 조작·바깥 클릭 닫기는 그대로
