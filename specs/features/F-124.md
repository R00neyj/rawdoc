## 3. 요소별 값

### 3.1 공통
- 본문: `--md-font-size` / `--md-line-height` (기존 15px / 1.75 대체). 편집·보기 모드. 보기 모드는 github css 의 `line-height` 를 `.app-shell .markdown-body` 에서 이 토큰으로 덮는다
- 원문 모드: `--font-mono` 14px, 줄 간격 1.5

### 3.2 제목
| 요소 | 크기 | 굵기 | 기타 |
| --- | --- | --- | --- |
| h1 | 2em | 600 (세리프는 포함된 700) | 아래 1px `--md-border-muted`, 아래 안쪽 여백 .3em |
| h2 | 1.5em | 600 (세리프는 700) | 아래 1px `--md-border-muted`, 아래 안쪽 여백 .3em |
| h3 | 1.25em | 600 | |
| h4 | 1em | 600 | |
| h5 | .875em | 600 | |
| h6 | .85em | 600 | 색 `--md-fg-muted` |

- 줄 간격 1.25, 위 여백 1.5rem, 아래 여백 1rem
- 편집 모드는 줄(`.cm-line`)에 세로 `margin` 대신 `padding` 을 쓴다. CM6 는 줄 높이를 DOM 에서 재는데 margin 이 반영되지 않는 것으로 알려져 있다 — 구현 시 커서·클릭 위치가 맞는지 실측하고, 어긋나면 보고한다
- h1·h2 서체 `--font-display`, h3 이하 `--font-sans` (design.md 2.1 유지)

### 3.3 인라인
- 인라인코드: `--font-mono`, 85%, 안쪽 여백 .2em .4em, 모서리 6px, 배경 `--md-code-bg`
- 링크: 색 `--md-link`, 밑줄 없음, 호버 시 밑줄
- 굵게 600, 기울임, 취소선: 브라우저 기본

### 3.4 블록
- 문단·목록·표·코드블록·인용 아래 여백 1rem (보기 모드. 편집 모드는 줄 단위라 적용하지 않는다)
- 인용: 왼쪽 .25em `--md-border` 선, 안쪽 여백 0 1em, 글자색 `--md-fg-muted`
- 코드블록(편집 모드 F-106 위젯, 보기 모드 `pre`): 안쪽 여백 16px, 85%, 줄 간격 1.45, 배경 `--md-bg-muted`, 모서리 6px, **테두리 없음**. 편집 모드 위젯의 정보 문자열(언어) 표시는 유지
- **긴 코드 줄은 코드블록 안에서만 가로 스크롤한다** (사용자 1차 수정 추가 요청 4번, 2026-09-14: "코드블럭만 가로스크롤 되도록 래퍼로 감싸야 할듯. 문서 전체가 가로스크롤 되서 가독성 떨어짐")
  - 코드는 줄바꿈하지 않는다(`white-space: pre`). 코드블록 너비는 본문 폭을 넘지 않는다
  - 편집 모드: 현재 `.md-codeblock pre` 에 `overflow-x: auto` 가 있어도 문서 전체가 가로로 밀린다. 원인을 실측으로 찾아 고친다 (예상 원인: 줄바꿈 모드 `.cm-content` 가 flex 항목이라 `min-width: auto` 로 `pre` 의 내용 폭까지 늘어남). 필요하면 `blocks.js` `CodeWidget.toDOM` 에서 `pre` 를 스크롤 전용 `div.md-codeblock-scroll` 로 감싼다 — `data-offset` 기반 클릭 위치 계산(F-106)은 유지
  - 언어 표시는 스크롤을 따라 움직이지 않는다
  - 표 위젯(`.md-block.md-table`)도 같은 원인이면 함께 고친다 (표만 가로 스크롤)
  - 보기 모드: `pre`·`table` 만 가로 스크롤, `.markdown-body` 는 가로 스크롤 없음
- 링크(편집 모드): `.md-link` 에 `cursor: pointer` (클래스는 F-129 가 붙인다)
- **펼친 코드블록 줄이 인라인코드 조각처럼 보이는 문제** (사용자 1차 수정 추가 요청 11번, 2026-09-14: "``` 로 여는 큰 코드블럭 내부에 작은 코드블럭처럼 보임" + 스크린샷 — 커서가 코드블록 안에 있어 원문으로 펼친 상태에서 줄마다 둥근 회색 조각)
  - 원인: `highlight.js` 가 `tags.monospace` 에 `md-code` 클래스를 주는데, lezer 마크다운은 인라인코드와 펜스 코드블록 본문(`CodeText`)에 같은 태그를 준다. `md-code` 의 인라인코드 바탕·모서리·안쪽 여백이 코드블록 줄마다 붙는다
  - 고칠 것: 펜스 코드블록 본문은 인라인코드 모양(바탕·모서리·안쪽 여백)을 받지 않는다. 편집·원문 모드 모두. 방법 예: `@lezer/highlight` `styleTags({ 'FencedCode/CodeText': 새 태그 })` 를 `markdown({ extensions })` 로 넣고 `highlight.js` 에서 `md-fence` 클래스로 매핑
  - 편집 모드에서 펼친 코드블록은 울타리 줄(```` ``` ````)부터 닫는 울타리 줄까지 **줄 단위로 이어진 한 덩어리 바탕**(`--md-bg-muted`)으로 보인다. 글자 `--font-mono` 85%. 줄바꿈 모드는 그대로(펼친 상태에서는 긴 줄이 줄바꿈됨 — 문서 가로 스크롤을 만들지 않기 위해)
  - 인라인코드(`` `x` ``) 모양은 그대로
- **가로 스크롤 요소 아래 줄 클릭 위치 어긋남** (사용자 1차 수정 추가 요청 12번, 2026-09-14: "코드블럭이나 테이블 등 가로스크롤 생기는 요소 밑에 생기는 줄들 커서로 클릭한 곳과 미스매치됨. 아마 가로스크롤바 높이 때문에 생기는 차이로 추정됨")
  - CM6 는 블록 위젯 높이를 DOM 에서 재어 줄 위치표(height map)를 만든다. 위젯 높이가 CM6 가 모르게 바뀌거나 CM6 가 재지 않는 부분이 있으면 그 아래 줄의 클릭 위치가 어긋난다
  - 원인 후보 두 가지를 실측으로 가린다: (가) 가로 스크롤바가 측정 뒤에 생겨 위젯 높이가 늘어남 (나) 블록 위젯 바깥 `margin`(현재 `.md-block` 에 `margin: 4px 0`)은 CM6 높이 측정에 들어가지 않음
  - 고칠 것
    - 블록 위젯 최상위 요소에 세로 `margin` 을 쓰지 않는다. 간격은 최상위 요소의 `padding` 이나 안쪽 요소로 준다
    - 위젯 높이가 바뀌면 CM6 가 다시 재게 한다: `toDOM` 에서 `ResizeObserver` 로 최상위 요소를 관찰해 `view.requestMeasure()`. `destroy(dom)` 에서 관찰 해제
    - 스크롤바 때문에 높이가 흔들리지 않게, 스크롤 요소에 스크롤바 자리를 항상 두는 방법(예: 스크롤바 높이만큼 `padding-bottom` 고정)을 쓸지는 실측 결과로 정해 보고
  - 표 위젯은 F-125 가 새로 만들지만, 지금 표 위젯에도 같은 규칙을 적용한다
- 표(편집 모드 위젯, 보기 모드 `table`): `border-collapse: collapse`, 칸 안쪽 여백 6px 13px, 칸 테두리 1px `--md-border`, 머리 칸 굵기 600 · 배경 없음, ~~행 배경 `--panel`, 짝수 행(본문 기준) 배경 `--md-bg-muted`~~ → 2026-09-14 F-164: 모든 행 같은 바탕(문서 칸 바탕), 너비는 내용만큼·최대 100%·넘치면 가로 스크롤
- 구분선: 높이 2px, 배경 `--muted`, 테두리 없음, 블록 전체 높이 = 본문 한 줄 높이(위아래 여백은 `calc((줄높이 - 2px)/2)`) (2026-09-16 사용자 "위아래 패딩 큼, 두께 2px 로 한줄높이와 동일하게" — 이전 1px·고정 24px. 2026-09-15 "hr 더 얇고 진하게" — 이전 .25em `--md-border`)
- 목록 들여쓰기 2em (보기 모드). 편집 모드 목록 들여쓰기는 원문 공백이 정하므로 바꾸지 않는다
- 작업 목록 체크박스: 보기 모드 `.task-list-item` 은 목록 기호 없음, 체크박스 `accent-color: var(--accent)`. 편집 모드 체크박스 위젯도 `accent-color: var(--accent)`
