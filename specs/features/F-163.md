# F-163 공유 메뉴 `파일로 공유…` 제거

작성일: 2026-09-14
상태: 사용자 승인(2026-09-14 "전부 승인"). 사람 확인(2026-09-14) H21 실패 "공유하지 못했습니다 오류", 사용자 선택 "파일로 공유 항목 제거". 다른 명세와 파일이 겹치지 않아 순서 제약 없음
근거: Chromium `chrome/browser/webshare/share_service_impl.cc` 의 공유 허용 확장자·MIME 목록에 `.md`·`text/markdown` 이 없어 `PERMISSION_DENIED` 로 거부된다 (main 브랜치 원문 확인 2026-09-14, 사용자 Chrome 버전과 다를 수 있음). `navigator.canShare` 는 파일 형식을 검사하지 않아 항목이 보인다 (조사 에이전트 보고, Blink `navigator_share.cc`). F-130 2장

## 1. 파일 소유

| 파일 | 변경 |
| --- | --- |
| `src/app/ShareMenu.jsx` | `파일로 공유…` 항목·처리 삭제, 문구 2개 |

| `e2e/topbar.spec.js` | 공유 메뉴 항목 수를 세는 기존 테스트가 있으면 이 명세에 맞게, `F-163 A*` 추가 |

## 2. 요구사항
- 공유 메뉴는 `링크 복사`, `마크다운 복사` 2개. 키보드 이동(↑↓·Enter·Esc)은 2개 기준으로 그대로
- `navigator.share`·`canShare` 호출 코드를 남기지 않는다
- 파일로 공유를 권하던 문구를 바꾼다
  - 8,000자 초과 warn: `링크가 깁니다(약 {N}KB). 일부 메신저에서 잘릴 수 있어 .md 내보내기를 권장합니다.`
  - 2,000,000자 초과 error: `문서가 너무 커서 링크로 공유할 수 없습니다. .md 내보내기를 이용하세요.`
- 안드로이드(Capacitor) 단계에서 네이티브 공유를 다시 검토한다 (이 명세 범위 밖)
- 승인 후 메인이 함께 고칠 명세 문구: F-130 2장 표·34~35줄·3.2, `specs/ia.md` 60줄·3.19, `specs/product.md` F-130 행, F-143 `IconShareFile` 행, F-158 39줄, `specs/human-checks.md` H21
