## 2. 계약
```ts
export type SplitLayout = 'single' | 'cols' | 'rows' | 'grid' | 'three-left' | 'three-right' | 'three-top' | 'three-bottom' // F-2159 3장 그대로
export type PaneTabs = DocTabsState & { viewMode: ViewMode }
export type SplitState = { layout: SplitLayout; ratios: number[]; focus: number; panes: PaneTabs[] }
export type SplitDir = 'right' | 'down'; export const MAX_PANES = 4, RATIO_MIN = 0.2, RATIO_MAX = 0.8, MIN_PANE_PX = { width: 280, height: 160 }
export function singleSplit(tabs: DocTabsState, viewMode: ViewMode): SplitState              // ratios [], focus 0
export function splitPane(s: SplitState, pane: number, dir: SplitDir, tab: DocTab): SplitState | null
export function cycleSplit(s: SplitState, tab: DocTab): SplitState | null                        // Alt+Shift+D
export function closePane(s: SplitState, pane: number): SplitState | null                        // single 이면 null
export function setPaneTabs(s: SplitState, pane: number, tabs: DocTabsState): SplitState; export function prunePanes(s: SplitState): SplitState
export function paneForNumber(s: SplitState, n: number): number | null                            // Ctrl+1~4, n 은 1부터
export function clampRatios(layout: SplitLayout, ratios: readonly number[], size?: { width: number; height: number }): number[]
export function totalTabs(s: SplitState): number; export function paneTabLimit(s: SplitState, pane: number): number
export function parseStoredSplit(raw: string, scope: string, viewMode: ViewMode): SplitState | null
export function storeSplit(raw: string, scope: string, s: SplitState): string
```
- `panes` 순서(F-2159 3장): `cols` 왼·오 / `rows` 위·아래 / `grid` 왼위·오위·왼아래·오아래 / `three-left` 큰(왼)·오위·오아래 / `three-right` 큰(오)·왼위·왼아래 / `three-top` 큰(위)·아래왼·아래오 / `three-bottom` 큰(아래)·위왼·위오
- **`ratios` 뜻 — 경계 위치를 왼쪽·위에서 잰 비율**(큰 칸 몫이 아님. 거울 배치끼리 바뀔 때 값이 그대로라 "남은 칸 제자리"). `cols` [세로 경계 x], `rows` [가로 경계 y], `three-left/right` [x, 작은 둘 사이 y], `three-top/bottom` [y, 작은 둘 사이 x], `grid` [x, y]. 첫 값이 늘 큰 칸 경계

## 3. 나누기·닫기 전이
- **새 칸** = `{ tabs: [{ ...tab, pinned: true }], active: tab.key, viewMode: s.panes[s.focus].viewMode }`(흐름 결정 15, F-2159 Q2). `tab` 은 부르는 쪽이 고른 탭(메뉴 = 그 탭, 팔레트·키 = 포커스 칸 활성 탭). 포커스는 새 칸. `splitPane` 은 탭 합을 보지 않는다 — 부르는 쪽이 `totalTabs(s) >= MAX_TABS` 면 기존 `TABS_FULL` 알림, `panes.length === MAX_PANES` 면 `화면은 4칸까지 나눌 수 있습니다.`(F-2163)
- 나누기 표(a·b·c·d = 기존 칸, n = 새 칸). **아래에 없는 (배치, 칸, 방향) 조합은 전부 `null`**:

| 전 | 칸·방향 | 뒤 `panes` | 뒤 `ratios` | focus |
| --- | --- | --- | --- | --- |
| single [a] | 0 right / 0 down | cols [a,n] / rows [a,n] | [0.5] | 1 |
| cols [a,b] r | 0 down / 1 down | three-right [b,a,n] / three-left [a,b,n] | [r, 0.5] | 2 |
| rows [a,b] r | 0 right / 1 right | three-bottom [b,a,n] / three-top [a,b,n] | [r, 0.5] | 2 |
| three-left [a,b,c] [x,y] | 0 down | grid [a,b,n,c] | [x, y] | 2 |
| three-right [a,b,c] [x,y] | 0 down | grid [b,a,c,n] | [x, y] | 3 |
| three-top [a,b,c] [y,x] | 0 right | grid [a,n,b,c] | [x, y] | 1 |
| three-bottom [a,b,c] [y,x] | 0 right | grid [b,c,a,n] | [x, y] | 3 |
- `cycleSplit`: (focus, right) → (focus, down) → (0, right) → (0, down) 순서로 처음 `null` 이 아닌 결과. single 포커스 0 에서 세 번 → cols → three-left → grid(F-2159 3장 예시와 같음), grid 면 `null`
- 닫기 표(포커스가 닫힌 칸이었을 때의 새 포커스 = **굵게**. 닫힌 칸이 포커스가 아니었으면 포커스는 원래 칸을 새 자리로 따라간다). single 은 `null`(부르는 쪽이 지금처럼 홈):

| 전 | 닫는 칸 | 뒤 |
| --- | --- | --- |
| cols·rows [a,b] | 0 / 1 | single [**b**] / single [**a**], ratios [] |
| three-left [a,b,c] [x,y] | 0 / 1 / 2 | rows [**b**,c] [y] / cols [a,**c**] [x] / cols [a,**b**] [x] |
| three-right [a,b,c] [x,y] | 0 / 1 / 2 | rows [**b**,c] [y] / cols [**c**,a] [x] / cols [**b**,a] [x] |
| three-top [a,b,c] [y,x] | 0 / 1 / 2 | cols [**b**,c] [x] / rows [a,**c**] [y] / rows [a,**b**] [y] |
| three-bottom [a,b,c] [y,x] | 0 / 1 / 2 | cols [**b**,c] [x] / rows [**c**,a] [y] / rows [**b**,a] [y] |
| grid [a,b,c,d] [x,y] | 0 / 1 / 2 / 3 | three-left [**c**,b,d] / three-right [**d**,a,c] / three-left [**a**,b,d] / three-right [**b**,a,c], 모두 [x,y] |
- 굵은 칸 = 늘어난 칸(같은 열·같은 줄 짝), 큰 칸을 닫았을 때는 남은 둘 중 위·왼쪽. three-top/bottom 에서 만든 grid 의 새 칸을 닫으면 three-left/right 가 된다 — F-2159 3장 "같은 열 칸이 세로로" 그대로라 되돌림이 아니다
- `setPaneTabs`: 그 칸 `tabs`·`active` 만 바꾸고, 결과가 빈 탭이고 칸이 2개 이상이면 `closePane`(흐름 5 "마지막 탭을 닫으면 칸 닫힘"). single 은 빈 채로 둔다(홈). `prunePanes`: 빈 칸을 뒤에서부터 `closePane`, 마지막 한 칸은 남긴다(F-2164 복원에서 칸마다 `restoreTabs` 뒤에 부른다)
- `paneForNumber`: 칸 번호 = 칸 왼쪽 위 꼭짓점을 위→아래, 같으면 왼→오로 읽은 순서(F-2159 5장). 배치별 `panes` 자리: single [0], cols·rows [0,1], grid [0,1,2,3], three-left·three-top [0,1,2], three-right [1,0,2], three-bottom [1,2,0]. 범위 밖 n 은 `null`

## 4. 비율·최소 크기·탭 상한
- `clampRatios`: 길이가 배치 기대값(single 0, cols·rows 1, 그 밖 2)과 다르면 전부 0.5. 각 값은 유한수가 아니면 0.5, 그다음 [`RATIO_MIN`, `RATIO_MAX`] 로 자른다. `size` 를 주면 그 값의 축(x 축 = `width`·280, y 축 = `height`·160)으로 하한을 `max(0.2, 최소px/축px)`, 상한을 `min(0.8, 1 − 최소px/축px)` 로 좁히고, 하한 > 상한(축이 두 칸 최소보다 좁음)이면 0.5. 축 px 는 칸 전체 영역(사이드바·패널 뺀 것)이고 경계 막대 두께는 빼지 않는다
- **최소 칸 크기 판정은 이 명세의 순수 함수로 둔다**(F-2163 몫이 아님) — 창 크기 변경·복원(F-2163·F-2164)과 경계 끌기(F-2165)가 같은 함수를 부르게 하려고. 나누기 자체는 크기로 막지 않는다: 분할은 창 1024px 이상에서만 켜지고(흐름 결정 1) 칸 영역이 축마다 두 칸 최소(560×320)를 넘으면 `clampRatios(…, size)` 가 280×160 을 보장한다. 그보다 좁은 축은 0.5 로 두고 최소를 보장하지 않는다
- `totalTabs` = 모든 칸 탭 수 합(같은 문서가 두 칸이면 둘로 센다). `paneTabLimit(s, i)` = `MAX_TABS − (totalTabs(s) − panes[i].tabs.length)`. 칸 안 열기는 `openTabCapped(pane, entry, mode, paneTabLimit(s, i))` — 창 합 20 에 닿으면 지금처럼 그 칸 활성 탭 자리를 바꾸고 `TABS_FULL_REPLACED`(F-2159 3장 "창 전체 합", 문구 그대로). 읽기는 합이 20 을 넘어도 자르지 않는다(지금 `parseStoredTabs` 와 같음)

## 5. 저장 형식
- `storeSplit`: single 이면 `{ tabs, active }` 만 — **`storeTabs(raw, scope, panes[0])` 와 같은 문자열**. 그 밖은 `{ tabs, active, split: { layout, ratios, focus, panes: [{ tabs, active, viewMode }] } }`, `tabs`·`active` = `panes[focus]` 거울. 다른 범위는 그대로
- `storeTabs`(분할이 꺼진 곳 — 휴대폰 폭·이전 경로): 범위 항목의 `split` 이 객체이고 `panes` 가 배열이고 `focus` 가 그 안 정수면 `split.panes[focus]` 의 `tabs`·`active` 만 새 값으로 바꿔 남긴다. 아니면 `split` 을 뺀다. `split` 이 없던 항목의 출력은 지금과 같다
- `parseStoredSplit`: 범위 항목이 없거나 `tabs` 가 배열이 아니면 `null`(`parseStoredTabs` 와 같음). 거울(`parseStoredTabs` 결과)을 먼저 읽고, `split` 이 아래 중 하나면 **깨진 것 → `singleSplit(거울, viewMode)`**: 객체 아님, `layout` 이 8개 밖, `panes` 가 배열 아님 또는 길이 ≠ 배치 칸 수, `focus` 가 범위 밖 정수·정수 아님
- 깨지지 않았으면 칸마다 `parseTabsEntry`(null 이면 빈 탭), `viewMode` 가 `live`·`raw`·`view` 밖이면 인자 `viewMode`(부르는 쪽 `md.viewMode`). **`panes[focus]` 의 탭은 거울로 덮는다**(어느 판이 쓰든 거울은 늘 맞춰진다). `ratios` 는 `clampRatios(layout, ratios)`(크기 없이), 끝으로 `prunePanes`. 이전 앱 판(지금 HEAD)의 `storeTabs` 는 `split` 을 지워 다음 읽기가 single 이 된다 — 그대로 받아들인다
