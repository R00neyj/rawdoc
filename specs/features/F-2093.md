## 2. 핵심 결정

1. **모든 권장 선택자는 `:root:root` 로 시작한다** — 변수(`:root:root { }`), 뼈대 훅(`:root:root [data-ui="…"]`), 본문 훅 편집·보기 양쪽. 개요는 뼈대 `:root [data-ui]`, 본문 `:root …` 초안이었으나 초안 33개 중 11개가 앱 규칙에 지고(M2), 이긴 것도 대부분 동률이라 tweak 하나에 뒤집힌다. 한 규칙으로 통일하면 사용자가 외울 것이 하나다. 과한 특정도는 사용자에게 손해가 없다 — 앱 규칙보다 뒤에 오는 사용자 시트 안에서는 같은 접두를 쓰는 한 뒤 규칙이 이긴다 (13장 Q1)
2. **U5 가 실패하면 앱 선택자를 낮춘다.** 권장 선택자를 올리면 이미 그 문자열을 쓴 사용자 스니펫이 지기 시작하므로 계약 변경이다(명세 + 체인지로그 `사용자 CSS:` 줄, 개요 1.1). tweak 은 새 규칙을 `:where()` 로 감싸거나 선택자를 줄여 통과시킨다
3. **테스트가 계약 이름의 고정 사본을 든다.** U1·U2 가 "모듈의 목록이 소스에 있다" 만 보면, 이름을 모듈과 소스 **양쪽에서** 바꾸는 tweak 이 통과한다. 테스트 파일에 이름 목록을 한 벌 더 적어 두 사본이 어긋나면 실패하게 한다 — 여기서는 어긋남이 곧 신호다 (13장 Q3)
4. **본문 훅 선택자는 배열이다.** 제목 1~6 을 한 훅(개요의 11개 셈)으로 두되 `edit`·`view` 에 6개씩 담아 U5 가 여섯 단을 모두 잰다. 개요 1.6 의 `edit: string` 을 `readonly string[]` 로 바꾼다
5. **뼈대 훅이 붙는 곳을 개요 표보다 넓힌다** — 값 17개는 그대로, 같은 뜻의 다른 모양에도 붙인다: `doc-title` 은 인쇄 제목까지, `outline` 은 중간 폭 팝업까지, `comments` 는 휴대폰 판까지, `menu` 는 드롭다운 8개까지 (4.2, 13장 Q4)
6. **템플릿 줄 형식은 "설명 줄 + 선언 줄" 두 줄.** 개요 5.3 의 한 줄 형식은 D-16(CM6)의 `Mod-/` 로 풀면 깨진다(R1) (7.2)
7. **`buildTemplateCss` 는 순수 함수로 두고 `tokens.css` 원문은 부르는 쪽이 넘긴다.** 원문을 들고 오는 얇은 모듈(`src/app/userCssTemplate.ts`, `?raw`)은 첫 호출부인 F-2096 이 만들고 **동적 import** 한다 (7.4)

- 콜아웃 종류: 편집 줄과 보기 `div` 가 **둘 다** `md-callout--{kind}` 를 갖는다(`lines.ts`·`renderMarkdown.ts`). `kind` 는 `note` `tip` `success` `question` `warning` `danger` `example` `quote` 여덟. 보기의 `data-callout` 은 사용자가 쓴 종류 이름 그대로(별칭 포함)라 개요 1.5 대로 남기되 라벨·템플릿에는 `.md-callout--{종류}` 를 권한다. 색만 바꿀 때는 `--callout-{종류}` 변수가 더 쉽다(안내 글 F-2100 몫)

- **가상 요소**(`::before`·`::after`·`::marker` 등). 편집 구분선은 `::before` 가 선을 그리고 보기 목록 기호도 `::before` 다 — 권장 선택자 뒤에 `::before` 를 붙여 써도 되지만 이긴다고 약속하지 않는다(U5 비교에서 빠진다, 6.5)
- **초점 표시**(`:focus`·`:focus-visible`·`:focus-within`). 사용자 CSS 가 초점 테두리를 우연히 덮지 않는 편이 낫다(접근성). 초점 규칙은 U5 비교에서 빠진다
- 뼈대 훅의 특정도 — 개요 1.4 대로 "요소가 거기 있다" 만 약속한다. `:root:root [data-ui="…"]` 는 (0,3,0) 이라 지금 뼈대 앱 규칙 최댓값 (0,3,0)(개요 M11) 과 동률이지만 U5 로 묶지 않는다

### 6.5 U5 — 권장 선택자가 앱 규칙 이상

**읽는 CSS:** `src/**/*.css` 전부와 `node_modules/github-markdown-css/github-markdown-light.css`(`Viewer.tsx` 가 import 한다). 주석을 지우고 문자열 안 괄호·중괄호를 건너뛰며 블록을 걷는다. `@media`·`@supports`·`@container`·`@layer`·`@scope` 블록은 **안으로 들어가고**, `@keyframes`·`@font-face`·`@page`·`@property`·`@counter-style`·`@font-feature-values`·`@font-palette-values` 블록과 `@import`·`@layer x;` 문장은 **건너뛴다.** 규칙 머리는 괄호 밖 쉼표로 나눈다. CM6 가 `style-mod` 로 넣는 규칙은 읽지 않는다(R2).

**특정도:** 표준 (a,b,c). `:is()`·`:not()`·`:has()`·`:matches()` 는 인자 중 최댓값, `:where()` 는 0, 가상 요소(`::x` 와 옛 한 쌍점 `:before`·`:after`·`:first-line`·`:first-letter`)는 (0,0,1), 그 밖 가상 클래스(`:nth-child()` 포함, `of S` 는 무시)는 (0,1,0), `*`·결합자는 0. 판정용 고정 값(이 PC 계산기와 같다):

| 선택자 | 특정도 |
| --- | --- |
| `:root:root .markdown-body :not(pre) > code` | (0,3,2) |
| `:is(.app-shell, .public-view, .wiki-preview) .markdown-body h1` | (0,2,1) |
| `.cm-host .cm-editor[data-view='live'] .md-link:hover` | (0,5,0) |
| `.print-root .markdown-body :is(pre, code, .markdown-callout, mark, th, tr:nth-child(even))` | (0,3,1) |
| `.markdown-body a:has(>p,>div,>pre,>blockquote):not(:has(.snippet-clipboard-content,>pre))` | (0,2,2) |
| `.cm-host .cm-editor .cm-line.md-hr::before` | (0,4,1) |
| `:where(h1, h2)` | (0,0,0) |
| `#x .y` | (1,1,0) |

**겨루는 앱 선택자 — 권장 선택자 R 마다:**
- R 의 **열쇠** = R 의 마지막 복합 선택자에서 기능 가상 클래스 괄호 밖에 있는 클래스·아이디·속성·타입 조각의 집합(예: `.cm-line.md-h1` → {`.cm-line`, `.md-h1`}, `:not(pre) > code` → {`code`})
- 앱 선택자 S 가 R 과 겨루는 조건 — 모두 참일 때:
  1. S 어디에도 `:focus`·`:focus-visible`·`:focus-within` 이 없다
  2. S 의 마지막 복합 선택자(괄호 밖 `:is()`·`:matches()`·`:where()` 가 있으면 인자마다 그 인자의 마지막 복합으로 펼친 것 각각) 중 **가상 요소가 없고 조각 집합이 열쇠와 똑같은 것**이 하나 있다. 조각이 더 많은 것(`pre.markdown-frontmatter-raw`, `.md-callout-type.md-link`)은 다른 요소로 본다
  3. 열쇠에 `md-`·`markdown-` 으로 시작하는 클래스가 없으면(`h1`·`table`·`.cm-content` 처럼 흔한 조각) S 가 R 의 앞쪽 복합 선택자들에 있는 클래스(`.markdown-body`·`.cm-editor`·`.md-block`·`.md-table`) 중 하나를 담는다 — 없으면 `.sidebar h2`·자동 완성 `li` 같은 남의 요소까지 겨루게 된다
- 판정: R 마다 겨루는 S 가 **1개 이상**이고(0개면 클래스 이름이 어긋난 것 — U2 와 겹쳐 잡는다), 특정도(R) ≥ 겨루는 S 특정도의 최댓값
- 실패 메시지에 R, 이긴 S, 그 파일을 담는다. 고치는 법은 2장 결정 2(앱 선택자를 낮춘다)

### 6.6 U6 — 템플릿 CSS

`tokens.css` 원문을 `readFileSync` 로 읽어 `buildTemplateCss` 에 넘긴다(vitest 는 `?raw` 를 쓰지 않는다 — 인자로 받는 까닭, 개요 5.3).

- 결과에 `PUBLIC_VARS` 이름 51개, `:root:root [data-ui="{값}"]` 17개, `CONTENT_HOOKS` 선택자 전부(33개)가 들어 있다
- **주석을 모두 지우면** 남는 글자(공백을 하나로 줄여)가 정확히 `:root:root { } :root[data-theme='dark'] { }` 다 — 켜 둬도 아무것도 안 바뀌고, 주석 안에 `*/` 가 새어 닫히는 일이 없다는 뜻이다
- 결과의 hex(`#` + 16진 3·4·6·8자리)가 모두 `tokens.css` 원문에 있는 문자열이다. `buildTemplateCss('')` 의 결과에는 hex 가 **0개**이고 이름 51개는 그대로 있다(값만 빈다, 7.3)
- 다크 블록의 선언 줄이 가리키는 이름 집합 = `tokens.css` `:root[data-theme='dark']` 블록이 선언한 이름 ∩ 공개 변수(지금 17개 — 숫자는 박지 않고 원문에서 셈한다)
- 선언 줄은 모두 `  /* {이름}: {값}; */` 꼴, 선택자 줄은 모두 `/* {선택자} { } */` 꼴(7.2). 어느 줄도 `/* … */ /* … */` 처럼 주석 둘을 담지 않는다
- 결과에 제품명(`brand.config.ts` 의 이름, 대소문자 무시)이 없다. 줄 끝은 `\n` 만, 끝은 `\n` 하나
- 같은 입력이면 같은 출력(두 번 불러 같다)

## 7. 템플릿 CSS — `buildTemplateCss(tokensCss)`

### 7.1 순서 (개요 5.3 의 다섯 부분 그대로)

1. 머리 주석 (7.2 원문)
2. 빈 줄, `:root:root {` — 공개 변수 51개를 3.2 순서로. 묶음이 바뀔 때 `  /* ── {묶음} ── */` 한 줄(첫 묶음 앞 빈 줄 없음, 그 뒤 묶음 앞에는 빈 줄 하나). 변수마다 설명 줄 + 선언 줄. `}`
3. 빈 줄, `/* ── 다크 테마에서 값이 다른 것 ── */`, `:root[data-theme='dark'] {` — 다크 블록이 선언한 공개 변수만, **3.2 순서로**, 같은 두 줄 모양. `}`
4. 빈 줄, 뼈대 머리 줄, 뼈대 훅 17개를 4.1 순서로 — 설명 줄 `/* {라벨} */` + 선택자 줄 `/* :root:root [data-ui="{값}"] { } */`
5. 빈 줄, 본문 머리 줄, 본문 훅 11개를 5.1 순서로 — `/* {라벨} — 편집 모드 */` + `edit` 선택자 줄들, `/* {라벨} — 보기·인쇄·HTML */` + `view` 선택자 줄들

### 7.2 줄 모양 (문자열이 계약이다)

머리 주석 원문 — `설정·상태에 따라:` 줄의 속성 목록은 `STATE_ATTRS` 에서 `data-theme` 를 뺀 것을 표 순서대로 쓴다. `on` 이 같은 것이 이어지는 동안은 ` · ` 로 잇고, 그 무리 끝에 ` (<html>)`(`on: 'html'`) 또는 ` (문서 영역)`(`on: 'content'`) 을 한 번 붙이며, 무리와 무리 사이는 `, ` 로 잇는다(아래가 지금 결과):

```css
/*
  사용자 CSS 템플릿
  모든 줄이 주석이라 켜 둬도 화면이 바뀌지 않습니다.
  바꾸고 싶은 줄의 앞뒤 주석 표시를 지우면 바로 적용됩니다.
  사용법: /guides/custom-css

  선택자 규칙
  - 모든 테마·인쇄·HTML 내보내기에: :root:root
  - 한 테마에만: :root[data-theme='white'] · 'sepia' · 'dark'
  - 설정·상태에 따라: data-heading-font · data-body-font · data-font-size · data-indent · data-printing (<html>), data-view-mode (문서 영역)
  - 이 템플릿에 없는 클래스는 업데이트로 바뀔 수 있습니다.

  화면이 망가져 이 창을 열 수 없으면 주소 끝에 ?safe 를 붙여 여세요 (/?safe).
*/
```

그 밖의 줄:

```css
  /* ── 기본 색 ── */
  /* 앱 바탕 */
  /* --paper: #faf8f4; */
/* ── 다크 테마에서 값이 다른 것 ── */
/* ── 화면 뼈대 — 요소가 그 자리에 있다는 것만 약속합니다. 앱 규칙에 지면 특정도를 올리거나 !important 를 쓰세요 ── */
/* 사이드바 — 접힌 레일·좁은 화면 겹침 포함 */
/* :root:root [data-ui="sidebar"] { } */
/* ── 본문 — 이 선택자는 앱 규칙과 특정도가 같거나 높아 그대로 쓰면 이깁니다 ── */
/* 인용 — 편집 모드 */
/* :root:root .cm-editor .cm-line.md-quote { } */
/* 인용 — 보기·인쇄·HTML */
/* :root:root .markdown-body blockquote { } */
```

- 위 `#faf8f4` 는 **보기일 뿐** — 모듈은 이 값을 적지 않고 `tokensCss` 에서 읽는다(3.6 불변식). 모듈 소스에 hex 가 없다(`npm run review` 의 `HEX_RE` 도 본다)
- **설명 줄과 선언 줄을 나눈 까닭:** D-16 은 CM6 + `lang-css` 이고(F-2092 Q1), `Mod-/` 는 줄 앞뒤 `/*`·`*/` 만 지운다(R1). 한 줄에 주석 둘이면 풀 때 깨진다. 선언만 한 줄에 있으면 `Mod-/` 한 번으로 `--paper: #faf8f4;` 가 된다. 빈 규칙 `{ }` 를 담은 선택자 줄도 같다
- 주소는 **상대 경로**만 쓴다(`USER_CSS_GUIDE_PATH`, `/?safe`). 도메인을 적으면 제품명 문자열이 소스에 들어간다(불변식)
- 들여쓰기: 두 블록(`:root:root`·다크) 안 줄은 공백 두 칸, 그 밖은 없음

### 7.3 기본값 읽기

- 주석을 모두 지운 `tokensCss` 에서 **첫 `:root {…}`** 와 **`:root[data-theme='dark'] {…}`** 블록을 찾는다(`tokens.test.ts` 와 같은 방식). 블록 안 `--이름: 값;` 의 값은 공백 묶음을 한 칸으로 줄이고 앞뒤를 자른다(`--transition-colors` 처럼 여러 줄인 값이 있다 — 비공개지만 방식은 같다)
- 값은 원문 그대로다: `--accent: var(--brand-accent);`, `--accent-soft: color-mix(in srgb, var(--accent) 10%, transparent);`. 풀어서 계산하지 않는다
- 찾지 못한 이름·블록은 **값을 비운 선언 줄**(`  /* --paper: ; */`)로 남긴다. 다크 블록을 못 찾으면 다크 블록 안은 비고 규칙 `{` `}` 는 남는다. 던지지 않는다 — 템플릿은 도움 글이고, 빈 값 줄은 풀어도 브라우저가 무시한다
- 크기: 지금 `tokens.css` 로 약 10.8KB(M4). 개요 3.4 상한 256KiB 에 비해 작다

### 7.4 원문을 어디서 얻나 — F-2096 이 지킬 모양

- `buildTemplateCss` 는 인자만 받는다. 원문을 들고 오는 것은 **F-2096 이 새로 만드는 얇은 모듈 `src/app/userCssTemplate.ts`** — `import tokensCss from '../styles/tokens.css?raw'` 와 `buildTemplateCss(tokensCss)` 를 돌려주는 함수 하나
- `템플릿으로 시작` 버튼은 그 모듈을 **동적 import** 한다(`await import('./userCssTemplate')`). 정적 import 하면 `tokens.css` 원문(11,918 바이트)이 설정 대화상자 청크나 앱 첫 청크에 들어간다
- 번들 영향(M6): 같은 `?raw` 를 `exportHtmlCss.ts`(이미 동적 import)와 함께 읽게 되므로 Vite 는 원문을 **작은 공유 청크 하나(약 12KB, gzip 약 5KB)** 로 뺀다. 앱 첫 청크는 그대로, `exportHtmlCss-*.js` 는 그만큼 준다. F-2096 구현 보고에서 `dist/assets` 로 확인한다
- `TOKENS_CSS_RAW`(`exportHtmlCss.ts`)를 재사용하지 **않는다** — 그 청크는 KaTeX 글꼴을 인라인으로 담아 437,722 바이트다(2026-09-30 `dist/assets/exportHtmlCss-zga5zKcH.js`)

## 13. 열린 질문 / 사람 결정 필요

### Q1. 모든 권장 선택자를 `:root:root` 로 통일할 것인가 — **기본값: 통일한다 (뼈대 훅 포함)**

- 기본값인 까닭: 초안 그대로면 11개가 지고(M2·M3), 이긴 것도 대부분 앱과 동률이라 tweak 하나(예: `[data-view='live']` 하나 더하기)에 뒤집힌다. 한 접두로 모두 한 단 위에 두면 여유가 생기고, 사용자가 외울 규칙이 "모든 선택자는 `:root:root` 로 시작" 하나가 된다 — 변수 권장(`:root:root { }`)과도 같다
- 다른 쪽(모자란 곳만 올림)을 고르면: 초안 22개는 `:root` 하나로 두고 11개만 `:root:root` 로. 표가 섞여 사용자가 어느 쪽인지 외워야 하고, 동률 22개는 여유가 0 이라 U5 가 tweak 마다 걸릴 확률이 커진다. 뼈대 훅은 개요대로 `:root [data-ui]`. 5.1·5.2·7.2 의 문자열과 고정 사본이 바뀐다

### Q2. U5 비교에서 초점 규칙·가상 요소를 뺄 것인가 — **기본값: 뺀다**

- 넣는 쪽을 고르면: 보기 링크가 `github-markdown-light.css` 의 `:focus-visible` 규칙 (0,3,2) 를, 보기 목록이 `markdown.css` 의 `li:not(.task-list-item)::before` (0,3,3) 를 넘어야 해 `:root:root:root …` 가 필요하다. 초점 테두리를 사용자 색 규칙이 덮을 수 있게 되는 것도 접근성에 불리하다

### Q3. 테스트에 계약 이름의 고정 사본을 둘 것인가 — **기본값: 둔다**

- 두지 않으면: 모듈과 소스 양쪽 이름을 함께 바꾸는 tweak 이 U1·U2 를 통과해 사용자 스니펫이 조용히 깨진다(개요 A10 이 막으려던 것). 대가는 계약을 바꾸는 명세가 테스트 사본도 고쳐야 한다는 것 — 의도한 마찰이다

### Q4. 뼈대 훅이 붙는 곳을 넓힐 것인가 — **기본값: 넓힌다 (4.2 — 인쇄 제목·목차 팝업·휴대폰 댓글 판·드롭다운 메뉴 8곳)**

- 개요 표 그대로를 고르면: `menu` 는 우클릭 메뉴에만, `doc-title` 은 인쇄에서 안 먹고, 중간 폭 목차·휴대폰 댓글 판에는 훅이 없다. 소유 파일이 9개 줄고(`printDoc.ts` + 메뉴 8개) 병렬 충돌 위험이 준다. 값 17개(사용자 결정 Q9)는 어느 쪽이든 같다

### Q5. 템플릿에 세피아 블록도 둘 것인가 — **기본값: 두지 않는다 (개요 5.3 대로 다크만)**

- 두는 쪽을 고르면: 3번 뒤에 `:root[data-theme='sepia']` 블록(지금 9개 변수, 약 0.4KB)이 붙고 U6 의 "주석을 지우면 남는 것" 이 규칙 셋이 된다. 세피아 사용자는 지금도 머리 주석의 테마 규칙으로 직접 쓸 수 있다

### Q6. 이 명세에 e2e 를 둘 것인가 — **기본값: 1개(A10)**

- 개요 6장 "판정 나눔" 은 계약을 단위 테스트만으로 적었다. 0개를 고르면 A10 이 빠지고, 속성이 엉뚱한 요소에 붙거나 `data-view-mode` 가 모드를 안 따라가도 F-2095 이후 사람 눈에만 걸린다

## 14. 확인한 것과 가정

### 14.1 코드를 읽거나 돌려 확인한 것

- 머리의 M1~M9(돌림), R1·R2(읽음)
- 훅을 붙일 요소와 파일(1장·4.1) — 각 파일의 해당 JSX·DOM 코드를 직접 읽었다. `Outline` 의 세 반환 분기, `CommentRailPanel` 의 `mode` 분기, `DocumentArea` 의 `Viewer` 조건(`viewMode === 'view'`), `editor-slot` 의 `hidden`

### 14.2 가정으로 남긴 것
