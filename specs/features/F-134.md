## 3. 수정 항목

### 3.1 조합 중 decoration 위치 옮기기 (high)
- 현재: `inline.js` `update()`·`lines.js` `update()` 는 조합 중이면 `return` 만 하고 `this.decorations = this.decorations.map(update.changes)` 를 하지 않는다. `blocks.js` 는 한다
- 결과: 조합으로 글자가 들어가면 아래쪽 숨김 범위가 옛 위치에 남아 줄바꿈을 덮고, CM 이 `RangeError("Decorations that replace line breaks may not be specified via plugins")` 를 던져 DOM 이 반쯤 갱신된 채로 남는다 (`@codemirror/view/dist/index.js:2753`). 입력 위치 오류의 1순위 후보
- 수정: 조합 중 보류할 때 `docChanged` 면 decorations 를 `update.changes` 로 map 한다. 조합 종료 따라잡기(`composition.js`)는 그대로
- 테스트: 조합 상태를 흉내 낼 수 없으면 map 분기를 함수로 떼어 "보류 + 문서 변경 → map 결과가 새 문서 범위 안이고 줄바꿈을 덮지 않음" 을 확인

### 3.2 링크 클릭은 링크 글자 위에서만 (medium)
- 현재: `links.js` 는 `posAtCoords` 결과로 `findLinkAt` 을 찾는다. 줄 끝 오른쪽 빈 곳을 눌러도 줄 끝 위치가 나와, 줄이 링크·맨 URL 로 끝나면 링크가 열리고 커서는 안 움직인다
- 수정: 클릭한 좌표가 실제로 링크 글자 위일 때만 연다. 방법: `event.target` 이 링크 표시 요소(링크 mark 의 DOM) 안인지 확인하거나, 찾은 링크 범위의 `coordsAtPos` 사각형 안에 좌표가 있는지 확인. 링크 밖이면 기본 처리(커서 이동)로 넘긴다
- 테스트: 판정 함수를 떼어 "줄 끝 오른쪽 좌표 → 열지 않음" 단위 테스트, 브라우저 확인 1회

### 3.3 위젯 `eq` 가 원문 위치 정보까지 비교 (medium-low)
- 현재: `blocks.js:96`, `:165` 위젯 `eq` 가 표시 내용만 비교한다. CM 은 `eq` 가 참이면 옛 DOM 을 재사용해서, 칸 글자는 같고 공백·구분 행·펜스 길이·들여쓰기만 다른 두 블록 사이에서 `data-offset` 이 옛 값으로 남는다
- 수정: 클릭 위치 계산에 쓰는 모든 값(칸별 원문 offset, `codeOffset` 등)을 `eq` 비교에 넣는다. 사실과 다른 주석 "codeOffset 은 info 길이에서 나오는 파생값" 은 고친다
- 테스트: 글자 같고 공백만 다른 표 두 위젯 → `eq` 거짓

### 3.4 여러 CodeText 코드블록 (medium)
- 현재: `blocks.js:215-221` 이 마지막 `CodeText` 노드만 쓴다. 목록·인용 안 코드블록은 lezer 가 줄마다 `CodeText` 를 나누어(`@lezer/markdown/dist/index.js:396-402, 478-487`) 마지막 줄만 보인다
- 수정: 모든 `CodeText` 를 모아 줄바꿈으로 이어 표시하고, 클릭 오프셋은 각 줄의 원문 시작 위치로 계산한다 (들여쓰기·`> ` 접두는 표시하지 않음)
- 테스트: `- 항목\n\n  ```\n  a\n  b\n  ```` 와 `> ```\n> a\n> b\n> ```` 에서 위젯 내용 `a\nb`, 줄 2의 첫 글자 offset 이 원문 `b` 위치

### 3.5 자동 짝 Backspace·건너뛰기 조건 (medium / low)
- Backspace (F-127 3.3 60행): 앞뒤 글자가 같은 기호일 때만 보지 말고 **빈 짝**일 때만 동작한다. 빈 짝 = 커서 앞 같은 기호 묶음과 뒤 같은 기호 묶음 길이가 같고, 앞 묶음 앞 글자가 같은 기호가 아니며 그 앞이 3.3 짝 조건의 "앞 글자" 조건을 만족. 코드블록·인라인코드 안에서는 동작하지 않는다
  - 테스트: `**굵게*|*` Backspace → 기본 동작(`**굵게|*`), `a**|b` 에서 규칙 미적용, `**|**` → `*|*`, `*|*` → `|`, 펜스 안 `*|*` 규칙 미적용
- 건너뛰기 (F-127 3.3 57행, 이 명세와 함께 수정): 앞 글자가 **공백이 아닌 글자이고 같은 기호가 아닐 때**만 건너뛴다. 줄 시작·공백 뒤에서는 건너뛰지 않는다
  - 테스트: 줄머리 `|* 항목`·`|*기울임*`·`단어 |*` 에서 `*` → 글자가 들어감

### 3.6 재사용 DOM 의 ResizeObserver 해제 (low)
- 현재: 위젯 DOM 이 재사용되면 새 위젯 인스턴스에 `observer` 가 없어, `destroy` 가 처음 만든 `ResizeObserver` 를 끊지 못한다
- 수정: observer 를 위젯 인스턴스가 아니라 DOM 요소에 묶어(예: `WeakMap<Element, ResizeObserver>`) `destroy(dom)` 에서 그 요소 기준으로 해제한다

### 3.7 줄바꿈을 덮는 숨김 방지 (low)
- 현재: 여러 줄 `LinkTitle`(`[a](u "첫줄\n둘째줄")`)도 숨김 범위로 만들어 RangeError 가 난다
- 수정: `inline.js`(와 플러그인이 만드는 모든 replace decoration)는 범위 안에 줄바꿈이 있으면 만들지 않는다. 한 곳의 공통 검사로 처리
- 테스트: 위 문서 `buildInline` 결과에 줄바꿈을 덮는 replace 없음

### 3.8 구문 트리만 바뀐 갱신 (low)
- 현재: `blocks.js`·`inline.js`·`lines.js` 는 문서·선택·뷰포트 변화가 없으면 재계산하지 않는다. 백그라운드 구문 분석이 끝나 트리만 바뀐 갱신을 놓쳐 긴 문서 뒷부분 위젯이 늦게 생긴다
- 수정: `syntaxTree(update.startState) !== syntaxTree(update.state)` 도 재계산 조건에 넣는다 (조합 중 보류 규칙은 그대로)

### 3.9 `#fff` 토큰화
- `src/styles/app.css` 의 `.dialog-actions button.danger`, `.seg button[aria-checked='true']` 의 `color: #fff` → `var(--panel)`
