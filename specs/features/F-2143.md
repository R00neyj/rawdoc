# F-2143 칸반 보드 만들기 진입점과 보드로 보기

작성일: 2026-10-14
상태: 승인 대기. 개요 F-2138 5장 사용자 흐름 1절 진입점과 2절 `보드로 보기`. 템플릿은 지금 문서에 넣기(F-2138 Q1), 사이드바 `새 문서` 버튼은 그대로(Q3), `보드로 보기` 는 `##` 칸 하나면 된다(Q5). 구현 담당 `feature-implementer`. `App.tsx` 증가 약 4줄

## 근거 (2026-10-14 HEAD, 이름으로 찾는다)
- `Sidebar.tsx` `FolderRow` `ownItems` 가 폴더 `⋯` 와 우클릭 메뉴(`onRowContextMenu`)에 같이 쓰인다. 순서 `new-doc` `새 문서` → `new-subfolder` `하위 폴더` → `rename` …
- 사이드바 빈 자리(`.sidebar-scroll`·`.tree-root-drop`)에는 `onContextMenu` 가 없다 — 최상위에 만드는 길은 새 메뉴를 만들지 않고 팔레트가 맡는다
- `useDocNavigation.ts` `createDoc(input)` 이 금고 폴더 확인·`beforeLeaveDoc`·생성·제목 포커스·폴더 펼치기를 한다. `createNewDoc` 은 `folderId` 생략 시 최상위
- 템플릿 넣기(`useCommandPalette.ts` `insertTemplate` → `planTemplateInsert`)는 문서 프론트매터에 없는 키만 더한다 → 내장 `칸반` 을 넣으면 `kanban: true` 가 붙는다. 설정 `새 문서 템플릿` 으로 골라도 같은 원문이 새 문서가 된다
- `tests/src/app/paletteCommands.test.ts` U3 가 명령 id 순서 전체를 못 박는다(38~86행)

## 2. 만들기
- `createNewBoard(folderId?)` = `createDoc({ folderId: folderId ?? null, title: '제목 없는 보드', focus: 'title', content })`, 본문은 `fromEditorText(KANBAN_NEW_DOC_TEXT, 'crlf')`(`새 문서 템플릿` 설정은 쓰지 않는다). 열리면 F-2140 `open` 이 `board` 를 고르고 `.kanban-title` 에 포커스·전체 선택
- **폴더 `⋯`·우클릭 메뉴**: `ownItems` 의 `하위 폴더` 바로 다음에 `new-board` `새 칸반 보드`(`IconKanban`) → `onCreateBoard(폴더 id)`. 옵시디언 폴더 우클릭 메뉴(새 노트·새 폴더·새 캔버스) 같은 자리
- **팔레트**: `kanban.new` `새 칸반 보드`(`doc.new` 바로 뒤, `when`: `docActions?.newBoard` 가 있을 때, 최상위)
- **템플릿**: `BUILTIN_TEMPLATES` 끝에 `{ key: 'kanban', title: '칸반', body: '---\nkanban: true\n---\n\n## 할 일\n\n## 진행 중\n\n## 완료' }`(다른 내장처럼 `#` 제목 없음 — 지금 문서에 넣는 틀이라). 넣은 뒤 문서가 처음 `isKanban` 이 되면 `showBoard()`

## 3. 보드로 보기
```ts
// paletteContract.ts
docActions.newBoard?: () => void // 선택 — 기존 테스트의 docActions 모양(443~448행·629행)을 그대로 두려고
kanban?: { shown: boolean; canShow: boolean; show: () => void }
```
- `kanban.show` `보드로 보기`(`mode.view` 바로 뒤). `when`: `ctx.kanban?.canShow`. `canShow` = 문서 화면에 문서가 열려 있고 보드가 안 보이며, (칸반 문서이거나 읽기 전용이 아님)
- `showBoard()`: 칸반 문서면 `choose board`. 아니면 `parseKanban(지금 원문)` 이 칸 0개 → 알림 `칸으로 쓸 ## 제목이 없습니다.`(정보), 원문 그대로. 1개 이상 → `applyKanban(kanbanFlagChange(원문), 'kanban.flag')` 뒤 `choose board`. `Ctrl+Z` 한 번이면 줄이 빠지고 F-2140 `kanbanChanged` 거짓으로 문서 화면
- `mode.live`·`mode.raw`·`mode.view` 의 `when` 에 `|| ctx.kanban?.shown` — 보드에서는 셋 다 보이고 고르면 F-2140 `chooseMode`
- 키워드: `kanban.new` `['kanban', '칸반', '보드', 'board', '할 일', 'todo', '작업']`, `kanban.show` `['kanban', '칸반', '보드', 'board', '보기', '목록', '모드']`
