# F-226 보기 화면 목록을 편집 화면과 같게

작성일: 2026-09-15
상태: 사용자 보고(2026-09-15 "리스트 태그의 모습이 프리뷰/보기와 다름"). 편집 모드 라이브 프리뷰(F-152 2.3)를 기준으로 보기 모드·공유·공개 보기 화면을 맞춘다
근거: F-152 2.3(편집 모드 목록 매달린 들여쓰기·기호 폭 2em), F-124 4장(보기 모드 덮어쓰기 규칙), F-216 2.3(`:is(.app-shell, .public-view)` 선택자)

## 2. 지금 차이 (조사 2026-09-15)

| 항목 | 편집 모드 (기준) | 보기 모드 (github-markdown-css) |
| --- | --- | --- |
| 글머리 기호 | `•` 글자, `--accent`, 굵게, 2em 칸 왼쪽 정렬 | 모든 단계 disc → circle → square, 글자색, 기호가 글자 쪽에 붙음 |
| 숫자 기호 | 친 그대로 `1.`, 글자색, 2em 칸 왼쪽 정렬 | 중첩 `ol` 은 lower-roman·lower-alpha, 오른쪽 정렬 |
| 항목 사이 | 줄 간격만 | `li + li { margin-top: .25em }` |
| 체크박스 | `.md-checkbox` 여백 `0 2px 0 0` | `margin: 0 .2em .25em -1.4em` |

## 3. 요구사항
- 대상: `:is(.app-shell, .public-view) .markdown-body` 안 `ul`·`ol`·`li`
- 글머리 목록(작업 목록 제외): 모든 단계 기호 `•`, 색 `--accent`, 굵게, 2em 칸 왼쪽 정렬. `list-style: none` + `li::before` 로 그린다(`::marker` 는 정렬을 못 바꿈)
- 숫자 목록: 모든 단계 `decimal` + `.`, 글자색, 2em 칸 왼쪽 정렬. 번호는 CSS `list-item` 카운터(`start`·`value` 속성 그대로 반영)
- 항목 사이 여백 0 (편집 모드와 같은 줄 간격). 느슨한 목록(`li > p`)의 문단 여백은 github 값 그대로
- 작업 목록: 체크박스 칸과 글자 시작이 편집 모드와 같게
- 들여쓰기 한 단계 폭과 기호·글자 시작 가로 위치는 편집 모드와 ±2px 안 (아래 A1 측정으로 맞춘다)
