# F-256 체크박스 항목이 글머리 항목과 줄이 안 맞는 문제

작성일: 2026-09-18
상태: 사용자 지시(2026-09-18 "체크박스 라인 안맞는것도 수정", 스크린샷). **디자인 수정 — 시각 판정은 사람이 한다(CLAUDE.md "개발 방식")**
근거: `specs/features/F-152.md` 2.3(기호 칸 폭), `F-226` A1(편집↔보기 가로 위치 ±2px/±4px), `F-251`(단계 고정 폭 `--md-list-step`)

## 1. 문제

`- [ ] 할 일` 줄이 `- 항목` 줄과 **기호 칸을 같이 쓰지 않아** 글자 시작선이 어긋난다

- **편집 모드**: `lines.ts` 가 체크박스 항목의 `ListMark`(`- `)를 통째로 숨기고(`hideMarkAndSpace`) `TaskMarker` 자리에 `<input class="md-checkbox">` 만 넣는다. `.md-checkbox` 에는 폭 규칙이 없어 글머리의 `.md-bullet`(`min-width: var(--md-list-step)`, 칸 안 가운데)과 칸 폭이 다르다
- **보기 모드**: `ul.contains-task-list { padding-left: 1.1875em }` + 체크박스 `margin-left: -1.1875em` 라, 일반 목록(최상위 `padding-left: 2em`, 기호 칸 `--md-list-step`)과 다른 값이다. `1.1875em` 은 F-226 당시 편집 모드 체크박스 **실측값**이라 `--md-list-step` 을 바꿔도 따라오지 않는다

2026-09-18 `--md-list-step` 을 `2em` → `1em` 으로 줄이면서 어긋남이 눈에 띄게 됐다

## 2. 한다 / 하지 않는다

### 한다
- 체크박스도 글머리·번호와 **같은 기호 칸**(`--md-list-step` 한 칸)을 차지하고 칸 안에서 가운데 정렬된다
- 편집 모드와 보기 모드가 같은 규칙을 쓴다 — 실측 상수(`1.1875em`)를 지우고 `--md-list-step` 으로 계산한다
- 체크박스 자체 크기는 칸보다 조금 작게 둬 칸 안에 여백이 남게 한다

### 하지 않는다
- `lines.ts` 의 decoration 구조 변경 — **CSS 로만 고친다**(F-254 가 같은 파일을 고치는 중)
- `--md-list-step` 값 변경, 글머리·번호 기호 규칙 변경
- 체크박스 동작(클릭 토글) 변경
