## 2. 모양 — 노션 방식
- **평소(접힘)**: 메인 열 오른쪽 여백에 제목마다 가로 짧은 선 하나씩 세로로 늘어선다. 선 길이는 수준별 `#` 16px · `##` 12px · `###` 8px, 두께 2px, 간격 8px, 모서리 둥글게. 색 `--rule`, **현재 위치 제목**은 `--ink-2`
- **마우스를 올리거나 키보드 포커스가 들어오면(펼침)**: 같은 자리에 목록 카드가 뜬다. 바탕 `--panel`, 1px `--rule`, 모서리 `--radius-control`, 그림자(대화상자와 같은 규칙), 폭 240px, 최대 높이 창 높이의 60%(넘치면 카드 안 스크롤). 제목 글자 13px `--font-sans` `--muted`, 수준별 들여쓰기 12px, 한 줄 말줄임, 현재 위치 제목은 `--ink` 600
  - 마우스가 목차를 떠나면 150ms 뒤 접힌다 (펼침 전환 `--transition-fast`, 움직임 줄이기면 즉시)
- 위치: 메인 열 오른쪽 끝에서 16px 안쪽, 위에서 상단바 아래 96px. 스크롤해도 제자리(스크롤 영역 밖에 고정)
- 편집 영역 내용(800px)과 겹치지 않을 때만 보인다: 메인 열 오른쪽 여백(내용 칸 오른쪽 끝~메인 열 오른쪽 끝)이 56px 이상일 때만. 좁으면 선 대신 목차 버튼(2026-09-15 F-229 로 변경)

## 3. 요구사항

### 3.1 대상
- 편집·원문·보기 모드 모두. 빈 상태·공유 화면(S-4)에는 없음
- 제목 `#`·`##`·`###`(ATX)와 Setext 제목(`===`→1, `---`→2). `####` 이하는 넣지 않는다
- 코드블록·프론트매터 안의 `#` 줄은 제목이 아니다 (파서 기준 그대로)
- 제목이 하나도 없으면 목차를 그리지 않는다

### 3.2 제목 글자
- 원문에서 제목 기호(`#`, 닫는 `#`, Setext 밑줄)를 뗀 글자. 인라인 기호도 뗀다: `**굵게**`→굵게, `` `코드` ``→코드, `[글자](주소)`→글자, `[[대상|별칭]]`→별칭, `\*`→`*`
- 뗀 결과가 비면 `(제목 없음)`
- `outline.js`: `extractHeadings(state) → [{ level: 1|2|3, text, from }]` (`from` = 제목 줄 시작 위치). 주 에디터의 syntax tree 를 쓴다. 파싱이 뷰포트까지만 끝났으면 `ensureSyntaxTree` 등으로 문서 끝까지 확보한다(시간 상한은 구현에서 정하고 보고)

### 3.3 동작
- 목록 항목을 누르면(또는 Enter) 그 제목이 스크롤 영역 위에서 16px 아래에 오도록 **스크롤만** 한다. 커서·선택은 옮기지 않는다. 스크롤은 즉시(부드러운 스크롤 없음)
- 현재 위치 제목 = 스크롤 영역 위 끝 + 24px 보다 위에 있는 제목 중 마지막. 없으면 첫 제목. 스크롤·문서 변경 시 갱신
- 문서가 바뀌면 목록을 다시 만든다. 입력 중에는 입력이 멈춘 뒤(150ms) 갱신하고, 한글 조합 중에는 조합이 끝난 뒤 갱신한다
- 문서를 바꾸거나 모드를 바꿔도 목차는 그 문서·그 모드 기준으로 다시 그린다

### 3.4 보기 모드
- 목록은 편집 모드와 같은 `extractHeadings` 결과를 쓴다 (보기 모드에서도 주 `EditorState` 가 원본)
- 스크롤 대상은 렌더된 제목 요소: `renderMarkdown.js` 가 `h1`~`h3` 에 원문 줄 번호 속성(`data-source-line`, markdown-it `token.map` 기준)을 붙이고, 목차는 `from` 의 줄 번호로 요소를 찾는다. 못 찾으면 그 항목 클릭은 아무것도 안 함
- 원문 HTML 이스케이프 규칙(F-123)은 그대로

### 3.5 접근성
- `<nav aria-label="목차">` 안 `<ol>`. 항목은 `<button type="button">` (링크 아님 — 주소가 바뀌지 않음)
- 접힌 선들은 장식(`aria-hidden`). 키보드 Tab 으로 목차에 들어오면 펼침 목록이 보이고 항목 버튼으로 이동한다. Esc 로 접고 포커스를 편집 영역으로
- 현재 위치 항목에 `aria-current="location"`
