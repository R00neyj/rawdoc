## 2. 요구사항

### 2.1 호버·상태 전환
- 마우스 호버, 키보드 포커스(`:focus-visible`), 눌림·선택·열림 상태(`[aria-pressed]`, `[aria-current]`, `[aria-expanded]`, `[aria-selected]`, `[aria-checked]`)로 **색이 바뀌는 모든 조작 요소**에 전환을 준다
  - 대상 속성: `background-color`, `color`, `border-color`, `box-shadow`, `opacity`, `fill`, `text-decoration-color`
  - 시간·곡선: `--transition-fast`(180ms, `--ease-spring`)
- 공용 토큰 하나로 묶는다 (예: `--transition-colors: background-color var(--transition-fast), color var(--transition-fast), …`). 규칙마다 속성 목록을 따로 적지 않는다
- 이미 다른 전환(폭·회전 등)이 있는 요소는 그 전환을 지우지 않고 합친다 (사이드바 레일 폭, 폴더 토글 회전)
- 대상 예 (전부 찾을 것): 상단바 아이콘 버튼·세그먼트·제목 입력, 사이드바 동작 버튼·레일 버튼·트리 행·토글·`⋯` 버튼, `⋯` 메뉴·공유 메뉴 항목, 설정 세그먼트·대화상자 버튼, 알림 띠 버튼, 빈 상태·공유 화면 버튼, 표 `+` 버튼, 자동완성 항목, 편집·보기 모드 링크·위키링크, 목차(F-144) 항목
- 제외: CM6 커서·선택 영역·줄 자체·표 칸 편집 하위 에디터 안 글자(입력 반응이 늦어 보이면 안 됨), 끌어놓기 강조(`--accent-soft`)는 넣어도 되지만 끌기 반응이 늦어지면 빼고 보고

### 2.2 툴팁
- 앱이 그리는 모든 툴팁(상단바 아이콘 버튼, 사이드바 레일·접기 버튼, 표 `+` 버튼)의 나타남·사라짐을 `opacity` 전환 `--transition-fast` 로
  - 마우스 호버로 나타날 때만 지연 400ms (F-142 3.2 그대로). 키보드 포커스는 지연 없이 전환만. 사라질 때는 지연 없음
  - 위치 이동 효과는 넣지 않는다 (투명도만)

### 2.3 공통
- `prefers-reduced-motion: reduce` 이면 전부 전환 없음 (`--transition-fast: 0ms` 규칙 그대로 따라감)
- 레이아웃 속성(폭·높이·여백·위치)에는 새로 전환을 넣지 않는다 (2.1 의 기존 전환 제외)
