# F-218 편집 모드 이미지 삭제 버튼

작성일: 2026-09-15
상태: 사용자 요청(2026-09-15 "이미지 삭제 아이콘 추가"). F-217 과 파일 겹침 없음, 병렬 가능
근거: F-157 2.3 정렬 버튼 묶음. 첨부 파일 자체는 지우지 않는다 — 실행 취소로 되돌릴 수 있어야 하고, 안 쓰는 첨부 정리는 F-156 2.7 규칙을 따른다

## 2. 요구사항

### 2.1 버튼
- F-157 2.3 도구 묶음 정렬 버튼 3개 뒤에 세로 구분선(1px × 16px `--rule`, 좌우 2px) + `이미지 삭제` 버튼 1개. 크기·모양·툴팁은 정렬 버튼과 같음(svg 18px), `aria-pressed` 없음
- 호버 때 아이콘 색 `--danger`

### 2.2 동작
- 누르면 이미지 블록 3줄을 지우는 트랜잭션 1개 (`userEvent: 'delete.image'`). 확인 대화상자 없음 — Ctrl+Z 1번에 원래대로
- 지우는 범위: 블록 첫 줄 시작 ~ 셋째 줄 끝 + 바로 뒤 줄바꿈 1개. 블록이 문서 끝이라 뒤 줄바꿈이 없으면 바로 앞 줄바꿈 1개. 둘 다 없으면(문서 전체가 블록) 블록만. CRLF 는 `\r\n` 을 줄바꿈 1개로 본다
- 삭제 뒤 커서는 지운 자리(범위 시작)에 두고 에디터에 포커스
- 첨부(IndexedDB·서버)는 지우지 않는다
- `mousedown` 전파 막기·더블클릭 원문 진입 제외는 정렬 버튼과 같게(F-157 2.5)
