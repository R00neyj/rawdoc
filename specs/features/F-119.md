## 1. 파일
- `vite.config.js`: 매니페스트 `file_handlers`
- `src/pwa/fileLaunch.js` 신규
- `src/app/App.jsx`

## 2. 요구사항
- 매니페스트: `file_handlers: [{ action: '/', accept: { 'text/markdown': ['.md'] } }]` — `action` 은 앱 범위 안 URL, `accept` 는 MIME → 확장자 배열 (MDN `file_handlers`)
- `launch_handler` 는 넣지 않는다 (확인하지 않은 동작에 기대지 않기 위해서다. 파일마다 새 창이 열릴 수 있다)
- `fileLaunch.js`: `'launchQueue' in window` 일 때만 `launchQueue.setConsumer(async (params) => …)`
  - `params.files` 는 `FileSystemFileHandle[]` → `getFile()` 로 `File` 을 얻어 F-114 `importFiles` 에 넘긴다
  - 저장소가 준비된 뒤(부팅 완료 후) consumer 를 등록한다
- 원본 파일에 다시 쓰지 않는다 (쓰기 권한 요청 없음)
- 실험적 기능: Chrome·Edge 데스크톱에서만 동작할 수 있다 (MDN "Limited availability", "Experimental")
