## 2. 요구사항

### 2.1 상단바 앞 묶음
- 상단바 왼쪽 끝부터: 제품 아이콘 + 제품명(F-142 3.3 그대로) → 사이드바 토글 → 검색. 토글·검색은 `icon-btn` 아이콘 버튼 18px, 둘 사이 간격 2px
- **넓은 창 + 사이드바 펼침**: 앞 묶음 폭을 사이드바 폭에 맞춘다. 검색 버튼 오른쪽 끝이 사이드바 오른쪽 테두리보다 8px 왼쪽에 온다. 제품명과 토글 사이는 남는 공간
- **넓은 창 + 레일(접힘)**, **좁은 창(1024px 미만)**: 앞 묶음 폭은 내용만큼. 제품명과 토글 사이 8px
- 펼침·접힘 전환 때 앞 묶음 폭도 사이드바와 같이 `--transition-fast` 로 바뀐다. 움직임 줄이기면 즉시
- 상단바의 기존 좁은 창 전용 `사이드바 열기` 버튼(제품 아이콘 왼쪽)은 없앤다 — 토글 하나로 합친다

### 2.2 사이드바 토글
| 창 | 상태 | 아이콘 | `aria-label`·툴팁 | `aria-expanded` |
| --- | --- | --- | --- | --- |
| 1024px 이상 | 펼침 | `IconPanelClose` | `사이드바 접기` | `true` |
| 1024px 이상 | 레일 | `IconPanelOpen` | `사이드바 펴기` | `false` |
| 1024px 미만 | 닫힘 | `IconPanelOpen` | `사이드바 열기` | `false` |
| 1024px 미만 | 겹쳐 열림 | `IconPanelClose` | `사이드바 닫기` | `true` |

- `aria-controls` = 사이드바 id
- 동작은 F-143 3.3·3.4 그대로(`md.sidebar` 저장, 좁은 창은 겹쳐 열기·닫기). 겹친 사이드바의 바깥 클릭·Esc 닫기도 그대로이며, 토글 버튼 클릭은 바깥 클릭으로 치지 않는다
- 버튼이 사라지지 않으므로 누른 뒤 포커스는 토글 버튼에 그대로 남는다 (F-143 3.3 "반대쪽 토글로 포커스 이동" 은 없앤다)
- 툴팁은 F-142 3.2 기본(버튼 아래)

### 2.3 검색 버튼
- 아이콘 `IconSearch`, `aria-label`·툴팁 `검색 — 준비 중`, `aria-disabled="true"`(포커스는 받음). 눌러도 아무 동작 없음. 비활성 모양은 F-143 3.5 그대로
- 사이드바(펼침 목록·레일)의 검색 버튼은 없앤다

### 2.4 사이드바
- 머리 줄(`.sidebar-head`)을 펼침·레일·겹쳐 열린 사이드바 모두에서 없앤다. 펼침은 `새 문서` 부터, 레일 위쪽은 새 문서 · 새 폴더 · 가져오기
- 그 밖(고정됨·트리·아래 버튼·레일의 새 폴더 동작)은 F-143 그대로

### 2.5 포커스 순서
상단바(제품명 제외: 토글 → 검색 → 제목 → 보기 모드 → 공유 → 내보내기) → 사이드바 → 편집 영역 (`specs/ia.md` 5장 그대로)
