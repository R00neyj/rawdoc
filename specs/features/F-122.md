## 2. 요구사항

### 2.1 모드 이름
- 상단바 세그먼트 문구 `라이브 프리뷰` → `편집`. `원문` 은 그대로
- 내부 값 `live` 와 설정 키 `md.viewMode` 는 바꾸지 않는다. 기존 사용자의 저장값을 그대로 읽기 위해서다
- 화면 문구만 바꾼다. 코드 식별자·주석은 바꾸지 않아도 된다

### 2.2 줄 번호와 본문 간격
- `tokens.css` 에 `--gutter-gap: 20px`
- 줄 번호 숫자의 오른쪽 끝에서 본문 첫 글자 왼쪽 끝까지 거리가 `--gutter-gap` 이 되게 한다. CM6 기본값(`.cm-lineNumbers .cm-gutterElement` 오른쪽 패딩 3px, `.cm-line` 왼쪽 패딩 6px)을 계산에 넣는다
- 편집·원문 모드 모두 같은 간격. 제목 줄(글자 크기가 큰 줄)에서도 같다

### 2.3 좁은 창 사이드바
- 원인: `Sidebar.jsx` 가 닫힌 상태에 `hidden` 속성을 주는데 `app.css` 의 `.sidebar { display: flex }` 가 브라우저 기본 `[hidden] { display: none }` 보다 우선해 사이드바가 숨지 않는다
- `app.css` 맨 앞에 `[hidden] { display: none !important; }` 를 둔다. 같은 원인으로 숨지 않는 다른 요소도 함께 고쳐진다
- 수정 후 ia.md 3.11 동작 전부 확인: 1024px 미만에서 기본 닫힘, `☰` 로 열기·닫기, 바깥 클릭·Esc 로 닫기, 문서 선택·새 문서·가져오기·대화상자 열 때 닫힘, 1024px 이상으로 넓히면 `☰` 사라지고 사이드바 원래 자리

### 2.4 강조 컬러 임시값
- `brand.config.js` 의 `accent` 를 `#3B4890` 으로. 정의 위치는 여전히 이 파일 하나다 (design.md 3.2)
- 다른 파일에 새 hex 를 쓰지 않는다. `--accent-soft` 등 파생색은 기존 `color-mix()` 그대로
- 대비 테스트 출력이 경고 없이 통과하는지 확인 (2026-09-14 계산: `--panel` 대비 8.28:1, `--paper` 대비 7.87:1)
- 앱 아이콘은 `--ink`·`--paper` 만 쓰므로 다시 만들지 않는다. `scripts/make-icons.py` 가 accent 를 읽지 않는지 확인만 한다
