## 1. 목적

화면 뼈대(상단바·사이드바·편집 영역 자리·알림 띠·대화상자), 브랜드 주입, 디자인 토큰, 서체 자체 호스팅, 해시 URL 을 만든다. 에디터는 F-103 에서 이 자리에 들어온다

## 2. 범위

### 한다
- `brand.config.js` 와 빌드 시 주입 (`specs/architecture.md` 5장)
- `tokens.css` (design.md 2.4·3.1·3.2·4장), `app.css`
- 서체 npm 패키지로 자체 호스팅
- 상단바: `☰`(1024px 미만), 제품명, 문서 제목 입력
- 사이드바 뼈대 (내용은 F-111·F-121)
- 편집 영역 자리: 최대 너비 `--content-max` 가운데 정렬. B1 에서는 빈 `<div>` 에 `data-editor-slot` 속성만 둔다. 안내 문구를 넣지 않는다
- 알림 띠 N-1 (규칙은 `notice.js`)
- 대화상자 공통 컴포넌트 `Dialog.jsx` (네이티브 `<dialog>` + `showModal()`)
- 해시 URL 해석·생성 `hashRoute.js`, `hashchange` 처리
- 좁은 창 사이드바 겹침 (ia.md 3.11)
- `prefs.js` (architecture.md 4장)
- `lib/contrast.js` + 테스트 (design.md 3.2)
- 기존 Vite 스캐폴드 제거

### 하지 않는다
- 에디터, 보기 모드 토글, 상태바 (F-103·F-107·F-113)
- 가져오기·내보내기 버튼 (F-112·F-114)
- IndexedDB (F-110). B1 은 `memoryStore` 만 쓴다
- 앱 설치 버튼, 아이콘, 매니페스트 (F-115)
- 다크 모드, 모바일 레이아웃

## 5. 요구사항

### 5.1 브랜드 주입
- `vite.config.js` 가 `brand.config.js` 를 import 해 `transformIndexHtml` 로 `%BRAND_NAME%` 치환, `<meta name="theme-color" content={accent}>` 와 `<style>:root{--accent:{accent}}</style>` 를 `<head>` 에 넣는다
- 앱 코드·CSS·HTML 어디에도 `Rawdoc` 문자열이나 `#D6337E` 를 직접 쓰지 않는다. `brand.config.js` 만 예외
- 상단바 제품명은 `brand.name` 을 `--font-display` 로 표시. 클릭 동작 없음

### 5.2 토큰
- design.md 3.1 색 토큰(`--paper` `--panel` `--ink` `--ink-2` `--muted` `--rule` `--rule-2` `--link` `--danger`), 2.4 서체 토큰과 `--font-display` 전환 규칙
- `--accent` 는 `tokens.css` 에 hex 로 정의하지 않는다(주입값). 파생: `--accent-soft`(선택 영역·현재 항목, 10%), `--accent-ring`(포커스 링)은 `color-mix()`
- 크기: `--topbar-h: 52px`, `--sidebar-w: 224px`, `--statusbar-h: 26px`, `--content-max: 800px` (ia.md 7장)
- 형태·움직임은 design.md 4장. `prefers-reduced-motion: reduce` 이면 전환 효과를 끈다
- 모든 조작 요소에 `:focus-visible` 표시

### 5.3 레이아웃 (ia.md 2장, 7장)
- 전체 높이 100%, body 스크롤 없음. 상단바 고정, 아래는 사이드바 + 본문 열
- 본문 열: 알림 띠(있을 때) → 편집 영역 자리(남은 높이 전부)
- 편집 영역 자리의 내부 콘텐츠 최대 너비 `--content-max`, 가운데 정렬, 좌우는 `--paper`
- 1024px 이상: 사이드바 고정. 미만: 사이드바 숨김 + `☰` 표시 → 누르면 편집 영역 위에 겹쳐 열림. 바깥 클릭·Esc·문서 선택·새 문서·대화상자 표시 시 닫힘. 창을 넓히면 원래 자리

### 5.4 해시 URL (ia.md 3.10)
- `hashRoute.js`: `parseHash(hash) → { docId: string } | { docId: null }` — `#/d/{id}` 만 인정, 나머지는 null. `formatHash(docId|null) → '#/d/{id}' | '#/'`
- 기록 추가: `location.hash = …` / 교체: `history.replaceState(null, '', …)`
- `hashchange` 로 바뀌면 해당 문서를 연다 (문서 결정 규칙은 F-111)

### 5.5 알림 띠 N-1 (ia.md 4.2)
- `notice.js` 순수 함수: `pushNotice(current, next) → current|next`
  - 종류: `info`, `error`, `update`
  - 동시에 1개. 새 알림이 대체한다. 단 현재가 `error`·`update` 이면 `info` 는 대체하지 못한다(버린다)
- 표시: 상단바 아래, 편집 영역 위 1줄. `info` 는 4초 뒤 자동으로 사라짐. `error`·`update` 는 `×` 로만 닫음. Esc 로 닫지 않음. 선택적 동작 버튼 1개(`update` 의 `새로고침` 등) 지원
- `role="status"`(info) / `role="alert"`(error)

### 5.6 대화상자
- `Dialog.jsx`: `<dialog>` + `showModal()`. 열 때 지정한 요소에 포커스, 닫을 때 연 요소로 포커스 복귀. Esc(`cancel` 이벤트)로 닫힘. 바깥(backdrop) 클릭으로 닫힘
- `alert`·`confirm`·`prompt` 금지

### 5.7 `prefs.js`
- `getPref(key, fallback)`, `setPref(key, value)`. 키는 architecture.md 4장 표의 것만. 예외는 삼키고 fallback

### 5.8 `lib/contrast.js`
- `contrastRatio(hexA, hexB) → number` (WCAG 2.x 상대 휘도 공식). `#RRGGBB` 만 받는다
- 테스트
  - `#000000`·`#FFFFFF` = 21, 같은 색 = 1
  - `brand.config.js` 의 accent 와 `tokens.css` 에서 읽은 `--panel`·`--paper` 의 대비를 계산한다(`node:fs` 로 파일 읽기)
  - 4.5 미만이면 `console.warn` 으로 수치를 출력하고 **테스트는 통과**시킨다 (design.md 3.2, 메인 컬러 확정 전)

### 5.9 `memoryStore.js`
- architecture.md 2장 인터페이스. `kind: 'memory'`. 반환 객체는 복사본(외부에서 고쳐도 저장값이 안 바뀜)
- 테스트: 생성·목록 정렬·수정 시 updatedAt 증가·삭제·없는 id 수정 reject
