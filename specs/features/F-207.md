## 2. 요구사항

### 2.1 캐시 (`remoteCache.ts`)
- IndexedDB DB 이름 `md-remote` (제품명 쓰지 않음, 불변조건). 스토어 `docs`(키 `[userId, id]`), `folders`(같음), `outbox`(자동 증가 키, `userId` 색인)
- 캐시 문서 = 앱 `Doc` + `version`(서버가 마지막으로 확인한 버전, 서버에 아직 없으면 0)
- 로그아웃해도 지우지 않는다 (다음 로그인·오프라인에 쓴다)

### 2.2 읽기
- `list()`: `GET /api/docs` 성공 → 서버 목록 기준으로 캐시 정리(서버에 없고 보낼 목록에도 없는 문서는 캐시에서 삭제) → **버전이 캐시와 다른 문서만** `GET /api/docs/:id` 로 본문을 받아 캐시 → 캐시에서 전체 `Doc[]` (`updatedAt` 내림차순). 네트워크 실패면 캐시만
- 보낼 목록에 있는 문서는 서버 값으로 캐시를 덮지 않는다
- `get(id)`: 캐시에 있으면 캐시. 없으면 서버에서 받아 캐시
- `listFolders()`: 같은 방식

### 2.3 쓰기와 보낼 목록
- `create`·`update`·`remove`·`moveDoc`·`setPinned`·폴더 5종: **캐시에 먼저 쓰고 즉시 resolve**, 보낼 목록에 작업을 넣고 보내기를 시작한다. 반환값은 M1 과 같은 모양
- `create` 는 id 를 클라이언트에서 `crypto.randomUUID()` 로 만들어 `POST` 에 넣는다 (재시도 안전, F-206 2.3)
- 같은 문서의 `update` 가 보내기 전에 여러 번 쌓이면 마지막 `title`·`content` 만 남긴다
- 보내기: 한 번에 하나씩 순서대로. 성공하면 목록에서 빼고 캐시 `version` 을 응답 값으로
  - 네트워크 오류·5xx·401: 목록에 남기고 멈춘다. `online` 이벤트, 30초마다, 다음 쓰기 때 다시
  - 401 은 `syncState` 를 `signed-out` 으로 (계정 메뉴에서 다시 로그인)
  - 413: 목록에서 빼고 error 알림 `문서가 너무 커서 서버에 저장하지 못했습니다(1MB 초과).` 캐시는 남긴다
  - 404(`update`·`move`·`pin`): 서버에서 지워진 문서 — 목록에서 빼고 캐시에서도 삭제
- `update` 는 `baseVersion` = 캐시 `version`

### 2.4 충돌
- `PUT` 이 409 `conflict` 면
  1. 내 `title`·`content` 로 **새 문서** `{제목} (충돌 사본)` 를 만든다 (같은 폴더, 2.3 `create` 흐름)
  2. 원래 문서 캐시를 응답의 서버 문서로 바꾸고 목록에서 뺀다
  3. 저장소 이벤트 `conflict { docId, copyId }` 를 알린다
- App: 열린 문서가 `docId` 면 **에디터에 서버 내용을 밀어 넣지 않는다**(불변조건). 대기 저장을 버리고 `copyId` 문서를 연다(해시 교체, 에디터 다시 마운트). warn 알림 `다른 곳에서 먼저 바뀌어 내 편집을 "{사본 제목}" 으로 저장했습니다.`
- 열린 문서가 아니면 알림만

### 2.5 동기화 표시
- `store.syncState`: `{ pending: number, online: boolean, signedOut: boolean }`, `store.subscribeSync(listener) → unsubscribe`
- 상태바 저장 글자: M1 값(`saved` 등) 뒤에 `pending > 0` 이면 ` · 동기화 대기 {N}`, 오프라인이면 ` · 오프라인`, `signedOut` 이면 ` · 다시 로그인 필요`
- 첨부(`putAttachment` 등 4종)는 이번에는 로컬 `md-docs` 첨부 스토어를 그대로 쓴다 (서버 이미지는 F-209). App 의 첨부 GC 는 `kind === 'server'` 일 때 캐시 문서 원문 기준으로 돌린다

### 2.6 저장소 고르기 (`openStore`)
- `openStore({ account, ...handlers })`
  - `account.state === 'in'` → `serverStore(account.id)`
  - `offline` 이고 `md.account` 저장값 있음 → `serverStore(저장 id)` (캐시만으로 시작, 온라인 되면 보냄)
  - 그 밖 → 지금처럼 IndexedDB / 메모리
- 로그인·로그아웃은 페이지 이동이라 저장소는 부팅 때 한 번만 고른다
- 로그인 상태의 첫 실행 안내 문서(F-111)는 서버 문서가 0개이고 로컬 이관(F-208)할 것도 없을 때만 만든다
- 로그인 상태에서 로컬 문서는 보이지 않는다 (옮기기는 F-208)
