# F-230 공유 읽기전용 화면 설정 (테마·서체·글자 크기)

작성일: 2026-09-15
상태: 사용자 승인(2026-09-15 "f230 ㄱㄱ" — 글자 크기 포함, 버튼은 아이콘+글자 "설정")
근거: 사용자 요청(2026-09-15) "읽기 전용 공유에서도 설정은 있어야할거같음 — 서체 변경 가능, 테마 변경 가능 해야할듯". `specs/features/F-210.md` 2.4 "테마·글자 크기·서체 설정은 이 브라우저의 기존 설정을 읽기만 한다"를 대체한다

## 0. 문제

`main.tsx`가 React 렌더 전에 `localStorage`(`md.theme`·`md.headingFont`·`md.bodyFont`·`md.fontSize`)를 읽어 `<html>` 속성에 적용하는 로직은 경로와 무관하게 항상 돈다 — 그래서 공개 보기 화면(S-5, `PublicView.tsx`)도 **그 브라우저에 값이 있으면** 이미 그 값을 따른다(F-210 2.4가 말하는 "읽기"). 문제는 **바꿀 UI가 없다는 것**: 링크를 처음 받는 사람은 로그인도, 앱을 써본 적도 없어 기본값(시스템 테마·제목 세리프·본문 산세리프·글자 보통)만 보고, 바꿀 방법이 없다

## 1. 파일 소유

| 파일 | 변경 |
| --- | --- |
| `src/app/SettingsDialog.tsx` | `indent`·`lineNumbers` 관련 props 를 선택(optional)으로 바꾸고, 없으면 그 두 `Segment` 를 그리지 않는다 (부분 Edit) |
| `src/app/PublicView.tsx` | 설정 상태(`theme`·`headingFont`·`bodyFont`·`fontSize`) + 버튼 + `SettingsDialog` 연결 (부분 Edit) |
| `src/styles/app.css` | `.public-view-settings` 버튼 (부분 Edit, `.public-view-export` 자리) |
| `e2e/publicView.spec.js` | 신규 케이스 `F-230 A*` |

- 새 의존성 없음. `src/app/prefs.ts`·`src/app/theme.ts`(F-141)를 그대로 쓴다 — 저장 키(`md.theme` 등)는 F-121·F-141·F-154 와 같다(제품명과 무관, 이미 그 규칙을 따름)
- `SettingsDialog`·`Segment`·`IconSettings`(`src/app/icons.tsx`)·`Dialog` 는 새로 만들지 않고 그대로 재사용한다

## 2. 요구사항

### 2.1 범위 — 4항목만
공개 보기 화면에 트는 항목은 **테마 / 제목 서체 / 본문 서체 / 글자 크기** 4개뿐이다. `들여쓰기`(F-154 2.3)·`줄 번호`(F-147)는 CM6 편집 영역 전용이라 넣지 않는다 — 공개 보기 화면은 편집기를 아예 띄우지 않는다(`PublicView.tsx` 머리 주석)

이 4개는 이미 다른 명세가 "공유 화면에도 적용된다"고 정해둔 항목이다: 테마는 F-141 3.1(다크 확인 대상에 "공유 화면" 명시), 글자 크기는 F-154 2.2("적용: …공유 화면"). 제목·본문 서체는 F-121·F-141 3.3 이 같은 토큰(`--font-display`·`--font-body`)을 쓰므로 같이 넣는다

### 2.2 SettingsDialog 재사용
- `SettingsDialogProps` 의 `indent`·`onChangeIndent`·`lineNumbers`·`onChangeLineNumbers` 를 `?` 로 바꾼다. 넷 중 하나라도 없으면(폴더·문서 공개 화면 쪽) `들여쓰기`·`줄 번호` `Segment` 를 그리지 않는다
- `src/app/App.tsx` 쪽 호출(사이드바 `설정`)은 지금처럼 6개를 다 넘기므로 화면·동작 변화 없음

### 2.3 공개 보기 화면 쪽 상태
- `PublicView.tsx` 최상위(`PublicDocView`·`PublicFolderView` 공통 — `DocPane` 을 부르는 두 곳)에서 `useState(() => getPref('md.theme', 'system'))` 형태로 4개 값을 읽고, `App.tsx` 의 `handleThemeChange` 등과 같은 방식으로 바꾼다: 누르면 `document.documentElement.dataset.*` 를 즉시 바꾸고 `setPref` 로 저장
  - 테마는 `resolveTheme(value, prefersDark)` 를 거쳐 `data-theme` 에 넣는다(F-141 3.1). `prefers-color-scheme` 변화 구독은 `main.tsx` 가 이미 전역으로 하지 않으므로, `App.tsx` 의 시스템 테마 구독 로직(692행 부근)과 같은 것을 `PublicView.tsx` 에도 둔다
  - 나머지 3개는 `data-heading-font`·`data-body-font`·`data-font-size` 에 그대로 넣는다
- 문서·폴더 두 화면이 상태를 따로 갖지 않는다 — `PublicView` 최상위(`kind` 분기 바로 위)에서 한 번만 관리해 `PublicDocView`·`PublicFolderView` 양쪽에 props 로 내려준다

### 2.4 버튼과 배치
- 머리 줄(`public-view-header`) 오른쪽, `.md 내보내기` 버튼 왼쪽에 아이콘 + 글자 버튼(`IconSettings` + "설정", `.public-view-export` 와 같은 모양 규칙 — `ia.md` I13 공유 화면 버튼은 아이콘+글자)
- 누르면 `SettingsDialog` 가 뜬다(그 문서 쪽 상태를 씀). `indent`·`lineNumbers` 관련 props 는 넘기지 않는다
- 닫기는 기존 `SettingsDialog`/`Dialog` 규칙 그대로(닫기 버튼, Esc, 바깥 클릭)
- 폴더 화면(F-211)도 `DocPane` 을 통해 같은 버튼을 쓴다 — 문서마다 따로 존재하지 않고 폴더 전체에 하나

### 2.5 저장
- 값은 `localStorage`(F-141·F-154 와 같은 키)에 저장돼 **그 브라우저**에 남는다. 같은 브라우저로 다른 공개 링크를 열거나, 나중에 로그인해 앱을 써도 그 값을 이어 쓴다(지금 F-210 2.4 동작과 같음 — 이번엔 "읽기"뿐 아니라 "쓰기"도 된다는 차이)
- 서버에는 아무것도 보내지 않는다. 문서 소유자의 설정에는 영향이 없다(읽는 사람 브라우저 로컬 값)
