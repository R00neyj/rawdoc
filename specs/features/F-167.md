# F-167 서식·링크 명령 (우클릭 메뉴용)

작성일: 2026-09-14
상태: 사용자 승인(2026-09-15 "이대로 승인·구현"). F-233(탭바) 전제. 사용자 요청(2026-09-14) 우클릭 기능 "링크 추가, 외부 링크 추가, 서식(볼드체·기울이기·취소선·하이라이트·코드·수식·주석·서식 지우기)" — Obsidian 편집기 우클릭 메뉴를 옮긴 것. 사용자 선택 "범위 밖 문법은 기호 삽입만". F-168·F-169 와 병렬 가능 (파일 겹침 없음). 메뉴 연결은 F-170
근거: F-109(단축키 명령 방식), F-131(위키링크 `[[`), `specs/product.md` 4.5(수식·각주 표시는 M1 범위 밖). 하이라이트 `==`·주석 `%%` 는 Obsidian 문법(https://obsidian.md/help/syntax, 2026-09-14 확인 필요)이며 GFM 에는 없다

## 1. 파일 소유

## 2. 공통
- 모든 명령은 `({ state, dispatch }) => boolean` StateCommand. 명령 1회 = 트랜잭션 1개 = 실행 취소 1단계. 여러 선택은 `changeByRange`
- **문법 기호만 넣는다.** 편집·보기 모드에서 하이라이트 색칠, 주석 숨김, 수식 렌더는 하지 않는다 (지금처럼 글자 그대로 보인다)
  - 갱신(2026-09-20): 하이라이트 `==` 는 **F-283 이 실제로 색칠한다.** 주석 `%%` 숨김은 F-214 가 했다. 이 명세가 기호만 넣는다는 것은 그대로고, 표시 담당이 다른 명세로 옮겨간 것뿐이다. 수식은 **F-291 이 실제로 렌더한다**(2026-09-21). 기호만 넣는다는 이 명세의 결정은 그대로고, 표시 담당이 옮겨간 것뿐이다
- 조합 중 실행하지 않는 판단은 호출하는 쪽(F-170)이 한다

## 3. 명령

| 메뉴 | 명령 | 선택 있음 | 선택 없음 |
| --- | --- | --- | --- |
| 링크 추가 | `insertWikiLink` | `[[선택]]`, 커서는 `]]` 앞 | `[[]]`, 커서 가운데 (F-131 자동완성이 뜬다) |
| 외부 링크 추가 | `insertLink` (F-109) | `[선택]()`, 커서 `()` 사이 | `[]()`, 커서 `[]` 사이 |
| 볼드체 | `toggleStrong` (F-109) | F-109 | F-109 |
| 기울이기 | `toggleEmphasis` (F-109) | F-109 | F-109 |
| 취소선 | `toggleStrike` | `~~` 감싸기/벗기기 | `~~~~`, 커서 가운데 |
| 하이라이트 | `toggleHighlight` | `==` 감싸기/벗기기 | `====`, 커서 가운데 |
| 코드 | `toggleInlineCode` | `` ` `` 감싸기/벗기기. 선택 글자에 `` ` `` 가 있으면 ``` `` 선택 `` ``` (안쪽 공백 1개씩) | ` `` `, 커서 가운데 |
| 수식 | `toggleMath` | `$` 감싸기/벗기기 | `$$`, 커서 가운데 |
| 주석 | `toggleComment` | `%%` 감싸기/벗기기 | `%%%%`, 커서 가운데 |
| 서식 지우기 | `clearFormatting` | 4장 | 4장 |

- 감싸기/벗기기(`toggleWrap(marker)` 공용): 선택 **바로 바깥** 양옆이 `marker` 이거나, 선택 글자 **안쪽 양끝**이 `marker` 이면 그 기호를 지운다. 아니면 `marker + 선택 + marker`. 감싼 뒤 선택은 안쪽 글자
- `toggleMath` 의 `$` 는 바깥이 `$$` 인 경우(수식 블럭 기호)는 벗기지 않고 감싼다
- 선택이 여러 줄이어도 인라인 기호로 감싼다 (블록으로 바꾸지 않는다)

## 4. 서식 지우기 `clearFormatting`
- 대상 범위: 선택이 있으면 선택, 없으면 커서가 들어 있는 서식 하나
- 지우는 기호
  - 구문 트리 노드 `Emphasis`·`StrongEmphasis`·`Strikethrough`·`InlineCode` 가 대상 범위와 겹치면 그 노드의 기호(`EmphasisMark`·`StrikethroughMark`·`CodeMark`) 전부
  - 대상 범위가 걸친 줄 안에서 `==…==`·`%%…%%`·`$…$`(`$$` 제외) 짝이 대상 범위와 겹치면 그 짝의 기호. 짝은 줄 안 왼쪽부터 가장 가까운 닫는 기호로 맞춘다
- 지우지 않는 것: 링크 `[]()`, 위키링크 `[[]]`, HTML 태그, 제목·목록·인용 같은 줄 앞 기호(단락은 F-168 `본문`)
- 선택은 지운 기호만큼 옮겨 같은 글자를 가리킨다
- 구문 트리가 없는 상태(마크다운 언어가 없는 표 칸 하위 에디터)에서는 `false` 를 돌려주고 아무것도 하지 않는다 (F-170 이 칸 안에서 비활성)
