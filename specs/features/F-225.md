## 2. 설계

지금 모양의 문제: 입력·권한·초대 버튼이 세 줄로 흩어져 무엇을 한 번에 하는지 안 보이고, 초대된 사람 목록이 `닫기` 와 같은 무게로 붙어 있어 위계가 없다. 대화상자의 일은 둘뿐이다 — **한 줄로 초대하기**, **누가 이 교안을 볼 수 있는지 보기**

```
┌────────────────────────────────────────────────────┐
│ 사람 초대                                          │
│ 1주차 교안                                         │  ← 대상 이름, --muted, 1줄 말줄임
│                                                    │
│ ┌──────────────────────────────┬───────────┐ ┌────┐│
│ │ 이메일 주소                   │ 보기│편집 │ │초대││  ← 한 줄 초대 막대
│ └──────────────────────────────┴───────────┘ └────┘│
│ 이메일 주소를 확인하세요.                           │  ← 오류일 때만
│                                                    │
│ 볼 수 있는 사람 2                                   │
│ ────────────────────────────────────────────────── │
│ kim@school.ac.kr                  보기│편집   삭제 │
│ lee@school.ac.kr                  보기│편집   삭제 │
│                                                    │
│ 같은 이메일로 로그인하면 사이드바       [ 닫기 ]    │
│ 공유받음에 보입니다.                                │
└────────────────────────────────────────────────────┘
```

### 2.1 머리
- `h2` `사람 초대` 그대로. 바로 아래 대상 이름(`target.name`, 폴더면 이름 뒤 ` 폴더`) — 13px `--muted`, 한 줄 말줄임, `aria-describedby` 로 대화상자에 연결
- 머리와 초대 막대 사이 16px

### 2.2 초대 막대 (대화상자의 중심)
- 한 줄: [이메일 입력 + 권한 세그먼트]가 **한 테두리 안에 붙은 입력 묶음** + 오른쪽 `초대` 버튼. 묶음 높이 36px, 버튼 높이 36px, 사이 8px
- 입력 묶음: 테두리 1px `--rule`, 모서리 `--radius-control`, 바탕 `--paper`. 입력은 테두리 없이 묶음을 채우고(placeholder `이메일 주소`, 라벨은 `aria-label="초대할 이메일"` — 보이는 `이메일` 라벨 줄은 없앤다), 오른쪽 끝에 권한 세그먼트(`보기`·`편집`, 기존 `role="radiogroup"`). 세그먼트는 묶음 오른쪽 칸을 여백 없이 채운다 — 버튼 높이 = 묶음 안쪽 높이, 선택 바탕이 칸 끝까지, 오른쪽 모서리만 묶음 곡률(2026-09-15 사용자 "보기 편집 좌우 여백 어색함, 빈공간생김"). 입력과 세그먼트 사이 세로 구분선 1px `--rule`
- 묶음 안에 포커스면 묶음 테두리만 `--accent` 2px(`:focus-within`, 테두리 1px + 바깥 그림자 1px). 입력 자체 `:focus-visible` 외곽선은 끈다(2026-09-15 사용자 "이메일주소 포커스가 너무 큼"). 세그먼트 버튼 키보드 포커스 외곽선은 안쪽(`outline-offset: -2px`)
- 오류면 묶음 테두리 `--danger`, 아래 6px 에 오류 문구(문구 그대로)
- `초대` 버튼: 대화상자 기본 버튼 모양에 `font-weight: 600`. Enter 로도 초대(지금과 같음)
- 폭 480px 미만(대화상자 안 폭 기준, 화면 좁을 때): 입력 묶음이 한 줄 전체, 그 아래 줄 오른쪽에 `초대`

### 2.3 볼 수 있는 사람
- 제목 줄 `볼 수 있는 사람 {N}` — 12.5px `--muted`, 숫자는 `--ink`. 초대 막대와 24px 떨어짐. 아래 1px `--rule`
- 행: 높이 40px, 행 사이 1px `--rule-2` 선. 왼쪽 이메일(13.5px `--ink`, 말줄임, `title` 로 전체), 오른쪽 권한 세그먼트(높이 26px) + `삭제`
- `삭제`: 테두리 없는 글자 버튼, `--muted`, 호버 `--danger` 글자 + `--rule-2` 바탕
- 목록이 5행을 넘으면 목록만 스크롤(최대 높이 200px)
- 0명: 제목 줄 `볼 수 있는 사람 0` 아래 한 줄 `아직 초대한 사람이 없습니다.` (13px `--muted`, 행 높이 40px)
- 방금 초대했거나 권한을 바꾼 행은 바탕 `--accent-soft` 에서 투명으로 1200ms `--ease-out` 으로 사라진다 — 조작이 어느 행에 반영됐는지 보여 주는 유일한 움직임. 같은 이메일을 다시 초대하면 기존 행이 강조된다. 움직임 줄이기면 강조 없음

### 2.4 발
- 왼쪽 안내 `같은 이메일로 로그인하면 사이드바 공유받음에 보입니다.` (12.5px `--muted`, 줄바꿈 허용), 오른쪽 `닫기`. 목록과 20px 떨어짐
- 알림 띠 문구(F-212 `…앱 주소를 직접 알려 주세요.`)는 그대로

### 2.5 키보드·접근성
- 열리면 이메일 입력 포커스(지금과 같음). Tab 순서: 입력 → 권한 세그먼트 → 초대 → 행마다 권한 → 삭제 → 닫기
- 삭제 뒤 포커스는 다음 행 `삭제`, 없으면 이전 행, 목록이 비면 이메일 입력
