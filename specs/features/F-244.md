# F-244 도움말 — 대화상자에서 전용 문서 페이지로

작성일: 2026-09-18
상태: 사용자 승인 대기 (2026-09-18 사용자 "도움말 모달, 이것도 모달로 되어있어서 조금 답답한 느낌임. 그냥 문서로 만들고 뷰어 전용으로 볼수있으면 되는거 아닌지? 이게 더 직관적이고 현재 앱 기조랑 더 어울릴듯". 전용 페이지 `#/help` 방식으로 결정 — 사용자 문서 목록에는 넣지 않음)
근거: `specs/features/F-235.md`(도움말 대화상자·문법 목록), `F-123.md`(보기 모드 `Viewer`), `F-232.md` 3.3(전체 화면 전환·해시 라우트), `F-111.md`(첫 실행 안내 문서 `guideDoc.ts`)

## 1. 범위

### 문제
도움말이 대화상자(`HelpDialog`, `size="xwide"`)라 내용이 창 안에 갇힌다. 문법 카드가 12묶음이라 스크롤이 길고, 원문 편집 화면과 나란히 두고 볼 수도 없다. 이 앱은 "원문 마크다운 문서" 가 기본 단위인데 도움말만 별도 UI 로 되어 있다.

### 한다
- 도움말을 **마크다운 원문 하나**(`helpDoc.ts`)로 만든다. 문법마다 원문(코드블록)과 그 문법을 실제로 쓴 결과를 이어서 적는다 — 문서 자체가 예시다
- 전용 라우트 `#/help` 에서 **전체 화면 읽기 전용 뷰어**로 보여준다. `Viewer` + `renderMarkdown` 은 보기 모드(F-123)가 쓰는 것을 그대로 쓴다
- 사이드바 `도움말` 을 누르면 대화상자 대신 이 페이지로 간다
- 페이지 상단에 `내 문서로 복사` — 누르면 도움말 원문으로 새 문서를 만들어 연다(편집·보관하고 싶을 때)
- `HelpDialog` 와 `helpSyntax.ts` 카드 UI 는 없앤다

### 하지 않는다
- 도움말을 **사용자 문서로 자동 생성** — 문서 목록에 넣지 않는다. 지워지거나 고쳐져 도움말 접근이 막히면 안 된다
- 기존 첫 실행 안내 문서(`guideDoc.ts` `사용법`) 변경 — 그대로 둔다. 도움말은 **문법 설명**, 안내 문서는 **앱 사용법**으로 역할이 다르다
- 도움말 내용 자체를 새로 쓰기 — `helpSyntax.ts` 에 있는 12묶음의 문법·원문·설명을 그대로 옮긴다
- 검색·목차 사이드바·문법별 앵커 링크
- 다국어

## 3. 요구사항

### 3.1 도움말 원문 (`helpDoc.ts`)

- `HELP_DOC_TITLE = '마크다운 문법'`
- `HELP_DOC_CONTENT` 는 한 덩어리 마크다운 문자열. 묶음 순서는 `helpSyntax.ts` 그대로(제목·강조·목록·인용·링크·위키링크·표·코드블록·이미지·콜아웃·구분선·프론트매터)
- 각 문법은 이 모양으로 적는다:

```
## 강조

### 굵게

` ``` `
**굵게**
` ``` `

**굵게**
```

  즉 **원문을 코드블록으로 한 번**, **그 아래 실제로 쓴 결과를 한 번**. 설명(`caption`)이 있으면 결과 다음에 한 줄로 붙인다
- 프론트매터처럼 문서 맨 위에서만 뜻이 있는 문법은 결과 예시를 넣지 않고 원문과 설명만 적는다(문서 중간에 넣으면 프론트매터로 읽히지 않는다 — 원문과 설명으로 충분하다)
- 이미지 문법은 실제 첨부가 없으므로 결과 예시 없이 원문·설명만
- 줄 끝은 `\n`(LF). `내 문서로 복사` 가 문서를 만들 때는 앱 기본 줄 끝 설정을 따른다

### 3.2 페이지 (`HelpPage.tsx`)

- 전체 화면. 상단 줄: 제목 `도움말`, 오른쪽에 `내 문서로 복사` · `닫기`
- 본문은 `<Viewer html={renderMarkdown(HELP_DOC_CONTENT)} />` — 보기 모드와 같은 렌더러·같은 CSS
- 코드블록 복사 버튼(F-240 `codeCopy`)을 **켠다** — 문법 원문을 바로 복사해 쓸 수 있다
- 읽기 전용. 편집 진입·선택 저장 없음
- 본문 폭은 보기 모드와 같은 `--content-max`
- 스크롤 위치는 들어올 때마다 맨 위

### 3.3 라우팅 (`hashRoute.ts`, `App.tsx`)
- `#/help` → `{ type: 'help' }`. 정확히 `#/help` 만
- 들어갈 때: `beforeLeaveDoc()` 대기 → `sharedDoc` 해제 → `currentDocId = null` → 해시 `#/help`
- `닫기` 는 홈(`#/`). 브라우저 뒤로 가기도 자연스럽게 동작한다(해시 이동이라 그대로)
- `helpOpen` 상태와 `HelpDialog` 는 없앤다. Esc 로 닫던 동작(`App.tsx` 824행 조건식)에서도 뺀다
- 이미지 드롭 차단 조건(`App.tsx` 992·995행)에서 `helpOpen` 을 빼고, 대신 `#/help` 화면에서는 편집기가 없으므로 차단 대상이 아니다

### 3.4 내 문서로 복사 (`App.tsx`)
- `store.create({ title: HELP_DOC_TITLE, content: HELP_DOC_CONTENT(앱 줄 끝 설정), lineEnding })` → 만든 문서를 연다(해시 `#/d/{id}`)
- 같은 제목의 문서가 이미 있어도 그냥 하나 더 만든다(중복 검사 없음 — 문서 만들기 기본 동작과 같게)
- 성공하면 info 알림 `도움말을 문서로 복사했습니다.`

### 3.5 사이드바 (`Sidebar.tsx`)
- `도움말` 버튼(`RailButton`·`SidebarButton` 둘 다)은 자리·아이콘·문구 그대로. 동작만 페이지 이동으로 바뀐다
