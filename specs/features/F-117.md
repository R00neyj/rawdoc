## 1. 파일
- `vite.config.js`: `registerType: 'prompt'`, `injectRegister: false`
- `src/pwa/useAppUpdate.js` 신규 — `virtual:pwa-register/react` 의 `useRegisterSW` 사용
- `src/app/App.jsx`: 알림 연결

## 2. 요구사항
- 새 서비스 워커가 대기 상태가 되면 N-1 `update`: `새 버전이 있습니다.` + 버튼 `새로고침`
- `새로고침`: `await beforeLeaveDoc()`(자동 저장 flush) → `updateServiceWorker(true)`. 현재 해시 유지되므로 같은 문서·보기 모드로 다시 열린다
- 누르지 않으면 알림 유지. **자동 새로고침 금지**
- 앱을 오래 켜 두는 경우를 위해 등록 후 60분마다 `registration.update()` 호출
- 첫 설치(대기 중인 옛 워커 없음)에는 알림을 띄우지 않는다
- `virtual:pwa-register/react` 는 Vitest(node)에서 해석되지 않으므로 이 모듈을 import 하는 파일은 테스트에서 import 하지 않는다
