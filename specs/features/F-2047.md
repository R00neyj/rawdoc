````markdown
# 오프라인과 동기화

이 앱은 입력한 내용을 지금 쓰는 브라우저에 저장합니다. 로그인하지 않았으면 문서는 그 브라우저에만 있고, 로그인했으면 같은 내용을 서버로도 보내 다른 기기와 맞춥니다. 그래서 연결이 끊겨도 쓰던 일을 대부분 이어 갈 수 있고, 아직 서버에 가지 않은 것이 있는지는 상태바가 알려 줍니다.

## 로그인하지 않았을 때와 로그인했을 때

| | 로그인하지 않았을 때 | 로그인했을 때 |
| --- | --- | --- |
| 문서가 있는 곳 | 지금 쓰는 브라우저 한 곳 | 서버, 그리고 쓰는 브라우저마다 둔 사본 |
| 다른 브라우저·다른 기기 | 보이지 않음 | 같은 계정으로 로그인하면 보임 |
| 브라우저 데이터를 지우면 | 문서도 지워짐 | 서버로 보낸 내용은 남음 |
| 서버 한도 | 해당 없음 | 있음(아래 "한도에 닿았을 때") |

로그인하지 않고 쓰던 브라우저에서 처음 로그인하면 그 브라우저의 문서·폴더·이미지를 계정으로 옮깁니다. 화면 위에 `로컬 문서 {N}개를 계정으로 옮기는 중…`이 뜨고, 옮긴 것은 이어서 서버로 보냅니다. 앱을 처음 열 때 생긴 안내 문서는 고치거나 댓글을 달지 않았다면 옮기지 않습니다.

- 옮긴 뒤에도 브라우저의 원래 문서는 지우지 않습니다. 로그아웃하면 그 문서들이 다시 보입니다
- 같은 계정으로 다시 로그인하면 다시 옮기지 않습니다. 그래서 로그아웃한 채 고치거나 새로 만든 문서는 계정에 들어가지 않습니다. 설정 `데이터` 탭 `전체 내보내기`로 받은 zip을 로그인한 뒤 `가져오기…`로 들이면, 같은 문서는 더 나중에 고친 쪽 내용이 남습니다
- 로그인 전에 만든 금고는 따로 묻습니다. [금고로 문서 암호화하기](/guides/encryption)에 있습니다

## 자동 저장과 상태 표시

저장 버튼은 없습니다. 입력을 멈추면 곧 저장하고, 다른 탭으로 옮기거나 창을 닫을 때도 남은 입력의 저장을 시도합니다. 지금 문서의 저장 상태는 상태바에 보입니다.

| 상태바 | 뜻 |
| --- | --- |
| `입력 중…` | 아직 저장하지 않은 입력이 있습니다 |
| `저장됨` | 이 브라우저에 저장했습니다. 서버와 실시간으로 이어진 문서라면 서버에도 전해졌습니다 |
| `저장됨 · 동기화 대기 3` | 이 브라우저에는 저장했고, 서버로 보낼 항목이 3개 남았습니다 |
| `… · 오프라인` | 연결이 끊겨 서버로 보내지 못하고 있습니다 |
| `연결 중…` | 이 브라우저에 있던 내용으로 먼저 열고 서버와 맞추는 중입니다. 그동안에도 고칠 수 있습니다 |
| `연결 끊김 · 다시 연결 중` | 실시간 연결이 끊겼습니다. 고친 내용은 이 브라우저에 쌓입니다 |
| `다시 로그인 필요` | 로그인이 만료되어 서버로 보내지 못합니다 |
| `저장 실패` | 이 브라우저에 저장하지 못했습니다. 화면 위 알림을 따릅니다 |
| `메모리 모드 — 새로고침하면 사라집니다` | 브라우저가 저장 공간을 내주지 않았습니다. 창을 닫기 전에 내보내 둡니다 |

## 오프라인에서 되는 것과 안 되는 것

한 번 연 브라우저에서는 연결이 끊겨도 앱이 열립니다. 설치하지 않아도 됩니다.

| 할 일 | 오프라인에서 |
| --- | --- |
| 내 문서 목록 보기·읽기 | 됩니다. 로그인했으면 이 브라우저가 마지막으로 받아 둔 목록과 본문입니다 |
| 고치기 | 로그인하지 않았으면 모든 문서를 고칩니다. 로그인했으면 이 브라우저에서 새로 만든 문서와, 연결된 상태로 최근 30일 안에 이 브라우저에서 연 문서를 고칩니다 |
| 금고 문서 | 연결된 상태로 이 브라우저에서 금고를 연 적이 있으면 오프라인에서도 열고 고칠 수 있습니다 |
| 새 문서·폴더 만들기, 옮기기, 지우기 | 됩니다. 로그인했으면 연결된 뒤 서버에 반영됩니다 |
| 검색 | 이 브라우저에 저장된 문서에서 찾습니다 |
| 이미지 | 로그인했으면 이 브라우저에서 한 번 본 이미지만 보입니다. 새로 넣은 이미지는 연결된 뒤 서버로 올라갑니다 |
| 공유받은 문서 | 목록에 나오지 않고 열 수 없습니다 |
| 전체 내보내기·폴더 내보내기·옵시디언 볼트로 내보내기 | 로그인했으면 `온라인일 때 내보낼 수 있습니다`로 막힙니다 |
| 읽기 전용 링크·사람 초대·금고로 옮기기·로그아웃 | 서버가 해야 하는 일이라 연결되어야 합니다 |
| 도움말 | 됩니다. 이 사이트의 사용법 글은 연결되어야 열립니다 |

로그인해서 쓸 때 고칠 수 없는 문서를 열면 `오프라인에서는 이 문서를 읽기만 할 수 있습니다. 연결되면 편집할 수 있습니다.`가 뜹니다. 연결이 돌아오면 그 문서를 다시 열어 고칠 수 있게 합니다. 처음 쓰는 글자나 처음 고른 서체는 이 브라우저에 아직 서체 파일이 없으면 오프라인에서 다른 서체로 보일 수 있습니다.

## 다시 연결될 때

연결이 돌아오면 끊긴 동안 쌓인 것을 순서대로 서버로 보냅니다. 새로고침하거나 브라우저를 닫았다 열어도 보내지 못한 것은 이 브라우저에 남아 있다가, 다음에 앱을 열어 연결되면 이어서 보냅니다. 지금 열어 둔 문서가 아니어도 앱이 켜져 있으면 함께 보냅니다.

- 서버와 실시간으로 이어지는 문서는 끊긴 동안의 편집을 서버의 최신 내용과 합칩니다. 다른 기기나 다른 사람이 같은 곳을 고쳤다면 두 글이 섞일 수 있습니다. 여럿이 함께 고칠 때의 이야기는 [문서를 공유하고 함께 편집하기](/guides/sharing)에 있습니다
- 금고 문서처럼 실시간으로 이어지지 않는 문서가 그사이 다른 곳에서 먼저 바뀌었다면, 내 편집을 `(충돌 사본)`이 붙은 새 문서로 남기고 알림으로 알려 줍니다. 두 문서를 견주어 직접 합칩니다
- 다른 곳에서 지운 문서를 끊긴 동안 고쳤다면 그 편집은 서버에 남지 않습니다
- 로그인이 만료되면 상태바에 `다시 로그인 필요`가 붙고 보내기를 멈춥니다. 보내지 못한 것은 이 브라우저에 남아 있다가 같은 계정으로 다시 로그인하면 이어서 올라갑니다. 그사이 새로고침하면 로그인하지 않은 화면으로 열리니, 상단바 계정 메뉴에서 `로그인`을 누릅니다

## 여러 탭과 여러 기기

**로그인하지 않았을 때**는 같은 브라우저의 탭끼리만 이어집니다.

- 두 탭에서 같은 문서를 열면 한 탭만 고칠 수 있습니다. 다른 탭에는 `다른 탭에서 편집 중입니다. 읽기만 할 수 있습니다.`가 뜨고, 고치던 탭이 그 문서를 닫으면 `이제 편집할 수 있습니다.`가 뜹니다
- 새 문서, 이름 바꾸기, 삭제 같은 목록의 변화는 다른 탭에도 바로 보입니다
- 다른 브라우저나 다른 기기로 옮기려면 `전체 내보내기`로 받은 zip을 그쪽에서 `가져오기…`로 들이거나, 로그인합니다

**로그인했을 때**는 같은 문서를 여러 탭이나 여러 기기에서 동시에 고칠 수 있고, 서로의 입력이 곧바로 보입니다.

- 같은 브라우저의 다른 탭은 목록도 바로 바뀝니다. 다른 기기에서 만들거나 이름을 바꾼 문서는 앱을 새로고침하거나 다시 열면 목록에 나타납니다
- 연결이 끊긴 채 두 탭에서 같은 문서를 고쳤다면, 다시 연결된 뒤 서버에서 하나로 합쳐집니다
- 금고 문서는 로그인해도 같은 브라우저에서 한 탭만 고칠 수 있습니다

## 한도에 닿았을 때

로그인해서 쓰는 계정에는 서버 한도가 있습니다. 계정 메뉴를 열면 연결되어 있을 때 지금까지 쓴 양이 보입니다. 쓰기 횟수나 문서 공간 한도에 걸려도 이 브라우저에 저장한 편집은 지우지 않고, 한도가 풀리면 원래 순서대로 이어서 보냅니다.

| 한도 | 넘으면 |
| --- | --- |
| 문서 하나 1MB | 그 문서가 서버에 저장되지 않는다는 알림이 뜹니다. 내용을 줄이거나 여러 문서로 나누면 다시 저장됩니다 |
| 문서 본문을 모두 합쳐 100MB, 문서 10,000개 | 넘게 하는 편집이나 새 문서가 서버에 가지 않고 알림이 뜹니다. 안 쓰는 문서를 지우거나 줄이면 쌓인 편집이 올라갑니다 |
| 서버에 쓰는 일(저장·이동·삭제) 1분에 120번 | 잠시 쉬었다가 이어서 저장합니다 |
| 같은 일 하루 5,000번 | 한국 시간 오전 9시(UTC 자정)까지 서버로 보내지 않습니다. 실시간으로 이어진 문서는 멈추지 않고, 서버에 저장하는 간격만 길어집니다 |
| 이미지 300MB | 새 이미지를 넣지 못했다는 알림이 뜹니다. 연결이 끊긴 동안 넣어 한도를 넘긴 이미지는 이 브라우저에만 남고, 다른 기기에서는 `이미지를 찾을 수 없습니다`로 보입니다 |

운영자가 쓰기를 막은 계정에는 `이 계정은 운영자가 쓰기를 막았습니다. 문서 읽기와 내보내기만 할 수 있습니다.`가 뜹니다. 이때도 이 브라우저에 쌓인 편집은 지우지 않습니다.

## 브라우저 데이터가 지워질 때와 대비

로그인하지 않고 쓴 문서는 이 브라우저의 사이트 데이터 안에만 있습니다. 브라우저 설정에서 이 사이트의 데이터를 지우면 문서도 함께 사라지고, 이 앱으로는 되살릴 수 없습니다.

브라우저는 저장 공간이 모자라면 사이트 데이터를 스스로 지울 수 있습니다. 로그인하지 않고 쓸 때 이 앱은 열릴 때 브라우저에 데이터를 지우지 말아 달라고 요청하고, 브라우저가 허락하지 않으면 그 사실을 한 번 알려 줍니다.

로그인했으면 서버로 보낸 내용은 브라우저 데이터를 지워도 남습니다. 끊긴 동안 고치고 아직 보내지 못한 편집만 함께 지워지므로, 지우기 전에 연결된 상태로 앱을 열어 상태바에 `동기화 대기`나 `오프라인`이 붙지 않았는지 봅니다.

백업은 이렇게 합니다.

- 설정 `데이터` 탭 `전체 내보내기`: 문서·폴더·이미지를 zip 하나로 받습니다. 같은 탭의 `가져오기…`로 되돌립니다
- 상단바 `내보내기` 메뉴의 `.md`: 지금 문서 하나를 파일로 받습니다
- 로그인하지 않고 쓰고 있다면, 로그인해 두는 것도 서버에 사본을 두는 방법입니다

## 설치와 업데이트

- 사이드바 `앱 설치`를 누르면 브라우저 탭이 아닌 따로 된 창으로 씁니다. 이 버튼은 브라우저가 설치를 지원할 때만 보입니다
- 새 버전은 앱을 쓰는 동안 뒤에서 받아 둡니다. 준비되면 `새 버전이 있습니다.` 알림에 `새로고침` 버튼이 뜨고, 누르면 저장하지 않은 입력을 먼저 저장한 뒤 새 버전으로 다시 엽니다
- 누르지 않으면 지금 버전을 계속 씁니다. 이 앱을 연 탭과 창을 모두 닫았다가 다시 열면 새 버전으로 열립니다

## 정리

- 로그인하지 않은 문서는 이 브라우저에만 있으니 `전체 내보내기`로 백업해 둡니다
- 로그인하면 이 브라우저와 서버 양쪽에 두고, 끊긴 동안 고친 것은 연결되면 보냅니다
- 로그인해서 쓸 때 오프라인에서는 새 문서와 최근 30일 안에 이 브라우저에서 연 문서를 고칠 수 있습니다
- 상태바에 `동기화 대기`나 `오프라인`이 붙어 있으면 아직 서버에 가지 않은 것이 있습니다
- 쓰기 횟수나 문서 공간 한도에 걸린 편집은 이 브라우저에 남아 있다가 풀리면 올라갑니다
````

- `…` 는 U+2026 한 글자다(`입력 중…`·`연결 중…`·`가져오기…`·`로컬 문서 {N}개를 계정으로 옮기는 중…` 은 화면 글자 그대로, `` `… · 오프라인` `` 의 앞 `…` 는 앞 글자 자리 표시)

## 10. 가정으로 둔 것 (코드로 확인하지 못했다)

1. **브라우저가 저장 공간이 모자라면 사이트 데이터를 지울 수 있다는 것, 사이트 데이터를 지우면 이 출처의 브라우저 데이터베이스가 함께 지워진다는 것.** WHATWG Storage Standard 의 best-effort·persistent 구분과 브라우저의 "사이트 데이터 삭제" 동작에 기댔고, 앱의 F-118 알림 문구도 같은 말을 한다. 이 세션에서 표준 원문을 다시 열어 보지는 않았다
2. **`새로고침` 을 누르지 않으면 모든 앱 탭·창을 닫은 뒤에 새 버전이 켜진다는 것.** `registerType: 'prompt'` 와 서비스 워커 표준의 대기(waiting) 수명 주기에 기댔다. `playwright.config.js` 가 서비스 워커를 막아 e2e 로 확인할 수 없다 — H4
3. **금고 문서를 오프라인에서 고칠 수 있다는 것.** 경로 판정과 금고 묶음 캐시 대체는 코드로 읽었고, 금고가 열린 채 끊긴 뒤의 저장이 보낼 목록으로 가는 것도 `withE2ee` 가 같은 서버 저장소를 감싸는 구조로 읽었다. 실제로 돌려 보지 않았다
4. 로컬 `origin/deploy` 참조가 원격과 같다는 것(m10). 원격이 더 나갔다면 결론(모두 배포됨)은 바뀌지 않는다
5. 오프라인 동작 전부(4.3·4.4)는 코드 읽기와 기존 명세로 판정했다. 이 세션에서 브라우저를 끊어 돌려 보지 않았다 — H2
6. `앱 설치` 버튼이 Chromium 계열에서만 보인다는 것. 코드는 `beforeinstallprompt` 를 받아야 보인다는 데까지 확인했고, 어느 브라우저가 그 이벤트를 쏘는지는 확인하지 않았다 — 그래서 글은 "브라우저가 설치를 지원할 때만" 으로만 쓴다. H4
7. 서체 조각을 오프라인에서 새로 받을 수 없어 다른 서체로 보인다는 것 — `runtimeCaching` 설정과 F-2040 설계로 판정했고 돌려 보지 않았다. H2 ⓓ
