## 2. 요구사항
- 설정 대화상자 마지막 항목 `줄 번호`: `표시` / `숨김` 2버튼 세그먼트 (`role="radiogroup"`, 다른 항목과 같은 방식). 기본 `표시`
- 누르는 즉시 반영, `md.lineNumbers`(`on` 기본 / `off`)에 저장, 다음 실행에도 쓴다
- 편집·원문 모드 공통. 보기 모드·공유 화면은 원래 줄 번호가 없어 영향 없음
- 끄면 거터 영역이 사라지고 내용이 그 폭만큼 넓어진다. 문서 칸 최대 폭(800px)·가운데 정렬 규칙은 그대로. 첫 글자 왼쪽에 거터 대신 `--gutter-gap` 만큼의 여백은 두지 않는다(내용 칸 왼쪽 끝에서 바로 시작)
- 전환해도 문서·커서·선택·실행 취소 기록·스크롤 위치(보이는 첫 줄)가 유지된다. 에디터를 다시 만들지 않는다 (`Compartment.reconfigure`)
- 문서를 바꿔 에디터를 새로 만들 때도 저장된 값으로 시작한다

## 3. 수용 기준

브라우저 확인은 5173 외 포트, `--strictPort`. 끝나면 서버 종료. 다른 에이전트가 브라우저를 쓰는 중이면 "확인 못 함"
