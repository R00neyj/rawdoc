# F-215 공개 보기 화면에 앱 로고

작성일: 2026-09-15
상태: 사용자 요청(2026-09-15 "열람용 공유 링크에도 앱 로고랑 있어야 하는거 아님?"). F-214 커밋 뒤
근거: 로그인 없이 링크로 들어온 사람이 어떤 앱의 문서인지 알 수 없다. F-210 2.4 "상단바 없음"은 유지하고, 앱 사이드바 머리 줄(F-159 `SidebarHead` 의 `brand-group`)과 같은 로고 묶음만 넣는다

## 1. 파일 소유

| `src/app/PublicBrand.tsx` | 신규. 로고 묶음 링크 |
| `src/app/PublicView.tsx` | 문서 링크 머리 줄, 좁은 창 폴더 머리 줄에 로고 |

## 2. 요구사항

### 2.1 로고 묶음 `PublicBrand`
- 마크업은 `SidebarHead` 의 로고와 같은 클래스: `<a class="brand-group public-brand" href="/">` 안에 `img.brand-icon`(`brand.icon`, `alt=""`, 20×20) + `span.brand`(`brand.name`). 제품명·아이콘 경로는 `src/brand.ts` 에서만 읽는다
- 링크 이름(`aria-label`): `{brand.name} 열기`. 누르면 같은 탭에서 앱 첫 화면(`/`)
- 글자 색은 `--ink`, 밑줄 없음. 호버는 바탕 `--rule-2`(모서리 `--radius-control`, 안쪽 여백 4px 6px, 색 전환 design.md 4장 규칙), 키보드 포커스 링은 앱 공통과 같게
- 새 색 hex·새 서체 없음. 서체는 기존 `.brand`(`--font-display` 700 16px)

### 2.2 배치
- **문서 링크 `#/p/{토큰}`**: 머리 줄 왼쪽이 `로고 묶음 | 문서 제목`. 둘 사이 세로 구분선 1px `--rule`, 높이 16px, 좌우 간격 12px. 제목은 기존처럼 줄임표. 오른쪽 `.md 내보내기` 그대로
  - 폭 600px 이하: 로고 묶음은 아이콘만(`.brand` 글자 숨김), 구분선 유지
- **폴더 링크 `#/p/f/…`, 넓은 창**: 왼쪽 목록(`PublicFolderList`) 맨 위, 폴더 이름(`h2`) 위에 로고 묶음. 로고는 목록 머리(`public-folder-list-head`, 높이 `--topbar-h`, 아래 선 `--rule`) 안에 두어 오른쪽 문서 머리 줄과 가로선이 이어지게 하고, 로고 아이콘 왼쪽 끝을 목록 글자와 맞춘다 (2026-09-15 메인 화면 점검). 머리 아래 폴더 이름까지 12px. 오른쪽 문서 머리 줄에는 로고를 넣지 않는다(두 번 보이지 않게)
- **폴더 링크, 좁은 창(≤1023px)**: `public-folder-topbar` 왼쪽에 로고 묶음, 그 오른쪽에 기존 `목록` 버튼. 목록을 겹쳐 열었을 때 목록 맨 위 로고는 그대로 보여도 된다
- 불러오는 중·404·네트워크 오류 화면에도 로고가 보인다 (문서 링크는 머리 줄이 이미 있음. 폴더 링크의 로딩·오류 화면은 `public-folder-topbar` 모양의 머리 줄에 로고만)
