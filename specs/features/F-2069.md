**F-2056 과의 경계(알림 열기 → 서버 목록 다시 읽기).** F-2056 2장 표 마지막 줄의 "알림 항목 열기(없는 문서) … 그대로" 경로는 `handleOpenNotification` 의 한 갈래다. 그 갈래는 `!docsRef.current.some((d) => d.id === item.docId) && navigator.onLine` 일 때 `await resyncFromStore().catch(() => {})` 를 부른다. 이 조각의 경계는 세 가지다.
- 훅은 **판정과 호출 한 줄만** 가져간다. `resyncFromStore` 본문(순번 `bootListSeqRef`·`mergeResyncList`·`keepLiveTitle`·삭제 문구 갈래)과 F-2056 의 `createListRefresher`·캐시 resync 는 App 에 남는다
- 옵션 타입을 `resyncFromStore: () => Promise<void>` 로 좁힌다(5장). 그래서 훅 안에서 `'bootMerge'` 를 넘길 수 없고, 문구 갈래를 고르는 권한은 App 에 남는다. App 의 `(deletedSource?: …) => Promise<void>` 는 이 타입에 대입된다(`tsc` 실측)
- 문서가 목록에 있으면 다시 읽지 않는다. 이 갈래는 지금 아무 e2e 도 보지 않아 C2 로 고정한다(7.2). 없는 문서 갈래는 F-507 E8(알 수 없는 문서)과 E9(`/api/shared` 가 한 번 더 불린다)가 본다

**해시 라우팅 구역(F-2071)과의 경계.** `handleOpenNotification` 은 `location.hash` 를 **쓰기만** 한다. 그 뒤 문서 열기·스레드 대상 잡기·`replaceHashUrl` 은 App 의 `hashchange` effect(F-2071 이 가져감)가 한다. `formatCommentHash` 는 `hashRoute.ts` 에 이미 있는 순수 함수라 import 만 훅으로 옮기고, F-2071 의 `hashNav.ts` 와 겹치지 않는다.

## 11. 열린 질문

### Q1. `docScreenId` 를 어디서 계산하나 — **기본값: App 에 남기고 훅은 값 하나를 받는다**

- 이유
  - 팔레트 context 세 곳(단계 4)이 이 값을 읽는다
  - 식의 재료 중 화면 플래그 4개는 F-2059 2.2 가 App 에 묶어 둔 상태다. 훅이 계산하면 옵션이 4개(`sharedDoc`·`sharesOpen`·`helpOpen`·`mapRoute`) 늘고, 알림 훅이 "문서 화면" 정의의 주인이 된다. 그러면 F-2059 7장 D1(화면 플래그 끄는 범위) 판정 때 이 훅도 봐야 한다
  - 남기면 옵션이 1개이고, 세 줄은 같은 파일 안 이동이다
- 다른 쪽(훅이 계산해 반환): 블록 g 와 "문서 화면" 정의가 한 파일에 모이고 App 이 3줄 더 준다. 대신 옵션이 4개 늘고, 팔레트가 알림 훅의 반환값으로 화면 판정을 하게 된다

### Q2. `handleOpenNotification` deps 에 `docsRef` 를 더하나 — **기본값: 더한다**

- 이유
  - 그대로 옮기면 `exhaustive-deps` 경고 1 이 난다(실측). A2 는 경고 포함 0 이다
  - F-2059 3.7 은 새 `eslint-disable` 을 금한다
  - ref 객체는 정체가 바뀌지 않아 콜백이 다시 만들어지는 시점이 같다
- 다른 쪽(`docsRef` 대신 `hasDoc: (id) => boolean` 같은 함수를 받음): 경고는 없어지지만 판정 식 `docsRef.current.some(…)` 이 App 으로 가고, 훅 쪽 줄이 바뀐다. 3.6 이동 줄이 더 줄어든다

### Q3. 쓰이지 않는 `NotificationsMenu` import 를 지우나 — **기본값: 이 조각에서 지운다**

- 이유
  - 이 구역 import 묶음(≈154~160)을 어차피 정리한다. 3.6 이 허용하는 "import" 분류 한 줄이다
  - 동작·번들에는 영향이 없다 — `TopBar.tsx` 가 같은 모듈을 import 하고, 모듈에 부작용 import 가 없다(머리 import 는 React·아이콘·순수 함수·타입뿐)
  - 남겨 두면 `^[A-Z_]` 무시 규칙 때문에 누구도 찾지 못한다
- 다른 쪽(남긴다): 전제 3 을 가장 좁게 읽는 쪽이다. App 에 죽은 줄 하나가 남고, A1 범위는 1 줄어든다

### Q4. 멘션 후보 원천까지 이 훅에 넣나 — **기본값: 넣는다**

- 이유
  - 로드맵 행 이름이 "알림함·멘션·안 읽은 점" 이다
  - `mentionDocId` 가 `notificationsEnabled` 를 읽어, 따로 두면 App 이 훅 반환값을 다시 받아 식을 만들어야 한다

### Q5. 특성 테스트가 둘로 충분한가 — **기본값: C1·C2**
