## 2. 요구사항

구조·IME 처리·활성 줄 판정은 F-104 2.1·2.3 과 같다. `buildLines(state, ranges)` 순수 계산 + ViewPlugin

| 요소 | 모든 줄(활성 포함) | 활성 줄이 아닐 때 추가 |
| --- | --- | --- |
| ATX 제목 `#`~`######` | 줄 클래스 `md-h1`~`md-h6` (크기) | `HeaderMark` 와 뒤따르는 공백 1칸 숨김 |
| Setext 제목 (`===`, `---` 밑줄) | 제목 줄에 `md-h1`/`md-h2` | 숨기지 않음 |
| 인용 `>` | 인용에 속한 각 줄에 `md-quote` (왼쪽 3px `--accent` 선, `--ink-2`) | 각 줄의 `QuoteMark` 와 뒤 공백 1칸 숨김 |
| 글머리 목록 `-` `*` `+` | | `ListMark` 를 `•` 위젯으로 치환 (`md-bullet`, `--accent`) |
| 번호 목록 `1.` | | 그대로 (기호 색만) |
| 체크박스 `- [ ]` `- [x]` | | `ListMark`+공백 숨김, `TaskMarker` 를 체크박스 위젯으로 치환 |
| 구분선 `---` `***` | | 줄 클래스 `md-hr` + 기호 글자 숨김 (선은 CSS 로 그린다) |

### 체크박스 위젯
- `<input type="checkbox" tabindex="-1">`, `[x]`·`[X]` 면 checked. `accent-color: var(--accent)`
- 클릭(`mousedown` 에서 `preventDefault`)하면 대괄호 안 한 글자를 `x` ↔ 공백으로 바꾸는 트랜잭션 1개. 선택은 바꾸지 않는다 → 그 줄이 활성 줄이 되지 않아 위젯이 유지된다. 실행 취소 가능
- `ignoreEvent()` 는 `mousedown`·`click` 에 대해 `false`
- `eq()` 는 checked 값만 비교

### 제목 크기 (`preview.css`)
- `md-h1` 28px, `md-h2` 22px, `md-h3` 18px, `md-h4`~`md-h6` 15px. 모두 굵게, `line-height` 1.45
- `md-h1`·`md-h2` 는 `font-family: var(--font-display)` (D6 토글을 따른다). `md-h3` 이하는 `--font-sans`
- 크기 수치 근거: `docs/prototype.html` 185~188행을 줄 높이에 맞게 조정
