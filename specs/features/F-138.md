## 3. 수정 항목

### 3.1 표 칸 역슬래시 왕복 (high) — F-135 3.1 을 대체
- 현재: `unescapeCell` 이 모든 `\X` 를 `X` 로 바꿔 `C:\Users`·`a\*b` 칸을 한 글자만 고쳐도 `\` 가 사라진다. `escapeCell` 은 `\` 를 다루지 않아 칸에 `a\|b` 를 치면 원문 `a\\|b` 가 되어 칸이 나뉜다
- 규칙 (파이프 앞 역슬래시 묶음만 바꾸고 나머지 `\` 는 글자 그대로)
  - `unescapeCell(raw)`: `|` 바로 앞 연속 `\` 가 k개(칸 안에서는 항상 홀수)면 `(k-1)/2` 개 + `|`. 그 밖의 `\` 는 그대로
  - `escapeCell(value)`: `|` 바로 앞 연속 `\` 가 j개면 `2j+1` 개 + `|`. 그 밖의 `\` 는 그대로
  - 칸 끝: 칸 값 원문이 홀수 개 `\` 로 끝나고 칸 범위 바로 뒤가 파이프(공백 패딩 없음)면, 원문 뒤에 공백 1개를 함께 넣는다 (뒤 파이프가 이스케이프되지 않게. 바뀐 곳은 그 칸뿐)
- 테스트
  - `parseTable` 로 읽은 칸 원문 r 에 대해 `escapeCell(unescapeCell(r)) === r` — `C:\Users`, `a\*b`, `a\|b`, `\\\|`, `a\`(패딩 있는 칸), 한글, 빈 칸
  - 한 줄 값 v 에 대해 `unescapeCell(escapeCell(v)) === v` — `a|b`, `a\|b`, `\`, `\\|`, `C:\Users`
  - 칸에 `a\|b`, `a\`, `|` 를 쓴 뒤 `parseTable` 열 수·행 수가 그대로이고 다시 읽은 칸 값이 쓴 값과 같음 (`|a|b|` 패딩 없는 표 포함)

### 3.2 공유 화면이 에디터를 언마운트하지 않음 (high)
- 현재: 공유 화면이 뜨면 Editor 가 언마운트되고, 같은 문서로 돌아오면 처음 열 때 읽은 옛 `openDoc.content` 로 다시 만들어져 그 사이 저장된 편집을 덮어쓴다
- 수정: 공유 화면이 떠 있는 동안 편집 영역(Editor·Viewer)을 언마운트하지 말고 `hidden` 으로 숨긴다. 공유 화면을 닫으면 같은 EditorView 가 그대로 보인다 (실행 취소 기록도 유지)
- 공유 화면을 열 때 저장 대기 중인 편집이 있으면 먼저 저장을 시도한다 (기존 저장 경로)

### 3.3 뒤로 가기로 공유 화면 떠나기 (medium)
- 현재: `#/d/A` → 공유 링크 → 뒤로 가기 시 해시가 현재 문서 id 와 같아 바로 return 하므로 공유 화면이 닫히지 않는다
- 수정: 해시가 문서 경로(`type: 'doc'`)로 바뀌면 문서 id 가 같아도 공유 화면을 닫는다. `type: 'none'` 도 같다

### 3.4 끊긴 폴더 id 를 가진 문서에서 새 문서 만들기 (medium)
- 현재: 저장소 `create` 가 없는 폴더 id 를 거부하는데(F-136), 앱은 `currentDoc.folderId` 를 그대로 넘긴다. 지운 폴더나 이전 버그로 문서 id 가 들어간 문서를 연 상태에서 사이드바 `새 문서`·없는 위키링크 클릭·가져오기가 처리되지 않은 rejection 으로 끝난다
- 수정
  - 새 문서 대상 폴더를 정하는 곳을 한 함수로 모은다: 현재 문서의 `folderId` 가 **존재하는 폴더**일 때만 그 값, 아니면 `null`(최상위). 세 경로 모두 이 함수를 쓴다
  - 세 경로의 저장소 호출 실패는 처리되지 않은 rejection 으로 두지 않고 기존 오류 알림(저장 실패와 같은 알림 경로)으로 보여 준다
- 테스트: 대상 폴더 함수 단위 테스트 (존재 폴더, 없는 id, 문서 id, null)

### 3.5 뷰 갱신 도중 dispatch 금지 (medium, 추정)
- 현재: `endEdit` 이 조합 중이면 `pushCellEdit`, 보류 재계산이 있으면 `forceRecalc` 를 dispatch 하는데, `TableWidget.destroy`·`updateDOM` 안에서도 불린다. CM6 는 갱신 중 `update` 를 부르면 예외를 던진다 (`@codemirror/view/dist/index.js:7948`)
- 수정: `destroy`·`updateDOM` 경로에서 끝낼 때는 칸 값·범위를 붙잡아 두고 dispatch 를 갱신이 끝난 뒤(마이크로태스크)로 미룬다. 미룬 사이 주 문서가 바뀌었으면 그 변경으로 범위를 옮긴 뒤 쓴다 (F-135 3.2 범위 추적을 편집 종료 뒤 보류 쓰기에도 적용). 범위를 옮길 수 없으면(범위가 지워짐) 쓰지 않고 `forceRecalc` 만 보낸다
- 확인: 브라우저에서 칸 편집 중(합성 조합 상태) 스크롤로 표를 뷰포트 밖으로 보냈을 때 콘솔 예외 없음

### 3.6 공유 링크 압축 해제 크기 상한 (low)
- 현재: `decompress` 가 풀린 결과 크기를 제한하지 않아 조작된 링크로 탭이 멈출 수 있다
- 수정: 풀린 바이트가 **20MB** 를 넘으면 읽기를 멈추고 거부한다 (기존 "열 수 없는 링크" 처리). 스트림을 읽으면서 누적 크기로 판정한다
- 테스트: 20MB 초과로 풀리는 조각 → 거부, 경계 아래 → 성공 (테스트 시간이 길면 상한을 인자로 받아 작은 값으로 확인)
