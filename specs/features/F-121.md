## 2. 요구사항

- 사이드바 맨 아래 `설정` 버튼(항상 표시) → D-2 (`Dialog.jsx` 사용)
- D-2 제목 `설정`. 항목 `제목 서체`: `세리프` / `산세리프` 2버튼 세그먼트. `role="radiogroup"` + 각 버튼 `role="radio"` `aria-checked`
- 누르는 즉시 `<html data-heading-font="serif|sans">` 변경 + `md.headingFont` 저장. 저장 버튼 없음
- 각 버튼 글자는 해당 서체로 표시한다 (`세리프` 는 `--font-serif`, `산세리프` 는 `--font-sans`)
- 닫기: `닫기` 버튼, Esc, 바깥 클릭. 닫으면 `설정` 버튼으로 포커스 복귀. 열 때 포커스는 현재 선택된 버튼
- 산세리프 제목은 굵기 700, 크기는 세리프와 같게 (design.md 2.4)
- `--font-display` 를 쓰는 곳: 상단바 제품명, S-2 `문서가 없습니다.`, (F-105) `#` `##` 제목. `--font-serif` 를 직접 참조하는 곳은 설정 버튼 미리보기 글자뿐이다
- 새로고침 후에도 선택 유지. 첫 화면 그리기 전에 반영돼 서체가 바뀌며 깜빡이지 않는다
