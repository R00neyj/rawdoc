## 2. 요구사항

### 2.1 표시 조건
- 편집 모드에서 문서 최상위(목록·인용 안 아님) `HTMLBlock` 중 `parseImageBlock` 이 성공한 블록 3줄을 블록 위젯 하나로 대체한다
- 커서·선택이 블록 줄 범위와 겹치면 원문 (F-106 코드블록 규칙). 방향키로 들어가는 방법은 F-106 2.2 `stepIntoBlock` 그대로
- F-146 이 있으면 에디터 포커스가 없을 때는 커서가 안에 있어도 위젯
- 원문 모드는 원문. 보기 모드는 F-158
- 해석 실패 블록은 원문 그대로 (위젯 없음)
- 한글 조합 중 재계산 보류·따라잡기는 blocks.js 규칙 그대로

### 2.2 모양
- 바깥 `div.md-image`: 폭 = `width` px, `max-width: 100%`, 모서리 `--radius-image`, `overflow: hidden`, 위아래 여백은 문단 간격과 같게(margin 금지 규칙 F-124 3.2 에 맞춰 padding). `width` 가 없으면 이미지 가로 (최대 100%)
- 정렬은 margin 으로만: `left` 는 `margin-inline: 0 auto`, `center` 는 `auto`, `right` 는 `auto 0`
- 안 `img`: `display: block; width: 100%; height: auto`. 불러오기 전에도 높이가 정해지게 바깥에 `aspect-ratio: {width} / {height}` (첨부 레코드 값)
- 첨부가 없으면(`null`) 같은 폭·모서리의 자리 표시: 바탕 `--md-bg-muted`, 높이 120px, 가운데 `broken_image` 20px + `이미지를 찾을 수 없습니다` 13px `--muted`. 정렬·크기 조절은 똑같이 동작
- 위젯은 `role="img"`·`aria-label` = `alt` (비면 `이미지`)
- blob URL 은 에디터 하나에 id 별로 한 번 만들고 에디터 `destroy` 때 모두 `revokeObjectURL`. 위젯 비교(`eq`)는 id·ext·alt·align·width 로 하고, align·width 만 바뀌면 `updateDOM` 으로 이미지를 다시 불러오지 않는다
- 높이가 바뀌면 blocks.js `observeHeight` 로 CM6 가 다시 잰다

### 2.3 정렬 버튼
- 위젯에 마우스를 올리거나 위젯 안 요소에 포커스가 있으면 이미지 안 오른쪽 위(8px 안쪽)에 버튼 3개: `왼쪽 정렬` `가운데 정렬` `오른쪽 정렬`
- 모양: 28×28 아이콘 버튼 묶음, 바탕 `--panel`, 1px `--rule` 테두리, 모서리 `--radius-control`, 겹쳐 뜨므로 그림자 허용(design.md 4장). 선택 상태는 F-153 선택 표시, `aria-pressed`. 툴팁은 앱 툴팁(F-142)
- 누르면 원문 `align="…"` 의 값 글자만 바꾸는 트랜잭션 1개 (`userEvent: 'input.image'`). 커서는 옮기지 않는다

### 2.4 크기 조절
- 손잡이 2개. 호버·포커스 때만 보인다. 바탕 `--panel`, 1px `--ink-2` 테두리
  - 가장자리 막대: 6×40px, 세로 가운데. 커서 `ew-resize`. `aria-label="크기 조절"`
  - 모서리: 12×12px. 커서 `nwse-resize`
- 위치: `left`·`center` 정렬은 **오른쪽 가장자리·오른쪽 아래 모서리**. `right` 정렬은 붙은 쪽이 오른쪽이라 **왼쪽 가장자리·왼쪽 아래 모서리**로 뒤집는다 (커서 `nesw-resize`)
- 두 손잡이 모두 가로 이동량으로 폭만 바꾸고 세로는 비율대로 따라간다. 폭 변화 = 이동량 × (`left` 1, `center` 2, `right` −1) — 끄는 가장자리가 포인터를 따라가게
- 끄는 동안은 화면 폭만 바꾸고(문서 변경 없음) 이미지 안 오른쪽 아래에 `{N}px` (12px, 툴팁 모양). 포인터를 놓으면 원문 `width="…"` 값 글자만 바꾸는 트랜잭션 1개. `width` 속성이 없으면 `alt` 뒤(없으면 `src` 뒤)에 ` width="{N}"` 를 넣는다
- 폭은 정수, 최소 48px, 최대 문서 칸 글자 폭. 값이 그대로면 트랜잭션 없음. 끄는 중 Esc 는 취소
- 키보드: 손잡이 포커스에서 ←/→ 10px, Shift 와 함께 50px. 누를 때마다 트랜잭션 1개
- 포인터 캡처를 쓴다. 끄는 동안 에디터 선택·스크롤이 바뀌지 않는다

### 2.5 원문으로 들어가기
- 이미지 더블클릭 → 커서를 블록 첫 줄 시작에 두어 원문을 보인다
- 한 번 클릭은 커서를 옮기지 않는다 (위젯이 마우스 이벤트를 받는다). 버튼·손잡이 조작도 같다
- 거터 줄 번호·위젯 아래 줄 클릭 위치는 코드블록 위젯과 같은 규칙
