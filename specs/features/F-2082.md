### 3.3 effect 순서

훅 안 effect 는 최신값 effect ⑤ 하나다. `useRef`(`openWikiLinkRef`)·`useCallback`(`handleOpenWikiLink`)은 effect 가 아니다.

F-2076 188행이 `useSharesPage` 에 대해 한 판정("⑤ 는 ref 대입뿐이고 그 ref 를 읽지 않는다")을 넓힌 것이다
- 다른 effect 는 한 줄도 자리를 옮기지 않는다. effect ③ 은 줄·자리 모두 그대로다
- 렌더 중 상태 조정 블록(F-2059 3.3 a~h)은 이 훅에 없다

## 11. 열린 질문 (모두 기본값 — 기본값대로면 사람이 정할 갈림길 없음)

### Q1. 훅 호출 자리 — **기본값: `saveCurrentAsNewDoc` 자리(effect ③ 바로 위)**

- 이유: effect ③ 의 `saveCurrentAsNewDocRef.current = saveCurrentAsNewDoc` 줄을 한 글자도 바꾸지 않고 `immutability` 를 피하는 유일한 자리 모양이다(3.1, 실측). 자리를 옮기는 effect 는 ⑤ 하나이고 그 ref 는 훅 안으로 들어가 관찰되는 차이가 없다(3.3)

### Q2. 특성 e2e C1~C3 을 두나 — **기본값: 셋 다 둔다**

- 이유: 공유 화면 두 버튼과 공유 관리 폴더 클릭은 이번에 옮기는데 보는 e2e 가 0건이다(F-2059 5.2 "e2e 가 하나도 없는 것은 옮기기 전에 단다"). 셋 다 변이로 잡는 것을 확인했다
- 다른 쪽(두지 않는다): e2e 파일 하나가 소유 표에서 빠지고 A5 가 없어진다. 대신 세 동작은 PC `verify:full` 로도 확인되지 않는다(보는 테스트가 없다)

## 부록 A. D1 버그 수정이 바꿀 자리 (판정·실행은 main — 이 명세는 하지 않는다)

F-2059 7장 판정 D1(2026-09-28, 사용자): `saveCurrentAsNewDoc` 의 **지도·공유 보기 칸만** 버그다. `새 문서로 저장` 알림은 만든 문서에 묶여 `currentDocId` 가 바뀌면 걷히는데(리뷰 A5), 지도(`mapRoute`)와 공유 보기(`sharedDoc`)는 `currentDocId` 를 유지해 알림이 남는다 — 지도 위에서 누르면 지도가 남고 주소만 `#/d/{새 id}`, 공유 보기 위에서 누르면 공유 보기가 남는다(F-2076 7장 표 넷째 행). 도움말·공유 관리 칸과 `beforeLeaveDoc` 칸은 무해 판정이라 고치지 않는다.

- **바꾸는 파일:** `src/app/useDocNavigation.ts` 하나. App 은 바뀌지 않는다 — 필요한 `setSharedDoc`·`setMapRoute` 는 이미 훅 인자다(2.3). 새 인자·반환 없음
- **바꾸는 자리:** `saveCurrentAsNewDoc` 본문 끝부분(스크래치 새 파일 ≈123행), `setDeletedElsewhereId(null)` 줄과 `setCurrentDocId(doc.id)` 줄 사이
- **어떻게:** 그 사이에 `setSharedDoc(null)`·`setMapRoute(null)` 두 줄을 더한다. 순서는 `createNewDoc` 과 같이 "화면 플래그 끄기 → `setCurrentDocId` → `setPref` → 주소" 가 된다. 이 두 줄은 `store.create` 성공 뒤라 실패하면 화면·주소가 그대로 남는다(3fc2713 과 같은 원칙). 앞 주석 한 줄(`` // `새 문서로 저장` — … ``)에 지도·공유 보기를 떠난다는 말을 더할지는 main 이 정한다
- **안 바꾸는 것:** `setSharesOpen(false)`·`setHelpOpen(false)`·`beforeLeaveDoc()` 는 더하지 않는다(판정이 무해). 더하면 D1 표를 `createNewDoc` 과 같게 맞추는 "다른 판정"(F-2076 Q1 다른 쪽)이 된다
- **회귀 테스트 후보:** `appSplit` `F-2070 C1` 처럼 4401 로 N4 알림을 띄운 뒤 지도를 열고(`openMap` — `currentDocId` 유지) `새 문서로 저장` 을 누르면 ① `.map-page` 류 지도 화면이 사라지고 ② 해시가 `#/d/{새 id}` 다. 고치기 전 코드에서 ① 이 실패해야 회귀 테스트로 쓸 수 있다(`CLAUDE.md` How we work). 실행해 보지 않았다 — 지도 위에서 N4 알림 띠가 보이는지(`NoticeBar` 는 `.main-column` 머리라 보일 것으로 읽었다)부터 버그 커밋이 확인한다
