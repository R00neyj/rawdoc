## 2. 요구사항

### 2.1 React
- 컴포넌트 props 는 `type {이름}Props` 로 파일 안에 둔다. `React.FC` 는 쓰지 않는다
- `useRef<EditorHandle | null>(null)` 처럼 ref 타입을 명시한다. `Editor.tsx`(F-202)가 내보내는 핸들 타입을 import 해 쓴다 — F-202 가 아직 커밋 전이면 `app/` 쪽에 임시 타입을 두지 말고 2.3 단계에서 연결한다
- 이벤트 핸들러는 React 이벤트 타입(`React.DragEvent<HTMLDivElement>` 등)

### 2.2 그 밖
- F-201 2.4·2.5 규칙
- `prefs.ts` 는 키별 값 타입을 유니온으로 (`specs/architecture.md` 4장 표 그대로)
- `hashRoute.ts` 반환 타입은 판별 유니온 `{ type: 'doc' } | { type: 'share' } | { type: 'none' }`

### 2.3 마무리 (F-202 커밋 뒤)
- `tsconfig.json` 에서 `allowJs` 제거
- `src/` 전체에 `.js`·`.jsx` 가 남지 않았는지 확인
- `npm run verify:full` 1회 — 이전 전체가 동작을 바꾸지 않았는지 전체 e2e 로 확인 (CLAUDE.md "마일스톤 직전" 에 해당)
