# F-233 상단바 서식 탭바

작성일: 2026-09-16
상태: 사용자 승인(2026-09-15 "이대로 승인"). F-167·168·169 커밋 뒤 착수 (2026-09-15 사용자 "우클릭 명세 확장으로 탭바에도 동일한 기능 들어갔으면함", "제목 있던 부분이 이제 비었으니까, 이부분에 기능 탭들 바로가기 아이콘으로 추가했으면 함", "들어가야 하는 내용은 우클릭 명세와 사실상 동일함", "설정에서 토글가능하도록"). 2026-09-16 사용자 "모바일일때 header밑에 툴바 노출 해야함, 두줄로 표시될수 있도록. 사실 모바일일때가 툴바 더 필요할거임" — 3.6 숨김을 뒤집어 좁은 창도 상단바 밑 자기 줄에 노출(접혀서 2줄까지)로 승인·반영. 같은 날 재개정: 탭 줄·아이콘 줄을 세로로 접는 방식이 탭 3개만 쓴 첫 줄 나머지를 낭비하고 탭 박스가 아이콘 줄과 따로 노는 문제가 있어, 사용자 "가로스크롤 생겨도 되니까 일렬로 모바일도 표시될수 있도록 하고 싶음" 으로 2줄 접힘을 버리고 좁은 창도 넓은 창과 같은 한 줄 + 가로 스크롤로 되돌림(3.6). 같은 날 추가 재개정: 사용자 "모바일 탭은 좌측 고정, 아이콘으로 공간 최소화" — 좁은 창 탭 3개를 글자 대신 아이콘으로 바꾸고 가로 스크롤 중에도 왼쪽에 고정(3.6)
근거: F-217 2.5(제목이 본문으로 옮겨가며 빈 `topbar-spacer`), F-167·F-168·F-169(서식·단락·삽입 명령 — **이 세 명세가 먼저 커밋돼야 착수 가능**, 아직 초안), F-149(툴팁 전환), F-172(팝업 전환), F-228(팝 곡선)
전제: F-167·F-168·F-169 커밋 뒤 시작. 우클릭 메뉴 자체(F-170·F-174)와는 무관하게 먼저 만들 수 있다(같은 명령 함수를 재사용할 뿐, 우클릭 메뉴 UI 유무와 무관)

## 1. 범위

### 한다
- 상단바 가운데 빈 자리(`topbar-spacer`, F-217 이후 제목이 빠진 자리)에 **탭 3개**(서식·단락·삽입) + 그 안 아이콘 버튼들로 F-167·168·169 의 모든 명령을 바로 실행
- 설정 대화상자에서 켜고 끌 수 있다(기본값 켜짐)
- 편집·원문 모드에서만 보인다. 보기 모드·문서 미선택(홈)·읽기 전용 문서에서는 숨김
- 좁은 창(narrow)은 `topbar-spacer` 에 넣지 않고 상단바 밑 자기 줄로 뺀다 — 그 줄 안은 넓은 창과 같은 한 줄 배치(탭+아이콘)이고, 안 들어가면 가로 스크롤(3.6, 2026-09-16 사용자 재개정)

### 하지 않는다
- 우클릭 메뉴(F-170) 자체 — 이 명세는 탭바만. 우클릭 메뉴는 나중에 F-170·F-174 로 별도 진행
- 표 칸 하위 에디터 안에서의 동작 — F-167 4장과 같이 구문 트리가 없으면 명령이 스스로 `false` 를 돌려줄 뿐, 탭바가 칸 안인지 따로 판정하지 않는다
- 명령 자체의 새 동작 — F-167·168·169 에 없는 기능을 탭바가 새로 만들지 않는다

## 3. 요구사항

### 3.1 자리·표시 조건
- 넓은 창은 `topbar-spacer` 자리를 대신한다(공간이 없으면 지금처럼 빈 채로). 좁은 창은 3.6 대로 상단바 밑 자기 줄
- 보이는 조건: `md.toolbar==='on'` AND 문서가 열려 있음(홈 아님, F-232) AND 읽기 전용 아님(F-212·F-213) AND `viewMode` 가 `live`·`raw`(보기 모드 아님) — 좁은 창은 더 이상 숨김 조건이 아니다(3.6)
- 조건에 안 맞으면 넓은 창은 지금처럼 빈 `topbar-spacer` (레이아웃 흔들리지 않게 자리는 유지), 좁은 창은 상단바 밑 줄 자체가 없음

### 3.2 탭·아이콘 줄
- 탭 3개: `서식`·`단락`·`삽입`(글자만, `.seg` 와 같은 모양). 기본 선택 `서식`. 눌러 바꾼다(같은 세션 안에서만 기억, 저장 안 함)
- 선택된 탭의 명령들을 아이콘 버튼 줄로. 버튼은 `.icon-btn` 재사용, 아이콘만(툴팁에 명령 이름, F-142 3.2 패턴)
- 서식 탭: 링크 추가·외부 링크 추가·볼드체·기울이기·취소선·하이라이트·코드·수식·주석·서식 지우기 (F-167 3장 순서)
- 단락 탭: 글머리 목록·숫자 목록·체크박스·**제목**(3.3)·본문·인용 (F-168 3장)
- 삽입 탭: 각주·표·콜아웃·수평선·코드 블럭·수식 블럭 (F-169 3장)
- 버튼 누르면: `editorRef.current.view` 를 그 명령에 넘겨 실행 → `view.focus()` 로 포커스를 에디터에 돌려준다(커서가 보여야 계속 입력 가능, F-149 툴팁이 안 걸리적거리게)
- 선택이 없어 자동 판단이 필요한 명령(F-167 3장 "선택 없음" 열 등)은 명령 자체가 처리 — 탭바는 그대로 호출만

### 3.3 제목 드롭다운
- "제목 1~6" 을 아이콘 6개로 나열하지 않고, 버튼 하나(`제목 ▾`) → 누르면 작은 목록(`.item-menu-list` 와 같은 모양·전환) `제목 1`~`제목 6` 7개 항목(F-168 3장 `setHeading(n)`)
- 목록 열림·닫힘은 F-172 전환, 나타남은 F-228 `--transition-pop`
- 현재 커서 줄이 어떤 제목이어도 목록에 표시하지 않는다(F-168 명령 자체가 "이미 그 종류면 본문으로" 토글이라 별도 활성 표시 불필요 — 과도한 상태 추적 안 함)

### 3.4 아이콘
- 기존에 없는 아이콘은 `@material-symbols/svg-400` 에서 이름에 맞는 것을 새로 골라 `icons.tsx` 에 추가한다(쓰는 파일만 인라인, design.md 4장 규칙 그대로). 정확한 Material Symbols 이름은 구현 때 패키지에서 확인(예상: `format_bold`·`format_italic`·`strikethrough_s`·`format_underlined`→하이라이트는 별도 확인·`code`·`functions`·`comment`·`format_clear`·`link`·`format_list_bulleted`·`format_list_numbered`·`checklist`·`title`·`notes`·`format_quote`·`superscript`→각주는 별도 확인·`table`·`table_rows`→콜아웃은 별도 확인·`horizontal_rule`·`code_blocks`)
- 이미 있는 아이콘 재사용: 없음(전부 새 명령이라 겹치는 상단바 아이콘 없음)

### 3.5 설정 대화상자
- "글자 크기" 아래(또는 F-232 "시작 화면" 옆) 새 Segment "탭바": `표시`(기본)·`숨김` → `setPref('md.toolbar', value)`
- 공개 읽기전용 화면(F-230)에는 이 항목 없음(그 화면은 애초에 편집 명령이 없다) — `showEditorSettings` 와 같은 옵셔널 prop 패턴

### 3.6 좁은 창 (2026-09-16 재개정 — 숨김 → 2줄 접힘 → 한 줄 가로 스크롤 → 탭 아이콘화·좌측 고정)
- `narrow`(F-159, 사이드바 겹침 기준 1024px 미만)면 탭바를 `topbar-spacer` 대신 상단바(`header.topbar`) 바로 밑 자기 줄(`.editor-toolbar-row`)에 그린다. 상단바와 같은 바탕·테두리로 이어 보이게
- 그 줄 안의 `.editor-toolbar`는 넓은 창과 같은 한 줄 배치(탭 3개 + 선택된 탭의 아이콘 버튼들, `flex-direction` 을 따로 바꾸지 않는다). 다 안 들어가면 줄바꿈 대신 `.editor-toolbar` 기본 `overflow-x: auto` 로 가로 스크롤(2026-09-16 사용자 "가로스크롤 생겨도 되니까 일렬로 모바일도 표시될수 있도록 하고 싶음" — 탭 줄만 쓴 첫 줄 나머지가 비고 탭 박스가 아이콘 줄과 따로 놀던 2줄 접힘 방식을 버림)
- 탭 3개(서식·단락·삽입)는 글자 대신 아이콘 하나씩(각 아이콘은 그 탭 안 개별 명령 아이콘과 겹치지 않는 것으로 고름), `aria-label` 로 이름 유지, 호버·포커스 시 기존 아이콘 버튼과 같은 툴팁으로 이름 표시. 가로 스크롤 중에도 항상 보이게 `position: sticky; left: 0` 로 왼쪽 고정, 뒤로 스크롤되는 아이콘 줄이 비치지 않게 배경 불투명(2026-09-16 사용자 "모바일 탭은 좌측 고정, 아이콘으로 공간 최소화")
- 제목 드롭다운(3.3)·아이콘 툴팁은 넓은 창과 같은 `position: fixed` 방식이라 이 줄의 레이아웃과 무관하게 항상 뜬다
- 숨기는 조건(문서 미선택·읽기 전용·보기 모드·설정 끔)은 3.1 과 같다 — 좁은 창 자체는 더 이상 숨기는 이유가 아니다

### 3.7 움직임 줄이기 · 접근성
- 탭 전환·드롭다운 열림은 `role="tablist"`/`role="tab"`(탭)·`role="menu"`(제목 목록) 패턴, 기존 `.seg`(`role="radiogroup"`)·`.item-menu-list`(F-126) 와 같은 키보드 규칙 재사용
- `prefers-reduced-motion` 이면 제목 드롭다운 전환 0(F-228 2.4 그대로, 새 토큰 없음)
