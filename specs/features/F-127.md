작성일: 2026-09-14

| 파일 | 변경 |

- `@codemirror/autocomplete` 의 `closeBrackets()` 는 쓰지 않는다. `*` 를 다시 쳐서 `**|**` 로 만드는 규칙과 줄머리 목록 기호 규칙을 넣을 수 없어서다. 새 의존성 없음

## 2. 대상 기호

| 입력 | 짝 | 종류 |
| --- | --- | --- |
| `(` | `)` | 괄호 |
| `[` | `]` | 괄호 |
| `*` | `*` | 강조 기호 |
| `~` | `~` | 강조 기호 |
| `` ` `` | `` ` `` | 강조 기호 |

- `{`, `"`, `'`, `_` 는 넣지 않는다. 따옴표·`_` 는 영문 축약형(`don't`)과 `snake_case` 에서 방해가 된다
- 편집·원문 모드 모두 동작한다

## 3. 규칙

`|` 는 커서 위치. "다음 글자" 는 커서 바로 뒤 한 글자, "앞 글자" 는 바로 앞 한 글자. 줄 끝·줄 시작은 "공백" 으로 본다

### 3.1 선택 범위가 있을 때 (감싸기)
- 대상 기호를 치면 선택 글자를 앞뒤로 감싼다. 선택은 감싼 안쪽 글자에 그대로 둔다
  - `굵게` 선택 + `*` → `*굵게*`, 한 번 더 `*` → `**굵게**`
  - `링크` 선택 + `[` → `[링크]`
- 선택이 여러 줄에 걸치면 감싸지 않고 기본 입력(선택을 기호로 바꿈)

### 3.2 괄호 `(` `[`
| 상황 | 결과 |
| --- | --- |
| 다음 글자가 공백·줄 끝·`)` `]` `}` `,` `.` `;` `:` 중 하나 | `(|)` |
| 그 밖 (예: 다음 글자가 글자·숫자·한글) | `(|` 만 (짝 없음) |

- **닫는 기호 건너뛰기**: `)` `]` 를 칠 때 다음 글자가 같은 기호이고 그 기호가 이 확장이 넣은 것이면 글자를 넣지 않고 커서만 한 칸 뒤로. 이 확장이 넣은 닫는 기호 위치는 `StateField` 로 추적하고 문서 변경에 맞춰 옮긴다. 커서가 그 줄을 떠나면 추적을 지운다
- **빈 짝 지우기**: `(|)` `[|]` 에서 Backspace → 두 글자 모두 지움 (추적 여부와 무관)

### 3.3 강조 기호 `*` `~` `` ` ``
짝을 넣는 조건: 다음 글자가 공백·줄 끝·같은 기호·`)` `]` `,` `.` `;` `:` 중 하나이고, 앞 글자가 공백·줄 시작·같은 기호·`(` `[` 중 하나

| 상황 (기호 `*` 예) | 결과 |
| --- | --- |
| 조건 충족, 빈 곳 | `*|*` |
| 빈 짝 `*|*` 에서 `*` | `**|**` |
| `**|**` 에서 `*` | `***|***` (3개까지. 4번째는 기본 입력) |
| 내용 뒤 `**굵게|**` 에서 `*` | 글자를 넣지 않고 커서만 한 칸 뒤 (`**굵게*|*`) — 다음 글자가 같은 기호이고 앞 글자가 공백이 아닌 글자이면서 같은 기호가 아닐 때. 줄 시작·공백 뒤에서는 건너뛰지 않음 (F-134 3.5). 추적 여부와 무관 |
| 조건 불충족 (예: `2*3`, `단어*`) | `*` 만 |
| 빈 짝 `*|*` 에서 공백 | 닫는 `*` 를 지우고 공백 → `* |`. 줄머리 목록 기호(`* 항목`)와 `2 * 3` 을 치는 흐름을 막지 않기 위해서다 |
| 빈 짝 `*|*` / `**|**` 에서 Backspace | 안쪽 한 쌍 지움 (`**|**` → `*|*` → `|`). 빈 짝이 아니면(`**굵게*|*`, `a**|b`) 기본 동작 (F-134 3.5) |

`` ` `` 추가 규칙
- 줄에서 커서 앞이 들여쓰기 뒤 ` `` ` ` 두 개뿐이고 뒤가 ` `` ` ` 두 개뿐인 상태(`` ``|`` ``)에서 `` ` `` → 닫는 백틱을 지우고 ```` ```| ```` (펜스 코드블록 시작)
- 펜스 코드블록(`FencedCode`)·인라인코드(`InlineCode`) 안에서는 강조 기호 3종 모두 짝을 넣지 않는다 (괄호는 넣는다). 판정은 `syntaxTree` 로 한다

### 3.4 공통
- 선택 범위(커서)가 여러 개면 적용하지 않고 기본 입력
- 짝 넣기·감싸기·건너뛰기는 입력한 글자와 **한 번의 트랜잭션**이다. Ctrl+Z 한 번에 짝까지 함께 되돌아간다 (`userEvent: 'input.type'`)
- 읽기 전용 상태(F-123 보기 모드 등)에서는 동작하지 않는다
- 붙여넣기에는 적용하지 않는다

### 3.5 한글 IME
- 조합 중(`view.composing` 또는 `view.compositionStarted`)에는 가로채지 않는다
- 한글을 조합하던 직후 `(` 를 치면 조합 종료와 기호 입력이 이어서 온다. 이때 짝이 안 붙는 것은 허용한다. **글자 중복·누락·커서 튐은 허용하지 않는다**
- 조합 판정은 `src/editor/composition.js` 에 있는 것을 쓴다

## 4. 구조
- `autoPair.js`
  - `autoPairInput(state, from, to, text) → TransactionSpec | null` — 규칙 계산 (DOM 없음). `null` 이면 기본 입력
  - `autoPairBackspace(state) → TransactionSpec | null`
  - `autoPair() → Extension` — `EditorView.inputHandler`, Backspace 키맵(`Prec.high`), 추적 `StateField`
- Backspace 키맵은 `@codemirror/lang-markdown` 의 `deleteMarkupBackward` 보다 먼저 받는다. 빈 짝이 아니면 `false` 를 돌려 다음 처리로 넘긴다
