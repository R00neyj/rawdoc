## 3. 요구사항

### 3.1 `wrangler.jsonc`
```jsonc
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "md-editor-web",
  "compatibility_date": "2026-09-14",
  "assets": { "directory": "./dist" }
}
```
- Worker 스크립트(`main`) 없음 — 정적 자산만
- `name` 에 제품명을 쓰지 않는다 (제품명 미정)
- `compatibility_date` 는 설정 생성일로 고정, 이후 바꾸지 않는다

### 3.2 `public/_headers`
Workers 정적 자산은 자산 디렉터리 안의 `_headers` 를 읽는다. 규칙 최대 100개, Worker 코드가 만든 응답에는 적용되지 않는다 (https://developers.cloudflare.com/workers/static-assets/headers/)

```
/
  Cache-Control: no-cache
/index.html
  Cache-Control: no-cache
/sw.js
  Cache-Control: no-cache
/manifest.webmanifest
  Cache-Control: no-cache
/assets/*
  Cache-Control: public, max-age=31536000, immutable
```
- 서비스 워커·HTML·매니페스트는 매번 재검증해 새 버전을 알아챌 수 있게 한다 (F-117). `/assets/*` 는 파일명에 해시가 있어 오래 캐시한다
- `.assetsignore` 는 만들지 않는다. 자산 디렉터리가 `dist/` 라 `node_modules`·`.git` 이 들어가지 않는다

### 3.3 스크립트
`"deploy": "npm run build && wrangler deploy"`
