## 2. 요구사항

### 2.1 구조
- 계산 함수와 확장을 나눈다: `buildInline(state, ranges) → Range<Decoration>[]` 는 DOM 없이 동작하고, `ViewPlugin` 은 이것을 `view.visibleRanges` 로 호출만 한다. 테스트는 `EditorState` + `ensureSyntaxTree` 로 계산 함수를 직접 부른다
- 스타일(굵게·기울임 등)은 F-107 `highlight.js` 가 이미 준다. 이 확장은 **기호를 숨기기만** 한다
- decoration 은 문서를 바꾸지 않는다

### 2.2 숨기는 기호 (커서·선택이 걸친 줄이 아닐 때만)

| 노드 | 숨김 | 조건 |
| --- | --- | --- |
| `EmphasisMark` | 전부 | |
| `StrikethroughMark` | 전부 | GFM |
| `CodeMark` | 전부 | 부모가 `InlineCode` 일 때만. 펜스 코드블록 울타리는 숨기지 않는다 (spike `inline.js` 18~27행) |
| `LinkMark`, `URL`, `LinkTitle` | 전부 | 부모가 `Link` 일 때만. 맨 URL(autolink)·`<https://…>`·`Image` 안의 것은 숨기지 않는다 — spike 는 `URL` 을 부모 확인 없이 숨겨 맨 URL 글자가 통째로 사라진다 |

- `Image`(`![]()`)는 원문 그대로 둔다 (product.md 4.5)
- `Table`, `FencedCode` 안으로 들어가지 않는다
- 활성 줄 판정 단위는 **줄**: 선택 범위가 걸친 모든 줄 (spike `activeLines`)

### 2.3 IME
- `ViewPlugin.update`: `isForced(update)` 면 무조건 재계산. 아니면 `docChanged`·`selectionSet`·`viewportChanged` 가 없으면 건너뛰고, `isComposing(view)` 면 건너뛴다 (`src/editor/composition.js`)
- 조합 종료 시 `forceRecalc` 로 반드시 따라잡는다 (CLAUDE.md 불변조건)
