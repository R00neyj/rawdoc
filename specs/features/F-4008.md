# F-4008 원격 MCP 서버 (ChatGPT·claude.ai 커넥터)

작성일: 2026-10-16
상태: 개요, 승인 전. 사용자 결정(2026-10-16)과 확정된 UX 흐름 `specs/wireframes/remote-mcp-flow.html` 위에 쓴다. 인가 서버·토큰·접근 권한이 중심이라 보안(`F-4NNN`). 새 의존은 사람 결정 필요(11장). `product.md` Q44·범위 밖 목록과 어긋난다(10장)

## 정해진 것 (사용자, 바꾸지 않는다)
1 ChatGPT·claude.ai 웹 커넥터, 공식 디렉터리 등재까지(제출은 구현 뒤 사람) · 2 읽기·쓰기, 쓰기는 `/v1` 과 같은 DocRoom 경로·`baseVersion` 409 · 3 금고 문서 제외 · 4 better-auth 위 OAuth 2.1(DCR·PKCE) · 5 권한은 계정 전체 · 6 쓰기 제한은 CLI 와 같고 도달 시 `/limits` 링크 · 7 설정 새 탭 `연결된 앱`(끊기 = 그 앱 토큰 전부 폐기) · 8 지우기는 휴지통으로만(F-3021, 지운 주체 = 앱 이름) · 9 동의 화면은 worker 렌더 로그인 페이지 모양

## 근거 (2026-10-16 HEAD·npm, 이름으로 찾는다)
- `node_modules/better-auth` 1.7.5 `dist/plugins` 에 `oidc-provider`·`mcp` 가 없다 — 1.7.0 에서 `@better-auth/oauth-provider`·`@better-auth/mcp` 로 빠졌다([변경 기록](https://github.com/better-auth/better-auth/blob/c3688ba88edff12dfcb1ced007e332711509ac29/packages/mcp/CHANGELOG.md)). 둘 다 1.7.10, peer `better-auth ^1.7.10`·`better-call 1.4.2`(지금 1.4.0). `zod` 4.5.4·`jose` 6.2.12 는 이미 전이 의존
- `worker/auth.ts` `getUser` 는 `/v1/` 이면 `getTokenUser`(`rd_` 해시)만 보고, `rememberUser` 로 심은 사용자는 다시 인증하지 않는다(`worker/v1.ts` `innerRequest` 의 길). `authOptions` 는 `rateLimit` 을 꺼 둬 플러그인의 엔드포인트별 제한이 돌지 않는다. `worker/index.ts` `AUTH_ROUTES` 는 콜백 둘·로그아웃만 열고, `/api/` 비 GET 은 `isAllowedOrigin` 이 Origin 없음을 403 으로 막는다(`worker/origin.ts`). `isWriteRoute` 는 `/api/`·`/v1/` 패턴만 참 → `/mcp` 는 라우트 관문 밖. `handleUpdateDocV1` 409 몸통은 `{ error: 'conflict', doc }`(최신 본문·version)
- 측정(스크래치): `@modelcontextprotocol/server` 2.3.1 `createMcpHandler(factory, { legacy: 'stateless' })` 를 esbuild 로 묶어 node 에서 부르니 2025-06-18 `initialize`·`tools/list`·`tools/call` 이 세션 없이 따로 200, `GET` 405. 번들 653KB(min)·148KB(gzip, zod 포함)

## 1. 인증 — 인가 서버
| 안 | 1.7.5 그대로 | 끊기 즉시성 | 저장소·새 의존 |
| --- | --- | --- | --- |
| **A `@better-auth/oauth-provider`**(추천) | 아니오 — 1.7.10 으로 올림 | `disableJwtPlugin: true` 면 불투명 토큰이 D1 에 해시, 지우면 다음 호출 401 | D1, 플러그인 1 |
| B `@cloudflare/workers-oauth-provider` 1.2.3 | 상관없음 | KV 는 다른 위치에 60초까지 늦게 보인다([KV](https://developers.cloudflare.com/kv/concepts/how-kv-works/)) | 새 KV `OAUTH_KV`, 로그인 따로 |
| C 직접 | 예 | 즉시 | D1, 없음 — 대신 RFC 8414·9728·7591·7636·8707·9207·7009 를 우리가 짜고 감사 |
- **A.** 결정 4 와 맞고 OpenAI 가 직접 구현을 말린다([Auth](https://developers.openai.com/apps-sdk/build/auth)). **`@better-auth/mcp` 는 쓰지 않는다** — `jwt()` 필수이고 JWT 접근 토큰은 서버에서 폐기할 수 없어([Revoke](https://www.better-auth.com/docs/plugins/oauth-provider)) 결정 7 을 못 지킨다. 그 패키지가 더하는 메타데이터·401 도전은 우리가 쓴다
- 설정: issuer `{BETTER_AUTH_URL}/api/auth`, DCR 두 플래그 켬, PKCE S256 만, scope `docs`·`offline_access`(openid 없음), resource `{origin}/mcp` 하나, 접근 1시간·갱신 30일·쓸 때마다 회전·재사용 창 30초(클라이언트 재시도), 토큰 해시 저장, 응답에 RFC 9207 `iss`(ChatGPT 고정 redirect 조건). CIMD 는 하지 않는다 — 두 클라이언트 모두 DCR 을 받는다
- 여는 경로만 `AUTH_ROUTES` 에: `oauth2/authorize`·`token`·`register`·`consent`·`revoke`, `/.well-known/oauth-authorization-server/api/auth`. 토큰·등록·폐기만 Origin 검사에서 뺀다(서버 간 호출). `run_worker_first` 에 `/mcp`·`/.well-known/*`·`/oauth/*`·`/limits`
- 표: 플러그인 표를 다음 빈 번호 마이그레이션으로, 열은 `authServer.ts` 처럼 snake_case 매핑, `user_id` 는 `ON DELETE CASCADE`(계정 삭제가 같이 지움). 우리 표 `oauth_client_use(user_id, client_id, last_used_at)` 하나 더. DCR 남용: 하루 등록 상한 500(`signup_gate` 같은 한 문장 조건부 UPDATE, 넘으면 429), 매일 Cron 이 동의 없이 24시간 지난 클라이언트를 지운다
- **API 토큰과 별개.** `rd_` 는 `/v1` 에만, OAuth 접근 토큰은 `/mcp` 에만 통한다. D-5 그대로. 로그인 이어가기: 플러그인이 보내는 `/login?{서명된 질의}` 를 소셜 로그인 내내 지니고 같은 출처 `/api/auth/oauth2/authorize` 로만 돌아간다. 동의 `/oauth/consent`·오류 `/oauth/error` 는 `worker/loginPage.ts` 모양. 검증 안 된 `redirect_uri` 로는 보내지 않는다

## 2. MCP 전송
- **`@modelcontextprotocol/server` 2.3.1**(추천): fetch 모양 하나로 2025 세대(무상태)와 2026-07-28 세대를 같이 받고 Workers 용 스키마 검사기(`cfWorkerProvider`)가 있다. **DO 없음** — 도구에 상태가 없다. 버린 안: `@modelcontextprotocol/sdk` 1.32.1(2025 세대만, express·hono·ajv), Cloudflare `agents` 0.28.1(세션마다 DO, peer `ai`·`react`·`vite`), 직접 JSON-RPC(두 세대 봉투·`server/discover` 를 우리가 따라감)
- `POST /mcp` 만, `GET`·`DELETE` 405, 요청마다 서버 인스턴스 새로. 순서: Origin 이 있고 `SITE_URL` 출처가 아니면 403(DNS 재바인딩) → 토큰 실패 401 + `WWW-Authenticate: Bearer resource_metadata="{origin}/.well-known/oauth-protected-resource/mcp", scope="docs"` → SDK. 보호 자원 메타데이터는 `/.well-known/oauth-protected-resource` 와 `…/mcp` 둘 다
- 도구 → 기존 핸들러: `/v1/…` 주소의 안쪽 `Request` 를 만들고 `rememberUser` 로 사용자를 심어 그대로 부른다. 금고 403·권한·409·크기·하루 쓰기 수가 `/v1` 과 한 곳. 응답은 `structuredContent` + 같은 JSON 텍스트, 오류는 JSON-RPC 오류가 아닌 `isError: true` 결과. 모델이 읽는 글은 영어(Q2)

| `create_document` `{title,content,folderId?}` · `create_folder` `{name,parentId?}` · `move_document` `{id,folderId\|null}` | F/F/F | `handleCreateDocV1` · `handleCreateFolderV1` · `handleMoveDocFolderV1` | |

## 4. 제한·연결 관리·문구
- 쓰기 도구만 핸들러 앞에서 `runWriteGate` 를 부른다(`trashDoc` 은 관문을 안에 두지 않는다 — F-3021). 429 → `isError` 글에 `scope`·`limit`·`retryAfter` 와 `{origin}/limits?scope={scope}&retry={초}`, 403 `account_blocked` 그대로
- `GET /limits` worker 렌더 공개 페이지(`X-Robots-Tag: noindex`): `1분에 {MINUTE_WRITE_LIMIT}번, 하루 {DAILY_WRITE_LIMIT}번까지 쓸 수 있습니다 (CLI·MCP·앱 공통)`, 하루는 UTC 자정 기준. 세션이 있으면 `지금 상태: 하루 {used}/{N}` 과 하루 한도의 다시 가능 시각, 질의 `retry` 는 `약 {retry}초 뒤 다시 가능` 으로 보이기만 한다
- `GET /api/connected-apps` → `[{ id, name, host, createdAt, lastUsedAt }]`(id = client id, 동의 있는 것만). `DELETE /api/connected-apps/:id` → 그 사용자·클라이언트의 동의·접근·갱신 토큰을 한 배치로 지우고 204, 관문에서 뺀다(막힌 계정도 끊게, GitHub 해제 선례). 마지막 사용은 `/mcp` 인증 때 10분에 한 번(`apiTokens.ts` 선례). 설정 탭 `연결된 앱`(`계정` 뒤, 로그인 상태만): 행 `{name}` / `{YYYY-MM-DD} 연결 · 마지막 사용 {상대 시간}` / `연결 끊기`(확인 없음). 빈 `연결된 앱이 없습니다`, 오프라인은 버튼 비활성 + `온라인일 때 연결을 끊을 수 있습니다`
- 동의: `{앱 이름} 앱이 {제품명} 계정에 접근하려고 합니다` / `{email} 계정` / `할 수 있는 일` / `· 문서·폴더 목록과 본문 읽기 (공유받은 문서 포함)` / `· 문서·폴더 만들기·고치기·옮기기` / `· 문서·폴더를 휴지통으로 보내기` / `돌아갈 곳: {redirect 호스트}` / `금고 문서는 열 수 없습니다. 연결은 설정 › 연결된 앱에서 끊을 수 있습니다.` / `허용` `거부`. 앱 이름 = DCR `client_name` 64자, 없으면 호스트

## 5. 디렉터리 준비물 ([Claude 제출](https://claude.com/docs/connectors/building/submission)·[Claude 인증](https://claude.com/docs/connectors/building/authentication)·[OpenAI 지침](https://developers.openai.com/apps-sdk/app-submission-guidelines))
- 도구 주석: Claude 는 `title` + readOnly/destructive, OpenAI 는 셋 다 명시 boolean·설명이 동작과 일치 → 3장 표. 인증: Claude 콜백 `https://claude.ai/api/mcp/auth_callback`·Claude Code 루프백 아무 포트, 토큰은 form-urlencoded·회전·`invalid_grant`·10초 안 응답. ChatGPT 는 S256 광고·`resource` 되돌림·`iss` → 1장(플러그인)

OpenAI 신원 확인과 `/.well-known/openai-apps-challenge` 평문 토큰(비밀 `OPENAI_APPS_CHALLENGE`, F-4011), Claude 는 유료 플랜 계정으로 제출
