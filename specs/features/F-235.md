## 2. 요구사항

### 2.1 진입점과 대화상자
- 사이드바 맨 아래, `설정` 버튼 바로 위에 `도움말` 항목(레일 모드는 아이콘만 + 툴팁, F-142 방식)
- 클릭하면 `HelpDialog` 열림. `Dialog` 컴포넌트 그대로 재사용(`size="wide"`, 열 때 첫 포커스는 대화상자 자체, F-121 과 같은 패턴), Esc·바깥 클릭·닫기 버튼으로 닫힘
- 공개 보기 화면(`PublicView`/`SharedView`)에는 사이드바가 없으니 진입점도 없다 — 이 명세 범위 밖

### 2.2 카드 목록
- `helpSyntax.ts` 에 그룹 배열: `{ group: string; items: { name: string; source: string }[] }[]`. 그룹·항목·순서는 0장 표 그대로
- 카드 = 문법 이름(`name`) + 원문 코드(`<pre><code>`, 고정폭 서체, 자동 줄바꿈 없이 가로 스크롤 — 기존 코드블록 표시와 통일) + 그 아래 `Viewer` 로 렌더링한 결과
- `Viewer` 는 `html={renderMarkdown(source)}` 만 넘긴다. `title`·`resolveAttachment`·`onOpenWikiLink`·`codeCopy` 는 생략
  - 이미지 카드: `resolveAttachment` 없으니 자동으로 자리 표시(깨진 이미지 아이콘 + "이미지를 찾을 수 없습니다")가 뜬다 — 이게 곧 예시 결과다. 원문은 실제 저장 형식(`attachments/{id}.png`) 그대로 보여주되 실존하는 첨부가 아님을 카드 이름 옆 괄호 문구로 짧게 알린다(`이미지 (예시)`)
  - 위키링크 카드: `resolveWikiLink` 생략 — "찾을 수 없음" 모양(대시 밑줄 등 기존 스타일)이 기본으로 뜬다. 실제로는 있는 문서를 클릭하면 열린다는 설명은 카드 캡션 한 줄로 보완
- 원문 예시 (그룹 순서대로, 정확한 문자열은 구현 때 `helpSyntax.ts` 에 고정):
  - 제목: `# 제목 1` / `## 제목 2` / `### 제목 3` (한 카드에 세 줄)
  - 굵게 `**굵게**`, 기울임 `*기울임*`, 취소선 `~~취소선~~`, 인라인코드 `` `코드` `` — 각각 카드 하나씩
  - 목록: 글머리 `- 항목`, 번호 `1. 항목`, 체크박스 `- [ ] 할 일` + `- [x] 끝낸 일` (한 카드, 두 줄)
  - 인용 `> 인용문`
  - 링크 `[링크](https://example.com)`
  - 위키링크 `[[문서 제목]]`
  - 표 3줄(머리·구분·본문 1행)
  - 코드블록 ` ```js\ncode\n``` ` 형태(펜스 3개, 언어 `js`, 내용 한 줄)
  - 이미지 `<div align="center"><img src="attachments/0000000000000000.png" width="320"></div>` (F-156 형식 그대로, id 는 실존하지 않는 16자리 0)
  - 콜아웃 `> [!note] 제목\n> 내용`
  - 구분선 `---`
  - 프론트매터 `---\ntitle: 문서 제목\n---`

### 2.3 반응형
- F-224 대화상자 폭 규칙 그대로(`wide` = `min(520px, calc(100vw - 32px))`). 카드 안 표·코드블록은 기존 가로 스크롤 규칙(F-124)을 그대로 물려받는다
- 좁은 창에서도 카드는 세로로 쌓이고 대화상자 자체가 세로 스크롤
