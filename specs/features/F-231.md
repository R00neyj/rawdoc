# F-231 OS 파일 열기 재중복 방지

작성일: 2026-09-15
상태: 사용자 승인(2026-09-15 "이대로 구현"). 착수 (2026-09-15 사용자 "로컬문서 열면 중복되서 올라감" → 재현: 같은 .md 파일을 OS 연결 프로그램으로 다시 열 때마다 새 복사본이 쌓임)
근거: `specs/features/F-119.md`(OS 파일 열기 연동), `specs/features/F-114.md` 2.2(가져오기는 매번 새 문서)

## 1. 범위

### 문제
F-119 는 OS 에서 `.md` 파일을 열 때마다 F-114 `importFiles` 로 **새 문서를 만든다**. 같은 파일을 다시 열어도 이미 가져온 문서인지 모르고 또 만들어 목록에 같은 제목 문서가 쌓인다

### 한다
- OS 파일 열기(F-119, `launchQueue`)로 받은 파일이 **이전에 이 경로로 가져온 파일과 같은 파일**(`FileSystemFileHandle.isSameEntry()`)이면, 새로 만들지 않고 **그 문서를 연다**(내용은 덮어쓰지 않는다 — 그 사이 앱 안에서 고친 내용이 있으면 지켜야 한다)
- 처음 보는 파일이면 지금처럼 가져오기 → 만들어진 문서에 그 파일의 handle 을 연결해 다음에 다시 열 때 알아본다
- `idb` 저장소 전용. `memory`·`server` 저장소는 이 판정을 하지 않고 지금처럼 매번 새로 가져온다(F-119 자체가 데스크톱 브라우저 로컬 전용 실험적 기능)

### 하지 않는다
- 파일이 바뀌었으면 내용을 새로 받아오기(재동기화) — 이번에는 "중복 안 만들기"만. 최신 내용이 필요하면 F-114 `가져오기` 로 새로 만드는 지금 동작을 그대로 쓴다
- 드래그앤드롭·`가져오기` 버튼(F-114) 경로의 중복 판정 — 이 경로의 `File` 에는 handle 이 없다(`DataTransferItem.getAsFileSystemHandle()` 을 쓰지 않는다, 범위 밖)
- 연결된 handle 로 원본 파일에 쓰기 — 불변조건대로 계속 읽기만 한다

## 3. 요구사항

### 3.1 `idbStore.ts`
```ts
findDocByFileHandle(handle: FileSystemFileHandle): Promise<string | null>
linkFileHandle(docId: string, handle: FileSystemFileHandle): Promise<void>
```
- `fileHandles` 스토어: `keyPath: 'docId'`, 값 `{ docId, handle }`. `FileSystemFileHandle` 은 구조화 복제로 그대로 저장된다
- `findDocByFileHandle`: 저장된 항목을 돌며 `await stored.handle.isSameEntry(handle)` 로 비교, 첫 매치의 `docId` 반환. 매치된 `docId` 가 `docs` 스토어에 없으면(문서가 지워졌으면) 그 항목을 지우고 계속 찾는다. `isSameEntry` 가 권한 등으로 예외를 던지면 그 항목은 건너뛴다. 끝까지 없으면 `null`
- `linkFileHandle`: upsert(있으면 덮어쓴다 — 문서가 지워졌다 같은 파일로 다시 만들어진 경우 대비)
- `removeDoc` 때 연결된 `fileHandles` 항목도 함께 지운다(고아 방지)

### 3.2 `fileLaunch.ts`
- `onFiles` 시그니처를 `(items: { file: File; handle: FileSystemFileHandle }[]) => void` 로 바꾼다 — `getFile()` 은 그대로 하되 handle 도 같이 넘긴다

### 3.3 `App.tsx` OS 파일 열기 경로
- `store.kind === 'idb'` 이고 `store.findDocByFileHandle`·`store.linkFileHandle` 이 있을 때만 아래 판정, 아니면 지금처럼 `runImportFiles(files)` 그대로
- 파일마다: `findDocByFileHandle(handle)` → 매치 있으면 **가져오지 않고** 그 문서를 연다(해시 교체, `beforeLeaveDoc` 은 문서 전환과 같은 경로로 처리) + 알림 `"{제목}" 을(를) 열었습니다. (이미 가져온 파일)`. 매치 없으면 지금 `runImportFiles` 그대로 실행 후 만들어진 문서 id 에 `linkFileHandle`
- 여러 파일을 한 번에 열었으면 파일마다 독립 판정. 마지막 파일 기준으로 연다(지금 `isLast` 규칙 그대로)

### 3.4 움직임 줄이기 · 접근성
- 해당 없음(파일 열기 흐름, 화면 전환 애니메이션 변경 없음)
