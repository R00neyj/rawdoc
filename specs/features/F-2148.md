## 2. 동작
### 2.1 탭
- 자리·조건: `계정` 다음 마지막 탭, `account` 가 있을 때만(로그인, 또는 오프라인 + 저장된 계정). 휴대폰 폭은 F-2114 목록에 같은 순서로 나온다
- 맨 위 안내 한 줄 `연결을 끊으면 그 앱은 곧바로 문서를 읽거나 고칠 수 없습니다.` 그 아래 상태 하나:

| 상태 | 보이는 것 |
| --- | --- |
| 불러오는 중 | `불러오는 중…` |
| 실패(401·5xx·네트워크·JSON 아님) | `연결된 앱을 불러오지 못했습니다.` + 버튼 `다시 시도` |
| 오프라인이고 아직 못 받음 | `온라인일 때 연결된 앱을 볼 수 있습니다` (요청 보내지 않음) |
| 빈 목록 | `연결된 앱이 없습니다` (`.connected-apps-empty`, `tabIndex=-1`) |
| 목록 | 2.2 행들 |

- 탭이 보일 때마다(마운트) 온라인이면 `GET` 한 번. 오프라인 → 온라인으로 바뀌었는데 아직 못 받았으면 그때 한 번. 받은 뒤 오프라인이 되면 목록은 남기고 버튼만 끈다
- 폴링·실시간 갱신 없음 — 다른 기기에서 끊은 앱은 탭을 다시 열 때 사라진다

### 2.2 행과 끊기
- `<ul className="connected-apps-list">` 의 `li.connected-app-row`(key = id, 서버 순서 그대로): 이름 `{name}` / 메타 `.connected-app-meta` `connectedAppMeta(app, now)` / 버튼 `연결 끊기`(`aria-label="{name} 연결 끊기"`)
- 오프라인이면 모든 `연결 끊기` 비활성 + 목록 아래 `온라인일 때 연결을 끊을 수 있습니다`
- 누르면 확인 없이(F-4008 4장) `DELETE`. 보내는 동안 그 버튼만 비활성·글자 `끊는 중…`. 결과:
  - `ok`(204)·`gone`(404) → 행을 빼고 초점은 `focusAfterRemove` 가 고른 행의 `연결 끊기`, 없으면 `.connected-apps-empty`. 초점이 `body` 로 떨어지면 대화상자 키보드 흐름이 끊기기 때문
  - `failed`(그 밖·네트워크·401) → 행 유지, 버튼 되살림, 목록 아래 `연결을 끊지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요.`(`role="alert"`, 다음 끊기 시작 때 지움)
- 이름은 DCR `client_name` 이라 텍스트로만 그린다(React 기본 이스케이프). 호스트는 보이지 않는다(개요 문구 그대로, 열린 질문 1)

### 2.3 순수 함수 (`connectedApps.ts`, DOM 없음)
```ts
export type ConnectedApp = { id: string; name: string; host: string; createdAt: number; lastUsedAt: number | null }
export function formatLastUsed(at: number, now: number): string
export function connectedAppMeta(app: ConnectedApp, now: number): string // '{YYYY-MM-DD} 연결 · 마지막 사용 {formatLastUsed}' | '{YYYY-MM-DD} 연결 · 아직 사용 안 함'
export function focusAfterRemove(ids: readonly string[], removedId: string): string | null // 다음 행, 없으면 앞 행, 둘 다 없으면 null
export function isConnectedAppList(value: unknown): value is ConnectedApp[]
```
- `formatLastUsed`(흐름 그림의 `3분 전`·`어제`): 60초 미만 `방금 전` / 60분 미만 `{N}분 전` / 24시간 미만 `{N}시간 전` / 지역 날짜로 하루 전 `어제` / 30일 미만 `{N}일 전`(지역 날짜 차) / 그 밖 `YYYY-MM-DD`. 미래 시각(기기 시계 차)은 `방금 전`. 날짜는 지역 시간 — `ApiTokensDialog` `formatDate` 와 같은 모양
- `connectedAppsApi`: `listConnectedApps(): Promise<ConnectedApp[]>` 는 200 이고 `isConnectedAppList` 일 때만 값, 아니면 `throw`. `disconnectConnectedApp(id): Promise<'ok' | 'gone' | 'failed'>`. 둘 다 `credentials: 'same-origin'`, fetch 예외는 실패로

### 2.4 사용자 흐름 (`specs/wireframes/remote-mcp-flow.html` 4절)
설정 › `연결된 앱` 들어감 → 목록(E1)·빈 상태(E2)·불러오기 실패·오프라인(E3) → `연결 끊기` → 행 사라짐·초점(E1·E2), 실패 문구(E2) → 그 앱 다음 호출 401(F-4011, H2)
