# F-129 편집 모드 링크 클릭

작성일: 2026-09-14
상태: 사용자 1차 수정사항 5번(2026-09-14). C2 묶음 (F-123·F-124·F-127 과 병렬). F-104 2.2 의 링크 활성 단위를 바꾼다
근거: 사용자 요청 "링크를 클릭하려고 해도 라이브 프리뷰 모드에서 클릭 불가능. 링크가 편집모드로 돌아가서 클릭할 수 없음. 옵시디언처럼 링크는 링크 안에 커서가 들어올 때만 편집모드여야 할듯"

## 1. 원인
- F-104 는 기호 숨김을 **줄 단위**로 판정한다. 링크 글자를 누르면 CM6 가 먼저 커서를 그 줄로 옮기고, 줄이 활성이 되어 `[` `](주소)` 가 드러나며 글자 위치가 밀린다. 누른 자리가 링크가 아니게 된다

## 2. 파일 소유
`src/editor/preview/` 의 아래 파일만 수정한다

| 파일 | 변경 |
| --- | --- |
| `src/editor/preview/links.js`(+test) | 신규. 링크 찾기, 열 수 있는 주소 판정, 클릭 처리 확장 |
| `src/editor/preview/inline.js`(+test) | 링크 기호만 범위 단위 판정, 링크 글자에 표시용 mark |
| `src/editor/preview/active.js`(+test) | 선택이 범위에 닿는지 판정하는 함수 추가 (기존 `activeLines` 는 유지) |
| `src/editor/preview/index.js` | `links.js` 확장 등록 |

- CSS 는 이 명세가 고치지 않는다. 링크 글자 `cursor: pointer` 는 F-124 가 `.md-link` 에 준다

## 3. 요구사항

### 3.1 대상
| 원문 | 열 주소 |
| --- | --- |
| `[글자](https://…)` (`Link` 안 `URL`) | `URL` 글자 |
| 맨 주소 `https://…` (GFM 자동 링크, 부모가 `Link` 가 아닌 `URL`) | 그 글자 |
| `<https://…>` (`Autolink`) | `<` `>` 안 글자 |

- `[글자][참조]`·`[글자]` 처럼 `URL` 이 없는 링크, `Image` 는 대상이 아니다 (누르면 보통 커서 이동)
- 열 수 있는 주소: `http:`, `https:`, `mailto:` 로 시작하는 것만 (대소문자 무시). 그 밖(상대 경로, `#앵커`, `javascript:` 등)은 열지 않고 보통 커서 이동

### 3.2 링크 기호 숨김 단위
- `Link` 의 `LinkMark`·`URL`·`LinkTitle` 은 **선택 범위 중 하나가 그 `Link` 범위 `[from, to]` 에 닿을 때만** 드러낸다 (끝 위치 포함 — 커서가 `)` 바로 뒤에 있어도 드러남). 같은 줄이라도 링크 밖에 커서가 있으면 숨긴다
- 링크 안에 있는 강조 기호 등 다른 인라인 기호, 그리고 다른 모든 요소는 기존 **줄 단위** 그대로
- 맨 주소·`Autolink` 는 원래 숨기는 기호가 없으므로 바뀌지 않는다

### 3.3 클릭
- 편집 모드에서 **기호가 숨겨진 링크 글자**(`Link` 의 링크 글자 부분) 또는 맨 주소·`Autolink` 글자를 마우스 왼쪽 버튼으로 누르면
  - 수정 키 없음: 주소가 열 수 있는 것이면 `window.open(url, '_blank', 'noopener,noreferrer')`. `mousedown` 에서 기본 동작을 막아 커서가 움직이지 않게 한다. 열 수 없는 주소면 보통 커서 이동
  - Ctrl(맥 ⌘) + 클릭: 열지 않고 누른 위치에 커서를 둔다 → 3.2 에 따라 링크가 드러나 편집할 수 있다
  - Shift + 클릭: 기존 선택 확장 동작 그대로
- 드러난 상태(커서가 링크에 닿음)의 링크는 누르면 보통 커서 이동이다. 열지 않는다
- 원문 모드에서는 링크를 열지 않는다 (확장이 편집 모드에만 들어 있음)
- 조합 중(`view.composing`)이면 가로채지 않는다
- 링크 글자에 `Decoration.mark({ class: 'md-link', attributes: { title: 주소 } })` — 마우스를 올리면 주소가 보인다. 드러난 상태에서는 넣지 않는다

### 3.4 구조
- `findLinkAt(state, pos) → { from, to, url } | null` — 구문 트리 기준. `url` 은 원문 글자 그대로 (`Autolink` 는 `<>` 제외)
- `isOpenableUrl(url) → boolean`
- `selectionTouches(state, from, to) → boolean` (`active.js`)
- 클릭 처리는 `EditorView.domEventHandlers({ mousedown })`. 누른 위치는 `view.posAtCoords`

### 3.5 IME
- F-104 2.3 규칙 그대로. 활성 판정 단위가 바뀌어도 조합 중 재계산 보류와 조합 종료 따라잡기(`forceRecalc`)는 유지
