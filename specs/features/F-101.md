# F-101 테스트 기반

작성일: 2026-09-14
상태: 사용자 지시로 구현 착수 (2026-09-14)
근거: `specs/product.md` 4.1 F-101, 6장 비기능 요구

## 1. 목적

이후 기능(저장소, 마크다운 범위 계산, 줄바꿈 변환, 대비 계산 등)의 순수 로직을 단위 테스트로 확인할 수 있게 러너를 들인다

- 한글 IME 입력은 자동 테스트로 판정하지 않는다. 사람이 직접 타이핑해 판정한다 (`.workflow/tasks/T-004/verify.md` 6.1·6.2)
- 이 명세는 러너만 들인다. 실제 기능 테스트는 각 기능 명세가 추가한다

## 2. 범위

### 한다

- Vitest 설치와 설정
- `npm test` 명령 추가
- 러너가 도는지 확인하는 스모크 테스트 1개

### 하지 않는다

- DOM 테스트 환경(jsdom, happy-dom), React Testing Library — 필요해지는 기능 명세에서 정한다
- IndexedDB 가짜 구현(fake-indexeddb) — F-110 에서 정한다
- 커버리지 측정, 브라우저 모드, E2E(Playwright 등)
- CI 설정
- `spike/` 코드 테스트

## 3. 의존성

| 패키지 | 버전 범위 | 구분 | 근거 |
| --- | --- | --- | --- |
| `vitest` | `^5.0.0` | devDependencies | 2026-09-14 npm 최신 5.0.0. peerDependencies 의 `vite` 범위가 `^6.4.0 \|\| ^7.0.0 \|\| ^8.0.0` 이라 설치된 vite 7.3.6 과 맞는다 (`npm view vitest peerDependencies`) |

이 외의 패키지는 설치하지 않는다

## 4. 수정 파일

| 파일 | 변경 |
| --- | --- |
| `package.json` | `vitest` devDependency, 스크립트 `test`·`test:watch` |
| `package-lock.json` | 설치 결과 |
| `vite.config.js` | `test` 설정 블록 추가 |
| `src/smoke.test.js` | 신규. 스모크 테스트 |

위 목록 밖의 파일은 바꾸지 않는다. `spike/vite.config.js`, `eslint.config.js` 도 바꾸지 않는다

## 5. 요구사항

### 5.1 스크립트

```json
"test": "vitest run",
"test:watch": "vitest"
```

- `npm test` 는 한 번 실행하고 끝난다(감시 모드 아님). 실패가 있으면 0 이 아닌 종료 코드를 낸다

### 5.2 설정 (`vite.config.js`)

- 기존 `plugins: [react()]` 는 그대로 둔다
- `test` 블록
  - `include: ['src/**/*.test.{js,jsx}']` — `spike/`, `dist/`, `dist-spike/`, `docs/` 는 수집하지 않는다
  - `environment: 'node'`
  - `globals` 는 켜지 않는다. 테스트 파일은 `import { describe, it, expect } from 'vitest'` 로 명시적으로 가져온다 (ESLint 설정을 바꾸지 않기 위해서다)

### 5.3 테스트 파일 규칙

- 테스트는 대상 파일 옆에 `{이름}.test.js` 로 둔다 (예: `src/storage/db.js` → `src/storage/db.test.js`)
- 테스트 이름(`describe`·`it` 문자열)은 한국어로 쓴다

### 5.4 스모크 테스트 (`src/smoke.test.js`)

- 러너가 `src/` 의 테스트를 수집하고 실행하는지만 확인한다. 예: `expect(1 + 1).toBe(2)` 수준
- 파일 맨 위 주석: 첫 기능 테스트가 생기면 지운다는 한 줄

## 6. 수용 기준

서브에이전트는 아래를 직접 실행하고 결과를 그대로 보고한다

| # | 확인 | 방법 | 기대 |
| --- | --- | --- | --- |
| A1 | 테스트 실행 | `npm test` | 테스트 파일 1개, 테스트 1개 통과. 종료 코드 0. 감시 모드로 머물지 않음 |
| A2 | 실패 감지 | `src/smoke.test.js` 의 기대값을 임시로 틀리게 바꿔 `npm test` 실행 후 되돌림 | 종료 코드 0 아님. 되돌린 뒤 A1 다시 통과 |
| A3 | 수집 범위 | `npm test` 출력의 테스트 파일 목록 | `src/` 밖 파일이 없음 |
| A4 | 빌드 | `npm run build` | 성공 |
| A5 | 스파이크 빌드 | `npm run build:spike` | 성공 (설정 변경이 스파이크에 영향 없음) |
| A6 | 린트 | `npm run lint` | 오류 0 |
| A7 | 의존성 | `package.json` diff | devDependencies 에 `vitest` 만 추가됨 |
