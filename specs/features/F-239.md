## 0. 포지셔닝 — 반드시 지킬 제약

- 헤드라인·서브카피는 **한국어 지원**을 핵심으로 건다. "원문이 안 사라진다"는 헤드라인 주장이 아니라 **타이핑 데모로 보여주는 증거**로만 쓴다(리서치 경고: 이 특징 자체는 HackMD·HedgeDoc도 이미 함)
- **"실시간 협업"·"동시 편집"·국내 리전·댓글 앵커 같은 문구를 쓰지 않는다** — 전부 미구현(M3~M4). 로그인 뒤 여러 기기 동기화(F-205~209)·공유 링크·초대 편집·편집 중 자동 잠금(F-210~213)은 이미 배포돼 있으므로 언급 가능하지만, "동시에 여러 명이 커서를 보며 편집"한다는 인상은 주지 않는다(잠금 방식이라 한 번에 한 명만 편집)
- 로그인·회원가입을 앞세우지 않음 — 로컬 우선 설계라 로그인 없이 시작하는 게 기본, 로그인은 "필요하면"으로만 언급

### 0.2 2026-09-17 재설계 — 앱과 같은 화면, 실제 편집기 데모 (사용자 지시)

사용자 피드백: 최대폭 560px 이 너무 좁음 / 애니메이션 자리를 스크린샷이 차지해 이상함(비율 깨짐) / `public/` 로고를 안 씀 / doc 요소와 색 토큰이 앱과 안 맞음 / 한국어는 `word-break: keep-all` / M3·M4 도 써 둘 것 / doc 을 실제 편집기로 포팅해 인터랙션 가능하게.

1. **팔레트·서체를 앱 화이트 테마와 같은 값으로.** `src/styles/tokens.css` 의 `--paper`·`--panel`·`--ink`·`--ink-2`·`--muted`·`--rule`·`--rule-2`, `--font-sans`(Pretendard Variable)·`--font-serif`(Noto Serif KR, 제목)·`--font-mono`(D2Coding), `--tracking: -0.02em`, `--radius-control`·`--radius-dialog` 를 랜딩 인라인 `<style>` 에 같은 값으로 다시 적는다. 워커가 돌려주는 단일 HTML 이라 CSS 파일을 import 하지 않는다
2. **폭**: 페이지 1060px, 본문 읽기 폭 40em. 히어로 카드는 페이지 폭 전체
3. **로고**: 헤더에 `brand.icon` 20×20 + `brand.name`(`--font-display` 700 16px) — 앱 `SidebarHead` 와 같은 모양
4. **`word-break: keep-all`** 을 `body` 에 건다. 한국어는 낱글자로 끊으면 뜻이 달라진다
5. **스크린샷 제거**(`public/welcome-screenshot.png` 삭제). 히어로가 곧 편집 화면이므로 사진이 필요 없다
6. **히어로 = 실제 편집기**(§2.1). 정적 HTML 에는 완성된 예시 문서가 줄번호와 함께 그대로 있고, `assets/welcome-demo.js` 가 뜨면 그 자리를 `createEditor()` 로 바꾼다
7. **한글 조합 타이핑**: 한 글자를 초성 → 초성+중성 → 완성 순으로 친다(`src/welcome/korChars.ts`). 편집기 데모는 CM6 트랜잭션으로, 아래 섹션 제목(`h2`)은 인라인 스크립트가 화면 진입 시 한 번씩
8. **M3·M4 예고 섹션** "만들고 있습니다" 추가 — 동시 편집, 댓글. §0 의 "쓰지 않는다" 제약은 **지금 되는 기능으로 오인될 문구**에 한한다. 예고 섹션은 지금 되는 기능 목록과 색·위치로 분명히 구분하고, "지금은 한 번에 한 명씩 편집합니다" 처럼 현재 상태를 함께 적는다

## 2. 왜 React/`index.html` 을 안 쓰는가 (GEO 요건)

- GPTBot·ClaudeBot·PerplexityBot 같은 AI 크롤러는 자바스크립트를 실행하지 않고 최초 응답 HTML만 읽는다. React SPA로 만들면 크롤러가 받는 HTML에 헤드라인 텍스트가 없어 GEO 목적(AI 답변에 인용되는 것)을 못 채운다
- `worker/publicPage.ts` 가 이미 같은 이유로 완성된 HTML 문자열을 직접 반환하는 패턴을 쓰고 있음 — 이번 페이지도 그 패턴을 그대로 따른다. 다만 토큰 조회가 없어 DB 접근 없이 고정 문자열만 반환하면 된다(`env` 불필요)
### 2.1 편집기 데모 (§0.2)

- `/welcome` 이 돌려주는 HTML 자체에는 **완성된 예시 문서가 줄번호와 함께 정적 마크업으로** 들어 있다. 크롤러·자바스크립트 꺼짐 상태에서 보이는 것이 이것이다
- 그 위에 `<script type="module" src="/assets/welcome-demo.js">` 가 뜨면 히어로(`#demo`)를 비우고 앱과 **같은 `createEditor()`** 를 마운트한다. 방문자가 직접 편집할 수 있다
- 자산 이름이 해시되면 워커가 경로를 알 수 없으므로 이 엔트리만 고정 이름으로 낸다(§1 `vite.config.ts`)
- 스타일은 앱 CSS 를 `?inline` 으로 받아 `document.head.prepend()` 로 넣는다 — 랜딩 자신의 `<style>` 이 뒤에 와서 겹치는 규칙은 랜딩이 이긴다
- 라이브 프리뷰 그대로이므로 **커서가 있는 줄만 기호가 원문으로 보인다.** 이것이 제품의 실제 동작이고, 방문자가 줄을 클릭하면 그 줄의 기호가 드러나는 것이 데모의 인터랙션이다
- 다 친 뒤 사람이 클릭·타자·터치하면 남은 애니메이션을 접고 전체 문장을 채운다. `prefers-reduced-motion: reduce` 면 처음부터 완성 상태

- 타이핑 애니메이션은 **이미 완성된 텍스트가 DOM에 그대로 있는 상태에서 시각 효과만 얹는 방식**으로 만든다(예: 텍스트는 그대로 두고 CSS `clip-path`/너비 트랜지션으로 "타이핑되는 것처럼" 보이게 하거나, 완성 텍스트를 감싼 뒤 JS로 글자 노출 타이밍만 제어). 자바스크립트가 꺼져 있거나 크롤러가 읽어도 완성된 예시 텍스트가 그대로 보여야 한다

## 3. 페이지 내용

### 3.1 `<head>`

- `<title>한국어로 쓰는 마크다운 협업 도구 — Rawdoc</title>` (문자열은 `brand.config.ts` `name` 을 템플릿에 섞어 만든다. 하드코딩 금지 — CLAUDE.md 불변조건)
- `<meta name="description">`: 서브헤드와 같은 문장 재사용(§3.2)
- OG/Twitter: `og:title`·`og:description`(랜딩 전용 문구, `src/lib/siteMeta.ts` 의 `SITE_DESCRIPTION` 과 달라도 됨)·`og:image`(`brand.ogImage`, F-238 과 동일하게 `new URL(brand.ogImage, siteUrl)` 절대경로)·`og:url`(`{siteUrl}/welcome`)·`og:locale=ko_KR`
- `<meta name="theme-color" content={brand.accent}>` (하드코딩 금지, `brand.config.ts` 값 사용)
- **`X-Robots-Tag` 헤더를 넣지 않는다** — F-238 의 공개 공유 페이지와 반대로 이 페이지는 색인 대상이다

### 3.2 본문 (시맨틱 HTML, 인라인 `<style>`. 외부 CSS·JS 파일 fetch 없음 — `worker/publicPage.ts` 처럼 단일 응답으로 완결)

- `<h1>` 헤드라인: "원문 그대로 쓰는" / "한국어 마크다운 협업 도구" (승인된 카피, 구현 시 완전히 동일한 문구로)
- `<p>` 서브헤드: `##` 를 쳐도 기호가 사라지지 않는다는 걸 한 문장으로 — 정확한 표현은 구현 중 다듬어도 되지만 §0 제약(한국어가 핵심, 협업/실시간 언급 금지)은 지킨다
- 타이핑 데모 블록(`<pre><code>` 또는 동등 시맨틱 요소): 완성된 예시 텍스트를 실제 문자로 담는다. 예시 문서:
  ```
  ## 소개

  이 문장은 **그대로** 남는다
  ```
  마크다운 기호(`#`, `*`)는 지우지 않고 옅은 강조 색(`--syntax`류, 다만 이 페이지는 워커 정적 HTML이라 CSS 토큰 파일을 import 하지 않으므로 `brand.accent` 기반 인라인 색상으로 흉내만 낸다)으로만 감싸 "안 사라진다"는 걸 시각적으로 보여준다. §2 의 애니메이션 방식 그대로
- CTA 버튼: "지금 써보기" → `href="/"` (새 탭 아님, 같은 탭에서 루트로 이동 → 기존 로컬 우선 에디터 진입)
- 로그인 안내 없음. "설치 없이, 로그인 없이 바로 로컬로 시작" 류 문구는 써도 됨(사실과 일치)
