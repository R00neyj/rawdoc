## 2. 요구사항

### 2.1 구문 클래스 (두 모드 공통)
- `HighlightStyle.define([...])` 에서 `class` 를 지정하는 방식. 색·굵기는 CSS 에서 토큰으로 준다
- 대상 태그와 클래스 (태그 이름은 `@lezer/markdown` 의 `markdownHighlighting`·GFM 확장 소스에서 실제 이름을 확인해 맞춘다)

| 대상 | 태그 | 클래스 | 스타일 |
| --- | --- | --- | --- |
| 모든 마크다운 기호(`#` `>` `-` `*` `` ` `` `[` `]` `(` `)` `~~` 등) | `tags.processingInstruction` | `md-mark` | `color: var(--accent)`, `font-family: var(--font-mono)` |
| 제목 텍스트 | `tags.heading` (1~6) | `md-heading` | 굵게 |
| 굵게 | `tags.strong` | `md-strong` | 700 |
| 기울임 | `tags.emphasis` | `md-em` | italic |
| 취소선 | `tags.strikethrough` | `md-strike` | line-through, `--muted` |
| 인라인코드 | `tags.monospace` | `md-code` | `--font-mono`, 배경 `--rule-2`, 반경 3px |
| 링크 텍스트 | `tags.link` | `md-link` | `--link` |
| URL | `tags.url` | `md-url` | `--link` |
| 인용 | `tags.quote` | `md-quote-text` | `--ink-2` |

### 2.2 모드 전환
- 상단바 제목 입력 오른쪽에 `라이브 프리뷰` / `원문` 2버튼 세그먼트, `aria-pressed`
- S-2 에서 비활성
- `handle.setViewMode(mode)`: 프리뷰 Compartment 를 `live` 면 `livePreview()`, `raw` 면 `[]` 로 재구성하고 `data-view` 속성 변경
- **재마운트하지 않는다.** 커서·선택·실행 취소 기록 유지
- 스크롤 위치 유지: 재구성 전 `view.scrollSnapshot()` 을 받아 재구성 트랜잭션에 effect 로 함께 넣는다
- 선택은 `md.viewMode` 에 저장, 다음 실행 기본값. 없으면 `live`
- `raw` 모드: 전체 고정폭, 기호 강조·2.1 스타일 유지, 숨김·크기 변화 없음
