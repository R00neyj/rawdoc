# F-2140 칸반 보드 보기 화면

작성일: 2026-10-14
상태: 승인 대기. 개요 F-2138 1·3·4장의 화면 틀 — 보드를 그리고 보기를 바꾸는 것까지. 고치기는 F-2141, 옮기기는 F-2142. 보기는 `보드`·`원문` 둘(F-2138 Q2). 구현 담당 `feature-implementer`. `App.tsx` 증가 약 12줄

## 근거 (2026-10-14 HEAD, 이름으로 찾는다)
- `src/app/DocumentArea.tsx` 는 보기 모드에서 `.editor-slot` 을 `hidden` 으로만 숨기고 `Editor` 를 언마운트하지 않는다 — 보드도 같은 방식이라 편집기 `Y.Doc`·게이트·실행 취소 기록이 그대로 산다
- `createEditor.ts` 핸들에 `onHeadingsChange`·`onContextMenu` 같은 구독 함수가 있다. 문서 변경 구독은 없다(`onDocChange` 는 마운트 때 prop 하나)
- 보기 모드 `viewMode` 는 앱 전체 하나(`md.viewMode`). 문서마다 다른 보드 여부는 여기에 넣지 않는다
- 제목 포커스 요청은 `focusTitleRef` 를 `Editor` 가 마운트 때 읽고 App effect 가 비운다. 보드 화면에서는 편집기 제목 위젯이 숨겨져 받을 수 없다
- 휴대폰 폭 보기 모드는 `ViewModeMenu`(메뉴), 넓은 창은 `TopBar` `.view-mode-seg`(아이콘 셋)
- `AppTopBar` `showToolbar` 는 지도처럼 누를 대상이 없으면 서식 바를 끈다

## 2. 계약
```ts
export type KanbanView = 'board' | 'source'
export type KanbanViewEvent =
  | { kind: 'open'; isKanban: boolean } | { kind: 'kanbanChanged'; isKanban: boolean }
  | { kind: 'choose'; view: KanbanView } | { kind: 'chooseMode'; mode: 'live' | 'raw' | 'view' }
export function nextKanbanView(prev: KanbanView, e: KanbanViewEvent): KanbanView
// createEditor 핸들 — 구독 해제 함수를 돌려준다. 원격 적용·되돌리기도 온다
onChanges(cb: (u: { changes: ChangeSet; state: EditorState }) => void): () => void
```
- `open` → `isKanban` 이면 `board`, 아니면 `source`. 저장하지 않는다(다시 열면 늘 `board`, 사용자 결정 4)
- `kanbanChanged` 거짓 → `source`. 참 → 그대로(원문에 `kanban: true` 를 치는 도중 화면이 바뀌지 않게. 보드로 가는 건 `보드로 보기` 명령, F-2143)
- `chooseMode` → `source`

## 3. 보드 화면 (`KanbanBoard`)
- 보드가 보이는 조건: `openDoc?.id === currentDocId` 이고 편집기 핸들이 있고 `isKanban` 이고 보기가 `board`. 금고 잠김(P1)·공유 화면·지도에서는 안 보인다. S-4·S-5·인쇄·내보내기는 지금 그대로 마크다운으로 그린다
- 그동안 숨기는 것: `.editor-slot`, `Viewer`, `Outline`, 댓글 레일·판·`댓글 달기`, 서식 바, 위키링크 미리보기. 상단바 `댓글` 버튼도 없다. `Ctrl+M` 은 `source` 로 바꾸고 댓글을 연다(보기 모드 선례 `toggleCommentsPanel`)
- 구성: `.kanban-board`(`role="region"`, 이름 `칸반 보드`, `tabIndex=-1`) → 제목 입력 `.kanban-title`(이름 `문서 제목`, `handleTitleChange`·`handleTitleCommit`, `titleReadOnly` 면 읽기 전용) → `.kanban-lanes` 가로 줄 → 칸 `section.kanban-lane`(이름 = 칸 이름, 빈 이름은 `이름 없는 칸`) 머리 `.kanban-lane-title` + 개수 → `ul.kanban-cards` → `li.kanban-card`(`tabIndex=0`) 안 체크 칸(체크 카드만, 이름 `완료`, 이 명세에서는 `disabled`)·`.kanban-card-text`·`.kanban-card-detail`(하위 줄 한 줄씩 글자 그대로)
- `.kanban-title` 값은 `currentDoc.title`. 포커스 중에는 바깥 값으로 덮지 않고 blur 뒤 맞춘다(`src/editor/docTitle.ts` `latestTitle` 과 같은 규칙). 제목 포커스로 열리면 글자 전체 선택
- 글자는 원문 그대로 텍스트로 넣는다(`textContent`). 인라인 마크다운을 그리지 않는다
- 규칙 밖 줄이 있는 칸: 카드 아래 `.kanban-stray` 버튼 `카드가 아닌 줄 {N}개` — 누르면 `source` 로 바꾸고 `jumpToLine(첫 줄)`
- 칸이 0개: `.kanban-empty` `칸이 없습니다. ## 로 시작하는 줄 하나가 칸 하나가 됩니다.`
- 첫 포커스: `focusTitleRef` 면 `.kanban-title`(편집기에는 `autoFocus` 를 주지 않는다), `focusEditorRef` 이고 휴대폰 폭이 아니면 `.kanban-board`
- 보드 스냅샷은 `onChanges` 마다 표시만 갱신하고 rAF 한 번에 묶어 다시 읽는다. 읽기는 `editorRef.current.view.state.doc` 하나 — 본문 사본을 React 상태에 두지 않는다(F-2139 의 칸·카드 배열만)

## 4. 보기 바꾸기
- 넓은 창(`TopBar` 넓은 갈래): `isKanban` 이면 `.view-mode-seg` 왼쪽에 `.seg.kanban-view-seg`(`role="group"`, 이름 `보드 보기`) — `보드`(`IconKanban`, 툴팁 `보드 — 칸반 보드로 보기`)·`원문`(`IconRaw`, 툴팁 `원문 — 보드를 닫고 문서로 보기`). `aria-pressed` 로 지금 보기
- 보드일 때 `.view-mode-seg` 의 `편집`·`원문`·`보기` 를 누르면 `chooseMode` → 문서 화면 + 그 모드
- 휴대폰 폭: `ViewModeMenu` 맨 위에 `보드 — 칸반 보드로 보기`(`isKanban` 일 때만). 보드면 버튼 이름 `보기 모드: 보드`. 다른 셋을 고르면 `chooseMode`
