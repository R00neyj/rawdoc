## 2. 여는 곳
- 앱 메뉴를 여는 곳: 편집·원문 모드 주 에디터 내용(`.cm-content`), 표 칸 하위 에디터, 보기 모드 본문, 공유 화면 본문
- 그 밖(사이드바·상단바·목차·대화상자·입력란)은 브라우저 기본 메뉴 그대로
- **Shift+우클릭**은 앱 메뉴를 열지 않고 브라우저 기본 메뉴 (맞춤법 제안 등)
- 한글 조합 중이면 앱 메뉴를 열지 않는다 (기본 동작도 막지 않는다)
- 키보드 메뉴 키·Shift+F10 으로 오는 `contextmenu` 도 받는다. 위치는 커서(선택 끝) 좌표
- 마우스 우클릭 지점이 현재 선택 밖이면 커서를 그 지점으로 옮긴 뒤 연다. 선택 안이면 선택을 유지한다

- 편집 모드에서 `표` 삽입 뒤에는 새 표의 머리 첫 칸 편집을 시작한다 (F-125 `enterTableFromKeyboard` 와 같은 진입). 원문 모드는 F-169 커서 그대로

### 3.2 표 칸 편집 중
- 3.1 과 같은 모양. 활성: 링크 추가·외부 링크 추가, 서식 2차 메뉴(서식 지우기 제외), 잘라내기·복사·붙여넣기·일반 텍스트로 붙여넣기, 모두 선택(칸 글자 전체)

- 명령은 칸 하위 에디터에 실행하고 칸 편집 트랜잭션(F-125 2.2)으로 주 문서에 간다. 붙여넣기 줄바꿈 → 공백 1개 (F-125 2.2)

- 항목 2개: `복사`(Ctrl+C, 선택이 비었거나 본문 밖이면 비활성), `모두 선택`(Ctrl+A, 본문만 선택)

## 4. 클립보드
- 복사: 선택 글자를 `navigator.clipboard.writeText`. 편집·원문 모드는 CM6 Ctrl+C 와 같은 글자(줄 구분 `\n`), 보기 모드는 `Selection.toString()`
- 잘라내기: 복사가 성공한 뒤에만 선택을 지운다 (`userEvent: 'delete.cut'`)
- 쓰기 실패: error 알림 `복사하지 못했습니다. 브라우저 권한을 확인하세요.` (F-130 문구 재사용), 잘라내기는 지우지 않음
- 붙여넣기: `navigator.clipboard.read()` 로 읽어 `text/plain` 을 선택 자리에 넣는다 (`userEvent: 'input.paste'`). 이미지 붙여넣기 흐름(F-156)이 구현돼 있으면 이미지 항목은 그 흐름으로 넘긴다. HTML → 마크다운 변환은 없다
- 일반 텍스트로 붙여넣기: `navigator.clipboard.readText()` 만 넣는다 (이미지 무시)
- 읽기 실패(권한 거부·미지원): error 알림 `클립보드를 읽지 못했습니다. Ctrl+V 로 붙여넣으세요.`
- 처음 읽을 때 Chrome 이 권한을 묻는 것은 브라우저 동작이다 (사람 확인)

## 5. 메뉴 동작과 모양
- 역할: 목록 `role="menu"`, 항목 `role="menuitem"`, 2차 메뉴를 여는 항목은 `aria-haspopup="menu"`·`aria-expanded`
- 위치: 우클릭 지점에 왼쪽 위를 맞춘다. 창을 넘으면 왼쪽·위로 뒤집는다. 2차 메뉴는 부모 항목 오른쪽, 넘으면 왼쪽. 창보다 길면 최대 높이 = 창 높이 − 16px, 안에서 스크롤
- 마우스: 2차 메뉴 항목에 올리면 연다. 다른 1차 항목에 올리면 닫는다. 클릭하면 실행
- 키보드: 열리면 첫 활성 항목에 포커스. ↑↓ 이동(비활성 건너뜀, 끝에서 처음으로), Home·End, → 또는 Enter 로 2차 메뉴 열고 첫 항목 포커스, ← 로 2차 메뉴 닫기, Enter 실행, Esc 한 단계 닫기(1차에서 Esc 면 닫고 에디터에 포커스)
- 닫기: 실행, Esc, 메뉴 밖 누르기, 창 크기 변경·흐림, 편집 영역 스크롤
- 실행 뒤 포커스는 원래 에디터(칸 하위 에디터 포함)로 돌아가고 커서가 보이게 스크롤한다. 명령 1회 = 실행 취소 1단계
- 모양: 공유 메뉴(`.share-menu-list`)와 같은 바탕·테두리·그림자·모서리·항목 높이·호버. 최소 너비 200px. 항목은 글자 + 오른쪽 끝 단축키(`--muted`). 2차 메뉴 항목은 오른쪽 끝 `›` 방향 아이콘(Material Symbols `chevron_right`). 아이콘 없는 글자 메뉴다 — `specs/ia.md` I13 에 "편집기 우클릭 메뉴는 글자만" 을 더한다
- 호버·포커스 색 전환은 F-149 규칙
