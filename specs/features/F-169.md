## 2. 블록 넣는 자리 (표·콜아웃·수평선·코드 블럭·수식 블럭 공통)
- 기준 줄: 선택이 없으면 커서 줄, 있으면 선택이 걸친 줄들
- 기준 줄이 빈 줄 하나면 그 줄에 넣는다. 아니면 기준 줄(마지막) 끝 뒤에 줄을 새로 만들어 넣는다 (감싸는 명령은 3장)
- 넣은 블록 **바로 윗줄**이 있고 빈 줄이 아니면 빈 줄 1개를 먼저 넣는다 (수평선이 setext 제목이 되거나 표·코드가 앞 문단에 붙지 않게)
- 넣은 블록 **바로 아랫줄**이 있고 빈 줄이 아니면 블록 뒤에 빈 줄 1개를 넣는다. 문서 끝이면 넣지 않는다
- 펜스 코드블록 안·프론트매터 안·표 안이 기준 줄이면 `false` (아무것도 안 함)

## 3. 명령

| 메뉴 | 명령 | 넣는 원문 | 커서 |
| --- | --- | --- | --- |
| 각주 | `insertFootnote` | 4장 | 각주 정의 줄 끝 |
| 표 | `insertTable` | `\|  \|  \|⏎\| --- \| --- \|⏎\|  \|  \|` (머리 2칸 + 본문 1행) | 머리 첫 칸 공백 뒤 (`\| ` 다음). 편집 모드 칸 편집 시작은 F-170 |
| 콜아웃 | `insertCallout` | 선택 없음: `> [!note]⏎> ` / 선택 있음: `> [!note]⏎` + 선택 줄마다 앞에 `> ` | 둘째 줄 끝 / 마지막 줄 끝 |
| 수평선 | `insertHorizontalRule` | `---` + 아랫줄이 없으면 빈 줄 1개 | 수평선 다음 줄 |
| 코드 블럭 | `insertCodeBlock` | 선택 없음: ```` ```⏎⏎``` ```` / 선택 있음: 선택 줄들을 ```` ``` ```` 줄 사이에 감싼다 | 가운데 빈 줄 / 여는 ```` ``` ```` 뒤(언어 입력 자리) |
| 수식 블럭 | `insertMathBlock` | 선택 없음: `$$⏎⏎$$` / 선택 있음: 선택 줄들을 `$$` 줄 사이에 감싼다 | 가운데 빈 줄 / 닫는 `$$` 앞 줄 끝 |

- 선택이 있는 표·수평선은 선택을 지우지 않고 선택이 걸친 마지막 줄 뒤에 넣는다
- 감싸는 명령(콜아웃·코드 블럭·수식 블럭, 선택 있음)은 선택이 걸친 줄 전체를 감싼다. 여러 줄 선택의 끝이 열 0 이면 그 줄은 뺀다 (F-168 2장과 같음)
- 선택 줄 안에 이미 ```` ``` ```` 가 있으면 코드 블럭은 ```` ```` ```` (백틱 4개)로 감싼다

## 4. 각주 `insertFootnote`
- 번호 n = 문서 안 `[^숫자]` 표지(정의 포함) 중 가장 큰 숫자 + 1. 없으면 1. 숫자가 아닌 이름(`[^note]`)은 세지 않는다
- 커서 자리(선택이 있으면 선택 끝 뒤)에 `[^n]` 을 넣는다. 선택 글자는 지우지 않는다
- 문서 끝에 정의를 붙인다: 문서 끝이 줄바꿈이 아니면 `⏎`, 마지막 줄이 각주 정의(`[^…]: `)가 아니면 빈 줄 1개, 그다음 `[^n]: `
- 두 변경은 트랜잭션 1개. 커서는 정의 줄 끝 (화면이 따라가는 것은 호출하는 쪽 `scrollIntoView`)
