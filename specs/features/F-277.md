## 1. 문서 한 개 내보내기

상단바 `.md 내보내기` 아이콘 버튼을 **`내보내기` 메뉴**로 바꾼다

| 항목 | 결과 | 비고 |
| --- | --- | --- |
| `.md` | 지금 그대로 (이미지가 있으면 zip, F-158) | 바이트 = 원문 (6장 원문 보존) |
| `.txt (평문)` | 기호를 뗀 글 (1.1) | 이미지·다이어그램은 글로 대체 |
| `HTML 파일` | 보기 모드 모양 그대로 파일 하나 (1.3) | 인터넷 없이 열림 |
| `PDF (A4 인쇄)` | 인쇄 창 → `PDF로 저장` (1.2) | 한글 서체·이미지·Mermaid 화면 그대로 |
| `서식 있는 복사` | 클립보드에 HTML + 평문 (1.4) | 메일·노션·워드·구글 문서에 붙이기 |

- 공유 화면·공개 보기(F-210) 화면의 `.md 내보내기` 는 이번 범위에서 바꾸지 않는다

### 1.1 `.txt` 평문 규칙

보기 모드 변환 결과(F-123)에서 글을 뽑는다. 원문을 정규식으로 지우지 않는다 — 코드블록 안 `**` 같은 것을 잘못 지우지 않게

| 원문 | 평문 |
| --- | --- |
| 제목 `## 소개` | `소개` (앞뒤 빈 줄) |
| 굵게·기울임·취소선·하이라이트·인라인코드 | 글자만 |
| 링크 `[글](주소)` | `글 (주소)`. 글과 주소가 같으면 주소만 |
| 위키링크 `[[제목\|보이는 글]]` | `보이는 글` |
| 목록 | `- ` / `1. ` 들여쓰기 유지, 체크박스는 `[ ]` `[x]` |
| 인용·콜아웃 | 줄 앞 `> ` 유지 (인용인 걸 알 수 있게), 콜아웃 제목은 첫 줄 |
| 표 | 칸을 탭(`\t`)으로, 행은 줄로 |
| 코드블록 | 내용만 그대로 (펜스 없이) |
| 이미지 | `[이미지: alt]` (alt 가 비면 `[이미지]`) |
| Mermaid | `[다이어그램]` |
| 프론트매터 | 뺀다 |
| 주석(F-214) | 뺀다 (공유에서 안 보이는 것과 같음) |

- 줄바꿈은 문서 `lineEnding`, 인코딩 UTF-8(BOM 없음), 파일명 `toFileName(title)` 의 확장자만 `.txt`

### 1.2 PDF (A4 인쇄)

- 인쇄 전용 영역에 보기 모드 변환 결과를 그리고 `window.print()`. 인쇄 CSS: `@page { size: A4; margin: 20mm }`, 인쇄 때 앱 화면(사이드바·상단바·목차)은 숨김
- 테마와 상관없이 흰 바탕·검은 글자로 인쇄. 서체 설정(제목·본문)은 따른다
- 쪽 나눔: 제목 바로 뒤에서 끊지 않기(`break-after: avoid`), 표·코드블록·이미지·다이어그램 안에서 되도록 끊지 않기(`break-inside: avoid`). 한 쪽보다 긴 표·코드는 끊긴다
- 문서 제목을 첫 쪽 맨 위에. 인쇄하는 동안 `document.title` 을 문서 제목으로 바꿔 `PDF로 저장` 기본 파일명이 제목이 되게 하고, 끝나면(`afterprint`) 되돌린다
- 이미지·Mermaid 가 다 그려진 뒤에 인쇄 창을 연다
- 앱에서 `Ctrl+P` 를 누르면 같은 인쇄를 쓴다 (앱 화면이 그대로 인쇄되는 것 방지)
- 머리글·바닥글(날짜·주소)은 브라우저 인쇄 설정이라 앱이 끄지 못한다 — 사람 확인 항목에 적는다

### 1.3 HTML 파일

- `<!doctype html>` 파일 하나. 보기 모드 CSS(흰 테마)를 `<style>` 로 넣고, 이미지는 `data:` URI, Mermaid 는 그려진 SVG 로 넣는다
- **스크립트를 넣지 않는다** (Q11 — 받는 사람 브라우저에서 코드가 돌지 않게). 서체 파일은 넣지 않고 `font-family` 목록만(용량) — 받는 사람 PC 에 없으면 기본 서체
- 파일명 `toFileName(title)` 의 확장자 `.html`

### 1.4 서식 있는 복사

- `ClipboardItem` 으로 `text/html`(1.3 의 본문, 스타일은 인라인) + `text/plain`(1.1 평문)을 함께 쓴다
- 이미지는 `data:` URI 로 넣지만 붙여넣는 앱이 받지 않을 수 있다. 앱별 결과는 사람 확인 항목
- 성공하면 알림 `서식을 포함해 복사했습니다`

## 2. 전체·폴더 내보내기

### 2.1 대상

- 로그인하지 않았으면 이 브라우저(IndexedDB)의 문서·폴더·첨부 전부
- 로그인했으면 **내가 소유한** 서버 문서·폴더·첨부 전부. 공유받은 문서는 뺀다. 오프라인이면 버튼을 끄고 `온라인일 때 내보낼 수 있습니다` (캐시에는 없는 첨부가 있을 수 있어서)
- 폴더 단위: 그 폴더와 하위 폴더, 안의 문서만. 형식은 전체와 같고 zip 맨 위가 그 폴더다

### 2.2 zip 모양

```
{날짜}-export.zip              (폴더 단위는 {폴더 이름}.zip)
├─ manifest.json
├─ attachments/{id}.{ext}      ← 맨 위 폴더 문서가 쓰는 이미지만
├─ {문서}.md
└─ {폴더}/
    ├─ attachments/{id}.{ext}  ← 이 폴더 문서가 쓰는 이미지만
    ├─ {문서}.md
    └─ {하위 폴더}/…
```

- zip 파일명·폴더명·문서 파일명에 제품명을 넣지 않는다 (이름을 바꿔도 가져오기가 되게)
- `.md` 바이트는 문서 한 개 `.md` 내보내기와 같다 (`lineEnding` 으로 이음)
- 파일·폴더 이름은 `toFileName` 규칙. 같은 폴더에 같은 이름이 생기면 `이름 (2).md` — 원래 제목은 `manifest` 에 있다
- 이미지는 폴더마다 복사하므로 같은 이미지가 여러 폴더에 들어갈 수 있다(사용자 결정)
- 원문에 있지만 저장소에 없는 이미지는 빼고 개수를 알린다 (F-158 과 같음)
- 이미지를 합쳐 수백 MB 가 될 수 있다(계정 300MB, F-221). 메모리에 한 번에 올리지 않게 `fflate` 의 스트리밍 zip 으로 만든다 — 방식은 F-281 에서 실측

### 2.3 `manifest.json`

```json
{
  "format": 1,
  "exportedAt": 1789000000000,
  "folders": [{ "id": "…", "name": "교안", "parentId": null, "path": "교안" }],
  "docs": [{
    "id": "…", "path": "교안/1주차.md", "title": "1주차",
    "folderId": "…", "lineEnding": "crlf",
    "createdAt": 0, "updatedAt": 0, "pinnedAt": null
  }]
}
```

- 첨부 목록은 두지 않는다 — 원문의 `attachments/{id}.{ext}` 참조가 원본이다
- `format` 이 모르는 값이면 가져오기가 거부한다

## 3. 가져오기

### 3.1 흐름

1. `가져오기…` → zip 고르기
2. zip 을 읽어 **미리보기 대화상자**: `새로 {N}개 · 갱신 {N}개 · 건너뜀 {N}개 · 이미지 {N}개`, 경고(3.4)가 있으면 목록. `가져오기` / `취소`
3. 진행 표시 → 끝나면 결과 알림. 실패한 항목은 목록으로 보여 주고 나머지는 계속한다

### 3.2 Rawdoc zip (`manifest.json` 있음)

| 경우 | 동작 |
| --- | --- |
| 같은 id 문서가 없음 | 새로 만든다. **id 를 유지**한다(위키링크·해시 주소·다음 가져오기 비교용). 서버가 `id_taken` 이면 새 id (F-208 과 같음) |
| 같은 id, zip 쪽 `updatedAt` 이 더 늦음 | **갱신.** 덮기 전에 지금 내용을 `{제목} (가져오기 전)` 새 문서로 같은 폴더에 남긴다 |
| 같은 id, zip 쪽이 같거나 이름(더 이전) | 건너뜀 |
| 폴더 | id 가 같으면 그 폴더를 쓰고, 없으면 id 유지해 만든다. 이름·위치는 바꾸지 않는다 |
| 고정 | 새로 만든 문서만 `pinnedAt` 을 따른다 |
| 첨부 | 같은 id 가 있으면 건너뛰고, 없으면 올린다. 5MB·계정 300MB·형식 검사는 기존 규칙 그대로(F-209, F-221) |

- 서버에서 다른 사람이 편집 중(잠금, F-213)인 문서는 갱신하지 않고 실패 목록에 넣는다
- `pinnedAt`·`createdAt` 을 서버 API 가 받는지는 F-282 에서 확인한다(F-208 은 받는다)

### 3.3 일반 `.md` zip (`manifest.json` 없음)

- `.md`·`.markdown` 파일만 가져오고 나머지는 건너뛴다(개수 알림)
- 제목은 파일명(확장자 제외), 내용은 F-114 와 같은 규칙(UTF-8, BOM 제거, 줄바꿈 형식 판정·섞이면 CRLF 통일 후 알림)
- 폴더는 zip 경로를 따른다. **3단계 이상은 2단계 폴더에 합친다**(F-126 폴더 2단계). 같은 이름 폴더가 이미 있으면 그 폴더에 넣는다
- 전부 새 문서다(갱신 없음). 같은 제목이 있어도 새로 만든다
- 이미지는 원문이 `attachments/{id}.{ext}` Rawdoc 형식이고 zip 안에 그 파일이 있을 때만 가져온다. Obsidian `![[그림.png]]` 같은 다른 형식은 원문 그대로 두고 경고에 개수를 적는다(원문을 바꾸지 않는다)

### 3.4 경고로 알릴 것

- 모르는 `format`, 깨진 zip → 가져오기 거부
- 3단계 이상 폴더를 합침, `.md` 가 아닌 파일 건너뜀, 가져오지 못한 이미지 참조, 문서 크기 상한(Q6·F-206) 초과, 계정 용량 초과
