# F-137 프론트매터 안 위키링크 제외

작성일: 2026-09-14
상태: C4 통합 확인에서 찾음. F-133 3.2 "위키링크(F-131)는 프론트매터 안에서 동작하지 않는다" 미충족
근거: `src/editor/preview/wikiLinks.js:15` `OPAQUE_NODE = new Set(['FencedCode', 'InlineCode', 'Table'])` 에 `Frontmatter` 가 없음. `src/editor/wikiComplete.js` 는 구문 트리를 보지 않음. 링크 클릭(`links.js`)은 구문 트리 기준이고 프론트매터 안에는 `Link`·`URL` 노드가 없어 해당 없음

## 2. 요구사항

### 3.1 편집 모드 표시·클릭
- `Frontmatter` 노드 안의 `[[…]]` 는 위키링크가 아니다: 기호를 숨기지 않고, `md-wikilink` 클래스를 붙이지 않고, 클릭해도 문서를 열지 않는다
- 테스트: `---\nrelated: [[사용법]]\n---\n[[사용법]]` 에서 프론트매터 안 0개, 본문 1개

### 3.2 자동완성
- 커서가 `FencedCode`·`InlineCode`·`Frontmatter` 안이면 `[[` 자동완성을 띄우지 않는다 (F-131 2장 "코드블록·인라인코드·표 칸 안은 위키링크가 아니다" 와 맞춤. 표 칸은 하위 에디터라 해당 없음)
- 판정은 구문 트리로 한다 (`wikiLinks.js` 의 판정 함수를 내보내 함께 쓰는 것 허용)
- 테스트: 위 세 위치에서 완성 소스가 `null`, 본문에서는 결과 있음
