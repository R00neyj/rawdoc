# F-217 문서 제목을 본문 맨 위로

작성일: 2026-09-15
상태: 사용자 선택(2026-09-15 "문서 제목 UI의 폭이 너무 커서… 문서 제목처럼 잘 안읽힘. 문서 최상단에 문서 제목이 오는게 맞는거같은데" → "본문 맨 위 큰 제목"). F-216 커밋 뒤

## 2. 요구사항

### 2.1 자리와 모양
- 편집·원문 모드: CM6 문서 위치 0 의 **block widget**(`side: -1`, StateField 로 제공). 줄 번호 칸 오른쪽, 본문 글자 첫 줄과 같은 왼쪽 끝. 본문과 함께 스크롤된다. 프론트매터 위젯(F-155)보다 위
- 보기 모드: `Viewer` 스크롤 요소(`.viewer`) 안 맨 위 `h1.doc-title-view`(글자만). 목차(F-144) 항목에 넣지 않는다
- 모양(편집·원문·보기 같게): 서체 `--font-display` 700, 크기 `calc(var(--md-font-size) * 2.25)`, 줄 간격 1.25, 색 `--ink`, 아래 여백 `calc(var(--md-font-size) * 1)`. 테두리·밑줄 없음(본문 `#` 제목의 아래 선과 구분). 원문 모드에서도 이 서체·크기
- 긴 제목은 줄바꿈해 여러 줄로 보인다(가로 스크롤 없음, `keep-all` 적용)

### 2.2 입력 요소
- 편집·원문 모드 widget 안 `textarea.doc-title`, `aria-label="문서 제목"`, `rows=1`, 내용 높이에 맞춰 자동으로 늘어난다. 테두리·바탕 없음, 포커스 링은 앱 공통
- 줄바꿈 입력 불가: Enter 는 막고 2.3 동작. 붙여넣기의 줄바꿈은 공백 1개로
- 빈 값일 때 흐린 자리 표시 `제목 없는 문서`(`--muted`)
- 입력 중 widget DOM 을 다시 만들지 않는다 — 포커스·커서·**한글 IME 조합이 끊기면 안 된다**. 바깥에서 제목이 바뀌면(서버 갱신 등) 포커스가 없을 때만 값 교체
- CM6 가 이 textarea 의 키·마우스·조합 이벤트를 처리하지 않게 한다(`ignoreEvent`). CM6 실행 취소 기록에 들어가지 않는다
- 기존 제목 규칙 그대로(F-111 3.4): 입력하는 동안 저장·목록 갱신, 포커스를 잃을 때 공백만이면 `제목 없는 문서`

### 2.3 키보드
- 제목에서 Enter 또는 ↓(커서가 제목 끝 줄일 때): 에디터 본문 맨 앞으로 포커스 (ia.md 6장 Enter 행 그대로)
- 본문 첫 줄에서 ↑(커서가 문서 첫 시각 줄일 때): 제목 끝으로 포커스
- 새 문서(F-111 3.2): 본문 제목에 포커스 + 전체 선택 (지금 상단바에 하던 것)

### 2.4 읽기 전용·빈 상태
- 지금 상단바 제목의 `disabled`·`readOnly` 조건(보기 권한 F-212, 편집 잠금 F-213, 403 강등, 공유받은 문서 화면 등)을 그대로 본문 제목 `readOnly` 로. 읽기 전용이면 자리 표시·포커스 링 없이 글자만처럼 보인다
- 빈 상태 S-2 는 문서가 없으니 제목도 없다

### 2.5 상단바
- 제목 입력을 뺀다. 가운데는 빈 자리(`flex: 1`)로 두어 보기 모드·공유·내보내기·계정이 오른쪽에 붙는다. 좁은 창 앞 묶음(F-159) 그대로
- `document.title` 은 바꾸지 않는다(이 명세 범위 밖)
