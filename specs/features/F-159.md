# F-159 사이드바 전체 높이·머리 줄·너비 조절

작성일: 2026-09-14
상태: 사용자 요청(2026-09-14 "사이드바 크기 조절 가능해야 함", "로고|사이드바 접기|검색 은 사이드바에 포함되는 느낌으로 — `로고|접기|검색| 제목 … |` 아래 `새 문서` `새 폴더`"). **F-152 커밋 직후, F-153 보다 먼저** 시작

## 2. 요구사항

### 2.1 레이아웃 (1024px 이상)
```
┌──────────────────────┬──────────────────────────────────────────────┐
│ ▣ {제품명}   [▯][⌕] │ [ 문서 제목 ]      [편집|원문|보기] [공유] [↓] │ ← 상단바(메인 열만)
│                      ├──────────────────────────────────────────────┤
│ ＋ 새 문서           │ 편집 영역                                     │
│ ＋ 새 폴더           │                                              │
│ ↥ 가져오기           │                                              │
│ …                    │                                              │
└──────────────────────┴──────────────────────────────────────────────┘
```
- 사이드바가 창 **맨 위부터 맨 아래까지** 한 열. 오른쪽 1px `--rule` 테두리도 맨 위부터 이어진다. 바탕 `--paper` 그대로
- 메인 열 = 상단바(높이 `--topbar-h`, 아래 테두리) + 알림 띠 + 내용 + 상태바. 상단바 아래 테두리는 메인 열 폭만
- 사이드바 머리 줄에는 아래 테두리가 없다

### 2.2 사이드바 머리 줄 (펼침)
- 높이 `--topbar-h`, 세로 가운데 정렬. 사이드바 맨 위, `새 문서` 위
- 왼쪽: 제품 아이콘 + 제품명 (F-142 3.3 모양). 제품 아이콘 왼쪽 x = 창 왼쪽 + 14px (지금과 같음)
- 오른쪽: 토글 · 검색 (F-151 2.2 표시 그대로. **검색 동작은 2026-09-21 F-287 이 대체** — 툴팁 `검색`, `aria-disabled` 없음, 누르면 검색 대화상자 D-6). 검색 버튼 오른쪽 끝 = 사이드바 오른쪽 테두리 − 8px (F-151 A1 과 같음)
- 너비가 좁아 제품명이 모자라면 말줄임(`…`). 토글·검색은 줄어들지 않는다
- 머리 줄 아래 `새 문서` 까지 간격은 지금 사이드바 위 여백(10px)

### 2.3 레일 (접힘)
- 머리 줄 높이는 같고 **토글만** 가운데. 제품 아이콘·이름은 숨긴다
- 검색은 레일 위쪽 버튼 맨 앞으로: 검색 · 새 문서 · 새 폴더 · 가져오기 (아이콘, 툴팁 `검색`. **2026-09-21 F-287 이 `aria-disabled` 를 없애고 실제 동작을 붙였다**)
- 메인 열 상단바에는 제품명·토글이 없다

### 2.4 좁은 창 (1024px 미만)
- F-151 그대로: 상단바 왼쪽에 제품 아이콘·이름·토글·검색(내용 폭), 사이드바는 상단바 아래에 겹쳐 열린다(머리 줄 없음). 너비 손잡이 없음
- 겹쳐 열린 사이드바 폭 = 저장된 너비, 단 창 폭 − 48px 이하

### 2.5 너비 조절
- 사이드바 오른쪽 테두리에 손잡이: 테두리 가운데를 중심으로 폭 8px 투명 영역, 창 맨 위부터 맨 아래까지. 커서 `col-resize`
- 호버·포커스·끄는 중에는 테두리 자리에 2px 선 `color-mix(in srgb, var(--ink) 25%, transparent)` (전환 F-149)
- 끄는 동안 사이드바 폭이 포인터를 따라간다. 폭 전환 애니메이션 없음, 글자 선택 막음, 편집 영역은 남은 폭에서 지금 규칙대로 가운데 정렬
- 범위: 최소 200px, 최대 `min(480px, 창 폭 − 560px)` (메인 열이 너무 좁아지지 않게). 기본 224px
- 놓으면 `md.sidebarWidth` 에 정수로 저장, 다음 실행에도 쓴다. 더블클릭은 224px 로 되돌리고 저장
- 창을 줄여 저장값이 최대보다 크면 화면에서만 최대로 줄인다 (저장값 유지)
- 키보드: 손잡이는 `role="separator"` `aria-orientation="vertical"` `aria-label="사이드바 너비"` `aria-valuemin`·`aria-valuemax`·`aria-valuenow`, `tabindex="0"`. ←/→ 16px, 누를 때마다 저장
- 레일·좁은 창에서는 손잡이가 없다. 레일 → 펼침은 저장된 너비로
- `--sidebar-w` 토큰 기본값은 224px 그대로 두고, 실제 폭은 앱 셸에 인라인 CSS 변수로 준다
- 저장값이 숫자가 아니거나 범위 밖이면 기본값·범위로 고친다

### 2.6 포커스 순서
사이드바(토글 → 검색 → 새 문서 … 설정 → 너비 손잡이) → 상단바(제목 → 보기 모드 → 공유 → 내보내기) → 편집 영역. DOM 순서도 같게 한다. 좁은 창은 F-151 2.5 그대로

### 2.7 F-153 과의 관계
- F-153 2.1 상단바 아이콘 버튼 모양 규칙은 머리 줄 토글·검색에도 같게 적용한다 (F-153 이 이 명세 뒤에 온다)
