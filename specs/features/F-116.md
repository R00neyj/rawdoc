작성일: 2026-09-14
상태: 사용자 지시로 구현 착수. B5 묶음
근거: `specs/product.md` F-116·4.4, `specs/features/F-102.md` 3장(서체 크기)

## 1. 파일
- `vite.config.js` 의 `VitePWA({ workbox })`

## 2. 요구사항
- 전략 `generateSW` (기본). 서비스 워커는 빌드 결과에만 생성. dev 서버에서는 켜지 않는다 (`devOptions.enabled: false`)
- `workbox.globPatterns: ['**/*.{js,css,html,woff2,png,webmanifest}']`
- `workbox.maximumFileSizeToCacheInBytes: 3 * 1024 * 1024` — Workbox 기본 상한은 2MiB 이고 `PretendardVariable.woff2` 가 2,057,688바이트라 여유가 거의 없다
- `workbox.navigateFallback: 'index.html'`, `cleanupOutdatedCaches: true`
- 런타임 캐시 규칙을 추가하지 않는다. 외부 요청이 없으므로 precache 로 충분하다
- 캐시 이름에 제품명이 들어가지 않는다 (Workbox 기본 이름 사용, `cacheId` 지정 안 함)
