## 3. 요구사항

### 3.1 테마 3종
- 적용 테마: `white` / `sepia` / `dark`. `<html data-theme="…">`
- 설정값 `md.theme`: `system`(기본) / `white` / `sepia` / `dark`. `system` 이면 `prefers-color-scheme: dark` → `dark`, 아니면 `white`. 앱이 열린 동안 OS 설정이 바뀌면 즉시 따라간다
- `theme.js`: `resolveTheme(pref, prefersDark) → 'white'|'sepia'|'dark'`. 모르는 값은 `system` 으로 본다
- 첫 화면부터 맞는 색: `main.jsx` 가 React 렌더 전에 `data-theme` 를 넣는다 (지금 `data-heading-font` 와 같은 자리)
- 각 테마에 `color-scheme` 을 준다 (화이트·세피아 `light`, 다크 `dark`). 기본 체크박스·입력칸이 테마를 따르게 한다
- 토큰 초안 (화이트 = 지금 값). 3.1 대비 기준에 못 미치면 **같은 색 계열에서 명도만** 조정하고 바꾼 값을 보고한다

### 3.3 본문 서체 토글
- 토큰 `--font-body: var(--font-sans)`. `:root[data-body-font='serif'] { --font-body: var(--font-serif) }`. 설정값 `md.bodyFont`: `sans`(기본) / `serif`
- `--font-body` 를 쓰는 곳: 편집 모드 문단·목록·인용·표(칸 포함)·콜아웃 본문, 보기 모드 본문
- 그대로 두는 곳: UI(버튼·사이드바·상단바·상태바·대화상자), 원문 모드, 코드·인라인코드, 프론트매터, 제목(`--font-display`)
- 세리프 본문용으로 Noto Serif KR 400(`korean-400.css`·`latin-400.css`)을 import 한다. 굵게는 기존 700. 서체 파일은 기존 700 과 같은 방식으로 precache 에 들어가야 한다
- 제목 서체와 본문 서체는 서로 독립이다

### 3.4 스크롤바
- 앱 안 모든 스크롤 영역(사이드바, 편집 영역, 보기 모드, 코드블록·표 가로 스크롤, 대화상자·메뉴)에 같은 모양
- `::-webkit-scrollbar` 계열로 만든다 (판정 브라우저 Chrome, Q7). 같은 요소에 표준 `scrollbar-color`·`scrollbar-width` 를 주지 않는다 (Chrome 은 표준 속성이 있으면 `::-webkit-scrollbar` 를 무시한다)
  - 두께 10px, 트랙·모서리 투명
  - 손잡이: `color-mix(in srgb, var(--ink) 22%, transparent)`, 둥근 끝, 안쪽 2px 투명 테두리(`background-clip: content-box`)
  - 손잡이 호버: 38%
- 테마를 바꾸면 따라 바뀐다 (`--ink` 참조)

### 3.5 위키링크 자동완성 서체
- 원인: CM6 자동완성 기본 테마가 목록에 `font-family: monospace` 를 주고, 그 선택자 구체성이 `wikilink.css` 규칙보다 높다. 한국어 Windows 에서 `monospace` 는 굴림체로 보인다
- 수정: 자동완성 목록과 항목 글자를 `--font-sans` 로. 선택자 구체성을 올리거나 같은 방식으로 확실히 이긴다 (`!important` 는 쓰지 않는다)

### 3.6 한국어 서체 자간 (2026-09-14 추가)
- 근거: 사용자 요청 "한국어 서체인 경우 letter spacing -0.02em 적용해야함". `specs/design.md` 2.4 자간
- 한국어 서체(`--font-sans`·`--font-serif`·`--font-body`·`--font-display`)로 그리는 모든 글자: `letter-spacing: -0.02em`. UI·편집 모드·보기 모드·대화상자·툴팁 전부
- 고정폭(`--font-mono`)으로 그리는 곳은 `0`: 원문 모드 전체, 인라인코드, 코드블록(편집·보기), 프론트매터, 그 밖에 `--font-mono` 를 쓰는 요소와 그 안쪽 요소
- **요소마다 자기 글자 크기 기준 -0.02em** 이어야 한다. `letter-spacing` 의 em 은 선언한 요소에서 길이로 굳어 상속되므로, 제목처럼 크기가 다른 요소도 자기 크기의 -0.02em 이 되게 한다 (예: 토큰 `--tracking` 을 두고 모든 요소에 `letter-spacing: var(--tracking)`, 고정폭 자리에서 `--tracking: 0`)
- 이미 `-0.02em` 을 따로 준 규칙(상단바 제품명 등)은 중복을 정리한다
- 파일: `tokens.css`, 그리고 `--font-mono` 를 쓰는 규칙이 있는 `app.css`·`markdown.css`·`frontmatter.css`·`preview.css` (부분 Edit)
