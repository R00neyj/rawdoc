# F-133 YAML 프론트매터

작성일: 2026-09-14
상태: 사용자 요청 13번(2026-09-14) "yaml 프론트메터도 넣어야함" — 문서 기능으로 확인함. C4 묶음 (F-130·F-131·F-132 와 병렬). F-128 완료 후
근거: CLAUDE.md 불변조건(원문 보존, decoration 은 내용을 바꾸지 않음)

> 프론트매터(front matter): 문서 맨 앞에 `---` 줄로 감싸 적는 YAML 형식 속성(제목, 태그, 날짜 등). Jekyll·Hugo·Obsidian 등이 쓴다

## 1. 현재 문제
- lezer 마크다운 파서는 프론트매터를 모른다. `---` 첫 줄은 구분선(`HorizontalRule`)으로, `title: 글\n---` 는 Setext 제목 2(`SetextHeading2`)로 읽는다. 그래서 편집 모드에서 첫 `---` 가 선으로 바뀌고 속성 줄이 큰 제목이 된다. 보기 모드(markdown-it)도 같은 이유로 선 + 제목으로 그린다

## 3. 요구사항

### 3.1 인식 규칙
- 문서 **첫 줄**이 정확히 `---` (뒤 공백 허용)
- 그 뒤 줄 중 처음으로 정확히 `---` 또는 `...` (뒤 공백 허용)인 줄까지가 프론트매터
- 닫는 줄이 없으면 프론트매터가 아니다 (지금처럼 일반 마크다운)
- 문서 맨 앞 BOM 은 `decodeMarkdown` 이 이미 처리한다. 첫 줄 앞에 빈 줄이 있으면 프론트매터가 아니다
- `lib/frontmatter.js`: `findFrontmatter(text) → { from, to, contentFrom, contentTo, closeMark: '---'|'...' } | null` (LF·CRLF 모두)

### 3.2 편집 모드 (`editor/frontmatter.js`, `lines.js`)
- 블록 파서 확장이 문서 시작의 프론트매터를 `Frontmatter` 노드(자식: 여는·닫는 `FrontmatterMark`)로 만든다. 이 범위 안에서는 구분선·Setext 제목·목록 등 다른 블록으로 읽지 않는다
- 원문을 숨기지 않는다. 기호도 그대로 보인다 (위젯 없음)
- 줄 클래스: 모든 줄 `md-frontmatter`, 첫 줄 `md-frontmatter-first`, 마지막 줄 `md-frontmatter-last`
- 모양: 줄 바탕 `--md-bg-muted`, 글자 `--font-mono` 85% · 색 `--ink-2`, `---` 줄 글자색 `--muted`, 첫 줄 위·마지막 줄 아래 안쪽 여백 8px (세로 `margin` 금지, F-124 3.4), 첫·마지막 줄 모서리 6px
- 원문 모드는 파서 확장만 적용되어 기호 색 강조가 구분선·제목으로 잘못 칠해지지 않는다. 줄 모양은 없음
- 자동 짝 기호(F-127)·링크 클릭(F-129)·위키링크(F-131)는 프론트매터 안에서 동작하지 않는다 (펜스 코드블록과 같은 취급). 각 확장이 구문 트리로 `Frontmatter` 안인지 확인한다 — F-127·F-129 파일을 이 명세가 한 줄씩 고치는 것은 허용

### 3.3 보기 모드 (`renderMarkdown.js`)
- 변환 전에 `findFrontmatter` 로 떼어 내고 나머지 본문만 markdown-it 에 넣는다
- 속성 해석(`lib/frontmatter.js` `parseSimpleProperties(content) → [{ key, value }] | null`)
  - 모든 비어 있지 않은 줄이 `키: 값` 형식(키는 `[^\s:#][^:]*`, `#` 으로 시작하는 줄은 주석으로 건너뜀)이거나, 바로 앞 키의 목록 항목(`  - 값`)일 때만 성공
  - 값은 앞뒤 공백 제거, 감싼 따옴표(`"` `'`) 한 쌍 제거. 목록은 값 배열
  - 인라인 값(`[a, b]`, `{ x: 1 }`)은 해석하지 않고 문자열 그대로 둔다
  - 목록 항목이 아닌 들여쓴 줄(중첩 객체, 여러 줄 문자열 `|` `>` 의 본문)이 하나라도 있으면 null
- 성공: 본문 위에 `<table class="markdown-frontmatter"><tbody><tr><th>{키}</th><td>{값}</td></tr>…</tbody></table>`. 목록 값은 `, ` 로 잇는다. 모두 이스케이프
- 실패: `<pre class="markdown-frontmatter-raw"><code>{내용 원문}</code></pre>`
- 빈 프론트매터(`---\n---`)는 아무것도 출력하지 않는다
- `.markdown-frontmatter` 스타일: 표 너비 100%, 글자 85%, `th` 는 `--ink-2` 굵기 600 · 너비 30% · 왼쪽 정렬, 칸 테두리 `--md-border`, 표 아래 여백 1rem. F-124 표의 짝수 행 바탕은 적용하지 않음

### 3.4 그 밖
- 내보내기·공유·가져오기는 원문 그대로 (바이트 동일)
- 문서 제목과 프론트매터 `title` 은 연결하지 않는다 (M1)
- 상태바 글자 수·단어 수는 프론트매터를 포함해 센다 (지금과 같음)
