# F-216 휴대폰 폭 상단바 넘침, 이미지 정렬 버튼 아이콘 크기

작성일: 2026-09-15
상태: 사용자 보고(2026-09-15 "핸드폰에서 불필요한 가로 세로 스크롤 생김", "아이콘보다 버튼이 작아서 그런거네"). 메인 수정
근거: 모바일 화면 조정은 M1 범위 밖이었으나(F-154 2.2) 교안 공유를 휴대폰으로 열어 보게 되어 넘침만 고친다. 모바일 전용 배치는 여전히 범위 밖

## 1. 파일 소유

| 파일 | 변경 |
| --- | --- |
| `src/styles/app.css` | 폭 600px 이하 상단바 |
| `src/styles/image.css` | 정렬 버튼 안 svg 크기 |

## 2. 요구사항

### 2.1 상단바 (폭 ≤ 600px)
- 실측(Pixel 7, 412px): 상단바 내용 454px → 계정 버튼이 화면 밖, 문서 전체가 454px 로 넓어져 브라우저가 축소하면서 세로 스크롤도 생김. 상태바(글자 수)는 412px 로 원인 아님
- 좁은 창 상단바 앞 묶음(F-159)에서 제품명 글자를 숨긴다(아이콘은 남김). 준비 중 검색 버튼(F-143 3.5)도 숨긴다
- 상단바 요소 간격 12px → 4px, 좌우 여백 14px → 8px
- 상단바는 가로로 넘친 것을 잘라 문서 폭을 넓히지 않는다(`overflow-x: clip`, 툴팁이 화면 끝에서 잘릴 수 있음)
- 601px 이상은 바꾸지 않는다

### 2.1a 줄바꿈 (design.md 2.4)
- `body` 에 `word-break: keep-all; overflow-wrap: break-word`, CM6 줄바꿈 줄(`.cm-lineWrapping`)도 `keep-all` (2026-09-15 사용자 "word break keep all로 예쁘게 자동 줄넘김")

### 2.2 이미지 정렬 버튼 (F-157 2.3)
- 버튼 안 svg 를 원본 파일 크기(48px) 대신 18px 로. 버튼 28×28 그대로

### 2.3 읽기 전용 링크 화면 표·콜아웃 (F-210 2.4)
- 사용자 보고(2026-09-15 "읽기전용 링크 페이지에서 표, 콜아웃이 다르게 렌더링"). 원인: `markdown.css`·`callout.css`·`frontmatter.css` 덮어쓰기 선택자가 `.app-shell` 아래로만 한정되어 `.public-view` 에서 github 기본 모양으로 보임
- 선택자 앞부분을 `:is(.app-shell, .public-view)` 로 바꾼다(우선순위 그대로)

### 2.4 보기 화면 이미지 사라짐 (F-158 2.1)
- 사용자 보고(2026-09-15 "읽기전용 공유 링크에서 이미지 블랙박스, src 속성 자체가 빠져있음"). 원인: `Viewer` 가 매 렌더 새 `{ __html }` 객체를 넘겨 React 가 같은 html 로도 `innerHTML` 을 다시 씀 → 채운 `img.src` 가 지워지고 이미지 효과는 `html` 이 같아 다시 돌지 않음. 공개 보기 화면은 서비스 워커 등록 뒤 한 번 더 그려져 항상 재현(F-217 이전부터)
- `dangerouslySetInnerHTML` 객체를 `html` 기준 `useMemo` 로 고정한다
