# F-2166 공유 폴더 안에 편집 초대자가 새 문서 만들기 — 클라이언트

상태: 승인됨(2026-10-24, 열린 질문 없음 — "결정 없으면 바로 진행" 상시 지시로 승인) — 사용자 버그 보고(2026-10-24) "내가 공유한 폴더에서 다른 사람이 위키링크로 새 문서 생성해도 나머지 사람들에겐 안보임". 흐름도 [`specs/wireframes/shared-folder-new-doc-flow.html`](../wireframes/shared-folder-new-doc-flow.html)(확정)·grill 결정 1~11 그대로, 서버 계약은 F-4017 2장 그대로. **배포 순서: F-4017 워커가 먼저.** 열린 질문 없음(남은 갈림길은 기본값이 분명해 본문에서 정함)

## 근거 (2026-10-24 HEAD `8d40a36`)
- **폴더 역할은 문서 `role` 로 못 안다**: `worker/grants.ts` `handleGetShared` 의 문서 `role = higherRole(폴더 사슬, 문서 초대)` — 문서 초대 edit + 폴더 view 면 `edit` 인데 F-4017 3.1 5번은 403. `viaFolder` 는 사슬에서 가장 가까운 초대 폴더, F-4017 3.2 `folders[].role` 은 그 폴더의 사슬 최고값 → **사슬 역할 = `folders` 의 `viaFolder.id` 항목 `role`**. `folders` 는 초대 폴더만 준다 — 하위 폴더는 원본 문서 `folderId` 를 보내면 서버가 사슬로 판정
- `ServerStore` 전용 메서드는 `withE2ee`(`...inner`)·`withTabBroadcast`(`...store`)·`bootFlow` `setStore` 펼치기로 App 까지 온다 → `Store`(`src/types.ts`)는 넓히지 않는다(로컬 저장소엔 공유가 없다)
- 실시간: 새 경로는 outbox·`store.create` 래퍼(`createdHereRef`)를 안 거쳐 `decideDocPath` 가 `role:'edit'` 온라인 → `realtime`. DocRoom 은 D1 행에서 시드(F-4017 3.1 끝). `mergeBootList` 는 요청 직전 스냅숏 id 만 지워 만든 직후 `setDocs` 한 문서는 안전하나, `lastSharedList()` 는 진행 중 `runList` 가 덮을 수 있다 → 3.2 ③
- **측정**: Playwright 1.63.0 `urlMatches`(스크래치패드 `glob2.cjs`) — `'**/api/shared'` 는 `…/api/shared?folders=1` 에 안 맞고, `'**/api/shared*'` 는 맞으며 `/api/shared/folders/x/docs` 엔 안 맞는다

## 2. 계약
```ts
// docsApi.ts — getShared 는 GET /api/shared?folders=1. 몸통이 배열(옛 워커)이면 { docs: 배열, folders: null }
export type SharedFolderItem = { id: string; name: string; role: 'edit' | 'view'; ownerEmail: string }
export function getShared(): Promise<{ docs: SharedDocMeta[]; folders: SharedFolderItem[] | null }>
export function createSharedFolderDoc(folderId: string, body: { id: string; title: string; content: string; lineEnding: LineEnding }): Promise<SharedDocMeta>
```

- `createSharedFolderDoc` 오류: 413 `owner_quota_exceeded` → 새 `ApiErrorKind` `'owner_quota_exceeded'`(+`resource`), 그 밖 413 `too_large`, 403 `account_blocked`/그 밖 403 `forbidden`, 404 `not_found`, 409 `id_taken`, 400 `invalid`, 429 `rateLimitedError`, 401·5xx·네트워크는 기존 분류

## 3. 동작
### 3.1 판정 (순수 함수)
- `wikiCreatePlan(origin, folders)` — origin = `source` 가 있으면 `docs` 의 `source.docId`, 없으면 `currentDoc`. `findLinkFolder` 가 내 폴더를 찾은 경로식 링크는 판정 전에 지금 흐름
  - 공유 문서 아님 → `own`(지금 흐름) / 공유 문서 + `viaFolder` + 사슬 역할 `edit` → `shared`, 폴더 = origin `folderId`(하위 폴더 그대로, 결정 9) / 그 밖(보기 초대 폴더·문서 하나만) → `fallback` = 내 최상위 `store.create` + 알림 A
  - `folders` 가 `null`(목록 실패·옛 워커)이거나 항목이 없으면 사슬 역할 대신 origin `role` — 틀리면 서버 403 을 3.4 F 가 받는다
- `sharedNewDocAllowed(folderId, folders)` — `folders` 에 그 id 가 `edit` 로 있을 때만 참 → 입구 A `새 문서`
- `sharedFolderGroups(sharedDocs, folders)` — 지금 `viaFolder` 묶음 순서 그대로, 그 뒤 문서 없는 `folders` 항목을 이름순(`localeCompare(…, 'ko')`). 이름은 `folders` 값 우선. 둘 다 비면 `공유받음` 머리도 없다
### 3.2 저장소 (`serverStore.ts`)
- `fetchShared` 가 `folders` 도 받는다. 실패(`null`)면 앞 값 유지(`knownSharedIds` 와 같은 규칙), 배열 몸통이면 `null`. 바뀌면 구독자를 부른다
- `createInSharedFolder`: id 는 `crypto.randomUUID()`. 성공하면 ① `knownSharedIds` 에 넣고 `md-remote`·outbox 에는 안 넣는다(F-212 2.4) ② `lastSharedList` 가 있으면 덧붙인다 ③ 요청이 먼저 나간 `runList` 가 끝나며 덮어도 그 문서를 지킨다(`session.createdDocIds` 와 같은 생각) ④ 돌려주는 `Doc` = 응답 메타 + 보낸 `content`. 실패는 `ApiError` 그대로. 탭 신호는 안 보낸다 — 다른 탭은 F-2120 자동 갱신에서 붙는다
### 3.3 만들기 순서 (입구 A·B 공통)
1. 사전 검사 — `syncState.online === false` 면 알림 O, 내 계정 막힘(`accountBlocked`)이면 기존 L5 문구. 보기 모드 전환·`beforeLeaveDoc` 전에 끝내 아무것도 안 바뀐다
2. 지금 흐름대로 편집 모드·`beforeLeaveDoc`·템플릿 — 입구 A 는 `createNewDoc` 과 같이 `제목 없는 문서`·`{{title}}` 빈 글자, 입구 B 는 `{{title}}` = 링크 제목(F-2037 4.1). `ensureE2eeOpenForFolder` 는 건너뛴다
3. `createInSharedFolder` 실패 → 3.4, 화면·주소·목록 그대로. 성공 → `setDocs`·열기·제목 포커스(지금 위키링크 새 문서와 같다). `공유받음` 열림 상태는 안 바꾼다
### 3.4 문구 (`sharedCreateErrorMessage(err)`)
| # | 언제 | 종류 | 문구 | 덧붙임 |

### 3.5 사이드바 (입구 A, 빈 폴더)
- 폴더 이름 줄 메뉴 = [`새 문서`(`IconNoteAdd`, `sharedNewDocAllowed` 일 때만, 첫 줄), `공유에서 나가기`]. `⋯`·우클릭·길게 누르기·선택 안 바꿈은 F-2115 2.1 그대로. 오프라인이면 `disabled` 모양, 누르면 알림 O
- 빈 폴더도 `li.shared-doc-folder[data-shared-folder-id]` 로 그린다(F-2116 폴더로 스크롤도 닿는다). 빈 폴더에서 나가면 D-17 문서 수 0. 로컬 저장소면 두 prop 을 넘기지 않는다
