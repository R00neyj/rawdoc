## 2. 요구사항

### 2.1 D1 `migrations/0003_links.sql`
```sql
CREATE TABLE share_links (
  token TEXT PRIMARY KEY,
  owner_id TEXT NOT NULL REFERENCES users(id),
  target_type TEXT NOT NULL CHECK (target_type IN ('doc','folder')),
  target_id TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  revoked_at INTEGER
);
CREATE INDEX share_links_target ON share_links(target_type, target_id);
```
- `folder` 는 F-211 이 쓴다. 이번에는 `doc` 만 만든다
- 토큰: `crypto.getRandomValues` 32바이트 → base64url(패딩 없음) 43자. 형식이 다르면 조회하지 않고 404

### 2.2 링크 관리 (로그인, `/api`)
| 요청 | 동작 |
| --- | --- |
| `GET /api/docs/:id/link` | 끊기지 않은 링크 `200 {"token"}`, 없으면 `404 {"error":"no_link"}` |
| `POST /api/docs/:id/link` | 끊기지 않은 링크가 있으면 `200` 그 토큰, 없으면 새로 `201` |
| `DELETE /api/docs/:id/link` | 끊기지 않은 링크 전부 `revoked_at` 기록 → `204` |

- 문서 소유가 아니면 404 (F-206 2.2)
- 재발급은 끊고 다시 만들기(DELETE → POST)

### 2.3 공개 조회 (로그인 없음, `/pub`)
- `GET /pub/docs/:token` → `200 {"title","content","lineEnding","updatedAt"}`. 토큰 없음·끊김·문서 삭제면 `404 {"error":"not_found"}` (이유를 구분하지 않는다)
- 응답 헤더: F-204 API 헤더 + `X-Robots-Tag: noindex`, `Referrer-Policy: no-referrer`
- **이 경로는 읽기만 한다.** `/pub` 아래에 쓰기 메서드 라우트를 두지 않는다 (405). 편집 권한은 링크로 절대 생기지 않는다
- 원본이 바뀌면 다음 조회부터 바뀐 내용 (캐시 `no-store`)

### 2.4 공개 보기 화면 S-5 (`#/p/{토큰}`)
- **저장소를 열지 않는다.** 첫 실행 안내 문서를 만들지 않고, `md.lastDocId`·`md.firstRunDone` 등 설정을 쓰지 않는다. 사이드바·상단바(모드·공유·계정)·상태바 없음
- 배치: 머리 줄(문서 제목 + 오른쪽 `.md 내보내기` 버튼, 아이콘 + 글자) → 본문(보기 모드와 같은 `Viewer`, 폭·여백 F-143 과 같음) + 오른쪽 목차(F-144 `Outline`, `viewMode='view'`)
- 본문 글자 선택·복사 가능, 코드블록 복사 버튼(2.5), 위키링크는 링크로 만들지 않는다(F-130 과 같음)
- 이미지: F-209 전까지 자리 표시 `이미지를 불러올 수 없습니다`
- `.md 내보내기`: 받은 `content` 를 그대로 `{제목}.md` 다운로드 (F-112 파일명 규칙, 줄바꿈은 받은 원문 그대로). 이미지 zip 은 F-209
- 불러오는 중: 본문 자리에 `불러오는 중…`. 404: `링크가 없거나 끊겼습니다.` 네트워크 오류: `링크를 불러오지 못했습니다. 연결을 확인하세요.` + `다시 시도` 버튼
- 문서 제목을 `document.title` 로
- 테마·글자 크기·서체 설정은 이 브라우저의 기존 설정을 읽는다 (없으면 기본값). 화면 안에서 바꾸는 UI 는 F-230 (초안, 2026-09-15 사용자 요청)

### 2.5 코드블록 복사 버튼
- `Viewer` 에 `codeCopy?: boolean`. 참이면 그린 뒤 `pre > code` 마다 오른쪽 위에 버튼(아이콘 `IconCopy` + 툴팁 `코드 복사`)
- 누르면 `navigator.clipboard.writeText(code.textContent)` → 아이콘을 `IconCheck` 로 1.5초. 실패하면 툴팁 `복사하지 못했습니다`
- 이번에는 S-5 에서만 켠다. 보기 모드(F-123)는 그대로
- 버튼은 `markdown-body` 안 코드 글자와 겹치지 않게 `pre` 의 오른쪽 위 여백에. 가로 스크롤해도 버튼은 제자리

### 2.6 소유자 메뉴 (C)
- 공유 메뉴(F-130)에 `store.kind === 'server'`(F-207, 로그인해 서버 문서를 열었을 때)일 때만 항목 추가
  - `읽기 전용 링크 복사` (IconLink 계열 기존 아이콘) → 저장 대기 입력 flush → `POST /api/docs/:id/link` → `{origin}/#/p/{토큰}` 복사 → 알림 `읽기 전용 링크를 복사했습니다. 링크를 아는 사람은 로그인 없이 볼 수 있습니다.`
  - `읽기 전용 링크 끊기` (IconLinkOff) — 메뉴를 열 때 `GET` 으로 링크가 있을 때만 보인다 → `DELETE` → 알림 `읽기 전용 링크를 끊었습니다. 이전 주소는 더 이상 열리지 않습니다.`
- 오프라인·5xx: error 알림 `링크를 만들지 못했습니다. 연결을 확인하세요.` / `링크를 끊지 못했습니다. 연결을 확인하세요.`
- 기존 `링크 복사`(해시)·`마크다운 복사` 는 그대로
