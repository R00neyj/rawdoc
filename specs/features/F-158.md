## 2. 요구사항

### 2.1 보기 모드
- markdown-it `html: false` 는 그대로. 블록 규칙을 하나 더해, **최상위**(`state.level === 0`, 목록·인용 밖)에서 `parseImageBlock` 이 성공한 3줄(뒤는 빈 줄 또는 문서 끝)만 아래로 출력한다
  ```html
  <div class="md-image md-image--center" style="width:480px"><img data-attachment="0f3a9c2e7b1d4a58" alt="다이어그램" width="480"></div>
  ```
  - 모든 값은 해석한 값에서 다시 이스케이프해 쓴다 (원문 문자열을 그대로 붙이지 않는다). `width` 는 숫자만
  - `src` 는 출력하지 않는다. `renderMarkdown` 은 순수 함수로 남는다
- 그 밖(외부 `src`, 형식 틀림, 목록·인용 안)은 지금처럼 이스케이프된 글자. `![a](b)` 는 F-123 대로 링크
- `Viewer.jsx` 는 그린 뒤 `img[data-attachment]` 마다 `resolveAttachment` 로 blob URL 을 `src` 에 넣고 `aspect-ratio` 를 준다. `null` 이면 F-157 2.2 자리 표시로 바꾼다. 다시 그리거나 사라질 때 blob URL 해제
- 모양은 F-157 2.2 와 같은 `image.css` (정렬 margin, 모서리). 정렬 버튼·손잡이는 없다

### 2.2 공유
- 공유 화면(S-4)은 첨부를 읽지 않는다. 이미지 블록 자리는 자리 표시 + 문구 `공유 링크에는 이미지가 담기지 않습니다`
- `링크 복사`: 문서에 `extractAttachmentRefs` 가 1개 이상이면 알림 `공유 링크를 복사했습니다. 이미지는 링크에 담기지 않습니다.` (없으면 F-130 문구 그대로)
- `마크다운 복사`·`파일로 공유…` 는 `.md` 원문만 (F-130 그대로)
- `내 문서로 가져오기` 한 문서의 이미지 블록은 첨부가 없어 자리 표시로 보인다 (허용)

### 2.3 내보내기
- `.md 내보내기` 를 누르면 에디터 원문(`getText(lineEnding)`)에서 `extractAttachmentRefs` 를 구한다
  - 0개: 지금(F-112)과 같다
  - 1개 이상: 저장소에서 첨부를 읽어 `{파일명}.zip` 을 내려받는다. 파일명은 `toFileName(title)` 의 `.md` 를 `.zip` 으로
- zip 안
  ```
  {toFileName(title)}          ← .md. 바이트는 zip 이 아닐 때 내보내는 파일과 같다
  attachments/{id}.{ext}       ← 저장된 원본 바이트
  ```
  - 압축 수준 0 (이미지는 이미 압축돼 있다). `fflate` `zipSync`
- 원문에 있지만 저장소에 없는 첨부는 빼고 알림(warn) `이미지 {N}개를 찾을 수 없어 빼고 내보냈습니다.` 전부 없으면 zip 대신 `.md` 만 내보내고 같은 알림
- 버튼 이름은 `.md 내보내기` 그대로. 툴팁 `.md 내보내기 (이미지가 있으면 .zip)`
- 저장 대기 flush 는 F-112 대로 기다리지 않는다
