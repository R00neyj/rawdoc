## 2. 문법

| 원문 | 대상 제목 | 보이는 글자 |
| --- | --- | --- |
| `[[회의록]]` | `회의록` | `회의록` |
| `[[회의록\|9월 회의]]` | `회의록` | `9월 회의` |
| `[[회의록#결정]]` | `회의록` (`#` 뒤는 M1 에서 무시) | `회의록#결정` |

- 정규식(한 줄 안): `\[\[([^\[\]\|\n]+?)(?:\|([^\[\]\n]+?))?\]\]`. 대상 제목은 앞뒤 공백 제거, 비면 위키링크 아님
- 펜스 코드블록·인라인코드·표 칸 안은 위키링크가 아니다 (구문 트리로 판정)
- 이미지식 `![[…]]` 는 대상이 아니다 (원문 그대로)
- 원문은 바꾸지 않는다. 내보내기 파일에는 `[[…]]` 그대로 남는다

### 2.1 제목 매칭 (`wikiLink.js`)
- `resolveWikiTarget(target, docs) → doc | null`. `docs` 는 `updatedAt` 내림차순 목록
  1. 제목(앞뒤 공백 제거)이 대상과 정확히 같은 문서
  2. 없으면 대소문자 무시(`toLocaleLowerCase('ko')`)로 같은 문서
  3. 여러 개면 목록 앞(최근 수정)의 것
- 제목이 빈 문서는 매칭하지 않는다
- `findWikiLinks(lineText) → [{ from, to, target, alias, targetFrom, targetTo }]` (줄 안 위치)

## 3. 편집 모드

- 커서·선택이 위키링크 범위 `[from, to]` 에 닿지 않을 때 (F-129 와 같은 범위 단위)
  - `[[` `]]` 숨김. 별칭이 있으면 `대상|` 도 숨겨 보이는 글자만 남긴다
  - 보이는 글자에 mark: 문서가 있으면 `md-wikilink`, 없으면 `md-wikilink md-wikilink--missing`. `title` 속성: 있으면 대상 제목, 없으면 `새 문서 만들기: {대상}`
- 닿으면 원문 전체 표시, 기호 색만 (`--accent`)
- 클릭(기호가 숨겨진 상태, 수정 키 없음, 조합 중 아님): `mousedown` 기본 동작을 막고 `onOpenWikiLink(target)` 호출. Ctrl(⌘)+클릭은 커서 이동(편집 진입) — F-129 3.3 과 같다
- 원문 모드는 표시·클릭 없음
- 제목 목록이 바뀌면(문서 생성·삭제·제목 변경) 있음/없음 표시를 다시 계산한다: `createEditor` handle 에 `setWikiTitles(titles: string[])` — 내부는 `StateEffect` + `StateField`, 재계산은 기존 프리뷰 확장과 같은 IME 규칙 (조합 중 보류, 종료 시 따라잡기)

### 3.1 자동완성
- `[[` 뒤에서 글자를 치면(`[[` 직후 포함) 제목 목록 팝업. `@codemirror/autocomplete` 의 `autocompletion({ override: [source] })`
  - 후보: 제목에 입력 글자가 들어 있는 문서(대소문자 무시), 최근 수정순, 최대 20개. 현재 문서도 포함. 제목이 빈 문서 제외
  - 선택(Enter·Tab·클릭): `[[` 뒤부터 커서까지를 제목으로 바꾸고, 커서 뒤가 `]]` 이면(F-127 이 넣은 짝) 그 뒤로 커서, 아니면 `]]` 를 붙이고 그 뒤로 커서
  - `|` 를 친 뒤(별칭 입력 중)에는 띄우지 않는다
  - Esc 로 닫기. 조합 중 동작은 CM6 기본 동작에 맡기고 **사람 확인 항목**
- 팝업 스타일 `wikilink.css`: 바탕 `--panel`, 테두리 `--rule`, 선택 항목 `--accent-soft`, 글자 14px `--font-sans`, 그림자는 기존 메뉴와 같게

## 4. 보기 모드

- `renderMarkdown(text, { resolveWikiLink })` — markdown-it 인라인 규칙
  - `resolveWikiLink(target)` 가 문서 id 를 돌려주면 `<a class="wikilink" href="#/d/{id}" data-wikilink="{대상}">{보이는 글자}</a>` (새 탭 속성 없음)
  - null 이면 `<a class="wikilink wikilink--missing" href="#" data-wikilink="{대상}">…</a>`
  - 옵션이 없으면(F-130 공유 화면) `<span class="wikilink wikilink--plain">{보이는 글자}</span>`
- `Viewer.jsx`: `a.wikilink` 클릭을 가로채 기본 이동을 막고 `onOpenWikiLink(target)` 호출 (있는 문서도 같은 흐름 — 저장 대기 입력을 먼저 저장하는 앱 전환 흐름을 타기 위해)

## 5. 앱 흐름 (`App.jsx`)

- `onOpenWikiLink(target)`
  - 문서가 있으면 사이드바에서 문서를 고른 것과 같은 흐름으로 연다 (대기 중 저장 → 전환 → 해시 `#/d/{id}` push). 보기 모드였으면 보기 모드 유지
  - 없으면 제목 `target` 으로 새 문서를 **현재 문서와 같은 폴더**에 만들고 연다(F-126 새 문서 규칙). 본문 빈 문서, 편집 모드로, 본문에 포커스
- 에디터·Viewer 에 제목 목록(`docs.map(d => d.title)`)을 넘긴다

## 6. 스타일 (`wikilink.css`, hex 금지)
- `.md-wikilink`, `.wikilink`: 색 `--md-link`, 밑줄 없음, 호버 시 밑줄, 커서 pointer
- `--missing`: 색 `--muted`, 점선 밑줄 1px
- `--plain`: 글자색 그대로
