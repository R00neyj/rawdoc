## 2. 요구사항

### 2.1 `decodeMarkdown(bytes: Uint8Array) → { text, lineEnding, mixed, hadBom }`
- 앞 3바이트가 `EF BB BF` 면 `hadBom: true` 로 두고 떼어 낸다
- `new TextDecoder('utf-8', { fatal: true, ignoreBOM: true })` 로 해독. 실패하면 `Error` (메시지 코드 `not-utf8`)
- `detectLineEnding` 으로 판정. `text` = `fromEditorText(toEditorText(원문), lineEnding)` — 섞이지 않은 파일은 원문과 같다

### 2.2 `importFiles(files, { store, onCreated, notify })`
- 파일마다 순서대로: `arrayBuffer()` → `decodeMarkdown` → `store.create({ title, content: text, lineEnding })`
- 제목 = 파일명에서 끝의 `.md`(대소문자 무시) 제거. 비면 `제목 없는 문서`
- 결과 알림 (N-1)
  - 성공 `info`: `"{파일명}" 을(를) 가져왔습니다.` + 섞였으면 ` 줄바꿈 형식이 섞여 있어 CRLF 로 통일했습니다.` + BOM 이면 ` 파일 맨 앞의 BOM 을 제거했습니다.`
  - UTF-8 아님 `error`: `"{파일명}" 을(를) 가져오지 못했습니다. UTF-8 텍스트 파일이 아닙니다.`
  - 읽기 실패 `error`: `"{파일명}" 을(를) 읽지 못했습니다.`
  - 여러 파일이면 마지막 파일의 결과를 표시하고, 실패가 하나라도 있으면 그 오류를 표시
- 마지막으로 만든 문서를 연다. 해시 **추가**
- 문서를 만들기 전에 현재 문서의 `beforeLeaveDoc()` 를 await

### 2.3 버튼
- 사이드바 `＋ 새 문서` 아래 `↥ 가져오기`, S-2 의 `가져오기` 버튼
- 숨긴 `<input type="file" accept=".md,text/markdown">` (단일 선택). 같은 파일을 연달아 고를 수 있게 선택 후 `value` 를 비운다

## 3. 원문 보존 예외
product.md 6장: 줄바꿈 형식이 섞인 파일, UTF-8 BOM 이 있는 파일은 내보낸 바이트가 원본과 다르다. 두 경우 모두 가져올 때 알린다
