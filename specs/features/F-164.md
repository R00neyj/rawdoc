## 2. 요구사항

### 2.1 표 줄무늬 제거
- 편집 모드 표 위젯, 보기 모드·공유 화면 표 모두 **모든 행 바탕이 같다**: 표 바깥 문서 칸 바탕과 같은 계산값 (세 테마)
- 머리 행 굵기·칸 테두리·안쪽 여백은 그대로

### 2.2 편집 칸 강조 제거
- 칸 하나를 편집할 때 파란 바탕·테두리 강조를 보이지 않는다. 입력 지점은 커서로만 보인다
- F-140 3.3 의 여백 규칙(편집 시작 전후 글자·칸 크기 불변, A11)은 그대로
- 강조 요소는 F-165 범위 선택 표시로 쓰므로 DOM·위치 계산은 남겨도 된다. 단일 칸 편집 중 계산 `opacity` 0 또는 `display: none`

### 2.3 글자 선택 색
- 새 토큰 `--selection-bg: color-mix(in srgb, var(--accent) 24%, transparent)` (값은 A4 대비 기준에 맞춰 구현에서 조정 가능, 조정하면 보고)
- 앱 전체 글자 선택에 적용한다: 편집·원문 모드 본문(CM6 는 `drawSelection` 을 쓰지 않아 브라우저 기본 선택을 쓴다 — `::selection`), 표 칸 하위 에디터, 보기 모드·공유 화면 본문, 상단바 제목 입력·대화상자 입력 등 `input`
- 선택된 글자 색은 바꾸지 않는다 (`color` 지정 없음)
- `.cm-selectionBackground` 규칙은 요소가 없어 효과가 없으니 지우거나 같은 토큰으로 맞춘다
