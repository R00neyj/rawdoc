## 2. 요구사항

### 2.1 `stats.js` (순수 함수, CM6 `EditorState`·문자열만 받음)
- `cursorInfo(state) → { line, col }` — 주 선택의 head. `line` 1부터. `col` = 줄 시작부터 head 까지의 **코드포인트 수 + 1**
- `countChars(text) → number` — 줄바꿈 문자(`\r` `\n`)를 뺀 코드포인트 수. 공백 포함
- `countWords(text) → number` — 공백류(`\s`)로 나눈 비어 있지 않은 덩어리 수

### 2.2 표시
- 형식: `줄 3, 열 12 · 1,204자 · 188단어` — 숫자는 `toLocaleString('ko-KR')`
- 오른쪽 끝에 저장 상태 자리(`StatusBar` 의 `saveStatus` prop). B2 에서는 비워 둔다
- 높이 `--statusbar-h`, `--font-mono` 10.5px, `--muted`, 위 1px `--rule`
- 커서 정보는 선택이 바뀔 때, 글자·단어 수는 문서가 바뀔 때 갱신. 글자·단어 수 계산은 마지막 변경 후 150ms 뒤 1회 (연속 입력 중 매 키마다 전체 문서를 세지 않는다)
- App state 에는 숫자만 둔다. 문서 문자열을 두지 않는다
- S-2 에서 숨김
