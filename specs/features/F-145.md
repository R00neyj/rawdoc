# F-145 `.md` 파일 끌어놓아 열기

작성일: 2026-09-14
상태: 사용자 수정사항 10번(2026-09-14). **F-143 완료 후** 시작 (`App.jsx`·`app.css` 가 겹친다). F-144 와는 부분 Edit 로 병렬 가능, 브라우저 확인은 한 번에 한 에이전트
근거: 사용자 요청 "화면에 마크다운 문서 드롭다운으로 바로 열수 있을까?" — 파일을 끌어다 놓아 여는 기능(드래그 앤 드롭)으로 해석. `specs/product.md` 4.5 의 "드래그 앤 드롭 가져오기" 제외를 이 명세로 푼다. 가져오기 흐름은 F-114·F-119 와 같다 (`src/app/importFiles.js`)

## 2. 요구사항

### 2.1 받는 곳
- 앱 창 **어디에 놓아도**(상단바·사이드바·편집 영역·빈 상태) 같은 동작
- 받지 않는 때: 대화상자(D-1·D-2·D-3)가 열려 있을 때, 공유 화면(S-4)일 때, 저장소를 쓸 수 없을 때. 이때는 놓아도 아무것도 하지 않는다(브라우저가 파일을 여는 기본 동작도 막는다)
- **외부 파일을 끌 때만** 반응한다 (`dataTransfer.types` 에 `Files`). 사이드바 안 문서·폴더 끌기(F-126), 에디터 안 글자 끌기는 지금 그대로
- 이미지 파일만 끌 때의 동작은 뒤에 오는 F-156 2.5 가 정한다 (이 명세 구현 때는 비 `.md` 파일로 처리)

### 2.2 가져오기
- 놓은 파일 중 `.md`(대소문자 무시)만 가져온다. 규칙·제목·줄바꿈·UTF-8 판정·알림 문구는 F-114 와 같다 (`importFiles` 재사용)
- 여러 개면 파일마다 새 문서, 마지막 파일을 연다 (F-119 3.14 와 같음)
- 만드는 위치: 현재 문서의 폴더 (F-114·F-126 규칙 그대로, 끊긴 폴더 id 는 최상위 — F-138 3.4)
- `.md` 가 아닌 파일이 섞이면 그것만 건너뛰고, 모두 `.md` 가 아니면 알림 `마크다운(.md) 파일만 가져올 수 있습니다.` (오류가 아닌 정보성)
- 폴더를 놓으면 폴더는 건너뛴다 (폴더 가져오기는 M1 범위 밖, 4.5)

### 2.3 편집 영역에 놓을 때
- CM6 는 파일을 놓으면 파일 글자를 본문에 넣는다. **`.md` 를 포함한 외부 파일 끌어놓기는 본문에 넣지 않고** 2.2 로 처리한다 (CM6 `domEventHandlers` 의 `drop`·`dragover` 에서 외부 파일이면 기본 처리를 막고 앱에 넘긴다)
- 에디터 안 글자 끌어 옮기기, 다른 앱에서 글자(`text/plain`) 끌어오기는 지금처럼 본문에 들어간다

### 2.4 덮개
- 외부 파일을 창 위로 끌고 들어오면 창 전체에 덮개: 바탕 `color-mix(in srgb, var(--panel) 85%, transparent)`, 가운데 점선 테두리 상자(2px dashed `--accent`, 모서리 `--radius-dialog`) 안에 `IconUpload`(F-143) 32px + 글자 `여기에 놓아 .md 파일 가져오기`
- 창 밖으로 나가거나(자식 요소 사이 이동으로 깜빡이지 않게 진입 횟수를 세거나 동등한 방법), 놓거나, Esc 면 덮개를 없앤다
- 2.1 의 받지 않는 때에는 덮개를 띄우지 않는다
- 덮개는 입력을 막는 용도만. 포커스를 가져가지 않는다. 움직임 줄이기면 전환 없음

## 3. 수용 기준

브라우저 확인은 5173 외 포트, `--strictPort`. 끝나면 서버 종료. 실제 OS 끌어놓기를 도구로 못 하면 `DataTransfer` 에 `File` 을 넣은 합성 `dragenter`·`dragover`·`drop` 이벤트로 확인하고 그렇게 보고

| --- | --- | --- | --- |
| A1 | 단위 테스트 | `npm test` | `fileDrop.js`: `Files` 없는 끌기 무시, `.md`/`.MD` 골라내기, 섞인 목록, 전부 비 `.md`. 기존 회귀 없음 |
| A2 | 한 파일 | 사이드바 위에 `a.md` 놓기 | 새 문서 `a`, 원문 바이트 동일, 열림, F-114 알림 |
