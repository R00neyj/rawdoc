## 2. 요구사항

### 2.1 고정폭 한글
> 2026-09-15 변경 (design.md D3): family `D2Coding`, `unicode-range`·`size-adjust` 없음, `--font-mono: 'D2Coding', 'Pretendard Variable', monospace`. 아래 JetBrains Mono 조합은 이전 기록. A4 기대는 "한글·영문 모두 D2Coding"
- `@kfonts/d2coding` 의 **Regular woff2 파일 하나만** 쓴다 (약 1.5MB). Bold 는 넣지 않는다(굵게는 브라우저 합성)
- 앱 CSS 에서 `@font-face` 를 직접 선언한다. 패키지 `index.css` 는 import 하지 않는다
  - family 이름 `D2Coding Hangul`, `unicode-range`: `U+1100-11FF, U+3130-318F, U+A960-A97F, U+AC00-D7AF, U+D7B0-D7FF`
  - `size-adjust` 로 **한글 1자 폭 = JetBrains Mono 영문 2자 폭**이 되게 맞춘다 (D5 검토 값 120%. 실측으로 확정하고 보고)
- `--font-mono: 'JetBrains Mono', 'D2Coding Hangul', 'Pretendard Variable', monospace`
- 폰트는 빌드에 포함하고 오프라인 precache 에 넣는다 (design.md 2.3). 빌드 precache 크기 변화를 보고
- 적용 범위는 `--font-mono` 를 쓰는 모든 곳 (원문 모드, 인라인코드, 코드블록, 프론트매터 원문, 상태바 등). 자간 0 규칙(F-141 3.6) 그대로

### 2.2 글자 크기 설정
- 설정 대화상자 항목 `글자 크기`: `작게` `보통` `크게` 3버튼 세그먼트 (`role="radiogroup"`, 다른 항목과 같은 방식)
- 항목 순서: `테마` / `제목 서체` / `본문 서체` / `글자 크기` / `들여쓰기` / `줄 번호`(F-147)
- `md.fontSize`: `small` / `medium`(기본) / `large` → `<html data-font-size>` → `--md-font-size` 14px / 16px / 18px. 모르는 값은 `medium`
- 적용: 편집·원문·보기 모드 본문과 공유 화면. 제목·표·코드·콜아웃은 지금처럼 `--md-font-size` 기준 비율(em)로 따라간다. 줄 번호도 본문과 같은 비율로 따라간다. 상단바·사이드바·상태바·대화상자 등 UI 글자는 바뀌지 않는다
- 바꾸면 즉시 반영, 새로고침 후 유지, 첫 화면 깜빡임 없음(테마와 같은 방식)
- 모바일 화면(M1 범위 밖)에서 여백·크기 조정은 이 명세에 넣지 않는다

### 2.3 들여쓰기 설정
- 지금: `indentUnit` 공백 2칸, `tabSize` 2 로 코드에 고정 (`createEditor.js`)
- 설정 대화상자 항목 `들여쓰기`: `2칸` `4칸` 2버튼 세그먼트. `md.indent`: `2` / `4`(**기본**). 모르는 값은 `4`
- 값 하나로 함께 바뀌는 것: CM6 `indentUnit`(공백 N칸) · `EditorState.tabSize` N, 보기 모드·공유 화면 코드블록 `tab-size` N
  - Tab / Shift+Tab 들여쓰기·내어쓰기, 목록 Enter 이어쓰기의 하위 들여쓰기가 이 값을 쓴다
- 바꾸면 열린 에디터에 즉시 반영(Compartment, 문서 다시 만들지 않음). **이미 쓴 문서 원문은 바꾸지 않는다**
- 표 칸 편집 중 Tab(칸 이동, F-125)은 그대로
