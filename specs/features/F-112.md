## 2. 요구사항

### 2.1 `toFileName(title) → string`
- `\ / : * ? " < > |` 와 제어문자(U+0000~U+001F, U+007F) → `_`
- 앞뒤 공백 제거, 끝의 `.` 과 공백 제거
- 결과가 비면 `제목 없는 문서`
- Windows 예약 이름(`CON` `PRN` `AUX` `NUL` `COM1`~`COM9` `LPT1`~`LPT9`, 대소문자 무시)과 같으면 뒤에 `_`
- 100 코드포인트 넘으면 자름
- 끝에 `.md`

### 2.2 내보내기
- 상단바 제목 입력 오른쪽 끝(보기 모드 세그먼트 뒤) `.md 내보내기` 버튼. S-2 에서 비활성
- 누르면 `handle.getText(doc.lineEnding)` 로 **에디터의 현재 원문**을 얻는다(대기 중 입력 포함). 저장소를 다시 읽지 않는다. 자동 저장 `flush()` 도 함께 호출하되 다운로드가 그것을 기다리지 않는다
- `new Blob([text], { type: 'text/markdown;charset=utf-8' })` → `URL.createObjectURL` → 임시 `<a download>` 클릭 → `revokeObjectURL`
- BOM 을 붙이지 않는다. 성공 알림 없음 (ia.md 3.8)
