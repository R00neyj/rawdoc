## 2. 조각 형식과 복사
- JSON 에 선택 키 `r`: 요청 토큰(43자 base64url). `v` 는 1 그대로 — 옛 앱은 `r` 을 버리고 지금처럼 연다
- `ShareDoc` 에 `requestToken?: string`. `encodeShare` 는 있을 때만 `r` 을 쓴다. `decodeShare` 는 `r` 이 `/^[A-Za-z0-9_-]{43}$/` 일 때만 `requestToken` 키를 붙이고, 아니면 키 없이(조용히 버린다 — 조작된 값으로 요청 화면이 뜨지 않게)
- `requestTokenDocId({ serverStore, doc })`: 서버 저장소이고, 문서가 내 것(`!isSharedDoc`)이고, 금고 아님(`doc.e2ee === undefined`)일 때만 문서 id, 아니면 `null`. 로컬 저장소 문서·받은 문서·금고 문서의 링크에는 토큰이 없다 → S-4 버튼도 없다
- `fetchRequestToken(docId)`: `POST /api/docs/{id}/request-token`, 200·201 → 토큰, 그 밖·네트워크·**3초** 넘김 → `null`. 성공한 값은 탭 메모리 `Map` 에 두어 같은 문서 두 번째 복사부터는 요청 0. `null` 은 두지 않는다
- `copyShareLink` 는 `requestToken` 이 있으면 먼저 부르고, `null` 이면 토큰 없이 지금처럼 복사한다 — 알림 문구·길이 판정은 그대로(토큰은 약 50자). 오프라인 복사가 계속 된다
- 주석을 떼는 순서(F-214)·`마크다운 복사` 는 바뀌지 않는다. `importSharedDoc` 도 그대로(토큰을 문서에 넣지 않는다)

## 3. S-4 버튼
- 그리는 조건: `account.state === 'in'` 이고 `sharedDoc.requestToken` 이 있을 때. 로그아웃·옛 링크·토큰 없는 링크는 지금 S-4 그대로
- `AccessRequestControl token={requestToken} docId={null} variant="text" openIn="hash"` — 상태 조회·D-23·오류 문구·다시 부르기는 F-2135 3·4장 그대로, 규칙은 F-4004 2장 표 그대로
- 글자 버튼(I13 — S-4 는 아이콘 + 글자): `권한 요청`(`IconPersonAdd`), 대기면 `권한 요청 보냄`, 원본을 열 수 있으면 `원본 문서 열기`(`IconOpenInNew`). 순서 `원본 문서 열기`·`권한 요청`·`내 문서로 가져오기`·`닫기`
- `원본 문서 열기` = `location.hash = formatHash(targetId)` — 지금 해시 흐름이 S-4 를 닫고 문서를 연다(목록에 없으면 다시 읽음)
- 알림은 앱 알림 띠(`showNotice`, info)
