## 2. 요구사항

### 2.1 뒤 막
- `.dialog::backdrop` 에 `backdrop-filter: blur(6px)`. 바탕 `rgba(0, 0, 0, 0.32)` 그대로
- 흐림도 막의 `opacity` 전환(F-172)으로 함께 나타나고 사라진다. 움직임 줄이기 설정이면 즉시

### 2.2 폭
- 내용 길이와 무관하게 폭이 고정된다. `box-sizing: border-box` 로 테두리·안쪽 여백 포함 폭
  - 기본(D-1 삭제 확인, D-2 설정, D-3 폴더로 이동): `width: min(420px, calc(100vw - 32px))`
  - 넓게(D-4 사람 초대, D-5 API 토큰): `width: min(520px, calc(100vw - 32px))`
- `min-width`·`max-width: min(90vw, 420px)` 는 지운다
- 내용이 폭보다 긴 줄(긴 이메일·토큰 원문·curl 예시)은 대화상자를 넓히지 않는다 — 각 요소가 이미 가진 말줄임·줄바꿈·가로 스크롤 규칙을 따른다. 넘치는 요소가 있으면 그 요소에 `min-width: 0`·`overflow-wrap: anywhere` 만 더한다
