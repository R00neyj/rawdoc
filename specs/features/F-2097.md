## 근거 (직접 읽거나 돌려 본 것, 2026-09-30 HEAD `3a4c1eb`)

- `src/app/userCssApply.ts` `appliedUserCss()` — 공유 시트 묶음의 `applied()`, 아직 안 만들어졌으면 `[]`. 원소는 `{ name, css }` 이고 `css` 는 `useUserCss` 의 `refresh()` 가 넣은 **`compileCached(원문).css`**(F-2094 검사 결과)다. 안전 모드·공개 보기면 `apply(null, …)` 로 `[]`(F-2095 5장·4장). 모듈 최상위에 DOM 접근 없음(`userCssSheets()` 가 처음 불릴 때 `document` 를 읽는다) → node 테스트에서 import 해도 된다
- `src/viewer/toHtmlDoc.ts` `buildHtmlDocument({ title, body, css })` — `css` 를 `escapeStyleClose` 한 번 거쳐 `<style>` 하나에 넣는다. `src/viewer/` 는 `src/app/` 을 import 하지 않는다(`grep "src/app\|'\.\./app"` 0건)
- `src/app/exportDoc.ts` `exportDocAsHtml` → `selectExportCss(body, EXPORT_CSS, MATH_EXPORT_CSS)` → `buildHtmlPayload({ title, body, css })`. `downloadBlob` 이 `document` 를 써서 `exportDocAsHtml` 자체는 node 단위 테스트가 없다(`tests/src/app/exportDoc.test.ts` 는 `buildHtmlPayload`·`selectExportCss` 만 본다)
- `src/app/exportActions.ts` `handleExportDocAsHtml` 이 유일한 호출부(`grep exportDocAsHtml src` — `App.tsx`·`AppTopBar.tsx`·`useCommandPalette.ts` 는 핸들러만 넘긴다). 공개 보기·공유 보기에 따로 HTML 내보내기·인쇄 경로 없음(`grep "window.print\|print()" src` → `printDoc.ts` 하나)
- **스니펫 이름에 `*/` 가 들어갈 수 있다** — `src/lib/userCssPolicy.ts` `checkSnippetName` 은 빈 값·60자 초과·앞뒤 공백·제어 문자만 막는다. 개요 5.4 의 `/* {이름} */` 를 그대로 쓰면 이름 `x */ a{background:url(http://e/x)} /*` 가 **검사를 거치지 않은 CSS 를 파일에 넣는다** — 불변식 "User CSS … only after the check" 위반. 3장 결정 2 로 막는다
- **컴파일 결과는 닫힌 텍스트다** (F-2094 2장 결정 6·4.6). 스크래치패드에서 `filterUserCss` 를 esbuild 로 묶어 돌림: `a{color:red` → `a{color:red}`, `a{color:red} /*` → `a{color:red} /**/`, `a{content:"abc` → `a{content:"abc"}`, `.b{` → `.b{}`, 맨 위 `rl(http://e.x/a.png)}` → `""`. 그래서 여러 스니펫을 한 `<style>` 에 이어도 앞 스니펫이 뒤 스니펫을 삼키지 않는다 — 개요 5.4 의 "한 `<style>` 에 잇기" 를 그대로 쓴다
- **인쇄 매체에서 adoptedStyleSheets 가 먹는다** — 설치된 Chrome 154.0.8037.58 + 저장소 Playwright: `document.adoptedStyleSheets` 에 `@media print { #x { color: rgb(1,2,3) } }` 시트를 붙이면 화면 `rgb(0, 0, 0)`, `emulateMedia({ media: 'print' })` 뒤 `rgb(1, 2, 3)`. `printDoc.ts` `printDoc` 은 같은 문서의 `[data-ui="print"]` 영역을 채워 `window.print()` 를 부르고 `data-theme`·`data-printing` 만 바꾼다 — 사용자 시트를 떼거나 붙이는 코드 없음

## 2. 정해진 것 (바꾸지 않는다)

1. 사용자 결정(개요 2.4): HTML 내보내기·인쇄에도 사용자 CSS 가 적용된다
2. 불변식 "User CSS never leaves its owner": 내보낸 파일은 주인이 만든 것이라 허용. 넣는 것은 **F-2094 검사를 거친 컴파일 결과뿐** — 원문(`md.userCss` 의 `css`)을 읽어 넣지 않는다
3. 무엇이 들어가나 = `appliedUserCss()` 그대로(개요 5.4·Q3). 켠 스니펫 목록 순서, 안전 모드·공개 보기면 0개
4. 서식 있는 복사에는 넣지 않는다(개요 2.4 — 인라인 `style=` 방식)

## 3. 결정

1. **조립은 `buildHtmlDocument` 안에서, `css` 뒤에 이어 `escapeStyleClose` 를 한 번에 거친다.** `<style>` 은 지금처럼 하나. 사용자 블록은 `css` 끝에 `userCssExportBlock(userCss)` 를 이어 붙인 것이다. `userCss` 가 없거나 빈 배열이면 `userCssExportBlock` 은 `''` 이고 **결과 바이트가 지금과 같다**(기존 테스트·파일 그대로)
2. **`userCssExportBlock` 모양:** 원소마다 `\n/* {이름} */\n{css}` 를 목록 순서대로 잇는다. 이름 안의 `*/` 는 모두 `*\/` 로 바꾼다 — CSS 주석은 첫 `*/` 에서만 끝나고 역슬래시는 주석 안에서 뜻이 없으므로 이름이 주석을 벗어날 수 없다. 그 밖의 글자는 그대로(`</style` 은 결정 1 의 `escapeStyleClose` 가 막는다). `css` 가 빈 문자열인 원소(검사가 통째로 버린 스니펫, F-2094 `unstable`)도 이름 주석은 남긴다 — 파일을 연 사람이 어느 스니펫이 빠졌는지 알 수 있다
3. **적용 중 목록은 누를 때 읽는다.** `handleExportDocAsHtml` 이 `exportDocAsHtml` 을 부르는 그 자리에서 `appliedUserCss()` 를 불러 `userCss` 로 넘긴다. `createExportActions` 가 만들어질 때 읽지 않는다(다른 탭 변경·조합 뒤 적용이 반영돼야 한다). `exportDoc.ts`·`toHtmlDoc.ts` 는 `userCssApply` 를 import 하지 않는다 — 순수 부분을 전역 없이 시험하게
4. **`.md`·`.txt` 내보내기, 서식 있는 복사, 전체·폴더·볼트 내보내기에는 `userCss` 를 넘기지 않는다**

## 4. 인쇄 — 코드 변경 없음 (확인 결과)

- `printDoc` 은 같은 문서에서 `window.print()` 를 부르므로 F-2095 가 `document.adoptedStyleSheets` 맨 뒤에 붙인 시트가 인쇄 매체에도 그대로 먹는다(근거의 Chrome 실측). 안전 모드면 시트가 없으니 인쇄에도 없다
- 개요 5.5 가 적은 유일한 코드 변경 `data-ui="print"` 는 F-2093 이 이미 넣었다(`App.tsx` 의 `.viewer.print-root` 요소, `userCssContract.ts` 훅 목록 `print`). `data-printing` 은 `userCssContract.ts` `STATE_ATTRS` 에 이미 공개돼 있다
- 인쇄 중 사용자 시트가 바뀌는 경우(다른 탭 변경): `window.print()` 가 대화상자 동안 스크립트를 멈추므로 새 일이 없다. 대화상자가 닫힌 뒤 적용된다
- 그래서 인쇄 쪽 수용 기준은 사람 확인(6장)만 둔다

## 6. 사람 확인 (메인이 `specs/human-checks.md` 에)

- `:root:root { --paper: … }`·`.markdown-body h1 { … }` 스니펫을 켜고 HTML 로 내보내 브라우저로 열면 그 모양이고, 네트워크 없이 열린다
- 같은 스니펫으로 `PDF로 저장`(인쇄) 미리보기에 반영된다. `@page { margin: 5mm }` 스니펫이 `print.css` 의 A4·20mm 를 이긴다(개요 5.5)
- `/?safe` 로 연 창에서 내보낸 HTML·인쇄에는 사용자 CSS 가 없다
- 이름에 `*/` 를 넣은 스니펫으로 내보내 파일을 열어도 뒤 스니펫과 문서 모양이 깨지지 않는다
