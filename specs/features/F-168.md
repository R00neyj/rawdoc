## 2. 대상 줄
- 선택이 걸친 모든 줄. 여러 줄 선택의 끝이 줄 맨 앞(열 0)이면 그 마지막 줄은 뺀다
- 건너뛰는 줄: 펜스 코드블록 안(`FencedCode`), 프론트매터(`Frontmatter`), 표(`Table`) 줄. 대상 줄이 모두 건너뛰는 줄이면 `false`
- 줄 구조를 이렇게 나눠 읽는다: `인용 기호`(`>` 와 뒤 공백 0~1개의 반복) + `들여쓰기`(공백·탭) + `줄 앞 기호` + `나머지 글자`
  - `줄 앞 기호` 는 하나만: 제목 `#{1,6}` + 공백 / 체크박스 `[-*+]` + 공백 + `[ ]`·`[x]`·`[X]` + 공백 / 글머리 `[-*+]` + 공백 / 숫자 `\d{1,9}[.)]` + 공백
- 명령은 `인용 기호` 를 유지하고(인용 명령 제외) `줄 앞 기호` 만 바꾼다. 콜아웃 안 줄도 같다

## 3. 명령

| 메뉴 | 명령 | 동작 | 이미 모든 대상 줄이 그 종류면 |
| --- | --- | --- | --- |
| 글머리 목록 | `setBulletList` | 빈 줄은 건너뛰고 `- ` | 본문으로 (기호 제거) |
| 숫자 목록 | `setOrderedList` | 빈 줄은 건너뛰고 `1. ` `2. ` … (대상 줄 순서대로 1부터) | 본문으로 |
| 체크박스 | `setTaskList` | 빈 줄은 건너뛰고 `- [ ] ` (이미 `[x]` 인 줄도 체크 상태 유지 없이 `[ ]`) | 본문으로 |
| 제목 1~6 | `setHeading(n)` | 빈 줄은 건너뛰고 `#`×n + 공백. 들여쓰기는 지운다 | 같은 n 이면 본문으로 |
| 본문 | `setParagraph` | `줄 앞 기호` 를 지운다. 목록·제목이던 줄은 들여쓰기도 지운다 | — |
| 인용 | `toggleQuote` | 모든 대상 줄(빈 줄 포함) 맨 앞에 `> ` (빈 줄은 `>`) | 대상 줄 중 빈 줄이 아닌 줄이 모두 `>` 로 시작하면 한 단계(`>` + 공백 0~1개) 제거 |

- 목록 명령은 기존 `들여쓰기` 를 유지한다 (중첩 목록 보존). 제목·본문으로 바꿀 때만 지운다 (4칸 이상 들여쓰기는 코드 블록이 되기 때문, CommonMark 4.4)
- 체크박스에서 `[x]` 상태를 버리는 것은 메뉴가 "체크박스로 만들기" 이기 때문이다. 이미 체크박스인 줄만 있으면 본문으로
- 커서·선택은 각 줄의 `나머지 글자` 안 같은 글자를 가리키게 옮긴다. 기호 안에 있던 커서는 `나머지 글자` 맨 앞으로
- 트랜잭션 1개 = 실행 취소 1단계
