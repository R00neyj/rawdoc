## 2. 요구사항

### 2.1 상단바 아이콘 버튼
- 상단바 아이콘 버튼(사이드바 토글·검색·보기 모드 3개·공유·내보내기)을 **테두리 없는 한 가지 모양**으로: 32×32px, 모서리 6px, 아이콘 `--ink-2`, 호버 바탕 `--rule-2` + 아이콘 `--ink`, 비활성 `--muted`
- 보기 모드 묶음: 바깥 테두리·버튼 사이 구분선 없음. 버튼 사이 2px
- **선택된 버튼**(`aria-pressed="true"`): 바탕 `color-mix(in srgb, var(--ink) 10%, transparent)`, 아이콘 `--ink`. 지금의 검은 칠(`--ink` 바탕 + `--panel` 아이콘)은 쓰지 않는다
- 공유 버튼이 메뉴를 연 동안(`aria-expanded="true"`)은 선택 버튼과 같은 바탕

### 2.2 설정 대화상자 세그먼트
- 선택된 버튼(`aria-checked="true"`) 모양을 2.1 선택 표시와 같게: 바탕 `--ink` 10%, 글자 `--ink` 600. 묶음 바깥 테두리와 버튼 사이 구분선은 유지(글자 버튼이라 경계가 필요)

### 2.3 사이드바 현재 문서 행
- 현재 문서 행(트리·고정됨 공통): 흰 바탕 + 안쪽 테두리 → **바탕 `color-mix(in srgb, var(--ink) 7%, transparent)`, 테두리 없음**. 글자 `--ink` 600 유지. 현재 행에 호버해도 같은 바탕
- **글자 시작선 맞춤**: 최상위 문서·폴더 행의 이름 글자 시작 x = 사이드바 동작 버튼(`새 문서` 등) 글자 시작 x (±1px). 지금 6px 어긋남(행 48px, 버튼 42px). 폴더 가이드 선(F-142 3.5)은 토글 아이콘 가로 가운데를 계속 지난다
- 하위 행 들여쓰기 14px 단위는 그대로

### 2.4 세피아 대비 올리기
- 세피아의 `--ink`·`--ink-2`·`--muted`·`--rule` 을 **같은 색 계열에서 더 어둡게** (지금 대비: `--ink` panel 11.88 / paper 11.05, `--ink-2` 7.62 / 7.09, `--muted` 4.16 / 3.87, `--rule` panel 1.31)
- 목표 (`--panel`·`--paper` 둘 다): `--ink` ≥ 14:1, `--ink-2` ≥ 9:1, `--muted` ≥ 4.5:1, `--rule` 은 `--panel` 대비 ≥ 1.4:1. `--paper`·`--panel` 바탕색은 바꾸지 않는다
- `tokens.test.js` 에 세피아 전용 기준으로 추가해 미달이면 실패. 바꾼 hex 와 대비 값 보고
- 세피아 콜아웃 색은 화이트 값 그대로(F-141 3.1). 콜아웃 색 대비 4.5 기준도 계속 통과해야 한다

### 2.5 제목 서체
- 편집 모드와 보기 모드(공유 화면 포함)의 `#`~`######` 제목 모두 `--font-display`. 설정 `제목 서체` 산세리프면 모두 산세리프
- 크기·굵기·`######` 색은 지금 그대로
- 원문 모드는 고정폭 그대로
