## 2. 현재 문제 (추정)
- 모든 전환이 `--transition-fast: 180ms var(--ease-spring)` 이고 `--ease-spring` 은 `cubic-bezier(0.51, 0.08, 0.5, 1.23)` — 출력이 1 을 넘는 구간이 있어 바탕색이 목표보다 한 번 더 진해졌다가 돌아온다. 사용자에게 "두 번 겹쳐 들어가는" 느낌으로 보인 원인으로 추정 (화면 측정 없음)

## 3. 요구사항
- 새 토큰 `--ease-out: cubic-bezier(0, 0, 0.2, 1)` (끝으로 갈수록 느려지는 곡선, 1 을 넘지 않음)
- `--transition-fast: 180ms var(--ease-out)` — 색·바탕·테두리·그림자·투명도·툴팁(F-149)과 F-172 의 `opacity`·`visibility` 가 모두 이 토큰을 쓰므로 한 번에 바뀐다
- 새 토큰 `--transition-move: 180ms var(--ease-spring)` — 크기·위치(`transform`) 전환만 쓴다 (F-172 메뉴 위로 4px·대화상자 0.98 크기·겹침 사이드바 밀려 들어옴)
- 표 칸 범위 강조 위치 이동(`preview.css` `--ease-spring` 100ms)은 그대로
- 움직임 줄이기 설정의 0ms 는 두 토큰 모두
