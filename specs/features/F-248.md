# F-248 코드블록 언어 이름을 정식 표기로

작성일: 2026-09-18
상태: 사용자 승인 (2026-09-18 "코드블럭 ```js 라고 적으면 Javascript 이런식으로 명칭 제대로 나왔으면함")
근거: `specs/features/F-240.md` 3.2(코드블록 머리줄 — 언어 + 복사 버튼), `F-210.md`(보기 모드 코드 복사)

## 1. 범위

### 문제
F-240 이 만든 코드블록 머리줄은 정보 문자열의 첫 단어를 **그대로** 보여준다. `js`·`ts`·`py` 처럼 줄여 쓰는 게 보통이라 머리줄에 `js` 라고만 뜬다. 옵시디언·GitHub 은 `JavaScript` 로 보여준다.

### 한다
- 흔한 별칭을 정식 표기로 바꿔 보여준다 — 표시만 바꾸고 **원문은 그대로**다(CLAUDE.md 불변조건)
- 편집 모드 머리줄과 보기 모드·공개 링크 코드블록 모두 같게 보인다
- 표에 없는 언어는 지금처럼 원문 그대로 보여준다(임의로 대문자화하지 않는다)
- 표는 한 곳(`src/lib/codeLang.ts`)에만 둔다 — 편집·보기 양쪽이 같은 표를 쓴다

### 별칭 표 (최소 집합)

| 원문 | 표시 |
| --- | --- |
| `js`, `jsx`, `javascript` | JavaScript |
| `ts`, `tsx`, `typescript` | TypeScript |
| `py`, `python` | Python |
| `sh`, `bash`, `zsh`, `shell` | Shell |
| `ps1`, `powershell` | PowerShell |
| `html` | HTML |
| `css` | CSS |
| `json` | JSON |
| `yml`, `yaml` | YAML |
| `md`, `markdown` | Markdown |
| `sql` | SQL |
| `java` | Java |
| `kt`, `kotlin` | Kotlin |
| `c` | C |
| `cpp`, `c++` | C++ |
| `cs`, `csharp` | C# |
| `go`, `golang` | Go |
| `rs`, `rust` | Rust |
| `rb`, `ruby` | Ruby |
| `php` | PHP |
| `swift` | Swift |
| `toml` | TOML |
| `xml` | XML |
| `diff` | Diff |
| `dockerfile` | Dockerfile |

- 대소문자는 구분하지 않는다(`JS`·`Js` 모두 JavaScript)
- `jsx`·`tsx` 를 따로 두지 않고 각각 JavaScript·TypeScript 로 묶는다 — 머리줄은 언어 종류만 알리는 자리다(F-240 3.2)

### 하지 않는다
- 문법 강조(하이라이팅) 추가 — 이 명세는 머리줄 글자만 바꾼다
- 표에 없는 언어를 추측해 바꾸기(`foo` → `Foo` 같은 자동 대문자화)
- 정보 문자열의 둘째 단어 이후(`js title="a.js"`) 처리 방식 변경 — F-240 대로 첫 단어만 본다
- 언어 없는 코드블록에 기본 이름 붙이기 — 지금처럼 비워 둔다

## 3. 요구사항

### 3.1 `codeLang.ts`
- `displayLang(info: string): string` — 정보 문자열을 받아 표시 이름을 돌려준다. 첫 단어만 보고, 소문자로 맞춰 표에서 찾고, 없으면 첫 단어를 그대로 돌려준다. 빈 문자열이면 빈 문자열
- 표는 상수 객체 하나. 별칭이 여러 개인 언어는 별칭마다 항목을 둔다

### 3.2 적용
- 편집 모드: `blocks.ts` 의 머리줄 언어 글자를 `displayLang()` 결과로 바꾼다. `data-*` 속성이나 원문 문자열은 건드리지 않는다
- 보기 모드: `renderMarkdown.ts` 가 만드는 코드블록 언어 표시에 같은 함수를 쓴다
- **원문 불변**: 표시만 바뀌고 문서 내용·`.md` 내보내기 결과는 그대로다
