# F-253 빈 줄로 끊긴 목록에서 Enter 가 빈 줄을 또 넣는 문제

작성일: 2026-09-18
상태: 사용자 승인 (2026-09-18). 방향 선택 "빈 줄 안 넣기"
근거: `specs/features/F-245.md` 6장(빈 목록 항목 Enter), `F-251`(중첩 목록 들여쓰기)

F-245 6.5 **A15 를 이 명세로 뒤집는다**. A15 는 "이미 loose 인 목록에서 Enter 가 빈 줄을 유지한다" 였고, 그것이 사용자가 계속 겪은 "두 번 줄넘김" 의 남은 절반이다

## 1. 범위

### 문제

목록 항목 사이에 빈 줄이 하나라도 있으면(마크다운의 loose 목록) 그 뒤 Enter 마다 빈 줄이 따라 붙는다. 2026-09-18 단위 재현(실제 앱과 같은 GFM 설정에서 `insertNewlineContinueList` 직접 호출, 커서는 문서 끝):

| 입력 | Enter 결과 | 판정 |
| --- | --- | --- |
| `- 하나\n- 둘` | `- 하나\n- 둘\n- ` | 맞음 |
| `- 하나\n\n- 둘` | `- 하나\n\n- 둘\n\n- ` | **틀림** |
| `- [x] 완료\n\n- 테스트` | `- [x] 완료\n\n- 테스트\n\n- ` | **틀림** |
| `- [x] 완료\n- 테스트` | `- [x] 완료\n- 테스트\n- ` | 맞음 |
| `#### 제목\n\n- 하나\n\n#### 제목2\n\n- 둘` | `…- 둘\n- ` | 맞음(헤딩이 목록을 끊는다) |

**체크박스는 무관하다.** 사용자가 `- [ ]` 를 의심한 이유는, 그 자리에서 목록을 끝내려고 Enter 를 두 번 쳐 빈 줄을 만든 뒤 다시 `- ` 로 새 목록을 시작했기 때문이다. 파서에게 그것은 새 목록이 아니라 앞 목록이 loose 로 이어진 것이라, 이후 모든 Enter 가 항목 사이 빈 줄을 재현한다

### 한다
- Enter 목록 이어쓰기는 loose·tight 와 무관하게 **바로 다음 줄에 기호만** 넣는다. 빈 줄을 새로 만들지 않는다
- 이미 문서에 있는 빈 줄은 건드리지 않는다 — 원문 그대로 둔다
- F-245 6.5 A15(단위·e2e)를 새 기준으로 고친다

### 하지 않는다
- 목록을 tight 로 다시 쓰기·빈 줄 정리 같은 원문 변경
- `insertNewlineContinueMarkup` 대체 — loose 빈 줄 삽입 **그 한 분기만** 끈다 (F-245 6.3 과 같은 방침)
- 빈 목록 항목에서 목록 끝내기(F-245 6.3) 동작 변경
- 인용문(`>`)·중첩 목록의 기호·들여쓰기 규칙 변경

## 3. 요구사항

### 3.1 근거 — 어디서 빈 줄이 들어가는가

`@codemirror/lang-markdown` 6.5.2 `dist/index.js` 275~276행:

```js
if (nonTightList(inner.node, state.doc))
    insert = blankLine(context, state, line) + state.lineBreak + insert;
```

`insertNewlineContinueMarkupCommand` 의 설정은 `nonTightLists` 하나뿐이고, 그것은 **빈 항목에서 목록을 loose 로 바꾸는** 다른 분기(227행)를 끈다 — 이미 `listEnter.ts` 가 쓰고 있다. 위 275행에는 설정이 없다

### 3.2 고치기

`insertNewlineContinueList` 가 만든 트랜잭션에서 위 접두사(`blankLine(...) + lineBreak`)만 걷어낸다. 명령을 감싸 dispatch 를 가로채고, 삽입 문자열 앞의 `공백·> 로만 된 줄 + 줄바꿈` 하나를 제거한 뒤 내보내는 식이다. 제거 대상이 없으면 그대로 통과시킨다

- 선택 범위(`changes` 의 `from`·`to`)와 커서 위치 계산은 명령이 내놓은 것을 따른다 — 접두사를 뗀 만큼만 어긋나지 않게 맞춘다
- 여러 커서(multi-range)에서도 각 변경에 같은 규칙을 적용한다
- 명령이 `false` 를 돌려주면(마크다운 문맥이 아님) 그대로 `false`
