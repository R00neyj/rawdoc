## 2-1. 순수 함수 `resolveInitialDoc`

```js
resolveInitialDoc({ hashDocId, lastDocId, docs }) → { docId: string|null, notFound: boolean }
```
- `docs` 는 updatedAt 내림차순
- 순서: `hashDocId` 가 docs 에 있으면 그것 → 해시가 없을 때 `lastDocId` 가 있으면 그것 → docs[0] → 없으면 null
- `notFound` 는 `hashDocId` 가 주어졌는데 docs 에 없을 때만 true
- 테스트: 네 갈래와 notFound 조합

## 3. 요구사항

### 3.1 부팅·최초 실행 (ia.md 3.1·3.2·4.4)
1. 레이아웃 뼈대만 그리고 목록·편집 영역을 비워 둔다. 로딩 표시 없음
2. `store.list()`
3. 목록이 비었고 `md.firstRunDone` 이 없으면 안내 문서를 `lineEnding: 'crlf'` 로 생성하고 `md.firstRunDone=1` 기록. 이때 에디터에 포커스를 주지 않는다
4. `resolveInitialDoc` 로 문서 결정 → 해시는 **교체**. `notFound` 면 N-1 info `문서를 찾을 수 없습니다.`
5. 문서 0개면 S-2, 해시 `#/` 교체
6. 연 문서 id 를 `md.lastDocId` 에 기록 (문서를 열 때마다)

### 3.2 새 문서 (ia.md 3.3)
- 사이드바 `＋ 새 문서` 와 S-2 의 `새 문서` 버튼
- 제목 `제목 없는 문서`, 내용 `''`, `lineEnding: 'crlf'` 로 생성 → 열기 → 해시 **추가**
- 상단바 제목 입력에 포커스 + 전체 선택
- 제목 입력에서 Enter → `onRequestEditorFocus` 콜백 호출 (B1 에서는 아무 일도 하지 않는 함수. F-103 이 연결)

### 3.3 전환 (ia.md 3.4)
- 목록 항목 클릭 → 열기 → 해시 **추가**. 현재 항목은 `aria-current="page"`
- 전환 전에 대기 중 저장을 끝내는 훅 자리: `App` 에 `async beforeLeaveDoc()` 를 두고 전환·삭제·해시 변경 경로에서 반드시 `await` 한다. B1 에서는 즉시 끝나는 함수 (F-110 이 채움)
- 뒤로·앞으로·주소창 수정(`hashchange`)도 같은 열기 경로. 없는 문서면 3.1 의 4번처럼 대체 문서를 열고 N-1, 해시 **교체**

### 3.4 제목 변경 (ia.md 3.5)
- 입력하는 동안 `store.update(id, { title })` 를 호출하고 목록 state 를 갱신한다 (updatedAt 이 바뀌므로 현재 문서가 맨 위로 — I6)
- 포커스를 잃을 때 공백만 남았으면 `제목 없는 문서` 로 되돌린다
- 연속 입력 시 저장 호출 순서가 뒤집혀 옛 제목이 남지 않게 한다 (마지막 값이 이긴다)

### 3.5 삭제 (ia.md 3.6)
- 항목 `×`: 마우스 오버 또는 항목·버튼 키보드 포커스 시 표시. `aria-label="{제목} 삭제"`
- D-1: 본문 `"{제목}" 을(를) 삭제할까요? 되돌릴 수 없습니다.`, 버튼 `삭제`(danger) `취소`. 기본 포커스 `취소`. Esc = 취소
- 삭제 후 현재 문서였으면 목록 첫 문서를 열고 해시 **교체**. 남은 문서가 없으면 S-2, `#/` 교체
- 현재 문서가 아니면 현재 문서 유지

### 3.6 빈 상태 S-2 (ia.md 4.3)
- 상단바 제목 입력 비활성
- 편집 영역 자리: `문서가 없습니다.`(`--font-display`) + `새 문서` 버튼. (`가져오기` 버튼은 F-114 가 추가)

### 3.7 안내 문서 (`guideDoc.js`)
제목 `사용법`. 본문은 아래 원문 그대로 (줄은 `\n` 으로 두고, 생성 시 `lineEnding: 'crlf'` 로 저장소에 넘길 때 `\r\n` 으로 잇는다 — 잇기는 F-110 의 `lib/lineEnding.js` 가 생기기 전까지 `split('\n').join('\r\n')` 로 한다)

````markdown

이 편집기는 마크다운 원문을 그대로 저장합니다. `.md 내보내기`로 받은 파일은 입력한 글자와 같습니다.

- **원문**: 모든 기호를 그대로 보여 줍니다
- 상단바 오른쪽에서 바꿀 수 있습니다

## 자주 쓰는 문법

| 입력 | 결과 |
| --- | --- |
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |

## 단축키

- `Ctrl+B` 굵게, `Ctrl+I` 기울임, `Ctrl+K` 링크
- `Esc` 다음 `Tab`: 편집 영역에서 빠져나가기

## 저장

- 브라우저 데이터를 지우면 문서도 지워집니다. 중요한 문서는 `.md 내보내기`로 백업하십시오
````
