## 3. 수정 항목

### 3.1 칸 값 이스케이프 왕복 (high) — F-138 3.1 로 대체됨
- 현재: 칸 편집기가 원문 `a\|b` 를 그대로 받고, 입력마다 `escapeCell` 이 `|` 를 다시 `\|` 로 바꾼다. `a\|b` 끝에 `c` → `a\\|bc` 로 저장되어 칸이 나뉜다. 공백 패딩 없는 표(`|a|b|`)에서 칸 끝에 `\` 를 치면 뒤 파이프가 이스케이프되어 칸이 합쳐진다
- 수정
  - `unescapeCell(raw) → value`: 칸 편집기에 넣을 값. 원문의 파이프 이스케이프(`parseTable` 이 칸 구분이 아니라고 판정하는 `\|`)를 `|` 로
  - `escapeCell(value) → raw`: `|` → `\|`. 값 끝의 연속 `\` 개수가 홀수면 `\` 하나를 더 붙여 뒤 파이프가 이스케이프되지 않게 한다
  - 칸 편집기는 `unescapeCell` 값으로 시작하고, 주 문서에는 `escapeCell` 결과를 넣는다
- 테스트
  - `parseTable` 로 읽은 모든 칸 원문에 대해 `escapeCell(unescapeCell(raw)) === raw` (예: `a\|b`, `a\\`, `\|`, 빈 칸, 한글)
  - `a\|b` 편집기 값이 `a|b`, 끝에 `c` 입력 후 원문 `a\|bc`, 열 수 그대로
  - `|a|b|` 첫 칸 값 `a\` 입력 후 `parseTable` 열 수 2 그대로
  - 편집 후 `parseTable` 결과의 열 수·행 수가 편집 전과 같음

### 3.2 칸 범위를 편집 세션이 직접 보관 (high)
- 현재: 조합 중에는 표 위젯 재계산이 보류되어 옛 `TableWidget` 이 남는데, 칸 입력(`pushCellEdit`)이 그 옛 `cell.from/to` 범위에 칸 전체 값을 넣는다. 조합 중 글자 수가 바뀌면 원문이 깨진다 (예: `abc` 에 병음 `zho` → `abczhoh`)
- 수정: 편집 세션(현재 편집 중인 칸 정보)이 칸의 원문 범위 `{from, to}` 를 직접 가진다. **모든 주 문서 트랜잭션**(칸 자신의 입력, 실행 취소 제외 다른 변경)마다 `tr.changes` 로 범위를 옮기고(`mapPos`, from 은 `-1`·to 는 `1` 쪽), 칸 입력은 이 범위를 바꾼 뒤 `to = from + 새 원문 길이` 로 갱신한다. 위젯 인스턴스의 칸 위치는 편집 중인 칸의 쓰기에 쓰지 않는다
- 테스트: 가능하면 세션 범위 갱신을 순수 함수로 떼어 "같은 칸에 길이가 다른 값을 연속 3번 쓰기 → 최종 원문이 마지막 값만 반영" 확인. 브라우저에서 합성 조합 이벤트(`compositionstart` → 값 교체 여러 번 → `compositionend`)로 원문 확인

### 3.3 다른 표 위젯 파괴가 편집을 끝내지 않음 (medium)
- 현재: 위젯 `destroy(dom)` 이 어떤 표인지 확인하지 않고 `endEdit(view)` 를 부른다. 표 B 편집 중 표 A 가 화면 밖으로 나가면 B 편집이 끝난다
- 수정: 편집 세션의 표 DOM 이 `dom` 과 같을 때만 편집을 끝낸다

### 3.4 조합 중 편집 종료 시 따라잡기 (medium)
- 현재: 조합 중 다른 칸을 클릭하면 `mousedown` 이 곧바로 `endEdit` 으로 편집기를 없애고, 이후 `compositionend` 가 와도 활성 칸이 바뀌어 재계산(`forceRecalc`)이 나가지 않는다
- 수정: 편집 세션이 "조합 때문에 보류한 재계산이 있음" 을 기록하고, **편집이 어떤 경로로 끝나든**(클릭, 포커스 이탈, Esc, 위젯 파괴) 보류가 있으면 끝낼 때 `forceRecalc` 를 보낸다. 편집기를 없애기 전에 조합 중이면 편집기의 현재 값을 먼저 주 문서에 반영한다

### 3.5 문서 맨 앞·맨 끝 표에서 나가기 (low)
- 현재: 첫 줄 표 머리 행에서 ↑ 는 커서를 0, 마지막 줄 표에서 ↓·Enter·Esc 는 `blockTo` 로 보낸다. 둘 다 위젯이 가린 범위 경계라 이어서 친 글자가 표 원문에 들어간다
- 수정
  - 표 앞에 줄이 없을 때 머리 행 ↑: 아무것도 안 함 (편집 유지)
  - 표 뒤에 줄이 없을 때 마지막 행 ↓·Enter, 그리고 Esc: 문서 끝에 줄바꿈 1개(문서의 줄바꿈 형식)를 넣고 그 새 줄 시작으로 커서. 트랜잭션 1개, `userEvent: 'input.table'`
  - 표 뒤에 줄이 있으면 F-125 2.3 그대로
