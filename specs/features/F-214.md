# F-214 공유 화면에서 주석 숨기기

작성일: 2026-09-15
상태: 사용자 요청(2026-09-15 "주석 처리한건 공유시 안보이도록 해야함"). F-212 앱 커밋 뒤

## 2. 요구사항

### 2.1 주석 문법
- Obsidian 주석: `%%` 로 열고 다음 `%%` 로 닫는다. 한 줄 안이든 여러 줄에 걸치든 같다
- HTML 주석: `<!--` 로 열고 다음 `-->` 로 닫는다
- 닫는 기호가 없으면 주석이 아니다 (글자 그대로 둔다)
- 펜스 코드블록(```` ``` ````·`~~~`) 안과 인라인코드(백틱) 안은 주석으로 보지 않는다
- 제거한 범위는 그 안의 줄바꿈만 남긴다 (줄 수 유지). CRLF 도 그대로 남긴다

### 2.2 적용 범위 — 원문을 받는 사람이 로그인한 소유자가 아닌 곳만
- 읽기 전용 링크 `GET /pub/docs/:token`, `GET /pub/folders/:token/docs/:docId` 응답 `content` (서버에서 제거 → 공개 보기의 본문·목차·`.md 내보내기` 모두 주석 없음)
- F-130 공유 링크(`#/s/…` 주소에 원문을 담는 방식): 링크 만들 때 제거해 주소에 주석이 담기지 않는다. 공유받은 화면 렌더도 제거
- 바꾸지 않는 곳: 소유자 편집·원문·보기 모드(F-167 그대로 글자로 보임), `마크다운 복사`, 소유자 `.md 내보내기`, DB 원문, 초대받은 사람(F-212) 화면
