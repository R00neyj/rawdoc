## 2. 요구사항

### 2.1 `wrangler.jsonc`
```jsonc
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "md-editor-web",
  "main": "worker/index.ts",
  "compatibility_date": "2026-09-14",
  "assets": {
    "directory": "./dist",
    "binding": "ASSETS",
    "not_found_handling": "single-page-application",
    "run_worker_first": ["/api/*"]
  },
  "d1_databases": [
    { "binding": "DB", "database_name": "md-editor-db", "database_id": "073462f8-7a95-4b0f-8d32-4b07f8c4448e", "migrations_dir": "migrations" }
  ],
  "r2_buckets": [
    { "binding": "BUCKET", "bucket_name": "md-editor-attachments" }
  ]
}
```
- `compatibility_date` 는 F-120 값 유지. `name` 에 제품명 쓰지 않음
- `/api/*` 가 아닌 요청은 Worker 를 거치지 않고 정적 자산(없는 경로는 `index.html`)

### 2.2 `worker/index.ts`
- `export default { fetch(request, env, ctx) }` (`ExportedHandler<Env>`)
- 라우트
  - `GET /api/health` → `200 {"ok":true,"db":true}` — `env.DB.prepare('SELECT 1').first()` 성공 여부로 `db`. 실패면 `503 {"ok":false,"db":false}`
  - 그 밖 `/api/*` → `404 {"error":"not_found"}`
  - 허용되지 않는 메서드 → `405 {"error":"method_not_allowed"}`
- 모든 API 응답: `Content-Type: application/json; charset=utf-8`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff` (`_headers` 는 Worker 응답에 적용된다는 보장이 없어 코드에서 넣는다)
- 처리 중 예외 → `500 {"error":"internal"}`. 오류 내용·스택을 응답에 넣지 않는다 (`console.error` 는 허용)
- 라우터는 라이브러리 없이 경로·메서드 비교. F-205 이후 라우트를 붙이기 쉽게 `{ method, path, handler }` 표 하나로 둔다

### 2.3 서비스 워커
- workbox 에 `navigateFallbackDenylist: [/^\/api\//]` — 주소창에서 `/api/...` 를 열 때 앱 화면으로 바뀌지 않게
- precache 대상(`globPatterns`)은 그대로. API 는 런타임 캐시하지 않는다

### 2.4 타입
- `npx wrangler types worker/worker-configuration.d.ts` 로 `Env` 생성 (`DB: D1Database`, `BUCKET: R2Bucket`, `ASSETS: Fetcher`)
- `worker/tsconfig.json`: `strict`, `noEmit`, `target`/`lib` `ES2022`, `module` `ESNext`, `moduleResolution` `bundler`, `types` 없이 `include: ["./**/*.ts"]` (생성된 d.ts 포함). DOM lib 넣지 않음
- 명시적 `any` 금지

### 2.5 스크립트
- `"cf:types": "wrangler types worker/worker-configuration.d.ts"`
- `"typecheck:worker": "tsc -p worker --noEmit"`
- `"dev:worker": "npm run build && wrangler dev --port 8790"` (5173·4317·45xx 와 겹치지 않게)
- 기존 `deploy` 는 그대로 (`npm run build && wrangler deploy`)
