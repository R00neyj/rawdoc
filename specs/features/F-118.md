## 2. 요구사항
- 부팅 후 저장소가 `idb` 일 때: `navigator.storage?.persisted()` 가 false 면 `navigator.storage.persist()` 요청. API 가 없으면 아무것도 하지 않는다
- 결과가 false 이고 `md.persistNoticeShown` 이 없으면 N-1 `warn` 1회: `브라우저가 저장 공간 보호를 허락하지 않았습니다. 저장 공간이 부족해지면 문서가 지워질 수 있으니 중요한 문서는 .md 내보내기로 백업하십시오.` 표시 후 `md.persistNoticeShown=1`
- 허락되지 않았으면 다음 실행 때 다시 요청한다(알림은 다시 띄우지 않음). `appinstalled` 이벤트 때도 한 번 더 요청한다
- `warn`: `×` 로만 닫힘(자동으로 사라지지 않음). `error`·`update` 는 `warn` 을 대체하고, `info` 는 대체하지 못한다
