## 2. 명령

명령은 `({ state, dispatch }) => boolean` 형태의 CM6 StateCommand 로 만든다. 그래야 DOM 없이 테스트할 수 있다. 여러 선택 영역은 `state.changeByRange` 로 각각 처리한다. 명령 1회 = 실행 취소 1단계

| 키 | 명령 | 선택 있음 | 선택 없음 |
| --- | --- | --- | --- |
| `Mod-b` | `toggleStrong` | 선택 양옆이 `**` 면 제거, 아니면 `**선택**` 으로 감싸고 선택은 안쪽 글자 유지 | `****` 삽입, 커서는 가운데 |
| `Mod-i` | `toggleEmphasis` | 양옆이 `*` 이고 그 바깥이 `*` 가 아니면(`**` 의 일부가 아니면) 제거, 아니면 `*선택*` | `**` 삽입, 커서 가운데 |
| `Mod-k` | `insertLink` | `[선택]()` 로 바꾸고 커서는 `(` 와 `)` 사이 | `[]()` 삽입, 커서는 `[` 와 `]` 사이 |

- 서식 적용이 아니라 텍스트 삽입이다 (`specs/product.md` F-109)
- IME 조합 중(`view.composing`)이면 명령을 실행하지 않고 `false` 를 돌려준다. keymap 래퍼에서 판단한다
- `Mod-k` 는 브라우저 기본 동작(Chrome 주소창 검색)보다 에디터가 먼저 받는다. CM6 keymap 이 처리하면 `preventDefault` 된다
