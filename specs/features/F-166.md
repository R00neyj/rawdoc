## 2. 현재 문제 (측정 확인)
- 목록 줄은 `padding-left: var(--md-list-indent)` + `text-indent: calc(-1 * var(--md-list-indent))` 로 내어쓰기한다 (F-152 2.3, `preview.css` 67~70줄)
- **원인 1**: `text-indent` 는 상속된다. `.md-bullet`·`.md-list-marker` 는 `display: inline-block` 이라 상자 안에서 음수 `text-indent` 가 다시 적용되어, 상자는 제자리인데 기호 글자만 왼쪽으로 밀린다. 커서 없는 `-` 줄에서 점 글자 x = 내용 칸 왼쪽 − 36px(거터 위). `1.` 줄은 `coordsAtPos(lineFrom)` 이 밀린 글자 위치를 돌려줘 잴 때마다 값이 32 → 64 → 96px 로 커지고, 긴 줄에서 둘째 화면 줄 x ≠ 첫 줄 글자 시작 x (A5 위반)
- **원인 2**: 앱이 줄 요소에 inline style 로 `--md-list-indent` 를 쓰면 CM6 의 DOM 관찰이 그 줄 속성을 더럽혀진 것으로 표시하고, 다음 동기화 때 decoration 에 없는 `style` 을 지운다 (`@codemirror/view` 6.43.11, 코드 기준 추정). 선택·문서 변경, 효과만 있는 update 때 값이 지워지고, `listIndentPreview.update` 는 효과만 있는 update 에서 재측정하지 않아 지워진 상태가 다음 입력까지 남는다
- 두 원인이 겹쳐 기호가 거터 쪽(−36px)과 제자리(0) 사이를 오간다. 거터 숫자 위치는 변하지 않는다

## 3. 요구사항
- 기호 상자(`.md-bullet`, `.md-list-marker`, 체크박스 위젯 등 목록 줄 안 `inline-block` 요소) 안에서는 `text-indent: 0`. 내어쓰기는 줄 단위로만 적용된다
- 측정값 쓰기가 CM6 에 의해 지워지지 않게 한다. 방법 중 하나를 고르고 보고
  - (가) `write` 의 `setProperty`/`removeProperty` 를 `view.observer.ignore(() => …)` 로 감싼다 — 재현 에이전트가 페이지 안 모의 적용으로 흔들림 0회·A5 오차 0px 측정
  - (나) 측정값을 StateEffect 로 넘기고 `Decoration.line({ attributes: { style: '--md-list-indent: …px' } })` 로 붙인다 — 측정 안 됨
  - (가)로 A1~A3 이 통과하지 않으면 (나)로 바꾼다
- 측정 결과가 이전과 같으면 쓰지 않는다 (불필요한 DOM 변경 방지)
- decoration 은 문서 내용을 바꾸지 않는다 (CLAUDE.md 불변조건). 조합 중 보류 규칙(`composition.js`)을 깨지 않는다
