## 2. 요구사항

### 2.1 `scripts/measure.mjs`
앱을 열어 문서를 넣고, 선택자별 위치·크기·계산 스타일을 JSON 으로 출력한다

```
node scripts/measure.mjs --doc long:200 --mode live --theme sepia --size 1600x900 \
  --select ".cm-line.md-h1" --select ".cm-lineNumbers .cm-gutterElement" \
  --style padding-top,line-height --action "press:Control+End" --shot out.png
```

| 옵션 | 뜻 | 기본 |
| --- | --- | --- |
| `--doc` | `.md` 파일 경로 또는 2.4 fixture 이름(`long:200`, `headings:30`, `mixed`, `list`) | `mixed` |
| `--mode` | `live` / `raw` / `view` (`md.viewMode` 를 열기 전에 심는다) | `live` |
| `--theme` | `white` / `sepia` / `dark` | `white` |
| `--pref k=v` | 그 밖의 localStorage 설정. 여러 번 | 없음 |
| `--size` | 창 크기 `WxH` | `1600x900` |
| `--select` | CSS 선택자. 여러 번. 선택자마다 요소 최대 50개 | 없음 |
| `--style` | 읽을 계산 스타일 이름 목록 | 없음 |
| `--action` | 측정 전 동작. 여러 번, 순서대로: `click:선택자`, `press:키`, `type:글자`, `hover:선택자`, `scroll:선택자:px`, `wait:ms` | 없음 |
| `--eval` | 측정 뒤 `page.evaluate` 로 돌릴 JS 식. 결과를 JSON 으로 | 없음 |
| `--shot` | 스크린샷 경로 (scratchpad 권장) | 없음 |
| `--port` / `--dist` / `--build` | 2.5 서버 옵션 | `4400` / `dist-measure` / 폴더 없을 때만 빌드 |

- 출력(stdout, JSON 한 덩어리): `{ url, size, selectors: { [선택자]: [{ i, text(앞 40자), rect:{x,y,width,height}, style:{…} }] }, eval, errors: [콘솔 오류] }`
- 문서 넣기·앱 열기는 `e2e/helpers.js` 의 `openApp`·`importMarkdown` 을 import 해서 쓴다 (같은 방식으로 판정되게)
- 전환이 있는 요소는 동작 뒤 전환이 끝날 때까지 기다린다 (`waitTransitionEnd` 재사용 또는 동등)
- 실패하면 exit 1 과 오류 한 줄

### 2.2 `scripts/verify.mjs`
```
node scripts/verify.mjs          # lint → 단위 → build
node scripts/verify.mjs --e2e    # + e2e 전체 (2.5 옵션 전달)
node scripts/verify.mjs --e2e --repeat 2
```
- 단계마다 실행하고 **마지막에 요약만** 출력: `lint 통과`, `단위 604/604 통과`, `build 통과`, `e2e 1회차 67/67 · 2회차 66/67 (실패: 이름…)`
- 실패한 단계는 그 단계 출력 끝 40줄을 요약 아래에 붙인다. 성공 단계 출력은 버린다
- 앞 단계가 실패해도 다음 단계를 계속 돌리되, 종료 코드는 하나라도 실패면 1
- `--e2e` 는 빌드를 한 번만 하고 반복 회차는 빌드를 재사용한다

### 2.3 `scripts/e2e-one.mjs`
```
node scripts/e2e-one.mjs "F-152 A8" --repeat 5
node scripts/e2e-one.mjs e2e/outline.spec.js --no-build
```
- 첫 인자가 `.spec.js` 경로면 파일, 아니면 테스트 이름 검색어(`-g`)
- `--repeat N` → `--repeat-each N`. 출력은 `통과 N / 실패 M` + 실패 테스트 이름·첫 오류 메시지
- 빌드 폴더가 있고 `src/` 보다 새로우면 빌드를 건너뛴다. `--build` 로 강제, `--no-build` 로 금지

### 2.4 `e2e/fixtures/docs.js`
순수 함수, 문자열을 돌려준다
- `longDoc(lines)`: `줄 {i}` 문단
- `headingsDoc(n)`: `#`~`###` 제목과 문단이 번갈아 n 개
- `listDoc()`: 긴 목록 항목(접히는 줄), `1.`, `- [ ]`, 중첩 1단
- `mixedDoc()`: 프론트매터, `#`~`######`, 문단 안 굵게·기울임·인라인코드·링크·위키링크, 인용, 콜아웃, 목록, 체크박스, 코드블록, 표, 구분선
- 기존 spec 파일은 이번에 고치지 않는다. 새 테스트부터 쓴다

### 2.5 서버와 병렬 실행
- `scripts/lib/server.mjs`: `ensureServer({ port, dist, build })`
  - `port` 가 5173 이면 거부
  - `dist` 폴더가 없거나 `build` 면 `vite build --outDir {dist}`
  - 그 포트에서 이미 응답하면 **재사용하지 않고 오류** (다른 에이전트 서버일 수 있다)
  - `vite preview --port {port} --strictPort --outDir {dist}` 를 자식 프로세스로 띄우고 응답할 때까지 대기(최대 30초)
  - 돌려주는 `stop()` 은 **자기가 띄운 자식 프로세스만** 종료한다. 포트 번호·프로세스 이름으로 남의 프로세스를 끄지 않는다. 스크립트가 오류·Ctrl+C 로 끝나도 `stop()`
- B: `playwright.config.js` 는 `E2E_PORT`(기본 4317), `E2E_DIST`(기본 `dist`), `E2E_SKIP_BUILD=1` 이면 빌드 없이 preview 만. `verify.mjs`·`e2e-one.mjs` 는 이 환경변수로 넘긴다
- 병렬 에이전트는 서로 다른 `E2E_PORT`·`E2E_DIST` 를 받는다. `.gitignore` 에 `dist-*`

### 2.6 `scripts/review-diff.mjs` (B, 2026-09-14 사용자 "파이프라인화")
메인이 구현 결과마다 손으로 하던 검토를 자동으로 한다

```
node scripts/review-diff.mjs F-159            # 작업 트리(추적 변경 + 새 파일) 기준
node scripts/review-diff.mjs F-159 --base HEAD~1
```
- **파일 소유**: `specs/features/F-xxx.md` 1장 표 첫 칸의 백틱 경로를 모은다. `(+test)` 는 같은 이름 `.test.js` 도, `A 또는 B` 는 둘 다 허용, `e2e/*.spec.js` 이름은 그대로. 변경 파일 중 목록 밖은 **경고**(메인이 판단). `.claude/settings.json` 은 무시
- 추가된 줄만 검사해 **위반**:
  - 여러 줄 주석: 연속 2줄 이상 `//` 주석, 여러 줄에 걸친 `/* */`, `/**` JSDoc 블록 (`.js` `.jsx` `.mjs` `.css`)
  - 색 hex(`#rgb`·`#rrggbb`·`#rrggbbaa`): `src/styles/tokens.css`·`brand.config.js`·테스트 파일 밖
  - `brand.config.js` 의 제품명 문자열이 `src/`·`index.html`·`public/` 에
  - `spike/` import, `console.log`(`scripts/**` 는 CLI 출력이라 제외), `debugger`, `window.__` 전역, `test.only`, 새로 넣은 `test.fail(`·`test.skip(`
- 출력: 경고·위반을 `파일:줄 종류 내용(앞 80자)` 로. 끝에 `위반 N · 경고 M`. 위반이 있으면 exit 1

- A 가 더한 옵션을 정식으로 둔다: `verify.mjs`·`e2e-one.mjs` 의 `--port`·`--dist`, 세 스크립트의 `--dry-run`(실행할 명령만 출력). B 에서는 이 옵션이 `E2E_PORT`·`E2E_DIST` 로 playwright 에 넘어가야 한다
