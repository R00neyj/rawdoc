작성일: 2026-09-13
상태: **초안 — 사람 승인 전.** D1~D3·D5~D9 결정됨 (2026-09-13~14). D4 메인 컬러는 미정이라 변수로 둔다 (3.2)
2026-09-21 갱신: 4장 아이콘 줄의 "공유 화면" 범위를 S-4 로 못박고, 공개 보기(S-5) 머리 줄이 앱 상단바와 같다는 것을 적었다 (`specs/ia.md` I14, F-293)
2026-09-21 갱신: 4장 대화상자 폭의 D-2 를 520px 쪽으로 옮겼다 (F-290 Q1 승인)
2026-09-22 갱신: 4장 선택 상태 줄의 `.seg` 테두리 규칙을 배타적 세그먼트 일반 규칙으로 넓히고, 아이콘 줄에 지도 머리 줄(S-8)이 아이콘+글자 목록에 안 든다는 것을 못박았다 (F-2011)

## 1. 레퍼런스에서 가져올 것

사용자 지정 레퍼런스 (2026-09-13)

| 레퍼런스 | 사용자가 좋다고 한 점 | 가져올 것 | 가져오지 않을 것 |
| --- | --- | --- | --- |
| Claude | 서정적인 분위기, 제목에 가끔 쓰는 세리프체 | 따뜻한 종이색 바탕, **읽는 글의 큰 제목에만** 세리프 | Claude 의 브랜드 색·서체 값 그대로 쓰기 |
| Vercel | 깔끔함 | 거의 무채색 구조, 1px 경계선, 넓은 여백, 강조색 최소화 | — |
| Apple | 디자인 완성도 | 원칙만: 절제된 위계, 정렬, 짧고 부드러운 전환 | SF Pro 서체 (2.3) |

### 조정 원칙

세 레퍼런스는 방향이 조금씩 다르다. 아래 순서로 합친다

1. **구조는 Vercel** — 면 구분은 색 대신 1px 선, 색은 회색 계열 위주
2. **온도는 Claude** — 순백·청회색 대신 살짝 따뜻한 바탕과 잉크색
3. **강조색은 1개** — 마크다운 기호 색. 이 제품의 정체성이다 (`docs/prototype.html` 22행 주석 "마크다운 기호 = 이 제품의 주인공")
4. **세리프는 드물게** — 자주 쓰면 Claude 분위기가 아니라 신문처럼 보인다

## 2. 서체

### 2.1 역할

| 역할 | 서체 계열 | 쓰는 곳 |
| --- | --- | --- |
| UI | 산세리프 | 버튼, 목록, 상단바 제목 입력, 상태바, 알림 |
| 본문 | 산세리프 (UI 와 같은 서체, D1). 사용자가 세리프로 바꿀 수 있다 (D8) | 라이브 프리뷰의 문단·목록·인용·표·콜아웃 본문, 보기 모드 본문 |
| 제목 강조 | 세리프 — Noto Serif KR (D2). 사용자가 산세리프로 바꿀 수 있다 (D6) | 편집·보기 모드 `#`~`######` 제목 (2026-09-14 `#` `##` 에서 넓힘, F-153), 빈 상태 문구, 상단바 제품명 |
| 원문·코드 | 고정폭 — D2Coding (영문·한글 모두, D3·D5, 2026-09-15) | 원문 모드 전체, 인라인코드, 코드블록, 기호 문자 |

세리프를 쓰지 않는 곳: 버튼·입력 등 조작 요소, 원문 모드

| 역할 | 후보 | 라이선스 | 한글 | 비고 |
| --- | --- | --- | --- | --- |
| UI·본문 | **Pretendard** | OFL-1.1 | O | Inter + 본고딕(Source Han Sans) 기반. 프로토타입이 쓰는 서체 |
| UI·본문 | Geist | OFL-1.1 | **X (실측 0자)** | Vercel 서체. 한글은 다른 서체로 대체돼 섞여 보인다. 한글 UI 기본 서체로는 제외 |
| 세리프 | Noto Serif KR | OFL-1.1 | O | 본명조(Source Han Serif) 계열. 굵기 폭이 넓다 |
| 세리프 | 마루부리 | OFL | O | 네이버. 부드러운 인상. 네이버 CDN 웹폰트 제공 |
| 고정폭 | JetBrains Mono | OFL-1.1 | **X (실측 0자)** | 프로토타입이 쓰는 서체. 한글은 다음 순위 서체로 대체된다 |
| 고정폭 | D2Coding | OFL | O | 네이버. **한글 1자 = 영문 정확히 2자 폭** (실측: 영문 500 / 한글 1000, 1em = 1000) |

### 2.3 서체 관련 제약

- **SF Pro 는 쓸 수 없다.** 라이선스가 Apple 플랫폼용 UI 목업 제작으로 용도를 한정하고, 소프트웨어에 포함하는 것을 금지한다 (https://developer.apple.com/fonts/ 라이선스 2A·2B)
- **원문 모드의 표 정렬.** 한글이 없는 고정폭 서체를 쓰면 한글은 다른 비례폭 서체로 대체돼 폭이 어긋난다. 그러면 원문 모드에서 `|` 로 맞춘 표 열이 틀어진다. D2Coding 은 이 문제가 없다
- 한글 웹폰트는 용량이 크다. 사용하는 글자만 내려받는 분할 방식(unicode-range 서브셋)을 쓴다
- **폰트는 앱 빌드에 포함한다. 외부 CDN·Google Fonts 에서 불러오지 않는다.** 오프라인 동작(`specs/product.md` F-116)을 위해 서비스 워커가 캐시해야 한다. 분할 파일이 많으면 미리 캐시할 범위를 F-116 작은 명세에서 정한다
- 한글 포함 여부는 2026-09-13 서체 파일의 cmap(글자 → 글리프 대응표)으로 실측했다. 한글 완성형 11,172자 기준 — Pretendard·D2Coding·마루부리(Regular·Bold) 전부 포함, Geist·Geist Mono·JetBrains Mono 0자. Noto Serif KR 은 파일을 실측하지 않았다

### 2.4 결정된 서체 (2026-09-14)

비교 화면에서 사용자가 선택. 산세리프(UI·본문, 산세리프 제목)는 Pretendard 로 확정 (D7)

| 역할 | 서체 | 한글 |
| --- | --- | --- |
| UI·본문 | Pretendard Variable | 포함 (실측) |
| 제목 강조 | Noto Serif KR Bold | 포함으로 알려져 있으나 파일 실측 전. F-102 에서 실측 |
| 고정폭 | D2Coding Regular (2026-09-15 JetBrains Mono 에서 변경, D3) | 포함 (실측) |

```css
--font-sans:  "Pretendard Variable", system-ui, sans-serif;
--font-serif: "Noto Serif KR", serif;
--font-mono:  "D2Coding", "Pretendard Variable", monospace;

/* 제목 강조 자리는 --font-serif 가 아니라 이 토큰을 참조한다 (D6) */
--font-display: var(--font-serif);
:root[data-heading-font="sans"] { --font-display: var(--font-sans); }
```

- 제목 강조 자리(2.1 표)는 반드시 `--font-display` 로 참조한다. `--font-serif` 를 직접 쓰면 토글이 먹지 않는다
- **자간**: 한국어 서체(Pretendard·Noto Serif KR — `--font-sans`·`--font-serif`·`--font-body`·`--font-display`)로 그리는 글자는 `letter-spacing: -0.02em`. 고정폭(`--font-mono`: 원문 모드, 코드, 프론트매터 등)은 열 정렬을 위해 `0`. 요소마다 자기 글자 크기 기준으로 계산되어야 한다 (2026-09-14 사용자 요청, F-141 3.6)
- **줄바꿈**: 앱 전체 `word-break: keep-all` — 한글 낱말 중간에서 줄을 바꾸지 않고 띄어쓰기에서 바꾼다. 한 줄보다 긴 낱말(주소 등)은 넘치지 않게 끊는다(UI `overflow-wrap: break-word`, 편집기는 CM6 기본 `anywhere`). 편집기(CM6 줄바꿈)·보기 모드·공유 화면·UI 모두 (2026-09-15 사용자 요청, F-216)
- 본문 자리(2.1 표)는 `--font-body` 로 참조한다. 기본 `var(--font-sans)`, `:root[data-body-font="serif"]` 이면 `var(--font-serif)` (D8). 세리프 본문용으로 Noto Serif KR 400 을 함께 포함한다 (F-141)
- 산세리프 선택 시 산세리프 제목은 굵기로 위계를 유지한다 (Pretendard 700). 크기는 세리프와 같게 둔다
- 산세리프를 선택해도 Noto Serif KR 은 오프라인 대비로 precache 에 남긴다

- 세 서체 모두 앱에 포함해 자체 호스팅한다 (2.3). Noto Serif KR 은 Google Fonts 링크를 쓰지 않는다
- **고정폭 D2Coding 전용 (2026-09-15):** 영문 0.5em·한글 1em 이라 크기 보정 없이 표 열이 맞는다. 이전 JetBrains Mono + D2Coding 한글 120% 조합은 한글이 커 보여 사용자가 바꿈 (D3·D5). `@fontsource/jetbrains-mono` 제거

## 3. 색

### 3.1 토큰 초안

`docs/prototype.html` 14~26행 토큰을 출발점으로, 1장 원칙에 따라 바탕·잉크를 따뜻한 쪽으로 옮긴 값이다. 메인 컬러를 뺀 나머지는 F-102 에서 대비 검산 후 확정한다

| 토큰 | 용도 | 프로토타입 값 | 초안 값 |
| --- | --- | --- | --- |
| `--paper` | 앱 바탕 | `#FBFBFA` | `#FAF8F4` |
| `--panel` | 편집 영역·상단바 면 | `#FFFFFF` | `#FFFEFB` |
| `--ink` | 본문 글자 | `#16171A` | `#1C1B18` |
| `--ink-2` | 보조 글자 | `#40434D` | `#4A4740` |
| `--muted` | 흐린 글자, 줄 번호 | `#8B8F9A` | `#8F8B82` |
| `--rule` | 경계선 | `#E6E5E1` | `#E8E4DB` |
| `--rule-2` | 약한 경계선, 호버 면 | `#F0EFEC` | `#F2EFE8` |
| `--accent` | **메인 컬러.** 마크다운 기호, 포커스 링, 체크박스 | `#D6337E` (`--syntax`) | **미정 — 3.2 브랜드 설정에서 주입.** 임시값 `#3B4890` (2026-09-14 변경) |
| `--link` | 링크 | `#2952CC` | `#2952CC` |
| `--danger` | 저장 실패, 삭제 버튼 | 없음 | `#C2410C` |

- M4 에서 쓸 `--people`(협업 색)은 M1 에 넣지 않는다
- 이 표의 초안 값이 화이트 테마다. 세피아·다크는 3.4 (2026-09-14 M1 에 넣음). 색은 **반드시 토큰으로만** 참조한다
- 초안 값의 대비(명도 차이)는 F-102 작은 명세에서 WCAG AA(본문 4.5:1) 기준으로 검산한다. 지금은 검산하지 않았다

### 3.2 브랜드 설정 — 제품명·메인 컬러

제품명은 `rawdoc`(표기 `Rawdoc`)으로 확정(2026-09-17). 메인 컬러는 미정이다 (`specs/product.md` Q14). 확정 후에도 **언제든 한 곳만 고쳐서 바꿀 수 있어야 한다**

| 항목 | 값 | 반영되는 곳 |
| --- | --- | --- |
| 제품명 (확정) | `Rawdoc` | 상단바 제품명, `<title>`, 매니페스트 `name`, 안내 문서 본문 |
| 짧은 이름 (확정) | `Rawdoc` | 매니페스트 `short_name` (설치된 앱 아이콘 아래 이름) |
| 메인 컬러 (임시값) | `#3B4890` (2026-09-14 `#D6337E` 에서 변경) | CSS `--accent`, 매니페스트 `theme_color`, `<meta name="theme-color">` |

규칙

- 정의 위치는 **루트 `brand.config.ts` 한 파일**이다. 앱 코드, CSS 변수 주입, `vite.config.ts`(매니페스트·HTML)가 모두 여기서 읽는다
- 코드·CSS·HTML·UI 문구에 제품명 문자열이나 메인 컬러 hex 를 직접 쓰지 않는다
- 메인 컬러에서 파생되는 색(현재 줄 배경, 선택 영역, 호버)은 `color-mix()` 로 `--accent` 에서 계산한다. 파생 색을 따로 hex 로 적지 않는다
- 글자 선택 영역: 토큰 `--selection-bg` = `color-mix(in srgb, var(--accent) 24%, transparent)`. 편집·원문·보기 모드, 표 칸, 입력란 등 앱 전체 `::selection` 에 쓴다. 선택된 글자 색은 바꾸지 않는다 (2026-09-14 사용자 요청, F-164. 값은 대비 기준으로 조정 가능)
- **이름을 바꿔도 사용자 데이터가 남아야 한다.** IndexedDB DB 이름, localStorage 키, 서비스 워커 캐시 이름에는 제품명을 쓰지 않고 고정 식별자를 쓴다
- 메인 컬러의 `--panel`·`--paper` 바탕 대비를 단위 테스트에서 계산해 출력한다 (F-101 러너). **메인 컬러 확정 전까지는 4.5:1 미달이어도 테스트를 실패시키지 않고 경고만 낸다.** 확정하면 실패 조건으로 바꾼다 (2026-09-14 사용자 결정: 임시값 조정 없이 변수로 둔다)
- 이전 임시값 `#D6337E` 는 WCAG 상대 휘도 공식으로 `--panel` 대비 4.49:1, `--paper` 대비 4.27:1 이었다. 현재 임시값 `#3B4890` 은 `--panel` 대비 8.28:1, `--paper` 대비 7.87:1 로 경고가 나오지 않는다 (2026-09-14 `src/lib/contrast.js` 로 계산)
- `#3B4890` 과 `--link`(`#2952CC`)가 둘 다 파란 계열이라 링크와 마크다운 기호 색이 비슷해 보일 수 있다. 메인 컬러 확정 때 함께 본다
- 앱 아이콘(192·512px, maskable)은 이미지라 변수를 따라 바뀌지 않는다. M1 임시 아이콘은 제품명 글자가 없는 도형으로 만들고, 이름·색이 확정되면 다시 만든다

### 3.3 1차 수정으로 추가한 토큰 (2026-09-14)

| 토큰 | 값 | 명세 |
| --- | --- | --- |
| `--gutter-gap` | `20px` (줄 번호 오른쪽 끝~본문 첫 글자) | F-122 |
| `--md-*` (본문 크기·줄 간격·테두리·코드 바탕 등) | 기존 토큰에 대응. GitHub 마크다운 스타일 수치 | F-124 2장 |
| `--callout-*` 8종 | note `var(--link)`, tip `#0B7285`, success `#177A33`, question `#855A00`, warning `#A84400`, danger `#C4212C`, example `#7644D0`, quote `var(--ink-2)`. 전부 `--panel` 대비 4.5:1 이상 | F-128 3장 |
| `--map-group-1`~`-8` | 위 `--callout-*` 8색의 **별칭**이다. 새 hex 가 아니다. 지도 그룹 색이 쓰고, 저장값은 hex 가 아니라 인덱스 `1`~`8` 이라 테마를 바꾸면 그룹 색도 따라 바뀐다 | F-292 개정판 6.5 |

- 마크다운 요소의 크기·여백은 GitHub 스타일(`github-markdown-css` 5.9.0)을 따르고, 색은 위 토큰, 서체는 2.4 그대로다 (`specs/product.md` Q18)

- **`tokens.css` 의 `color-mix()` 는 반드시 `in srgb` 로 쓴다.** 지도(F-292 개정판)가 프로브 요소의 계산된 `color` 를 파싱해 three 에 넘기는데, `in oklab`·`in oklch` 로 쓰면 Chrome 계산값이 `oklab(…)`/`oklch(…)` 문자열이 되고 `src/lib/cssColor.ts` 가 거절해 지도 색이 통째로 중간 회색으로 떨어진다 (2026-09-21 F-2002 5.1 실측). 현재 9건 전부 `in srgb` 인 것은 확인했다

### 3.4 테마 (2026-09-14, D9)

- 화이트(3.1 값) / 세피아 / 다크 3종. `<html data-theme>` 속성 하나로 토큰 값만 바꾼다
- 기본은 시스템 설정 따라가기(라이트 → 화이트, 다크 → 다크). 설정 대화상자에서 고정할 수 있다 (`specs/ia.md` 3.15)
- 세피아·다크 토큰 초안 값과 대비 기준은 `specs/features/F-141.md` 3.1. 대비 검사는 테스트가 실패 조건으로 한다 (메인 컬러만 경고)
- 세피아는 글자 대비를 더 올린다: `--ink` ≥ 14:1, `--ink-2` ≥ 9:1, `--muted` ≥ 4.5:1 (2026-09-14 사용자 "검정색 더 적극적으로", F-153 2.4)
- 메인 컬러는 브랜드 설정 값 하나다. 다크에서는 어두운 바탕 대비를 위해 `color-mix(in srgb, 브랜드색 55%, white)` 로 밝혀 쓴다 (3.2 파생 규칙과 같은 방식)
