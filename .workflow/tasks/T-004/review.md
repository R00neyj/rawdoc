## 계획에서 확인된 핵심 사실

계획 단계의 실측이 **기존 코드의 버그 하나를 잡아냈다.** 이것이 이 검토의 가장 큰 소득이다.

브라우저에서 문서에 펜스 코드블록을 넣어 보니:

| 문서 | 화면 |
| --- | --- |
| ` ```js ` | `js` |
| `const a = 1` | `const a = 1` |
| ` ``` ` | (빈 줄) |

`inline.js` 의 `MARKER` 에 있는 `CodeMark` 를 **인라인 코드의 백틱과 펜스 울타리가 공유한다.**
울타리가 화면에서 지워지는데 `InlineCode` 가 아니라 `.md-code` 스타일은 안 붙는다.
결과적으로 코드블록이 일반 문단과 구분되지 않는다.
T-003 의 SEED 에 코드블록이 없어 검증에서 드러나지 않았다.

두 번째 사실 — `markdown()` 의 `base` 기본값이 `commonmarkLanguage` 라
**지금 코드로는 GFM 표가 아예 파싱되지 않는다.** `| 이름 | 값 |` 이 원문 그대로 표시됐다.
`markdownLanguage` 로 바꾸지 않으면 이 task 자체가 성립하지 않는다.
