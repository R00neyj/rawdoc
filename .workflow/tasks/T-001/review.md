## 지적 사항

1. **R6 (경미) — A4 명령의 실패 모드가 두 가지다.** `grep` 은 매치가 없으면 종료 코드 1,
   대상 파일이 없으면 종료 코드 2 를 낸다. 실제로 지금 이 명령을 돌려보니
   `spike/src: No such file or directory` 가 났다 — 아직 파일이 없기 때문이다.
   수용 기준을 "출력 0줄" 로 적었으므로 판정 자체는 성립하지만, **"파일이 없어서 조용한 것"과
   "위반이 없어서 조용한 것"을 구분해야 한다.** verify 단계에서 A4 를 볼 때
   `spike/src/` 가 실제로 존재하는지 먼저 확인할 것. build 단계에서 처리 가능한 수준이라
   plan.md 재수정 사유로는 보지 않는다.

2. **미결 사항 — git 저장소 초기화.** plan.md 7장이 "review 단계에서 사람이 판단한다" 로
   넘겨둔 항목이다. 현재 이 프로젝트는 git 저장소가 아니라 롤백이 전부 수동 파일 조작이다.
   T-001 은 백업 복사로 대응하지만, B-002 이후로 갈수록 이 방식은 감당이 안 된다.
   `backlog.yaml` 에 별도 항목으로 올릴지 지금 판정과 함께 결정할 것.
